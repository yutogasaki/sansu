## 完了結果

9件各1回、Meshy 7 standard / PBR / 2K / GLB。開始790→終了520、実消費270。各タスクの消費と残高差を照合済み。寸法・面数・容量は [計測一覧](metrics.md)。

Blender 5.2.1 LTSで高さ調整、底面中央原点、変換焼込み、UV/法線/PBR保持。案内板のみ180度回転。rawとfinalの画像hash、再インポート寸法・三角形と描画差分を検査。1K版は形状バイトを維持し、配信用nearはUASTC圧縮、farは既存の属性考慮簡略化。新規生成や有料後処理で修正しない。

near容量は転送ファイル量であり、GPUメモリや島の同時配置性能ではない。farはnearの材質共有、nearはKTX2対応ローダーが必要。

生成時間は各meshy_raw/timing.jsonの「送信から成功観測まで」。順番にBlender処理してから次のタスクを確認するため待機を含み、サーバー内生成時間とは異なる。
