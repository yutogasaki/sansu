# P1 全体見本 — 実際に送信するプロンプト

出典：ユーザー提供 `24_SMALL_PARK_IMAGE_PROMPTS_v0.2.md` のP1本文。本文は変更なし。組み込み画像生成ツールを使用し、既存SVG画面は画像参照に含めない。

幼児から小学3年生程度の子どもが、遊具を並べ替えて人形を遊ばせるゲーム「ちいさな遊園地」の美術見本を1枚作ってください。

目指すのは、机の上に組み立てた、本当に手でつまんで動かしたくなる小さな玩具です。実写の遊園地や経営ゲームの町ではありません。遊具の厚みと触感、人形の重心と表情、配置を変えて試したくなる見た目を重視します。

同じ小さな台座の上に、左から「すべり台 → シャボンゲート → トランポリン」を、等間隔の3位置に並べてください。すべり台は左から上がり、右へすべり降りる形です。ゲートは地上を通り抜ける穴があり、トランポリンには踏む面があります。入口側と右端に少しだけ余裕を置き、右端には安全に着地できる柔らかな終点を作ってください。

オリジナルの人形は1体だけ。短い手足を持つ2.2〜2.4頭身程度、豆のように丸みのある頭、接地が読める丸い靴、表情が読み取れる簡潔な顔。額の片側の小さな丸い突起など、輪郭の特徴を一つだけ持たせてください。大きな目や赤い頬だけで可愛さを作らず、動きたくなる姿勢と重心で魅力を出してください。既存のキャラクターには似せません。

人形はゲートを通った直後、地上で薄いシャボンに包まれ、次のトランポリンへ進もうとしている一瞬にしてください。泡は前後に回り込みますが、顔ははっきり見えます。人形の分身や残像は描かないでください。

素材は、半艶の色付き樹脂を主役にし、明るい木は台座の側面や支柱に限定します。すべり面はコーラル、トランポリン枠は青緑、ゲート枠はバター黄。人形の主色は青紫と淡いクリーム、目や口は深い青灰。大きな面と太い縁に柔らかいハイライトがあり、樹脂、木、柔らかな踏み面、泡の違いが見えるようにしてください。全部品を虹色にしたり、全体を淡いベージュにしたりしないでください。

固定の平行投影に近い見え方で、横から少し斜めに回り込み、軽く見下ろします。左から右へ進む関係を保ちつつ、ゲートの穴とトランポリンの面が見えることを優先してください。極端な俯瞰、強い遠近感、奥へ曲がるコースにはしません。ゲートの輪は、進行方向に対して少し斜めに立て、穴をカメラ側へ開いてください。

ほぼ正方形の画面。人形の直立時の全高は画像の横幅の約1/6を目安とし、スマートフォンで見ても小さな点にならないようにします。上部には跳躍できる空間を残しますが、背景の余白だけが主役にならないようにしてください。

柔らかい左上寄りの光、短い接地影、明るく簡潔な背景。被写界深度によるぼけは使わず、遊具全体の形が読み取れるようにしてください。

UI文字、ボタン、ロゴ、説明ラベル、数字、透かしは入れません。観覧車、追加の建物、来園者、花壇、背景小物も足さないでください。人形と3つの遊具、台座、泡だけで魅力が成立する1枚にしてください。
