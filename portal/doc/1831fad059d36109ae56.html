包括仕様51へ。次期の発見規則版は fantasy-discovery-v1。条件判定、現象の再生、本人が見た記録を別の状態として扱う。

D-01 不思議の三層

> 2026-09-29: この節の一部は北極星と食い違うため無効。51冒頭の整合表を正とする。

日常には葉・水・住人の小さな動きがある。通常発見は配置と本人の働きかけから繰り返せる。精霊は育てた場所へ準備される特別な来訪で、学習の正解数に対する抽選ではない。

条件の変化だけでは発見済みにしない。最初に現象を見たとき、ぽこもこの視線と対象の短い変化で知らせる。全画面図鑑・必須の受取・未発見シルエットの大量配列を通常画面へ出さない。

全v1発見で端末の時刻に合わせた朝・昼・夕ぐれ・夜を表示する。見え方は変えるが資格は同じ。季節・実日付・曜日・深夜・連続ログイン・追加学習・ネット接続を条件にしない。環境生物の装飾的な出入りはseedで変化させても、発見資格や所有物を確率にしない。

D-02 通常発見の全カタログ

距離と到達性は02章。品は所有・配置中で、プレビューではないこと。住人を要する行は、実際の経路移動と接触完了を要求する。機械的にkindだけ置いたテストを実体験の証拠にしない。

rule ID子ども向け名配置・状態の条件起点と見える結果
F-D01葉っぱの やね成熟木とベンチが距離2以内、ベンチに到達可能ぽこもこが座って見上げると葉の影が緩く集まり、頭上に一瞬の小さな葉の輪
F-D02ひろがる 水の わ水ばちが配置中水面タップまたは「さわる」で波紋が広がる。相棒が近くならのぞく。単独でも成立
F-D03水に うつる ほし水ばちと灯りが距離2以内、水ばちの観察点へ到達可能ぽこもこが観察すると器の内側だけに星の筋と光の波紋。昼も確認可能
F-D04花の あかり灯りから距離2以内に、咲いた花の異なる所有IDが2株以上関係する花を選んで「みる」と数枚の花びらが浮き、灯りへ緩く向く
F-D05水の こみち同じ水ばちにつながる水路が最短経路で3セル以上、通水末端から距離1以内に花または鉢水路の「みる」で水源から末端へ淡い光が順に移る。乾いた区間へ飛ばない
F-D06庭の ごはん実収穫物を鉢または保管庫から住人が食卓へ配送済み、その食卓に実在庫あり到達・着席して1個の食事を終える。運搬と食事の事実を関連付け、架空の食料を表示しない

同じ入力の連打は一つの演出に合流する。通常発見は終了後3秒の演出休止を挟んで再現可能。休止は通貨・発見資格の待ち時間ではない。異なる反応が同じ対象に重なる場合は本人の選択を優先、未選択の自発反応は後へ回す。同時の主役演出は島全体で1件とする。

ぽこもこが別の行動中でも、対象の「いっしょに みる」から目的地を選べる。到達不能なら原因を示し、現象の発生を偽装しない。経路が要らない水面の直接反応は独立して遊べる。

D-03 精霊の全カタログ

精霊は小さな土地の客で、常設住人・通貨・図鑑の戦力ではない。名称と外形の最終美術は候補審査するが、条件と役割はここで固定する。

rule ID仮称・表現の役割来訪資格
F-V01みなもの 旅鳥。水からほどける小さな翼と光の足跡F-D03をliveで見た。灯りから距離2以内の水ばちと、その水ばちから距離2以内の咲いた花が、同じ所有IDの組で成長時計8時間連続成立
F-V02こもれびの お客。葉をまとった小さな丸い影と温かい核F-D01をliveで見た。成熟木から距離2以内に到達可能なベンチと咲いた花2株が、同じ所有IDの組で成長時計8時間連続成立

組の選択は成立開始時刻が早い順、同時は所有IDの辞書順。配置条件の連続時間は不在中も計算する。必要なlive発見を見る前でも場所の連続時間は蓄積する。植物が不在中に成熟した場合は成熟時刻から数え、帰島時から8時間待たせ直さない。配置を変えて条件を壊すと未成立の連続時間だけリセットする。

資格ができたら永続の pendingVisit を一件作る。起動・再読込で抽選をやり直さない。庭に薄い気配と「なにか いるみたい」の任意ボタンを示す。押せばすぐ接近・現象へ進めるため、アプリを開いたまま待つ必要はない。本人が静かに眺めている場合には30〜90秒内で自然に現れる候補時刻も設定するが、編集・学習・シート表示中は保留する。

一度成立した来訪権は失わない。発生前に関係物を収納・移動した場合は、必要な場所が再成立するまで待つ。別の同種の組でも再成立できる。二つ同時なら成立時刻順で、同時はrule ID順。一回の来訪が終わるまで次を重ねない。

表示途中に学習へ移動・背景化・描画失敗した場合、liveで見た基準を満たしていなければpendingを残す。既に基準を満たした場合は見た記録を保持し、途中だった演出は「また みる」で最後まで再現できる。

一度見た精霊は、条件を満たす現在の場所でいつでも無料の「よんでみる」が可能。再会を新規発見に数えない。自発的な再来訪は前回のlive表示から成長時計24時間以上、1種につきpending最大1件。溜まった日数分を一度に再生せず、見逃し通知・期限・コンプリート報酬を設けない。

D-04 三つの時計

時計進む条件使うもの
成長時計受理した実経過。不在も含む植物・土・鉢の収穫・場所の連続成立・再来訪間隔
活動時計現在の本人の島が前景で操作可能住人の移動・配送・食事・見せる演出
景色の時刻端末のローカル時刻による朝・昼・夕ぐれ・夜空・環境光・灯りの見え方だけ

景色は端末のローカル時刻へ自動で合わせる（仕様52 §2）。本人の時間選択は保存せず、過去の選択も使わない。景色の切替で成長・発見・報酬・土を進めない。

成長時計は既存の単調な論理時刻を引き継ぐ。前景は単調タイマーで進め、再起動・背景からの復帰は壁時計差分を使う。負の差分は0として補正理由を記録し、時刻を過去へ戻さない。不在一回の受理は最大7日、超過分は消化待ちにせず破棄して現在の壁時計を基点に置き直す。7日でv1の植物・来訪資格・在庫上限は十分進む。端末の日時変更だけで増殖する財布や価値を作らない。時計変更を子どもの不正と決め付けない。

活動時計は背景化時に停止し、復帰時に最後の保存状態から続ける。景色の操作、写真、プロフィール切替で別本人の時計を進めない。offline catch-upは経路の微小tickを何万回も再生せず、境界時刻を積分する。二つの時計の更新は同じworld revisionに保存する。

D-05 「見た」の記録

表示状態は eligible → pending/ready → presenting → witnessed → saved(optional)。eligibleとreadyだけでは図鑑・思い出の既発見にしない。presentingは一時状態で、保存済みのwitnessedを戻さない。

liveで見た資格は、現在の本人・実world・同じscene tokenで、主対象と現象の有効フレームが連続1秒以上表示されたこと。前景で、canvasが可視、主要対象の画面内投影の50%以上が見え、シートや前景物に主要な接点を隠されていないことを確認する。これは画面へ表示した証拠であり、子どもの注視や理解を測定したものではない。

描画のcommit確認を持たないシミュレーター、画像生成、offscreen canvas、非表示タブ、条件のみのunit testはliveの証拠にしない。音OFF・動きを減らす設定の静かな代替現象でも、同じ資格を満たせる。

記録にはrule版、対象所有ID、成立時の関係snapshot、world revision、scene/art版、表示時刻、sourceを保存する。sourceは live / current-replay / past-replay / preview / test。自動の既発見集合へ入れるのはliveのみ。初見IDは一度だけ追加し、何度見ても水増ししない。

D-06 おもいでと写真

「おもいで」の中を「見つけたこと・たいせつ・しゃしん」に分ける。入口を一つにしてもデータを同じ物として混ぜない。

種別保存契約満杯・再演
見つけたことruleごとの初見は恒久。最近見た履歴は20件最近の履歴は古い順に置換できるが初見を消さない
たいせつ本人が選んだ場面snapshot、最大12件満杯では選んで整理。無断削除なし。古い姿の再演と明記
しゃしん実canvasから本人操作で撮った画像、最大12枚自動撮影なし。削除前確認、満杯時も撮影プレビューは試せる

写真は表示した実フレームを保存し、生成絵や高品質な別描画へ差し替えない。日時と出典は詳細に示し、子ども名・成績は画像へ自動で焼き込まない。PNG等の画像本体とmetadataの保存を一緒に完了する。変換中に退出した写真を後から勝手に保存・ダウンロードしない。

過去の思い出は当時の配置・段階・発見を再演し、現在の財布・植物・住人・解放・学習を変えない。当時の描画資源がない場合は当時の画像と説明を表示し、現在の姿を「当時」と偽らない。今の庭で再現する入口は別にし、条件が足りなければ対象を示す。

学習と世界のつながりは、材料の購入時点で関連した学習完了ID群を内部に保持して示せる。「この日に選んだ花が咲いた」という時間の関係を表し、「算数を3問したから花が咲いた」と誤った直接因果にしない。保護者の学習詳細は別入口へ渡す。

D-07 ヒントと再発見

未発見の全レシピを最初から課題一覧にしない。対象を選んだ詳細で「近くに あかりを おいたら どうなるかな」のように一つの関係を任意で示す。ヒントを読まずに遊べ、隠された期限・確率はない。既発見の詳細では実際の成立条件と現在足りない関係を示し、再現を謎解きで妨げない。

初見・ヒント閲覧・再会に学習力・集中力・性格の推定を付けない。世界に戻った回数や閲覧時間を外へ送らず、評価用の観測は明示的な検証時だけ08章に従う。

ID順。一回の来訪が終わるまで次を重ねない。\n\n表示途中に学習へ移動・背景化・描画失敗した場合、liveで見た基準を満たしていなければpendingを残す。既に基準を満たした場合は見た記録を保持し、途中だった演出は「また みる」で最後まで再現できる。\n\n一度見た精霊は、条件を満たす現在の場所でいつでも無料の「よんでみる」が可能。再会を新規発見に数えない。自発的な再来訪は前回のlive表示から成長時計24時間以上、1種につきpending最大1件。溜まった日数分を一度に再生せず、見逃し通知・期限・コンプリート報酬を設けない。\n\n## D-04 三つの時計\n\n| 時計 | 進む条件 | 使うもの §2](../52_growing_island_game_spec.md#2-島の時計)）。本人の時間選択は保存せず、過去の選択も使わない。景色の切替で成長・発見・報酬・土を進めない。\n\n成長時計は既存の単調な論理時刻を引き継ぐ。前景は単調タイマーで進め、再起動・背景からの復帰は壁時計差分を使う。負の差分は0として補正理由を記録し、時刻を過去へ戻さない。不在一回の受理は最大7日、超過分は消化待ちにせず破棄して現在の壁時計を基点に置き直す。7日でv1の植物・来訪資格・在庫上限は十分進む。端末の日時変更だけで増殖する財布や価値を作らない。時計変更を子どもの不正と決め付けない。\n\n活動時計は背景化時に停止し、復帰時に最後の保存状態から続ける。景色の操作、写真、プロフィール切替で別本人の時計を進めない。offline catch-upは経路の微小tickを何万回も再生せず、境界時刻を積分する。二つの時計の更新は同じworld revisionに保存する。\n\n## D-05 「見た」の記録\n\n表示状態は `eligible → pending/ready → presenting → witnessed → saved(optional)`。`eligible`と`ready`だけでは図鑑・思い出の既発見にしない。`presenting`は一時状態で、保存済みの`witnessed`を戻さない。\n\nliveで見た資格は、現在の本人・実world・同じscene tokenで、主対象と現象の有効フレームが連続1秒以上表示されたこと。前景で、canvasが可視、主要対象の画面内投影の50%以上が見え、シートや前景物に主要な接点を隠されていないことを確認する。これは**画面へ表示した証拠**であり、子どもの注視や理解を測定したものではない。\n\n描画のcommit確認を持たないシミュレーター、画像生成、offscreen canvas、非表示タブ、条件のみのunit testはliveの証拠にしない。音OFF・動きを減らす設定の静かな代替現象でも、同じ資格を満たせる。\n\n記録にはrule版、対象所有ID、成立時の関係snapshot、world revision、scene/art版、表示時刻、sourceを保存する。sourceは `live / current-replay / past-replay / preview / test`。自動の既発見集合へ入れるのはliveのみ。初見IDは一度だけ追加し、何度見ても水増ししない。\n\n## D-06 おもいでと写真\n\n「おもいで」の中を「見つけたこと・たいせつ・しゃしん」に分ける。入口を一つにしてもデータを同じ物として混ぜない。\n\n| 種別 | 保存契約 | 満杯・再演 |\n|---|---|---|\n| 見つけたこと |
