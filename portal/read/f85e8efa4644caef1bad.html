起動

npm run dev:nature-town

http://127.0.0.1:5233/#/nature-town 。プロフィール未登録なら既存の初回設定を完了してからこのURLを開く。必要なflagは VITE_ISLAND_ENABLED=true と VITE_NATURE_TOWN_ENABLED=true。通常の起動先と配布設定は変更しない。

操作

  • 地図をスクロールして移動。「全景」で広く見る。
  • 「どうぐ」から選択、場所をタップして「ここにする」。道・橋・水路は指でなぞって選択し、一括確定する。「地図を動かす」でスクロールへ切替。無効な配置は×と理由を表示し、確定できない。
  • 住人をタップ、または「住人をさがす」で選択すると、行動・行き先・実際の荷物・残りの経路を表示。「本人／家／行き先のところ」で地図を移動する。
  • 配置物をタップして移動・収納。同じ個体の在庫と成長を保つ。家に住人がいる場合は移動を使う。
  • 北は座標y=15、東はx=15まで初期食たくから道をつなぎ、「ひろげる」。川には基本の橋を置く。
  • 空き家と同じ食たくの供給履歴・備蓄が揃うと旅人を抽選。現れた候補は消えず、「むかえる」で一人増える。
  • 「れんしゅう」は通常の学習画面。完了区間1つで1単位。支援完了も同額。水路・台車は各3単位で一度だけ解放。
  • 取得した台車は、食たくをタップして利用を選ぶ。連続する道・橋がある配送だけ積載4個になる。
  • 「きろく」で書出し・検査付き復元。復元は同じプロフィールIDが対象。現在の学習単位・道具の権利は減らさない。

検証の読み方と残る制限

受入対応表は仕様47項目について PASS / FAIL / NOT_RUNを分ける。テスト名に複数IDがある場合でも、そのID全体を網羅したと自動判定しない。

  • 地図の施設表現はルールと操作の検証用。住人は既存の実3Dモデルの肖像を再利用。最終美術と住人の全身の受渡し演出は未完成。
