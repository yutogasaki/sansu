原所有幹を保つ森林冠3案 — 実3D source 比較

2026-10-12。sansu-art-direction-loop に従い、最初の3案から層の厚み・U字の庭へ粗形を作り直した。現在はstage4の128役割＋6主枝と全景1枚を保存済みだが、美術はHOLD、strict geometry・全役割roundtrip・接合・runtimeも未合格。通常buildとHOLD v1〜v4の原失敗・最終全形・全景 を入力一致とともに保持した。背景は固定c1 shoulder35のowner-only static contextで、P02 v5や最新本体ではない。 rootの並列比較 も美術HOLD。単一leafのstable-baseline roundtrip PASSを全役割へ広げていない。独立観察 N=0。最初の固定c1 contextの3案は編集可能な .blend / GLB と全景を保持し、b1を次の制作の出発点にした。採用案・runtime得点はない。以下は各段階の履歴で、最新の限定診断は末尾に記す。

正本の app、固定 c1 candidate、元 GLB/Blender、root docs に書込みはない。この bundle は tmp で制作し、root の明示許可で docs/design/2026-10-12-authored-forest-crowns/ に exact copy した。新規 gallery、土地、木、owner、配置権、地形変更は責任外。

全景比較の判定

b1 の低く広い冠は屋根状の葉量を増した。一方、3案とも輪郭差が小さく、左群は個体または雲形の面が並んだように見え、層のある森林内部には達していない。最高大樹との大小差だけでは、家と中庭の背後を包む連続した森の面を作れなかった。接合・固定検査の数値をこの美術上の不足の埋合せにしない。

次段階は b1 を足場に、同じ4所有木の上・中・下の冠を非対称に重ね、2つの異なる外周の入口を残す構成を調べる。新しい木や自由 anchor を足さず、必要な接合は元幹に連続する実枝で扱う。.85m は作者が初回に設けた移動上限であり製品の不変条件ではない。次段階の値は再検討できるが、浮遊、幹・根・owner 変化、最高主景の置換は許容しない。実行・runtime 接続は別の許可を待つ。

準備当初の7ファイルは history/preparation と同じ SHA で復元保存し、完了後・root 比較前の README / manifest も history/completed-before-root-review に保持した。

承認 benchmark は元 docs/design/2026-10-10-island-final-3d/whole-island-render.png。現在の実全景では、左4木は冠の間隔と個体の縦長さが強く、家と中庭を包む葉面に届かない。肩3木は前後差を増したが、左の裸斜面まで連続した森とは読めない。肩近景は l14 群の接合品質を証明する画像ではない。

移す移さない
冠が前後・上下に重なる大きな面、最高大樹と中層の尺度差benchmark の別15軒配置、未所有の木数、自由 anchor
元柳の垂れ葉、白樺の丸い葉塊、尖冠の異なる素材と形一律の丸い primitive 冠、巨木の追加複製、全材料の平準化
家の背後を包む冠と、明るく抜ける幹下家・水庭・花庭・入口を一枚の葉屋根で隠す構成
既存幹から実枝を経て冠へ届く連続画像上だけの接合、浮いた葉、枝を歩行床と扱う変更

構図の制作文は「同じ4本の冠を広げる → 葉面が重なる → 家の背後に奥行きができる → 幹の間に入れる明るい空間が残る」。新しい gameplay の説明や通常取得契約を実装しない。

接合と法線

白樺の3枝と3葉冠は同じ連続変形場を使い、元 branch-root 高さの固定帯を残す。枝だけを動かして冠を置き去りにしない。元幹・樹皮模様は変えない。元生成 script の branch anchor と実幹接合は別なので、実行後に元接合の連続も確認が必要。

柳の冠89 node は同じ変形場へ通し、元 tip core を固定する。独立 main-bough が原GLBにないため、5つの既存 lobe ごとに、実幹表面から実 lobe へ届く短い閉じた木質枝を生成する。幹表面が既に lobe 内部なら余計な枝を足さない。原 trunk/lobe の BVH ray と2方向の内外判定が合わなければ生成を止め、最初の失敗を保存する。新枝は同じ l14 owner・元幹材・元 tip 半径に由来する taper で、旧幹を削らず接触する別の閉体。端点の ray 接触は全断面支持や干渉の合格ではない。

上部の NORMAL は元 split normal へ変形場の Jacobian 逆転置を適用する。全島一括 weld や法線の一括再計算をしない。原材料は GLTFLoader で保持する。根元や他 owner の材質を調整して粗形の弱さを隠さない。

実行の分離

  • prepare-study.py — 実行済み。metadata/SHA/parameter の準備のみ。15入力の前後 SHA 一致、GLB頂点 decode・domain compile・Blender・render なし。
  • extract-context.mjs — attempt02実行済み。固定 c1 の authoredWorldFrame→sceneLayout→buildObjectLayer と ground を静的に使用。左4個体の材batch済 tree を一度だけ外し、元GLBの役割別原本128 nodeを同じ tree world matrix/pivot で別GLBへ出した。その他の context は不変。正確な owner matrix/pivot を保存。
  • build-variants.py — 実行済み。3つの editable .blend、whole .glb、owner-only .glb、manifest を生成。既存出力があれば止まる。
  • render-whole.py — 実行済み。3枚の全景だけ。確定 c1 のカメラ matrix/projection から UI を除く同じ crop を使用。1280px幅・Cycles CPU16 samples。近景・追加視点・重い actor-band 検査は未実施。
