1. 基本方針

1.1 コンセプト

「反射的に意味がわかる」状態を目指す

  • 能動的な単語練習は英語→日本語の4択を基本とし、短い文章を聞くだけの任意体験を併設する（第7節）
  • スペル入力や和文英訳は扱わない（まずは受信スキル）
  • 既存の中学レベル教材（1184学習項目）を完璧にすることをゴールとする

1.2 対象範囲

項目内容
対象学年中学で扱う語彙を中心とする既存教材。学年・英検の到達認定は行わない
単語数1184学習項目（20レベル、各47〜60項目）
出題形式4択ボタン（英語→日本語）

2.3 語義別の単元と証拠

3. 問題生成ルール（4択）

3.1 正解の決定

  • ユーザーの学習進捗（復習・未出・苦手）に基づいて出題対象の単語（正解）が決定される（01仕様書参照）。

3.2 誤答（Da, Db, Dc）の生成ロジック

方針：可能な限り「同じレベル」から選ぶが、ヒントにならないようにする。

  • 候補プール作成:
  • 原則：同じレベルに所属する他の単語。
  • 予備：不足する場合は Level ± 1 の単語も含める。
  • 除外条件（フィルタリング）:
  • 現在のかな／漢字モードで正解と同じ表示ラベルを持つ単語は除外（別解防止）。
  • 英単語が違っても日本語が「すむ（live/reside）」などで重複する場合はNG。
  • 正解と同じ英語の綴りを持つ別項目も除外し、別の意味が同時に正答にならないようにする。
  • 品詞が明らかに違うものは除外しない（今のところ厳密な品詞データを持たないので許容）。
  • 直近10問で「正解または誤答」として出現した単語は避ける（クールダウン）。
  • 選択:
  • フィルタ後のプールから、誤答どうしも表示ラベルとIDが重ならない3つをランダムに選ぶ。クールダウンを緩める場合も4ラベルの一意性を守る。

3.3 選択肢の配置

  • 正解の位置（ボタン1〜4）は毎回ランダムに決定する。

---

4. 日本語訳ルール

4.1 訳の採用基準

  • 中学生にとって最も一般的な訳を1つだけ採用する。
  • 複数意味がある場合も、そのレベル帯で頻出するものを優先。
  • ひらがな・カタカナを多用し、漢字は常用漢字の範囲で見やすく。

4.2 品詞の扱い

  • 動詞：言い切り（〜する）
  • 形容詞：言い切り（〜い、〜な）または名詞修飾形
  • 名詞：単数・複数による訳し分けはしない（「本」で統一）

5.2 表示要素

要素説明

5.3 スタイル要件

  • ボタンの高さ: 指でタップしやすいよう、画面下半分を均等に4分割する程度の高さを確保する。
  • 文字サイズ: 視認性を最優先し、可能な限り大きく表示する。

5.4 英文例文表示

2026-09-11採用。Study通常学習とIslandの英単語カードでは、対象語に校閲済みの固定例文がある場合、英単語の下に短い英文を常時表示する。

  • 英単語と選択肢を主役にしたレイアウトは維持し、例文は文脈を添える補助情報として扱う。
  • 例文の表示は読むための補助であり、回答、追加タップ、採点、習得判定、SRS、進度、報酬を発生させない。
  • 例文はリポジトリ内の固定教材だけを使う。出題カード用のカタログは src/domain/english/examples.ts のレベル1〜20・1,184語とし、第7節の短文リスニング用10文とは分離する。
  • 固定例文がない単語は従来どおり単語だけを表示する。実行時に英文を生成・推測しない。
  • 例文はオフラインで表示し、英語として読み上げ可能な lang="en" を付ける。例文の横に任意再生の「ぶんを きく」ボタンを置くが、自動再生はしない。既存の単語発音ボタン・自動読み上げは単語の読み上げに限定する。
  • 出題カードには例文の日本語訳を表示しない（4択の答えを先に示さないため）。日本語訳は回答を求めない第7節の短文リスニング画面で表示する。

6. データ構造

6.1 単語定義

interface EnglishWord {
  id: string;        // 安定した学習項目ID。初出は "apple"、同綴りの後続項目は "orange_lv2" 等
  surface?: string;  // IDと綴りが違う場合の表示語（"orange"）
  level: number;     // 1
  japanese: string;  // "りんご"
  japaneseKanji?: string; // 漢字モードの表示訳
  category: string;  // "食べ物" (メタ情報)
  pos?: string;      // "noun" (品詞: Optional)
}

同綴りの複数項目は別IDで学習する。旧IDは先頭の既存項目に維持し、後続項目へ過去の正解・強度・Dueをコピーしない。具体的な対応は05仕様書に定義する。出題文字は surface ?? id とする。

6.2 問題データ（クライアントへのレスポンス）

interface VocabProblem {
  wordId: string;    // "apple"
  question: string;  // "apple"
  choices: {
    id: string;      // "apple" (正解), "dog" (誤答)
    text: string;    // "りんご", "いぬ"
  }[];
  answerId: string;  // "apple"
}

7. 短い文章を聞く

7.1 採用範囲とねらい

2026-09-09採用。同日、Studyの通常学習とIslandの学習に初版を実装。端末・学習効果の検証範囲は完了記録で区別する。

単語練習の合間に、絵と短い英文を見て、その文章の音声に触れる機会を用意する。「この文章を聞いてみる」で完結し、理解度の回答を求めない。既存の4択など能動的な学習と併存する。文中で知っている単語に出会い、自分からもう一度聞きたくなることが体験の仮説であり、学習効果は未検証。

7.2 基本体験

  • 1枚に場面の絵、短い英文1文、対応する日本語の文章、「きく」を表示する。日本語はヒントに隠さず、再生前・再生中・再生後を通して英文のそばに常時表示する。英文や日本語を読めることを再生の条件にしない。
  • 日本語は単語訳の羅列ではなく、英文全体の意味が伝わる自然な1文とし、既存のかな／漢字設定に従う。「きく」で流すのは英語の音声とする。
  • 「きく」で文全体を1回再生する。終了後は同じ画面に留まり、何度でも再生できる。聞き終わったあとの問題、発話、書き取り、和訳、確認テストは付けない。
  • 自動再生・自動ループは初版に含めない。既存の英単語自動読み上げ設定から短文の自動再生を引き継がない。
  • 再生前・途中・終了後のどの時点でも「つづける」で通常学習に戻れる。最後まで聞くことや再生ボタンを押すことを必須にしない。
  • 未再生・見送りに誤答、警告、能力評価を付けない。「きけた？」などの確認操作や聞いた印の回収を要求しない。

7.3 出し方と頻度

  • 英語が有効な通常学習で、単語練習の自然な区切りに任意の「ぶんを きく」入口をたまに表示する。回答中・採点中・保存中に割り込むモーダルにはしない。
  • 初版の調整値は、同じ学習セッション内で英単語の回答完了が6問に達した後、最初の区切りに入口を1回表示し、1セッション最大1枚とする。混合学習では英単語だけを数え、算数のみ・定期テストには出さない。6問は効果が確立した値ではなく、試用で調整する値。
  • セッションは学習画面を開いてから退出するまでとし、再読込・プロフィール切替で頻度カウンターをリセットする。カウンターは保存しない。
  • 入口を押さなくても通常の連問はそのまま進む。島の自動次問・成長に追加タップを要求しない。開いた場合も同じ未回答問題・予約・下書きへ戻す。
  • 学習済みの対象語を含む校閲済み短文がない場合は表示を省く。保護者が無効にした範囲の語を対象語として補充しない。
  • 初版は、このセッションで回答を完了した直近12語から対象語を選ぶ。6問以上の最初の区切りで対象がなければ、そのセッションでは省略する。今の未回答問題と同じ対象語の短文は入口を隠し、別の語の問題になるまで待つ。日本語文が現在の問題の答えを直接示すことを防ぐ。

7.4 教材の契約

初版は身近な場面の1文、目安3〜7語とする。最近練習した語を対象語にし、冠詞や代名詞などは文を聞くための補助表現として扱う。文法解説や全単語の習得を前提条件にしない。既存語彙のレベルだけで文全体の難度を決めない。

英文例絵・意味の対応
The cat is sleeping.ねこが寝ている場面
I like apples.話している人物と、好きなりんごがわかる場面
This is a red flower.指している赤い花がわかる場面

常時表示する日本語文の例は、順に「ねこが ねています。」「わたしは りんごが すきです。」「これは あかい はなです。」とする。

上の例は方向性であり、音声・画像を含む校閲済み教材ではない。短文リスニング初版の実教材は src/domain/english/listening.ts の10文とする。apple、orange、banana、dog、cat、rabbit、bird、flower、tree、houseに対応し、基本の This is a/an … に Look at the cat. と The tree is green. を加える。安定した短文ID、版、英文、かな／漢字の日本語文、対象wordId、補助表現、絵の参照と代替テキストを持つ。出題カード用の固定例文は src/domain/english/examples.ts でレベル1〜20の1,184語をカバーするが、短文リスニングの入口対象はこの10文から変更しない。

文章は今回作成した固定教材、図はリポジトリ内の既存教材図 IslandGlyph を再利用する。音声参照は共通の端末英語TTS（en-USを優先、速度0.9）とし、合成音声ファイルを再配布しない。英文・日本語・図の意味対応は作者確認、発音は利用端末の音声に依存し専門家校閲済みとは扱わない。全文の実行時自由生成は含めない。

7.5 音声と復帰

  • 音声の重複再生を防ぐ。再生中は「とめる」、終了・停止後は「もういちど きく」で先頭から聞ける。
  • 退出・次問へ復帰・プロフィール切替・アプリ背景化で停止する。復帰時には勝手に再開しない。
  • 音声設定を尊重し、ミュートを暗黙に解除しない。音なしでも絵・英文を見て、そのまま学習を続けられる。
  • 英文・日本語・図はアプリとともにオフラインへ配信する。初版の音声は端末内にインストール済みの英語音声を優先する。端末によりオフライン再生できない場合があり、英語音声なし・再生失敗時は「いまは おとが でないよ」と再試行・続行を用意し、学習を止めない。録音教材の同梱は後続とする。

7.6 学習記録との境界

再生・最後まで聞く・再聴・見送りは回答ではない。正誤ログ、独力正解、SRS強度、Due、弱点、レベル解放、昇格、学習問題数、科目配分に加算しない。島のほし・成長・賞の条件にも数えず、既存の学習予約を変更しない。見送りは既存の問題スキップや連続スキップ停止にも数えない。

初版では短文の閲覧・再生履歴を永続保存しない。「聞いた」を理解・習得とみなす保護者表示を作らない。将来、聞いて選ぶなどを追加する場合は独立した教材・評価として定義し、受動的な再生記録から達成を推定しない。

7.7 実装時の受入条件

  • 聞くだけ、繰り返し聞く、聞かずに続ける、途中で戻るがすべて成立し、回答を要求されない。
  • 入口を使わない通常連問に追加操作がなく、任意閲覧後も同じ予約・問題・下書きに戻る。
  • 頻度上限、英語無効、対象教材なし、テスト中での非表示を確認する。
  • 再生・見送りの前後で学習記録、SRS/Due、進度、島の報酬が変わらない。
  • phone/tabletで日本語文の常時表示と実音・絵・英文・日本語文の意味の一致を確認し、連打、停止、背景化、音off、オフライン、音声失敗から復帰できる。
  • 子どもが回答不要とわかるか、自発的に聞き直したいかを別に確認する。再生回数だけで理解・学習効果を合格にしない。

answerId: string;  // \"apple\"\n}\n```\n\n---\n\n## 7. 短い文章を聞く\n\n### 7.1 採用範囲とねらい\n\n2026-09-09採用。同日、Studyの通常学習とIslandの学習に初版を実装。端末・学習効果の検証範囲は完了記録で区別する。\n\n単語練習の合間に、絵と短い英文を見て、その文章の音声に触れる機会を用意する。「この文章を聞いてみる」で完結し、理解度の回答を求めない。既存の4択など能動的な学習と併存する。文中で知っている単語に出会い、自分からもう一度聞きたくなることが体験の仮説であり、学習効果は未検証。\n\n### 7.2 基本体験\n\n- 1枚に場面の絵、短い英文1文、対応する日本語の文章、「きく」を表示する。日本語はヒントに隠さず、再生前・再生中・再生後を通して英文のそばに常時表示する。英文や日本語を読めることを再生の条件にしない。\n- 日本語は単語訳の羅列ではなく、英文全体の意味が伝わる自然な1文とし、既存のかな／漢字設定に従う。「きく」で流すのは英語の音声とする。\n- 「きく」で文全体を1回再生する。終了後は同じ画面に留まり、何度でも再生できる。聞き終わったあとの問題、発話、書き取り、和訳、確認テストは付けない。\n- 自動再生・自動ループは初版に含めない。既存の英単語自動読み上げ設定から短文の自動再生を引き継がない。\n- 再生前・途中・終了後のどの時点でも「つづける」で通常学習に戻れる。最後まで聞くことや再生ボタンを押すことを必須にしない。\n- 未再生・見送りに誤答、警告、能力評価を付けない。「きけた？」などの確認操作や聞いた印の回収を要求しない。\n\n### 7.3 出し方と頻度\n\n- 英語が有効な通常学習で、単語練習の自然な区切りに任意の「ぶんを きく」入口をたまに表示する。回答中・採点中・保存中に割り込むモーダルにはしない。\n- 初版の調整値は、同じ学習セッション内で英単語の回答完了が6問に達した後、最初の区切りに入口を1回表示し、1セッション最大1枚とする。混合学習では英単語だけを数え、算数のみ・定期テストには出さない。6問は効果が確立した値ではなく、試用で調整する値。\n- セッションは学習画面を開いてから退出するまでとし、再読込・プロフィール切替で頻度カウンターをリセットする。カウンターは保存しない。\n- 入口を押さなくても通常の連問はそのまま進む。島の自動次問・成長に追加タップを要求しない。開いた場合も同じ未回答問題・予約・下書きへ戻す。\n- 学習済みの対象語を含む校閲済み短文がない場合は表示を省く。保護者が無効にした範囲の語を対象語として補充しない。\n- 初版は、このセッションで回答を完了した直近12語から対象語を選ぶ。6問以上の最初の区切りで対象がなければ、そのセッションでは省略する。今の未回答問題と同じ対象語の短文は入口を隠し、別の語の問題になるまで待つ。日本語文が現在の問題の答えを直接示すことを防ぐ。\n\n### 7.4 退出・次問へ復帰・プロフィール切替・アプリ背景化で停止する。復帰時には勝手に再開しない。\n- 音声設定を尊重し、ミュートを暗黙に解除しない。音なしでも絵・英文を見て、そのまま学習を続けられる。\n- 英文・日本語・図はアプリとともにオフラインへ配信する。初版の音声は端末内にインストール済みの英語音声を優先する。端末によりオフライン再生できない場合があり、英語音声なし・再生失敗時は「いまは おとが でないよ」と再試行・続行を用意し、学習を止めない。録音教材の同梱は後続とする。\n\n### 7.6 学習記録との境界\n\n再生・最後まで聞く・再聴・見送りは回答ではない。正誤ログ、独力正解、SRS強度、Due、弱点、レベル解放、昇格、学習問題数、科目配分に加算しない。島のほし・成長・賞の条件にも数えず、既存の学習予約を変更しない。見送りは既存の問題スキップや連続スキップ停止にも数えない。\n\n初版では短文の閲覧・再生履歴を永続保存しない。「聞いた」を理解・習得とみなす保護者表示を作らない。将来、聞いて選ぶなどを追加する場合は独立した教材・評価として定義し、受動的な再生記録から達成を推定しない。\n\n###
