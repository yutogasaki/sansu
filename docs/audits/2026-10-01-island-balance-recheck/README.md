## 残る指摘（優先順）

### B1：高 — 有限土地で成長が止まる

`src/domain/growingIsland/commands.ts:33` の拡張は5回、土地は最大144マスのまま。家の容量・建築所要時間も前回と同じ。

同じ手順で再実行すると、育成優先は180日67人→365日67人、花を先に置く手順は90日26人→365日26人。新しいすべりだい・ポスト・トランポリン・ふんすい・パンやさんを各1個購入し、届いたふしぎのたねも置く追加手順では、育成優先180日56人→365日56人、装飾優先90日27人→365日27人だった。

追加品で土地の用途が増えた一方、成長先は増えていない。各人数は固定の配置手順での結果であり、エンジンの絶対人口上限・利用者の平均値ではない。収納・移設を行わず、建物を奇数行に置く手順の制約も含む。それでも5回で土地拡張が終わる契約は、憲法の「小さな固定上限で止めない」との整合が必要。

### B2：高 — 出来事の抽選は引き続き学習量・往復頻度に依存

`town.ts:99–106` は、学習で進んだ夜明けごとに出来事を抽選し、最後の結果だけを返す。咲いた花6個・同じ60完了・同じ乱数seedで、まとめて開くと1件、6完了ずつ10回開くと9件を再現した。決定的な乱数なので単なる再読込による引き直しではない。

くじら・にじいろのとり・つきのうさぎも同じ `dayMoment` へ追加されている。出会いの種類は増えたが、憲法§1.2の「学習の量で、運を引く回数を増やさない」との不一致は残る。
