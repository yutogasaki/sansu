# Nature Town v0.2 implementation gap

> 2026-09-22: 開発方針は[今の島への統合](../island-nature-integration.md)へ変更。以下の「新しい独立試作」は過去の判断であり、別製品を今後も作る指示ではない。

## 統合に向けて解消する違い

| 項目 | 今の島 | Nature Townの試作 | 接続前に決めること |
|---|---|---|---|
| 画面 | `IslandLife` / `LifeWorld`の3D。家・学習と共通の行き来 | `TownMap`の平面地図と独自の操作面 | 島の描画を継続し、計算結果を同じ場所・住人へ表示する。TownMapを主画面にしない |
| 場所 | `domain/islandLife`のCellと土地・家具の占有 | `domain/natureTown`の16セル単位の地区・経路 | 座標と占有の対応。既存配置の上書きや二重の障害物判定を避ける |
| 時間 | 島の保存履歴から暮らしを再現 | 固定tickの世界更新 | 学習・非表示・再開時の時計を一本化。別々に二重進行させない |
| 物 | 購入・所有・移動・収納と本/道具の運搬 | 収穫物の在庫・配送予約・共同食 | 装飾の運搬と実在庫を分け、同じ荷物を二重に消費しない |
| 学習 | 正式な学習記録、しずく、既存解放。水路は通常カタログで2しずく/マス | 完了区間単位の水路・台車解放 | 現行の水路は島の通常購入へ統一し、旧試作の別解放・別通貨を使わない。台車と今後の解放は別に決める。学習writerは変更しない |
| 保存 | `SansuIslandLifeV1` | `SansuNatureTownV02` | 旧データの保持、版付き変換、再送と失敗復旧。DB丸ごとの合算はしない |

2026-09-27: 最初の食料の一周は `domain/islandLife/foodLoop.ts` を現行のCell・成長時計・住人の訪問経路・保存履歴に接続した。既存の鉢と食卓を使い、Nature Townの格子地図・tick・財布・DBを二重起動しない。収穫在庫は鉢/食卓/運搬中/保管分として保存状態から再現する。学習writerは変更せず、有効成長時間を読む。水ばち・育った木から鉢までのマンハッタン距離を使う。`domain/islandLife/waterChannels.ts` で水ばちから最大8マスの辺接続をたどる。`domain/islandLife/soilMoisture.ts` で土地ごとの水分をLifeの実時間から決定的に進め、鉢の成長はその区間の水分を読む。旧試作の8%/tickは時計が違うため直輸入せず、実時間3時間の半減期を採用した。配置を変えても土・鉢の途中の育成・在庫を保持する。固定地形水源、来訪・入居、供給と土地拡張の接続、旧Nature Town保存の扱いは引き続き未接続。

## 旧試作を作った時点の接続記録

2026-09-16。添付仕様を新しい独立試作へ採用。旧Lifeの本番既定・作品・通貨は保持する。

| 接続 | 現物 | 方針 |
|---|---|---|
| runtime | React 19 / Vite 7 / Three 0.185 / Dexie 4 | 既存依存を利用 |
| 旧世界 | domain/islandLife、SansuIslandLifeV1 | 新DB SansuNatureTownV02、破壊的移行なし |
| 学習正本 | db.islandPlans / islandEvents | 完了済み予約の全slotと成功イベントを照合。予約1区間を1 checkpoint / 1単位として読取専用で再取得 |
| 学習支援 | supported-completion / assisted-correct | 同額。習得/SRSをゲームから変更しない |
| 学習開始 | /island?start=learn | 既存UIに接続、世界を停止。戻る導線を追加 |
| 個体美術 | LifeResidentPortrait / residentRig / buildHomeJourney | 既存3種の実モデルを再利用。新規キャラ生成なし |
| 経路 | 旧Lifeは連続座標・固定配置 | 16セル格子の純粋コアへ分離 |
| 保存 | Dexie、既存PWA critical persistence hold | 原子的snapshot＋前版、チェックサム、単一writer、明示復旧 |

既存の「1問1しずく」と新しい「完了予約1区間1単位」は別契約。過去の旧通貨を変換しない。開始時点の既存完了IDを基準として、新規の完了区間のみ反映する。開始後に完了した途中予約は対象にできる。

## 表示方針

S1のルールと操作を検証する独立した地図試作。既存美術の全面置換・本番切替はしない。世界の実在庫と座標を描画し、既存キャラの実モデル肖像を保持。正式な美術合格・無文字理解・教育効果は未判定。
