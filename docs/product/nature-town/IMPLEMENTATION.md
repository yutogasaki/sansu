# Nature Town v0.2 ローカル試作

2026-09-16。仕様00〜10をもとに、既存アプリと独立したシミュレーションと操作面を追加。公開・旧保存の変換は行わない。

## 起動

```bash
npm run dev:nature-town
```

http://127.0.0.1:5233/#/nature-town 。プロフィール未登録なら既存の初回設定を完了してからこのURLを開く。必要なflagは `VITE_ISLAND_ENABLED=true` と `VITE_NATURE_TOWN_ENABLED=true`。通常の起動先と配布設定は変更しない。

## 操作

- 地図をスクロールして移動。「全景」で広く見る。
- 「どうぐ」から選択、場所をタップして「ここにする」。道・橋・水路は始点と終点のタップで間の格子をまとめて選択し、一括確定する。
- 配置物をタップして移動・収納。同じ個体の在庫と成長を保つ。家に住人がいる場合は移動を使う。
- 北は座標y=15、東はx=15まで初期食たくから道をつなぎ、「ひろげる」。川には基本の橋を置く。
- 空き家と同じ食たくの供給履歴・備蓄が揃うと旅人を抽選。現れた候補は消えず、「むかえる」で一人増える。
- 「れんしゅう」は通常の学習画面。完了区間1つで1単位。支援完了も同額。水路・台車は各3単位で一度だけ解放。
- 取得した台車は、食たくをタップして利用を選ぶ。連続する道・橋がある配送だけ積載4個になる。
- 「きろく」で書出し・検査付き復元。復元は同じプロフィールIDが対象。現在の学習単位・道具の権利は減らさない。

## 実装対応

| 仕様 | 主な実装 |
|---|---|
| 固定tick、決定的乱数 | `src/domain/natureTown/simulation.ts`, `random.ts` |
| 16×16の初期地形、北/東の拡張 | `starter.json`, `world.ts`, `commands.ts` |
| 水路・水分・日陰・育成 | `environment.ts` |
| 歩行コスト、混雑、橋 | `grid.ts` |
| 予約、実配送、共同食、物量保存 | `transport.ts`, `validation.ts` |
| 行動の好み、席、共有反応、虫、入居 | `life.ts` |
| 学習の永続完了再読込、重複排除 | `learning.ts`, `progress.ts` |
| 原子的保存、前版、チェックサム、復元 | `repository.ts` |
| 操作、停止、2倍速、学習往復 | `src/pages/NatureTown.tsx`, `src/components/natureTown/` |

数値の正本は `src/domain/natureTown/balance.json`。新保存は `SansuNatureTownV02` のみ。旧Life・学習DBを新形式へ変換しない。プロフィール削除時は新保存も削除する。

Web Locksでプロフィール単位のwriterを確保し、さらにDBのgenerationで古い書き込みを拒否する。Web Locks非対応環境では安全な保存ができると偽装せず、開始しない。1秒ごと・操作確定ごとに完全なsnapshotを保存する。実時計による不在分の進行はない。

## 検証の読み方と残る制限

[受入対応表](acceptance-status.json)は仕様47項目について PASS / FAIL / NOT_RUNを分ける。テスト名に複数IDがある場合でも、そのID全体を網羅したと自動判定しない。

- 地図の施設表現はルールと操作の検証用。住人は既存の実3Dモデルの肖像を再利用。最終美術と住人の全身の受渡し演出は未完成。
- 操作はタップで経路の始点・終点を指定する方式。指で連続してなぞるブラシ、ピンチ操作は未実装。
- 旧作品の移行、別プロフィールへの復元、学習履歴そのものの移送は対象外。書出しは新しい島と進捗台帳のみ。
- 配置の取り消しは直前の追加・移動の逆操作。時間や学習を戻さない。撤去ブラシの逆操作は未提供。
- 24/96人・8/24地区の性能、実機iOS、長期運用、子どもによる遊び・無文字理解・学習動機は未検証。
- 新しいモードに対する異なる2ビルド間のSW更新検証は未実施。通常のオフライン起動・保存とは区別する。

視覚的魅力：HOLD（地図試作）。無文字理解・安全：未判定（参加者0人）。実装整合：自動検査・ブラウザー実測の範囲を受入表に記録。これらを平均して公開可能とは判定しない。
