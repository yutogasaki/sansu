# 育てて広がる島：地区・解放・施設カタログ

## 位置づけ

2026-09-12。ユーザーの「既存のまとまりによる発展、成長アンロック、複数置く意味、シムシティの公共施設のような特殊機能を組み合わせ、レパートリーを増やす」という依頼に対する設計。

親は[01](01_app_spec.md)、現在動く暮らす島は[48](48_island_life_spec.md)。本書は次期設計の正本であり、32種の実装・配布完了を示さない。数値は初回調整用の提案値。現行の価格・保存済み成長・所有をこの文書だけで変更しない。現在の4商品、6×5の島、1回拡張、最大30個に32種をそのまま押し込む実装はしない。

## 1. 体験のつながり

学習でしずくを得る → 好きな品を買う → 個体が育つ／住人が使う → 配置のまとまりが場所になる → 初めての場所の完成で新商品が解放される → 特別な施設を組み合わせ、暮らし方を変える。

次の4つをそれぞれ成立させる。

| 発展の軸 | 例 | 達成後に残るもの |
|---|---|---|
| 個体を育てる | 芽 → つぼみ → 開花、苗 → 若木 → 成木 | 同じ個体の育ち |
| 同種をまとめる | 花3個 → 花壇、成木3本 → 木立 | 現在の配置による場所。初完成の実績は恒久 |
| 異種を組み合わせる | 木立＋テーブル → ピクニックの庭 | 組み合わせに対応する住人の行動 |
| 拠点を置く | 図書室＋近くのベンチ → 読み聞かせ | 施設の所有と解放済みの品 |

島の一律レベルは追加しない。庭・木立・遊び場・水辺から好きな入口を選ぶ。学力レベルや独力正解率を施設の資格にせず、既存の学習判定とは分離する。

## 2. まとまりと初完成

花・木・遊具・水辺の4系統を基本地区とする。初完成はプロフィールごと、地区種別ごとに一度だけ記録する。別の場所で作り直す、移設で分割する、収納して戻す操作では再取得できない。

| 地区 | 成立条件 | 初完成で増える選択肢 |
|---|---|---|
| 花壇 | 開花した花3個以上が上下左右で連結 | チューリップ・ひまわり・花のアーチ |
| 花畑 | 開花した花6個以上が連結し、幅3セル以上・奥行き2セル以上 | あじさい・園芸小屋 |
| 木立 | 成木3本以上が連結 | りんごの木・みかんの木・ハンモック |
| 森の庭 | 成木6本以上が連結し、幅3セル以上・奥行き2セル以上 | 桜の木・木工工房 |
| 遊び場 | 遊具2個以上が連結。同じブランコ2個でも成立 | すべり台・砂場・風車 |
| 遊園地 | 遊具3個以上が連結。同じブランコ3個でも成立 | シーソー・音楽堂 |
| 水辺の庭 | 水辺品2個以上が連結 | 小さな池・噴水・丸太橋 |
| 水の広場 | 水辺品4個以上、2種類以上が連結 | 小川・水車小屋 |

花の異種も合算する。現行の花・ブランコだけで作った地区の条件を厳しくしない。新規地区も全個体の利用位置まで到達できる配置が必要。施設やベンチを置くだけでは花・木・遊具の数に含めない。

初完成時は新規解放する小物のうち1個を選べる「はじめての品」を1回分保存する。施設本体は購入対象。受取は任意、期限なし、通常学習の途中では出さない。未受取でも次へ進める。贈与個体を撤去してもしずくは発生しない。再購入した個体は実支払額の半分を返却する。

現在の地区と恒久実績を分ける。地区を崩すと現在の見た目・組み合わせ効果は変わるが、解放・受取資格・育ち・記念は失わない。仮配置は実績に数えない。

### 効果範囲・容量・重複

- 原則は施設の出入口から地面の最短経路4歩以内にある対象の利用位置。水車は例外で、出入口に接する小川の同一連結成分に作用する。島全体への無条件倍率にしない。
- 設置予告は効果を受ける実物を明るくし、「このベンチで おはなし」のように結果を一つ示す。施設自体の入口に通れない配置は確定不可。
- 図書室・カフェ・保健室・音楽堂は一度に1組、最大2人を対象にする。空いた席、別々の利用位置、歩行経路を予約してから活動を始める。既存の住人3人で成立させる。
- 同じ席を複数施設で同時使用しない。候補が複数ある時は、到達可能性・空席・好み・前回と異なる活動をもとに1件選ぶ。効果やひかりを加算重複しない。
- 園芸小屋・工房の巡回も住人1人の活動時間を使う。花や家具が多くても報酬イベントを対象数分生成しない。
- 移設で範囲外になれば、その組み合わせ活動を安全に終了し通常行動へ戻る。既に完了した活動を消さず、途中の活動に報酬を付けない。
- 道路敷設・維持費・電力供給の連鎖を要求しない。次期配置は[48](48_island_life_spec.md)の孤立予告に従い、到達できなくても配置は許す。孤立中の施設は新しい利用を開始せず、無料移動で経路が戻ると自然な利用が再開する。配置と保存切替はローカル実装済み、公開は未実施。

## 5. 混ぜてつくる場所

基本地区は同種の連結、以下は異種の関係を扱う。成熟、配置確定、移設、収納で再評価する。距離は両者の利用位置間の歩行経路4歩以内。現在成立している場所が活動を生み、一度成立した実績が解放の根拠になる。

| 組み合わせ | 場所／起こること | 複数置く意味 |
|---|---|---|
| 花壇＋ベンチ | 花を眺める庭 | 違う花壇のそばに休憩先を分ける |
| 木立＋テーブル | ピクニックの庭 | 席と果樹の関係で集まる場所が変わる |
| 遊び場＋ベンチ | 待ち合わせの広場 | 遊ぶ人と休む人の居場所を分ける |
| 水辺の庭＋ベンチ | 水音の庭 | 別方向から水を眺める |
| 花畑＋アーチ | 花の入口 | 通り抜ける入口と花のまとまりを作る |
| 木立＋ハンモック | 木陰の休憩所 | 複数の木陰に好きな休憩先を作る |
| 小川＋丸太橋＋水車 | 水車の小道 | 流れと横断場所を自分で決める |
| 音楽堂＋席＋灯り | 星の演奏会 | 観客席と照明の配置を作る。実時間の夜を待たない |

巨大な花畑に全品を集約する配置だけを優遇しない。小さな庭を複数つくると違う場所で異なる暮らしが起きる。名称が変わるだけで行動・見た目が同じ組み合わせは、完成品として数えない。

## 6. 成長と経済の調整案

### 学習と成長

1完了2しずく、支援完了も対象、誤答・途中行・スキップは対象外、二重付与防止は48を継承する。問題の難度を下げて稼ぐ操作を促さず、通常plannerを使う。

新ルールの育つ個体は基礎速度0.5。過去24時間の有効完了数nに応じて速度を `0.5 + 0.5 × min(n / 6, 1)` とする調整案。3問でも0.75、6問で1.0、休んでも0.5。6問を超えても倍率は上がらない。UIに新たな経験値通貨は出さない。

花は有効成長時間2／6時間、木は6／18時間を仮置きする。家具・特殊施設は購入直後から使える。建物を使えるようにするための待ち時間は設けない。花は基礎速度でも12時間で開花、木は36時間で成木。収納中は進まず、成熟後は衰退しない。

速度は完了時刻と24時間後の失効時刻を区切って積算する。残り時間は今後追加学習がない場合の失効も含めて予測し「めやす」と表示する。単に有効時間を実時間として表示しない。留守中、途中再開、時計補正の契約は保存設計と合わせて検証する。

### しずくとひかり

しずくは個体・機能施設・土地、ひかりは恒久的な外観に使う。特殊施設を買うためにひかりも要求する二重の支払条件は付けない。新しい品を見つける喜びと、購入の選択を分ける。

ひかりは同じ住人の30分の活動完了につき1という既存基準を維持する案。2人の活動なら各自に最大1、同じ時刻の複数施設から重複付与しない。自動活動は開きっぱなしや回収タップを有利にしない。

追加外観は、花の模様・木製家具の木目・布の柄・水辺の縁・灯りの形・施設の看板の6群×4種、計24種を制作候補とする。8／12／16／24ひかりの4段階で、1度買えば対応品に何度でも適用可能。既存の2色各4と所有権は維持する。外観は32商品の種類数とは別に数える。

24種の総価格は360ひかり。既存2色を足して368。既存3住人なら活動が途切れない上限6ひかり/時に対し約61.3時間分に過ぎず、これだけで長期経済を解決したとは扱わない。収集完了後は残高を保持し、不要な獲得通知や未実装商品の予告を止める。維持費・消耗・重複抽選で無理に消費させない。

## 7. 土地と持ち物

新商品と同時に収納容量と土地を設計する。所有上限は120個、同時配置は経路を確保できる範囲で最大60個を仮置きする。全32種を一度に置くことは達成条件にしない。

既存の初期6×5、東／西3列の初回拡張12しずくは保持。追加は未所有側の3列24しずく、その後に南3行36しずくを候補とし、最大12×8セル。2回目は基本地区1系統、3回目は2系統の初完成で購入資格を得る。既存土地の再購入や家具の自動移動はない。

通常品は原則1×1、特殊施設は2×2、音楽堂は3×2、橋は2×1を見積り基準とする。入口・座席・通行セルを占有外に別途確保する。セルの大きさを変えて大物を小さく見せる解決はしない。小川のセルは地上歩行不可、橋だけが対応する小川上への重ね置きを許可する。基礎地形まで水没させない。

花6個＋園芸小屋＋ベンチ、木3本＋テーブル＋カフェ、遊具3個＋音楽堂＋2席、水鉢＋池＋噴水＋小川＋水車＋橋を、それぞれ段階相応の土地で実配置してから寸法を確定する。花と遊具の既存地区が移行後も通行可能であること、390px幅で全域を編集できることを必須にする。

## 8. 次が見える出し方

最初から32種の鍵一覧を見せない。購入可能なものに加えて、選んだ系統の次の2〜3品を実物の見本で示す。「おはなを 3こ さかせると」のように実際の条件を一つ伝える。任意の欲しいものは1件選べ、無料で変更できる。

施設の見本には対象との組み合わせを示す。例：図書室だけを回す見本に加え、ベンチで本を読む住人を見せる。範囲や人数の数字だけで施設の価値を説明しない。

地区・解放・活動の通知を連続モーダルにしない。学習は即時再開可能に保つ。未制作の品は実装・検証が完了した時にカタログへ追加する。オフラインで成立した活動は計算結果であり、「あなたが見つけた」観察記録にはしない。

## 9. 実装順と受入

今回完了するのは設計と品揃えの定義。以下は実装のまとまりであり、実装完了の記録ではない。

1. 地区初完成の恒久記録・重複防止・残り時間修正・成長の版管理。新カタログを先に見せない。
2. 花2種と花のアーチ・園芸小屋、すべり台・砂場・図書室・絵本かごを追加し、花系／遊び系の二経路を完成させる。4品から12品へ。必要な土地・収納拡張を同時に検証する。
