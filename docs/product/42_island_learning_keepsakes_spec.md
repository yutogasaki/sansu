# 学習の賞状とトロフィー

2026-09-09採用。ユーザーの「選手が家にトロフィーを飾るように、学習の賞状やトロフィーを飾り、意欲につなげたい」という要望を具体化する。親仕様は[01](01_app_spec.md)、世界は[28](28_mystic_island_spec.md)、学習との結合は[30](30_living_island_growth_spec.md)。採用と子どもの意欲向上の検証は分ける。

## 体験

学習を終える→本人の成果として賞状/トロフィーが使える→暮らしている家の一角へ飾る→眺めたり写真に残したり、選んで学習の記録を振り返る。島にある実際の家をタップするか、補助の「いえ」ボタンから入る。学習/再開は同じ予約へ一操作で戻る。

- 初めての完了で「はじめの いっぽ」の賞状。25・100回にも歩みの賞状。
- 5・10・20・30・50・75・100・150・200・300・500・750・1000回の学習区間完了で、形や素材に違いのある13個のトロフィー。賞状と合わせて16点を、同時に飾れる。
- 回数は `completedSets`（完了区間）を正確に使う。問題数/学習日数/習得技能数とは呼ばない。初回と通常で区間の問題数が異なる。
- 時間制限、連続日、ノーミス、支援を使わないこと、他者との順位は条件にしない。休んでも獲得権を失わない。
- 所有可能な賞は保存済みの本人の成果から導く。無料で飾る/しまう/選び直す。受取や展示を連問の必須操作にしない。

## 展示とUI

椅子、ラグ、写真帳、植物、掲示板のある生活空間の片隅に、賞状3点とトロフィー13点を飾れる壁と複数段の棚を置く。成果だけの専用室へ切り離さず、島で見えていた家の中だと分かる構成にする。賞状は額/紙/印、トロフィーは台座/杯などの輪郭で区別する。音や輝きだけに頼らず、静止・音なしでも展示品が分かる。

島と家は同じThree.js Sceneとrendererを使う。既存cottageの位置を保ち、玄関から入り、床・天井・四方の壁に囲まれた実際の家内へPerspective cameraを置いて見る。外側から屋根/外壁を開いた断面を眺める構図は採用しない。入退室の切替は短いfade以内に収め、reduced motionでは即時とする。退出時は元の島へ戻り、学習中は室内画角や演技を続けない。別の土地へ移した室内や別Sceneへの切替で家との連続性を代替しない。室内の飾りは家の既存予約域に収め、島の自由配置物や経路に新しい占有を追加しない。

画面の見出しは「いえ」。入った直後は生活空間のoverviewで、「大事なもの」のアルバム/かざりと記憶、「お知らせ」、「まなびの きねん」を選べる。実棚・写真帳・掲示板のタップと補助DOM入口は同じ行き先へつなぐ。学習の棚を開いた時は選んだ賞と「いえに かざる／しまう」の主操作を先に見せ、その後に取得済みの品を並べる。「これから」の品と詳しい学習履歴は任意に開く。初回の賞状を使う前に16品を縦に読み進めさせない。額内の細かい文字を読むことは必須にせず、詳細はDOMに表示する。「もっているものを ぜんぶ かざる」で資格のある品をまとめて展示でき、一品ずつしまえる。展示済みの一品を選ぶと同じ実物の近景へ寄り、「いえを みわたす」で生活空間へ戻せる。取得していない模型を実物として並べない。

家内の一時sectionは `home` / `keepsakes` / `notices`。棚を開く `open-keepsakes` と掲示板を開く `notices` は家内の切替、`home` は生活空間のoverviewへ、`close` は島へ戻る。家の「大事なもの」は既存の実アルバムと「かざりと きおく」へつなぐ。掲示板は0件でも開け、「いまは あたらしい おしらせは ないよ」と実状態を示す。本人の `pendingRewards.length > 0` のときだけ、具体的な実おくりものへの操作を表示する。通知を演出するための偽データ、未読数、急がせる期限や警告は追加しない。成果の展示・確認・受取で通常学習へ割り込まない。

資格は本人の保存済み `completedSets`、詳細は本人の完了したplan/eventを根拠にする。正確な完了日付を復元できる時だけ表示し、古いデータの不明日を現在日時で埋めない。記録を確認できた範囲の教科・問題数・内容を表示し、再試行のeventを問題数へ二重加算しない。25回以下の節目はその節目まで最大25組、より大きな節目は該当区間のcanonical plan/event 1組を読む。1000区間の全走査を表示の前提にせず、部分的な問題履歴はその範囲を明示する。保存データが不足する場合は、確実な累計完了区間の事実のみ示す。

## 保存

IslandRecordのoptional `learningKeepsakes`（version 1、`displayed` ID配列）へ展示選択だけを保持。最大16件、重複なし、catalog順に正規化する。欠如は未展示として受理する。資格は保存済みcompletedSetsから検証する。既存transactionで所有profile・revision・資格を確認し、canonicalな操作receiptで再送を一度だけ反映する。未知保存結果の再試行を保持する。財布や学習writerを追加せず、通常回答は既存のspreadによってこの選択を保持する。

操作は `display { keepsakeId, displayed }` と `display-earned`。`['island-learning-keepsakes-v1', profileId, revision]` をキーに `learning_keepsakes_changed` receiptを保存する。active profileを検査した後、同じreceiptをCASより先に照合する。結果不明の旧操作を再送した場合は最新の島を返し、後の収納を取り消したり、その後に資格を得た品を自動で追加展示したりしない。保存schema・UserProfile・学習の採点と加算は変更しない。

現在の家の一角と新しい実写真には現在の展示を含める。既存の成長履歴/保存景色へ現在の賞を後付けせず、古い写真の画素を変えない。棚の展示が保存景色に含まれないことは景色保存/家のUIで短く明示する。

## 検証

資格境界、未取得の展示拒否、無料変更/収納、旧欠如、無効状態、別profile、競合、再送、通常学習後の保持、実記録のみの日付/問題数を単体とrepositoryで検証する。phone/tabletでは実際の初回3問と累計5区間の完了から賞状と最初のトロフィーを得て、展示/収納/再展示/再読込、家内の全体/一品近景、実写真、同じ予約の非最終回答を確認する。家タップ/補助ボタンから玄関を通る入口、実cameraが家内にあること、家内sectionの往復、お知らせなし/実おくりものあり、音off/reduced motionも照合する。16点の盛景は明示した別の診断fixtureとして配置と見切れを確認し、1000区間を実際に学習した証拠へ代えない。

島拡大時の地区ナビは[仕様30](30_living_island_growth_spec.md)に従う。普段の地区と全景を切り替え、家は島の大きさに関係なく同じ一品を読み取れる画角を保つ。視覚・理解/学習阻害・runtimeを別々に記録し、子どもの自発的再訪/意欲は観察なしでは未検証とする。

2026-09-09の固定23 app（`../../output/island-experience/workshop-snapshot-23/build-source.json`）（`ecdb5041e7c4`）とQAのみの修正版（`../../output/island-experience/keepsakes-qa-23-02/qa-source.json`）によるgenuine検証（`../../output/island-experience/keepsakes-23-02/report.json`）はphone/tabletでPASS。各幅で実初回3問から5区間24問を完了し、賞状と最初のトロフィーの無料展示/収納/再展示/再読込、実0件掲示板、家内の近景/全体、実写真PNGの保存/出力、同予約の非最終1問後の全islands保持を確認した。app/QAの前後hashは不変、ブラウザは終了済み。旧01のQA FAIL（`../../output/island-experience/keepsakes-23-01/report.json`）は変更せず、写真入口で画面の縦横比に合わせて変わるPerspective投影を扱う検査だけを修正した。全16品の実資格、実おくりものあり、実家の直接tapはこのrunの証拠へ含めない。固定23の正式80runは合格（自動keyboard固定問題、通常plannerや子どもの実速度とは区別）、art parityはHOLD、子どもの自発的再訪/意欲はHuman N=0で未検証。元のGoalは進行中で、全Goal完了を意味しない。
