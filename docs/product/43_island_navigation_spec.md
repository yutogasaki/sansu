# 島のタブと戻り先

2026-09-09、ユーザーがワイヤーの実装を指示。島を訪れる操作と学習を開始する操作を分ける。

## 通常画面

- 下部は「しま / まなぶ / きろく」。中央だけが学習を開始・再開するアクション。
- 「しま」は常に島の先頭を開く。未完了予約があるだけでは学習を表示しない。
- 設定は通常画面の右上から開く。設定の項目は個別の詳細画面として開き、「もどる」で一段上に戻る。
- 島、記録、設定、家具・写真等の一覧はタブを表示する。タブの移動は目的地の先頭へ戻す。

2026-09-09の比較後の実装指示に基づき、下部ナビの約60pxと44px以上の操作領域を保ち、ホームの任意操作を必要時に開く「しまのメニュー」へまとめる。島・学習・一覧・編集・思い出・管理の表示配分は[仕様44](44_display_layout_spec.md)に従う。全入口とこの仕様の学習・保存・復帰契約を維持する。

## 集中する画面

| 画面 | 下部タブ | 終了操作 |
|---|---|---|
| 学習 | 隠す | 「× とじる」で開始前の画面へ戻る |
| 家具配置 | 隠す | 「× とじる」で選択元へ。配置の保存成功後は島へ |
| 撮影・写真拡大・見学・入江の操作 | 隠す | 閉じると開く前の画面へ戻る |

学習は現在の画面に重ねて開き、元の詳細・選択・スクロール位置を保持する。同じプロフィールの学習を閉じて再開しても現在の問題と入力を保持する。入力下書きの保持は同じ起動中に限定し、確定回答・予約・SRS等の永続化契約は変更しない。

画面内の「もどる」は一段上、「とじる」は集中画面を開く前へ戻る。ブラウザ履歴も同じ遷移を使う。直接URLで戻る履歴がない場合は、学習は通常画面、写真は写真一覧、設定詳細は設定一覧へ戻す。閉じる操作で回答を記録しない。 発見の背景保存では通常の閲覧ナビを保ち、中央の学習開始だけ保存完了まで待つ。実際の学習開始・編集処理中は既存の全体ロックを維持する。

## 互換性と保存

トップの `/` は学習を開始・再開しない。Island有効時は `/island`、Island無効かつBuildPlay有効時は `/park` の作品画面、両方無効時は既存の `/battle` の探検基地を開く。旧active探索runがあっても起動先を変えない。プロフィールなしは各画面の認証境界から初回設定へ進む。設定のプロフィール切替・削除後と、初回設定済みでの再訪も同じトップを使う。未定義URLはトップへ戻し、トップや未定義URLに残った学習queryを引き継がない。PWAの起動URLも通常トップのままとする。

通常の `/study` と `?session=normal`、初回設定からの明示的な学習開始は維持する。学習中のURLには開始意図を残し、再読込で同じ予約へ戻れるようにする。復習・テスト等の指定範囲、明示的な `/explore` 開始は維持する。Island無効時の変更は上記のトップ起動先に限定する。

保存中は画面内の移動操作を無効にする。ブラウザ履歴の移動で保存完了前の内容を破棄せず、既存のPWA保存holdを維持する。見えない島で観察・音・操作を実行しない。プロフィール切替で他人の入力を引き継がない。

## 検証

未完了予約ありのトップ・島訪問、設定詳細から学習して終了、入力を残した再開、ブラウザ戻る・進む、直接URL、プロフィール切替、配置取消・確定、写真拡大から一覧への復帰を確認する。全配信モードで旧探索runがトップを学習へ送らないこと、既存の通常連問・支援・筆算・初回設定・PWA保存保護も回帰確認する。
