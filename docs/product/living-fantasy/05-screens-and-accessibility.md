# 05 画面・操作・言葉

[包括仕様51へ](../51_living_fantasy_island_spec.md)。次期の画面契約。既存URLは[43](../43_island_navigation_spec.md)を互換入口として保ち、新しい表示構成をこの章で定める。

## U-01 情報構造

常設の下部ナビは「しま・まなぶ・おもいで」の3つ。アイコンと文字を併記する。「まなぶ」を押して初めて既存plannerの予約を再開・作成する。島表示・家表示・写真の閲覧は学習開始にしない。

| 画面ID | 表示・主操作 | 入口と戻り先 |
|---|---|---|
| `island` | 庭、ぽこもこ、短い残高、つくる、見かた、メニュー | `#/island`。標準ホーム |
| `learn` | 既存の問題、入力、支援、途中状態、音 | 「まなぶ」。予約があれば同じslot、退出は島へ |
| `memories` | 見つけたこと・たいせつ・しゃしん | `#/island?view=memories`。下部「おもいで」。次期で追加するview |
| `house` | 現在の家内、展示、記念、任意チャレンジ | 庭の家とメニューの「いえ」。既存の家URLを保持 |
| `catalog` | 10品と実3D見本、価格、現在の姿／育った姿 | 「つくる」。閉じると同じ庭の視点 |
| `placement` | 無料の試し置き、回転、確定、取消、占有・通路表示 | 品または所有物の選択。保存後は対象を見せる |
| `object-detail` | 対象名、成長、関係、移動・収納・観察 | 実物タップ、または「あるもの」一覧 |
| `resident-detail` | 名前、今の行動、ぽこもこの行き先、おでかけ | 実住人タップ、または「ともだち」 |
| `discovery-detail` | 見た内容、今の庭で試す、当時の場面、保存 | 庭の気配か思い出。退出は呼出元 |
| `camera` | 実景プレビュー、撮影、保存、やめる | 島・家の「しゃしん」。撮影前の画角へ戻る |
| `island-menu` | いえ、あるもの、ともだち、ひろげる、しゃしん、せってい | 島上部の文字付きメニュー |
| `settings` | 音・動き・文字、プロフィール、保存、保護者入口 | メニュー→せってい。戻り先を保持 |
| `parent-records` | 既存の学習記録、単元、支援と独力、バックアップ | メニュー→「おうちの方へ」。既存保護者入口も保持 |

補助画面は既存の親route内のviewとして扱い、ブラウザBackと戻り先を一貫させる。2026-09-27の `App.tsx` / `domain/island/navigation.ts` を読んだ次の対応を次期の互換基準とする。実装時に追加済みpathがあれば差分をこの表へ追記して検証する。

| 既存path / query | 次期の意味・戻り先 |
|---|---|
| `/` / `/island` / `?view=home` | 島ホーム。学習予約があっても自動で開かない |
| `/island?learn=1` / `?start=learn` | 明示的な学習要求。同じ予約を再開。退出は学習queryを除いた島 |
| `/island?view=learning` だけ | 既存同様、学習開始要求として解釈しない |
| `/study` / `?session=normal` だけ | 現行同様、島有効時は明示学習要求へ。復習・scope・return等のqueryがある場合は元のStudy契約を保つ |
| `/island?view=keepsakes` | 家。`house=keepsakes`はまなびの記念、`house=notices`は既存のおしらせ。Backは家overview |
| `/island?view=album` / `photos` / `shared` | それぞれ既存アルバム、写真、本人保存の互換詳細。親入口はおもいで。旧sourceとIDを維持 |
| `/island?view=inventory` / `placement` / `furniture` / `play` | 所有物・配置・既存家具と遊びの対応画面。placementのBackは所有物。対象不明は一覧へ |
| `/island?view=camera` / `photos&photo=ID` | 撮影／指定写真。Backは写真、無効なIDは本人の写真一覧 |
| `/island?view=challenge` / `workshop` / `showcase` | 既存の任意チャレンジ・工作・展示を互換表示。新しい通常報酬と混ぜず、家からの入口を保つ |
| `/island?view=customization` / `expression` | 旧取得済みの外見・着替えの権利を維持。新しい無料の景色選択とは台帳を混ぜない |
| `/island?view=growth` / `experience` / `guide` / `help` | 指定された旧記録・説明があれば保持して表示。新規の説明は次期へ。過去を現在の成果にしない |
| `/island?view=reward` | 未処理の旧予約報酬があればその契約で一度だけ処理。対象なしなら島。新規の受取面として再利用しない |
| `/stats` | 学習記録。島の思い出へ置き換えない |
| `/settings` / `/settings/curriculum` / `/parents` | 既存の設定・教材・保護者機能。直接URLと保存契約維持 |
| `/onboarding` | 既存プロフィール設定。終了後はP-01の次期初期庭へ |
| `/explore` / `/battle` / `/battle/play` / `/park` | 既存の入口整理と転送を維持。島メニューへ再追加しない |
| `/nature-town` / `/dev` / `/__dev/*` | 現行の開発用flag・認証条件を維持。次期の通常導線へ出さない |

URLのprofile指定だけで他の本人の保存を開かない。既存の本人選択と認証境界を通す。未認識のviewは島へ戻し、未知queryを学習予約変更・取引確定として実行しない。

## U-02 通常画面と学習画面

島は上部に本人の島名、短いしずく表示、音、メニュー。下部は3タブ、その上に庭の「つくる・見かた」の小さな操作列。大きな説明カードと未発見件数を常設しない。残高の押下から品へ行ける場合はボタンとして意味を付ける。

学習画面は世界と同じ生成り・深い緑の文字・落ち着いた余白を使う。動く庭・精霊の気配・残高の点滅は背後に置かない。問題、回答欄、支援、音声が最優先。世界へ戻る操作は保存と入力途中を守る。正答・訂正のフィードバックは既存契約を維持し、庭の通貨表示に置き換えない。

家は外観と室内で同じ材質・窓の光・相棒を使う。既存の写真、記念、チャレンジ、工作の資格と入口はメニューから辿れる。次期の美術によって家の機能を隠さない。主ナビの「おもいで」を家からも使える。

## U-03 主フロー

| フロー | 必須の流れと終了条件 |
|---|---|
| 新規 | 既存プロフィール設定→初期庭→任意の無料遊び→本人が学習開始→正規完了→帰島。受取操作なし |
| 既存利用者 | 読込→移行前検証→保持結果→同じ庭。大きな変更の説明は一枚で後から読める。途中学習の再開を先に選べる |
| 購入 | 一覧→試す→価格と位置を確認→確定→保存完了→置いた現物。失敗は財布と所有の両方を元状態に保つ |
| 移動 | 現物選択→動かす→位置と通路を見る→確定→同じ所有IDで保存。取消は元位置 |
| 発見 | 通常の庭の現象→任意で近景→見た資格保存→任意でたいせつへ。学習へいつでも退出可能 |
| 招待 | 来訪準備→友達を見る→「いっしょに くらす」または閉じる→資格の保持。受取ノルマなし |
| 写真 | 撮影面→実frame撮影→確認→本人が保存→写真一覧。取消で画像を永続化しない |
| 再開 | 起動／プロフィール切替→本人の状態→学習は同じ予約、島は同じ配置・選択可能な視点 |

シートを重ねて深くしない。最大は主画面＋詳細シート＋一時確認の3層。閉じる・Back・Escapeは最上位から一段ずつ戻り、元の入口へfocusを返す。未確定の試し置きはBackで取消可能で、購入済みの削除を意味しない。

## U-04 全状態の扱い

| 状態 | 見せること | できること・保存契約 |
|---|---|---|
| 初期化中 | 生成りの軽い枠と「しまを よんでいるよ」 | 学習・設定入口をDOMで保ち、WebGL完了だけを待たせない |
| 3D素材の読込中 | 寸法と接点が合う簡略モデル | 必須形状が表示されてから購入確定を許す。別商品の絵で代用しない |
| しずく不足 | 現在残高と価格、「ためしてみる」 | 無料プレビュー、既存物の編集。追加学習の強制なし |
| 配置30個 | 「しまに おける ものが いっぱいだよ」 | 一つ収納してから試す。収納した物の所有・成長は残る |
| 思い出／写真が空 | 「みつけたことを ここに のこせるよ」 | 庭へ。架空の本人履歴を埋めない |
| 思い出／写真が満杯 | 保存予定と既存一覧 | 一件を本人が選んで削除または取消。無断置換なし |
| 通路なし | 使えない対象と塞いだ位置 | 配置は可能、直す・今はそのまま。架空の利用なし |
| 食料なし | 空の食卓と休憩動作 | 庭を遊べる。飢え・損失・住人退去を表示しない |
| ネットなし | 必要なときだけ「この たんまつで あそべるよ」 | キャッシュ済み学習・島・保存は継続。初回未取得素材は軽量表示 |
| 保存処理中 | 対象内の短い進行表示 | 同じ取引の連打を止める。他操作の移動意図は保持 |
| 保存失敗 | 保存できた範囲、再試行、取消可能な範囲 | 成功を先取りしない。学習の確定結果を巻き戻さない |
| 容量不足 | 「ほぞんする ばしょが たりないみたい」 | 保護者入口→書き出し・本人選択の写真整理。勝手な削除なし |
| 描画失敗／context lost | 保存済みの内容と再表示入口 | DOMの学習・思い出・設定へ行ける。白紙で閉じ込めない |
| 未対応WebGL | 静かな簡略表示と使える機能 | 学習・記録・バックアップ可。遊べない3D操作を有効に見せない |
| 保存形式が新しすぎる | 更新案内と現在データが保持されている旨 | 旧コードで書かない。対応版への更新・書き出し |
| 移行失敗／破損 | 保護者向けの対象と復旧方法 | 原本を維持し、診断書き出し・旧表示可能なら読取専用。リセットを主操作にしない |
| 別タブで編集 | 最新版へ追従する案内 | 競合編集は再プレビュー。別本人の状態へ混ざらない |
| 背景化・中断 | 復帰後、保存済みの同じ状態 | 進行中演出は再開・取消。未見を見た扱いにしない |

## U-05 操作寸法とアクセシビリティ

390×844と768×1024を主要構図とし、320px幅・横画面・文字200%にも横方向の必須スクロールなしで対応する。safe areaとソフトキーボードを避け、下部タブが確定・戻るを覆わない。

タップ対象は44×44 CSS px以上、主要確定は48px以上を目標。小さい3D物には実物の周囲で適切なhit領域を持たせるが、隣の物と重なる場合は候補名を選ばせる。長押しは補助操作で、必須操作はタップと文字付きメニューから実行できる。

本文16px以上を基本、補助14px未満を使わない。漢字には対象年齢に応じた読み補助を設け、数字や単位は既存教材表記を保つ。小さい丸文字を長文へ使わない。本文コントラスト4.5:1以上、操作境界・大きな文字3:1以上を実色で検査する。草や写真の上へ読めない本文を直接置かない。

canvasの全必須操作にDOMの代替を持つ。「あるもの」で名前・場所・状態を選べ、方向キーまたはボタンで移動・回転・確定ができる。tab順序は見える操作順、focus表示を消さない。画面切替時は見出しを知らせ、ARIA liveは保存結果など必要な一件だけ。環境の葉・粒子・住人の毎秒の位置を読み上げない。

色・音・動きのいずれか一つだけで状態を伝えない。動きを減らす・音OFFはOS設定と本人設定を反映する。演出を短縮しても報酬や発見を失わない。拡大すると文字と対象の対応が失われる場合はシートへ情報を移す。

## U-06 コピーの基準

| 場面 | 推奨文例 | 避ける意味 |
|---|---|---|
| 帰島 | 「おかえり。つぼみが ふくらんだよ」 | 休んだことへの責め、連続日数切れ |
| 学習で増えた | 「しずくが 6 ふえたよ」 | 支援完了を独力習得として褒める |
| 不足 | 「4しずくで えらべるよ」「ためしてみる」 | 「あと2問やらないと遊べない」 |
| 通路 | 「ここへは まだ いけないよ」 | 配置した子を失敗者にする |
| 気配 | 「水べに なにか いるみたい」 | 今すぐ開かないと逃す期限 |
| 土 | 「土が しっとりしてきたよ」 | 水分量を学力に読み替える |
| 保存失敗 | 「まだ ほぞんできていないよ。もういちど ためす？」 | 保存できたと見せる、子どもの操作を責める |

文章は短く具体的にする。赤色を学習能力の評価に使わない。成長・発見・購入ごとに大げさな賞賛を繰り返さず、起きた変化を伝える。保護者面では完了件数・独力・支援・日時を正確に示し、庭の美しさを学習評価にしない。
