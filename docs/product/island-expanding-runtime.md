# 広がり方で姿が変わる島 — 実装契約

2026-10-11。利用者「一気に実装」により、[三つの全島案](island-expansion-art-strategy.md)を本人の土地・配置から描く。くふう・にぎわい・ふしぎ・愛着に効き、柱・既得権・学習を弱めない。

## 床の契約

- 保存4、初期6×5、東西南の購入単位・価格・解放・所有セルを保持する。島タイプや乱数seedの追加をしない。
- native美術では、矩形の論理セルを、折り返さない連続した床へ写す。東西の床は前方へゆるく曲がり、中央に湾の抜けを作る。南の床は小さく左右へうねり、低い丘と庭が連なる。
- 写像と床高は絶対セル座標に基づき、土地の外側boundsや購入順で旧地区の形を再生成しない。初期の家・玄関・セル中心は従来位置を保持する。配信の切替に伴う拡張床の見た目の変化と、取得セルの消失を区別する。
- 全取得セルは陸の床を持つ。湾は床の連続写像と未所有の外周から描き、既得セルを水へ取り上げない。四角いセル数が保存上変わらなくても見た目の海岸線は変わる。
- 描画床・道・分数位置の足・実入口・配置hit・移動previewに同じ写像と逆写像を使う。上階の経路は同じ地面からの高さを保って写す。橋の歩行セルは陸の端から同じ実deckへ接続する。
- 地形は取得済みの材料や水源を増やさない。実通水8マス、実入口距離、論理到達、成長・利用・分離の規則を保持する。

## 所有物と視点

- native-05のkitを共用し、家・住人の原本meshを地形のために歪めない。足元の位置を写す。大きな共有形は実構成IDと成熟に対応させる。
- 大樹の列は枝と複数の冠が横へ続く姿、中庭は空洞と回廊、塊は共有樹冠で描く。列まで同じ一個の巨大冠にしない。
- カメラは変形後の実meshを全景に収め、物・住人のfocusへ戻れる。配置操作と実写真も同じ描画を使う。

## 配信と検証

候補IDを`native05-expanding-runtime-v2`、床写像を`curved-owned-v1`とする。DEV／明示した`VITE_NATIVE_GROWING_ART=true`で確認する。通常productionの既定falseを保ち、美術・独立理解／安全・runtimeを別判定にする。

16軒三案と32軒は明示診断保存で、実取得とは区別する。初期／拡張全セルと分数位置の実floor ray、逆写像、購入方向・順による旧床不変、実道・入口・回廊・橋・previewを検査する。固定productionで390／768幅の実回答・購入・移動・保存・offline・更新と、同じ診断所有からの実全景を確認する。kitの既存SHAと新候補のsource／dist／QAを対応させる。

実機性能・子どもの独立理解／再訪と公開は、この実装や合成所有の画面だけで合格にしない。
