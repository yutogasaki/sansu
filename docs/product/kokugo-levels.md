# 国語のレベル進行

2026-10-26の「国語もレベルにして」という依頼に基づく設計。**内容をまとめたLv1〜20を採用する。** 既存の単元別証拠から確認済みLvを読み取り、島の到達条件と国語の表示へ用いる。取り組む内容と確認済みを分け、新しい保存フィールドや独自の合格閾値は追加しない。

愛着とくふうに効く。できるようになった内容と次に取り組む内容が分かり、学習・アチーブメント・航海をつなげる。既存の単元ID、独力と支援の区別、作品、復習、記録は保持する。

## レベルの意味

[3教科の共通Lv1〜20](learning-levels.md)に合わせる。レベルは確認済み単元数を言い換えた数値ではなく、既存教材を内容のまとまりにした段階。学年や年齢によるロックは設けず、本人に合う範囲から取り組める。

「取り組むレベル」と「確認できたレベル」を分ける。初回や保護者の設定で選んだレベルは習得証拠ではない。各単元の正本の確認条件を満たした事実から、そのレベルの確認へ集約する。確認後に復習期限が来ても過去の達成と航路は取り消さない。

各段階は文字・語彙・文・読解の内容を細かく組み合わせた設計で、実測で校正された難易度ではない。各段階の分量と到達時間は教材拡充・児童観察で見直す。国語全体の完全習得、全配当漢字1,026字の筆記や全音訓の習得を、この41単元の確認で認定しない。

H06、E05、E06、E07、E08は自由活動。対応する内容帯で提示し、作品・活動のアチーブメントにできるが、提出や保存を独力の習得に変換しない。H06はLv9、E05はLv17、E06はLv19、E07はLv20、E08はLv1の活動として扱う。読書も活動として残す。

全配当漢字教材の読み・場面・筆記の記録は専用の評価境界を維持する。スターターの漢字単元だけで学年配当全体を確認したとは表示しない。

## 確認と次の範囲

1. 対象単元の評価対象・形式・要求様式を固定し、[国語コース](kokugo.md)の独力初答3件・異なる文脈群2件以上・単元別必須条件を満たす。
2. 一つの単元の一部形式だけから、対象の全形式が確認済みとは推測しない。各単元の必要な評価境界を列挙した集約器が実装の前提。
3. そのレベルの対象単元をすべて確認すると「LvNの内容を たしかめた」を記録する。未確認単元は具体名で示し、同じ単元の反復で別単元の条件を埋めない。
4. 後日の想起、既知例の復習、作品活動は、それぞれ現行の別記録を保持する。レベルのために期日や独力判定を変えない。
5. 次の内容を案内するが、未確認レベルの教材を閲覧・練習すること自体を禁止しない。

ポータルの解放表は「そのレベルの内容を確認済み」を入力にする。「Lv3を選んだ」と「Lv3を確認した」を混ぜない。数学・英語の進級テストを国語へそのままコピーしない。

通常開始では下位から積み上げる。上位から始める場合は「取り組みLv」と「確認済みLv」を別表示し、下位の単元や学年全体を一括習得扱いにしない。上位確認から下位のゲーム航路を認める規則は[島解放案](island-achievements-unlock-proposal.md)の利用資格であり、学習の下位確認を生成しない。

## 島の解放との接続案

旧案の「確認単元が1／3／6／10／16個」を廃し、国語はLv2／5／9／13／17の内容確認を後続五段階の仮条件にする。算数・英語との学力等価性や学習時間の等価性は主張せず、解放までの実時間で配信ペースを調整する。

このレベル設計の方針と、アチーブメントの特典・航路数値の採用は区別する。今回のポータルは設計シミュレーターであり、本人の学習記録を読み書きしない。

## 実装へ進む際の条件

- 教材ID・形式別の必要証拠を集約する純粋ロジックと検査。
- 現在の取り組み範囲、単元ごとの確認、レベル達成、後日の復習状態を混同しない表示。
- 上位開始・最高Lv・旧記録・証拠欠損・複数タブ・二重受取の扱い。
- 既存記録から確実な確認だけを導出する移行。存在しない過去の到達日や下位確認を補作しない。
- 01・国語・記録画面・保存・島の報酬・検証matrixを変更範囲に応じて同期する。

仕様とポータルの検証は、児童の理解、教育的適切さ、実装、公開の合格とは別に扱う。
