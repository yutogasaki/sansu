## 実装した体験

| 仕様 | 実装 | 実際の境界 |
|---|---|---|
| 通常の森/花庭 | ベンチ再割当による誤降格を修正し、実床の滞在先を追加 | 旧規則の席要件は保持。大木の既存有限部品も保持 |
| SG1 森の返事 | 選択した木まで本人が実経路を歩き、現在joinの最短距離順に葉/短い光/音が返る | 切断・環状を再計算。可視の最大48応答/最大96葉、900ms以内。成長・通行能力は変えない |
| SG2 水面の返事 | 実給水済みの水だけを最大8辺まで辿る短い波紋 | 乾いた水路・別成分には伝わらず、土/畑の水計算を進めない |
| 花への接触 | 本人が近づき、その花から短い返事 | 新色/報酬/記念の追加発行はしない |
| SG3 音の掛け合い | 演奏台の選択から「おとで おはなし」。近隣の実住人が別々の実床へ歩き、現場の本人へ触れた順に返す | 来訪待ち/船/保持中/遠方を演者にしない。音offは身振り。従来の曲を聴く「えんそうかい」も選べる |
| 住人の行動 | 到達・実床・空席の候補から好み/性格、新規、既知、散歩を40/25/20/15で選ぶ。直近3対象、実利用、短期予約 | 旧規則の保存は旧AIを保持。表示予算12人を人口上限へ読み替えない。学習/報酬の乱数と保存を変えない |
| 思い出 | 初成熟/初利用を既存履歴から系列/actorごとにまとめる。共同演奏は双方が触られ、前景/可視/現場の実参加が3秒重なった時だけ初共同をCAS保存 | raw revision/元群が変わっても再発行しない。編集・収納・別島往復で当時の事実を保持。あゆみから見返せる |
| 同素材の3島 | `prototypes/place-qa/experience.html` に同じGrowingWorldの比較。実domainの移動/収納/復元、触る、演奏を試せる | 開発専用・本人DBへの注入なし。38所有/96セル/4住人は診断条件で、取得実績ではない |

非表示・島切替・編集で短期の反応/演奏/重なりを破棄し、保存済みの思い出を保持する。同一対象の連打は進行中の返事へ合流する。音は同時3入力音に制限し、取消では予定済みの音も止める。動き軽減では葉を動かさず短い表示で返す。

## 大型の場所を本体へつなぐ追加実装

続く「いっきにいける？」では、普通の島の実所有から成立する大型形を拡張した。元のID・位置・色・家のstyle・成熟時計を保持し、新しい床や所有枠を発行しない。

| 形 | 今回の実装境界 |
|---|---|
| 木の長い回廊 | 4本以上の一直線・間隔1〜2セルの成熟木を繰り返し接続。必要な大木2本と実床の経路を要求。若木の追加では成熟済み部分を保持し、残りの普通の木も表示・選択できる |
| 中空の庭・有限の屋上 | 既存4主材の実空洞・実床・昇降経路を保持。任意の複雑な配置を新しい建築へ認定したものではない |
| 花の長いアーチ | 4輪以上の一直線を実接続ごとの支えへ変更。長くなるほど中央の高さや支持棒が巨大になる形を除き、各所有の花色を保持 |
| 家どうしの屋根 | 同じ列の成熟した2軒、間隔2〜4セルの空いた前庭に開いた屋根を架ける。元の家に支えを限定し、取得済み地面と到達・全身の高さを確認。第三の木/建物が占有した場合は普通の庭へ戻す |
| 場所を自分で使う | 主材の選択に「ここで すごす」を追加。本人が実経路で回廊・庭・水辺へ向かい、実際の利用後だけ既存の記録を保存。利用中・欠落・到達不可なら実行しない |

新しい繰り返しと家の屋根は普通の島の境界。別の作者地形へ未監査の建築を持ち込まない。診断用成熟配置と通常取得、美術採用、実機、子どもの理解は別々に扱う。新しい屋根の本体画面は作者の動作確認段階であり、benchmarkに対する美術合格ではない。検証の固定入力・結果・失敗は[大型形の追加検証](architecture-verification.json)に記録する。島対象114ファイル745件、型・lint・build/assets・docs・入口guardはPASS。390幅の共有屋根は実操作→歩行→利用保存とoffline再起動を確認した。長回廊は60秒以内に実利用記録を得られず、全景へ戻す画角修正の再検査でも未解決。花/中空の後続ケースと768幅は未実行。原因の確定や全旅程の合格をせず、実歩行・描画経過・receipt受理の切り分けを次の一手にする。
