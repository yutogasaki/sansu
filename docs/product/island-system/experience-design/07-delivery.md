# 制作単位と受入と残る判断

2026-10-20。詳細設計候補。[全体入口](README.md)。ここで定めるのは、完成像を実装へ落とす際の契約。今回の文書制作を、下記の実装/美術/実機/子どもの合格へ読み替えない。

## 1 現行と候補と将来制作を分ける

| 区分 | 対象 | 今回の結論 |
|---|---|---|
| 継承する現行 | 学習・報酬・時計・価格・入居・家成長・A/B・W・既得権・海図・保存境界 | 規則変更を提案しない。既存の正本を参照 |
| 採用した機能 | SG1〜3、好み/性格別利用、共同演奏の初回記憶、同素材3島比較 | 2026-10-20に親仕様01/52と保存13へ採用し本体へ実装。未採用の大型形と区別する |
| 候補初期値 | 行動割合40/25/20/15、直近3対象、群内重み2/1、共同利用3秒 | 確定値でなく、実際の偏り/意味/性能を検証して調整 |
| 修正した不整合 | ベンチの再割当による森/花の未成立への降格 | 通常の構造成立と任意席を分離済み。3島の論理診断を再検証 |
| 既知の正本差 | 旧JSONの材料条件とv0.4、記念品の旧10表記と実装13形 | 優先する規則を明記し、二重の購入条件を作らない。別途正本整理 |
| 将来美術/能力 | 中空幹・上階回廊・大花天蓋・共同屋根、地区のより大きい空間 | 対応する形/支持/床/入口/全身検査まで一体で制作 |

## 2 作品を小さくしない制作単位

最初に粗くても一つの全島の配置→成長→遊び→暮らしを組み、その所有セットを3全島へ組み替える。水だけ・席だけ・葉だけの局所合格を全体完成にしない。大きな空間の完成像を保ち、作業は独立して検証できる変更に分ける。

| 単位 | 作る結果 | 必要な確認 | 終了時に言えること |
|---|---|---|---|
| I0 設計の固定 | 今回の全品/関係/体験/例外/座標 | 台帳・リンク・現行との差の照合 | 詳細設計候補が追跡できる |
| I1 全島の粗い実体 | 元IDと成熟から4系列を含む所有島が描かれる | ベンチ不整合の解消、形/入口/実床/元個体選択 | 一つの全島の構造を試せる |
| I2 同じ素材の3全島 | 森回廊/共有集落/泉花庭の異なる空間 | 同じ素材/成熟/住人、通常移動/分離/再接続 | 配置の差が全島へ出る |
| I3 場所の遊びと暮らし | 場所ごとに意味の違うPoko操作と住人の行為 | 接近/利用/退出、空席、性格/好み/新旧対象 | 景色と実行動を一体に試せる |
| I4 通常取得と長期 | 初回→学習→購入→成熟→入居→拡張→帰島 | 経済/三時計/旧品/全保存/島切替/更新復旧 | 診断専用でない取得循環を確認 |
| I5 美術と独立観察 | native-05の魅力と本人の所有の因果が両立 | 実画面比較、実機、説明なしの理解と自発再訪 | 合格した対象/条件に限る体験評価 |

既存の入り江R2の美術HOLDやR3の採用待ちを、この文書でGOへ変更しない。通常配布flag、公開、commit/pushも今回の設計作業には含めない。

## 3 七つの独立した合否

| ID | 評価 | 合格として観測すること | 不合格になる具体例 |
|---|---|---|---|
| G1 | 設計の網羅性 | 全品/旧品/全25体験/8愛着領域、4系列12形、全11組、時計/土地/別島/回復に行先がある | 行先のない旧品、出典のない数値、候補を現行と記載 |
| G2 | 同じ素材の全島 | 同一ID/成熟/時計/土地/住人で輪郭/経路/行為/利用先が違う3案 | 背景色だけ違う、席の競合で成熟場所が降格 |
| G3 | 美術と空間 | 本人の所有物が主景。全景/地区/内部の縮尺、入口と余白が読める | 背景の巨木だけ豪華、本人の小物が埋もれる、入口が見えない |
| G4 | 予告と確定 | 同じ入力の形/水/到達/床が同じ計算結果で、取消で正しく戻る | 予告でだけ通れる、確定後に別の対象が濡れる |
| G5 | 実利用と保存 | 実actorが接近→使う→退出し、受領と元所有/履歴が保存後も整合 | 架空利用、上階から落下、同じ記念の再発行、旧writerの破壊 |
| G6 | 説明なしの理解 | 子どもが配置の違いを予想し、自分の言葉/操作で原因と回復を示す | 長い帳面や大人の誘導なしでは操作も違いも不明 |
| G7 | 自発的な継続 | 自分でまなぶを選び、翌日も戻り、遊ぶ/眺める/作るを選ぶ | 義務/困り顔/受取だけで戻る。技術検査で面白さを代用 |

G6/G7は対象年齢、自然な利用状況、誘導の有無、観察日時を記録する。対象が未定のまま成功率やNを捏造しない。配置を残す子、人口を増やさない子も対象にする。憲法の最終基準は自発的学習と翌日の再訪であり、この表はその代替基準を新設するものではない。

## 5 八つの遊びの行き詰まり

| 困る状況 | 子どもが直せること | 実装で必要なこと |
|---|---|---|
| 空き地がない | 収納、無料再配置、入口を空ける。拡張は任意 | 追加床と今の占有を同じ予告で示す |
| 自生が邪魔 | 摘む、別の物へ置き換える | 自生と購入株を区別。恒久占有しない |
| 交配/自生の上限 | 今の株で庭を作る、任意の整理/土地拡張 | 25%は交配生成時の全花総数、40%はwild総数。購入花の配置上限と誤表示しない |
| 同じ住人ばかり | 個体の名前/色/性格を楽しむ、別の本人へfocus | 船の固定候補と描画の偏りを分離。気に入らない住人の追放を進行手段にしない |
| 好きな場所を崩した | 無料で並べ直す、元の個体で新しい場所を作る | 分離の予告、過去の記録、年齢を保護。未実装の一括Undoを約束しない |
| 新島の無料品が多い | 別の構想として使い分ける | 島別の非換金/非移送と共通受領を保持。既存島へ没収や新規制を足さない |
| 重くて触れない | 地区/個体へ寄る、戻る/取消する | 差分再計算、予約/receiptだけで全worldを再構築しない。実機で測る |
| 一週間しても変化がない | 現在の条件を見て形/目的を変える、今の庭で遊ぶ | 時計/到達/成熟不足を事実で示す。成長を捏造せず、学習催促にしない |

## 6 未解決の判断を閉じる条件

| ID | 判断 | 初期方針と閉じるための証拠 |
|---|---|---|
| QX01 | 行為が散歩/着座の反復で飽きないか | 3全島で同じ入力の経路/行為/見える結果が異なることを実画面と子どもの選択で確認。名前の言い換えでは不可 |
| QX02 | 大型部品の実寸/干渉 | 能力表・支持・全身マージン・実床を測り、非対応形は通常形。未測定値を固定しない |
| QX03 | 行動割合/最近3対象 | 同じ配置で全員集中/永久固着を起こさず、個性が読めることを実行動で比較 |
| QX04 | 共同利用の意味 | 3秒の重なりに加え、同じ活動領域と見える参加が伝わるか。近くで別々にいるだけを「一緒に遊んだ」と記録しない |
| QX05 | 思い出が増えすぎるか | 自動初回は系列単位、全NPCペアを記録しない。任意写真と既存履歴を保持し、保存容量を測る |
| QX06 | pendingの対象消失 | 実所有IDで追従、存在しない旧座標では描かない。未表示結果を没収せず、安全に再配置できる提示契約を採用時に規定 |
| QX07 | 自然の分布と上限 | 既存の親増加/安定ID順/収納を含む上限で、30日分布と入口保護を比較。増える速さを旧方式と同じと呼ばない |
| QX08 | 物量と性能 | 38個だけでなく16/32軒等の既存基準と実機で計測。所有削除や架空群衆で軽くしない |
| QX09 | 導入と経済 | 初期0しずく、無料家、既存bank、短い学習量での通常旅程を確認。38個を初週の必須セットにしない |
| QX10 | 無説明理解と継続 | 年齢/観察条件を定め、自発的な学習と翌日再訪を実観察。作者/AIの同意で閉じない |

## 7 今回の検証と文書同期

詳細設計作成時の変更分類は設計候補の追加で、文書だけを検証した。続く2026-10-20の実装では、SG1〜3・住人行動・共同演奏記憶・3島比較を採用し、親仕様01/52、保存13、ADRを先に改訂した。[実装と検証](implementation.md)。憲法、通常配布flag、美術の採用判定は保持する。未採用の大型形を製品ルールとして扱わない。

文書の必須確認は`npm run docs:check`と読合せ。座標診断は別に実施し、対象を限定したPARTIALの結果を保持する。アプリのlint/typecheck/全unit/build/E2Eを、文書だけの変更から実行済みとは主張しない。実装するときは[変更別matrix](../../../ai/verification_matrix.md)と対応runbookの全必須条件を適用する。
