# 置くものと愛着の全台帳

2026-10-20。全体体験の詳細設計候補。[全体入口](README.md)。現行の取得・所有はv0.4を継承し、この台帳を理由に価格・供給・取得資格を変更しない。O/Hは設計上の追跡IDであり保存IDではない。

## 各品を置く理由

「育成に効く」「そこで遊ぶ」「自分らしくする」「思い出を残す」は、それぞれ存在理由になる。全品に成長倍率を付けない。基本素材には、配置による空間・環境・利用の違いを持たせる。歴史的な採用の経緯が不明な品は、今の機能から役割を整理する。

Aは初期、Bは初入居後。継続品の旧解放は保持する。所有済みなら資格に関係なく再配置できる。新規購入終了は既存の現物を廃止する意味ではない。

### 家の中にある既存の遊びと学びの痕跡

家は島で育てた日々と学んだことを残す場所。[52 §13](../../52_growing_island_game_spec.md#131-ぽこもこの-いえ学んだもので-もようがえ2026-10-01)の細目も全体へ引き継ぐ。新しい室内商店や島と別の育成通貨は作らない。

| 対象 | 入力と結果 | 継承する条件と境界 |
|---|---|---|
| 単語の壁紙 | 覚えた単語が決まった位置の水玉になる。触ると英語/日本語と読み上げ | 独力の語彙事実を使う。部屋で再テストしない。8色のまとまりと表示/非表示の自由を維持 |
| 算数の模様 | 水玉、ブロック、時計の輪、星、ケーキを選ぶ | 既存の主レベル対応0/8/13/19/21を継承し、訪問日数や購入数へ置換しない |
| 英語の模様 | 頭文字のアルファベットとハート | 既存の英語Lv3/Lv6の条件を保持 |
| ラグ/色のまとまり | 好きな配色へ無料で変更 | 回数で能力や学習到達を増やさない |
| 手紙 | 入居/家の最終成長/記念品/きょうだいの花から生成。触ると読む | 元事実から導出し、読んだ印と区別。ポストの購入を必須にしない |
| 室内の仲間 | その日に遊びに来た既存住人1〜3人へ触る | 日内の顔ぶれ、おでかけ除外等の現行契約。新しい架空住人を増やさない |
| 窓と机 | 窓から最新写真を見る。その日の独力単元/単語カードから学ぶ | 写真と学習の既存事実。カードから通常の学習予約へ進む |
| なぞって飾る | 覚えた単語の頭文字3つ/数字1つから選び、文字の6割をなぞると旗へ飾れる | 採点なし、描き直し可。島の学習資格/SRSへ結果を戻さない |
| 島カードの枠 | 水玉/ブロック/星/シンプルを選ぶ | 元の記念と資格を保持。外部送信は別の依頼 |

ここは既存仕様の役割を追う範囲で、今回全ての室内画面を動作確認したという意味ではない。新しい場所内の遊びが増えても、家に残る本人の学習事実と自由な表現を削らない。

## 網羅範囲

O01〜O32、O33a〜h、O34a〜e、O35a〜e、H01〜H08を列挙した。継続購入の15めじるし、家/畑、購入不可の記念、旧6品、さらに古い5品、常設物を分けている。アイテム同士の専用合成を総当たりで追加する台帳ではない。作用は[共通規則と空間](02-space.md)へ、遊びは[全体験](05-experiences.md)へ追う。
