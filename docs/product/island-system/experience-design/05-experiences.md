## 2 画面の行き来

下部は「しま/いえ/まなぶ/きろく/設定」の既存5タブを維持する。島は3D世界を主面にし、小さい操作を重ねる。[44の画面契約](../../44_display_layout_spec.md)に従い、世界を常設の大パネルで分割しない。

| 目的 | 入口 | 確定の境界 | 戻る場所 |
|---|---|---|---|
| 遊ぶ/使う | 世界の本人/住人/対象 | 実前提を満たし行為開始 | 同じ場所と画角 |
| 新しく置く | しまに おく→あたらしく おく | 価格/資格/床を再検査し明示確定 | 置いた場所 |
| 持ち物を使う | もちもの | 元所有の再配置だけ。再購入しない | 同じ島 |
| 場所を知る | そだつ場所/世界の場所 | 任意目標。選んだだけで所有や成長は増えない | 該当する実場所 |
| 住人に会う | 実住人/なかま | 命名や既存の装いを確定 | 本人が見える場合は本人、表示外なら本人の家 |
| 島を見る | ながめ | 回転/近景/全景。購入と別 | 同じ島の表示 |
| 広げる | ひろげる | 方向・価格・追加床を見て確定 | 元の庭と追加床が見える島 |
| 家で過ごす | いえ | 現行室内機能の保存境界 | 同じ島の家 |
| 残す/振返る | メニューの写真/花図鑑、きろくの該当入口 | 写真保存/既存記録。全履歴を一律移設しない | 元の場所/島。対象がなければ全景 |
| 学ぶ | まなぶ | 既存の回答/予約/完了transaction | 開始元の島と正当な最新状態 |
| 別島 | メニュー→海図と ふね | 退避/復元の同一transaction完了 | 選んだ島 |

### 次の行動の発見

候補は現在の対象とその場の根拠に結び付ける。例：「みずが とどいているよ」は現在通水、「ここを あるけるよ」は実経路、「こっちに ならべると？」は取消可能な同じ計算の予告がある場合だけ。持っていない素材や未来の冠を現在の所有のように表示しない。

常設の全条件説明を減らし、まず変わる対象を短く示す。詳細は本人が開ける。次の行為を毎回指示しない。未選択/所有0件/残高0/目標未選択でも、入口と閉じる操作を残す。

### 画面状態の競合

| 状況 | 優先する処理 |
|---|---|
| 対象操作中にカメラを開く | 二つを同時に重ねず既存の排他を守る |
| 配置予告中に別物を触る | 確定/取消の境界を曖昧にしない。取消後に次対象 |
| 保存失敗 | 編集内容と明示再試行を残す。成功した画面へ先に戻さない |
| 複数の成長/出来事/案内 | 主役を一つに絞る。実保存済みの事実を保持し、連続モーダル消化を強制しない |
| 島切替/本人切替 | 開いていた編集・名前入力・古い対象を閉じ、対象IDを照合 |
| 初期読込/WebGL失敗 | 読込/失敗/再試行を区別。別の島や保存初期化へ誘導しない |
| 小画面/短い横画面 | 閉じる操作を内部スクロールから分離し、世界と主要対象を残す |
| 音off/reduced motion | 流れ/空席/現在状態を色や音だけで伝えない。説明可能な形と短い文字を持つ |

## 3 ふしぎの三層

| 層 | 起き方 | 子どもの予想 | 体験の役割 |
|---|---|---|---|
| 育つ空間 | 既存の接続/成熟/実床の決定的な結果 | 列なら道、空ければ内庭を作れそう | 自分の工夫への確かな見返り |
| 小発見 | 花色/自然/実際の暮らしの変化 | この色を近づけたら、あの子はどこを使うか | 次の構想のきっかけ |
| 珍しい来訪 | 実環境と固定された日判定の確率 | 水と灯りの場所に何か来るかも | 全部は予想できない驚き |

### 花11色と全交配

基本4色＝赤/黄/白/青。混色6色＝オレンジ/ピンク/紫/水色/クリーム/ミント。特別1色＝ふしぎな水玉。

| 親 | 子 | 親 | 子 | 親 | 子 |
|---|---|---|---|---|---|
| 赤＋黄 | オレンジ | 赤＋白 | ピンク | 赤＋青 | 紫 |
| 青＋白 | 水色 | 黄＋白 | クリーム | 黄＋青 | ミント |
| オレンジ＋紫 | 水玉 | ピンク＋水色 | 水玉 | クリーム＋ミント | 水玉 |

現行の24自然時間境界・40%を継承。開花した異色親を距離2以内、生成できる空地に置き、花総数は取得セル25%までを判定する。現コードの生成先は、両親に隣接する空地があれば優先し、なければどちらかの隣を使う。「必ず二株の真ん中」とは案内しない。親IDを消費せず、新色の登録と現物を保持する。

自生は別規則。木/花/旧wildの成熟した親、隣の空地、湿り0.35以上、12自然時間境界・50%、wild総数は土地40%まで。自生wildを交配用の購入花へ昇格させない。

### 実日の出来事と客の全候補

下は現在の[moments.ts](../../../../src/domain/growingIsland/moments.ts)の候補条件。条件を満たしても、その日に必ず選ばれるわけではない。

| 候補 | 現行の条件 | 全体体験での意味 |
|---|---|---|
| 虹 | 土の平均湿り0.42以上 | 島全体の水/土の変化に気づく |
| ちょうちょ | 開花6以上（対象とする旧wildの花を含む） | 花の景色に出会う |
| なかよしが並ぶ | 共通の好みを持つ実住人の家が距離2以内等 | 人口の捏造をしない二人の出来事 |
| みなものたびどり | 水ばちの距離2以内に灯りと開花 | 灯りと花のある水辺へ来る客 |
| こもれびのおきゃく | 成熟木の距離2以内に到達するベンチ、開花2 | 木陰に作った居場所へ来る客 |
| くじら | 水ばち/噴水が計2以上、または灯台 | 海側の大きな驚き |
| にじいろのとり | 花図鑑5色以上 | 配色の発見の積重ね |
| つきのうさぎ | 灯り/灯台が計3以上 | 灯りを置いた島の驚き |

日判定は60%の出来事抽選と、その候補へ珍しい客を含める30%の別判定。各客が18%で来る意味ではない。学習や町時間から日を作らず、参加からの実24時間区切りで判定する。未表示のpendingを保持し、留守の日数分を一括抽選しない。

夜の灯り2つ以上等で出る流れ星は、景色の一時演出と区別する。記録/取得の新条件として一般化しない。珍しい常住住人の船抽選と、一晩の客と、光る個体色も別である。

### 予想から次の創作まで

1. 森：列にしたら道になりそう→同じ木を並べる→成熟した地上の木陰が連なる→実利用を残す→森の先に泉を作る。
2. 花：赤と黄を寄せたら別色が出るかも→開花親と空地を用意→境界で成功した場合オレンジ→図鑑と現物→次は色帯/中庭へ。
3. 客：水と灯りの花庭に何か来るかも→実条件を整える→日判定で候補となり選ばれれば来訪→実際の出来事を記録→別の環境も作ってみる。

条件を消しても過去の発見は残す。pendingを現在のどこで安全に表示するか、移動済み対象への追従、条件が消えた客の観察記録は[未解決の設計判断](07-delivery.md)で扱う。取得済みと未表示と未発生を混ぜない。

## 4 Wと学習記念と体験記憶を区別する

W1=初入居、W2=有料通常建築の初完成、W3=開始後に未成熟から成熟した木/花の保存事実、W4=初土地。各島各枠一度。初期満開はW3にしない。旧Lv由来と新達成理由、根拠不足の保護者復元は[既存の詳細規則](../growth-rules.md)へ従う。

独力学習の記念は主レベル/教科と共通受領。将来の共同体験記憶は実出来事。どれも同じ「星のポイント」に合算しない。新島・再接続・再演・写真の見返しから再発行しない。
