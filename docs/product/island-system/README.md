2026-10-19。**育成規則v0.4を実装対象として採用。実装前の台帳・採用規則・実装後の関係を分けて読む入口。** [実装と検証](../../tasks/active/2026-10-19-island-growth-v04.md)

ぽこもこと自分の島を育てる。置いた物の位置・つながり・成熟が景色と暮らしを変え、住人と使う場所が増える。学習を選ぶと材料とまち時間が届き、自然は実時間で育つ。昔の場所を残しながら土地を広げ、別の島では同じ規則で違う構想を試す。

**現行の遊びの正本は[52](../52_growing_island_game_spec.md)、場所の規則は[場所目標](../island-place-goals.md)と[初期値](../island-place-goals.json)、複数島は[海図](../island-voyages.md)。** 本マップの追加だけで、それらを置き換えない。v0.4の採用は該当正本・保存契約・ADRへ反映済み。今後の規則変更でも同じ正本を更新する。

効く柱は、配置で原因と結果を試す「くふう」、実在する住人と使う場所が増える「にぎわい」、条件付きの出会いである「ふしぎ」、所有と履歴が続く「愛着」。v0.4では商品を順に解放する楽しみとのトレードオフを採用判断に含めた。配置の違いを試す深さと子どもの再訪は引き続き実測する。

## 全体を読む順

1. 現行マップの総覧で、学習・自然・暮らしの時間を分ける。
2. 品のIDから、関係台帳と場所P01〜P06へ進む。
3. 個体・場所・地区・島・別島の階層と、遊ぶ体験を確認する。
4. 次期案の対応表で、残すものと変えるものを確認する。

IDはこのマップ内の参照用。Oは物、Rは関係、Pは既存の場所目標、Cは既存の場所間関係、Eは体験、Dは次期の判断、Qは残課題を表す。P/C以外を保存IDとして使わない。組み合わせ台帳は**規則の全範囲**を扱い、全座標の配置を列挙するものではない。

## 地図の読み違いを避ける

- 矢印に「必要」「影響」「選択」「記録」を書き分ける。隣に描かれたものすべてが合体するわけではない。
- 見た目・通行・供給容量・入居・履歴を分ける。大樹や泉が大きく見えても土地の権利や人口枠は増えない。
- 今の配置から計算する場所と、一度取得した成長・所有・記念を分ける。動かすと形は変わるが、育てた個体を失わない。
- 仕様の採用、コードの存在、対象検証、美術の評価、公開、子どもの理解と再訪は別の状態。[native-05](../../design/2026-10-10-island-final-3d/README.md)は到達美術の模型で、通常画面の完成を証明しない。
