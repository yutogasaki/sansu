# 教材の意味・種類・導入の整合性

親仕様は[01](01_app_spec.md)。2026-10-01の[教材監査](../audits/2026-10-01-learning-content/README.md)C01〜C12の修正契約。理解して進める学習が島の愛着と継続を支える。島の成長・取得済みの権利・進度を弱めない。

## 英語

既存1,184項目のID・所属・採用訳を維持し、例文を採用語義・品詞に合わせる。文字列が違っても同じ意味になる許容訳や同義語を誤答候補から除外する。同義グループ・日本語ラベルの正規化・文脈を問わず曖昧な禁止ペアを使い、クールダウンを緩めても適用する。例文の訂正から旧回答の語義理解を推定しない。

20レベルは既存教材の進度であり、校正済み難度・学年・検定合格の証明ではない。properlyの同義再登場は保存項目を維持するが、異なる語義の総数に重複計上しない。訳語認識と聞く・話す・書くの技能を区別する。

## 算数の数範囲・種類

- `add_1d_1`とbridge: 導入後はa=1〜9、b=1〜3、和≤12。導入は和2〜6へ進むが、導入終了後に和≤5だけへ縮小しない。
- 平均: 3〜5個の非対称な数列を順番も変えて生成。整数の平均と小数第1位の平均を区別する。導入の対称例だけでは代表証拠にしない。
- 2桁÷2桁: 商1は導入として残す。通常の広い範囲では商1を20%、商2〜9を80%の目安とし、被除数も除数も2桁に保つ。
- 分数比較: 同分母、同分子、等値、分子分母とも違う不等値の4型を持つ。一般型の双方の分数は真分数で、等値・同分子・同分母へ退化させない。

## 内容から決まる型と保存互換

算数の型は答え・式・生成内容から検証して記録する。九九は各段、百分率は割合/部分、速さは距離/速さ/時間、10の倍は×10/×100/÷10、万/億、分数比較4型、平均の整数/小数、2桁÷2桁の商1/複数を区別する。通常練習では型を循環させ、仕上げ20問にも各必要型を少なくとも1問含める。現在範囲の資格は各型の異なる3問を同じ方法で独力正解した証拠で確認する。

旧defaultの記録・保存済み予約は保持し、特定の新しい型の証拠へ読み替えない。旧文脈の既知性と新しい型の達成を分ける。旧予約の答え・座標・問題を生成し直さない。取得済みレベルは下げない。

## 基礎の9教材

118既存スキルと29レベルの所属は維持する。次の9教材は追加の短い導入であり、レベルの新しい必須関門にしない。独力正解の記録は専用IDに保持し、通常のレベル資格20問・仕上げの計算coverageを水増ししない。

| ID | 概念 | 開始Lv |
|---|---|---:|
| foundation_tens | 10と1のまとまり | 11 |
| foundation_expanded | 100以上の位 | 12 |
| foundation_groups | 等しい集まりと掛け算 | 13 |
| foundation_division | 等分除・包含除 | 16 |
| foundation_decimal | 小数の量と位・比較・10倍 | 19 |
| foundation_fraction | 等分された全体と分数の量・比較 | 21 |
| foundation_equivalence | 等しい分数・約分・通分 | 21 |
| foundation_mixed | 整数と分数を合わせた量 | 22 |
| foundation_rate | 1あたりの量 | 26 |

通常の計算候補を選んだ後、初めての関連概念に足りない導入を先に出す。3回の独力正解で通常の計算へ進む。既に関連計算を3回以上独力で解いている子は初回の導入に一律戻さない（基礎を習得したと認定する意味ではない）。直近の誤答・支援後は基礎へ戻れる。期限復習・明示的な無効設定・当日停止・同一区間の上限を守る。9教材がないままplanned前提を必須ロックへ変更しない。

導入は出題可能なときの優先候補とする。導入の停止・クールダウン・区間上限に当たったら、通常の計算を使ってセッションを続けられる。導入の完了で全基礎の習得を認定しない。時間制限のBattleには導入を混ぜない。

同一区間の予約では独力正解数と区間内の予約数から導入の段階を回す。凍結したプロフィールで同じ段階を2問作り、次区間で比較などの中間段階を飛ばさない。これは提示の順序であり、各段階の習得証拠を合算して全基礎の達成を認定する機能ではない。

小数比較Lv25、分数比較Lv26、10倍Lv24は保存上そのまま。各計算前の導入教材でも量・比較・10の倍を経験できるようにする。

## 表示と範囲説明

数える/数の次/最小を選ぶなど実際に答える行為を表示名にする。レベルの教材数、概念数、表現・問題の型を混同しない。算数は四則・小数・分数を中心に、幼児の数量・形・空間・比較と割合・平均・比・速さの限定した問題を含む。学校算数全体や公文教材への適合認定とは区別する。

教育的な難度校正・保持・子どもの自発的継続の実証は別の評価であり、テストPASSをその代わりにしない。
