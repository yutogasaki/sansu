# 仕様書の地図（人向け）

このページは、仕様書を「番号順」ではなく「何の話か」と「今どう扱うか」で探すための入口です。
仕様の内容を決める正本は各リンク先であり、このページは案内役です。

## 最初に知っておくこと

- アプリ全体の約束は[親仕様01](01_app_spec.md)。迷ったら最初に読む。
- 現在の標準画面は「ぽこもこと不思議な島」。通常起動は不思議な島で、旧探索モード（Explore）は任意の別モード。
- 「仕様がある」ことと「実装済み・公開済み」は同じではない。進み具合は[現在のタスク](../../.agents/tasks/TASKS.md)で確認する。
- 番号は作成順に近く、重要度や新しさの順ではない。同じ番号46の文書が2つあるため、番号だけで呼ばない。
- 今の島とNature Townの関係は[統合方針](island-nature-integration.md)。別々の作品としては進めない。

それ以外は、特定の機能を直すときに必要な詳細資料です。最初からすべてを読む必要はありません。

## 大きな区分

| 区分 | 具体例 | 扱い |
|---|---|---|
| 今使うもの | 学習、不思議な島、家、写真、記録 | 現在のアプリを決める |
| 改善中のもの | 不思議な島 v3、家と島の統合、自然と町の仕組みの統合 | 一部実装済み。統合方針の採用と実装完了は別。現在地はタスクで確認する |
| 比較用の試作 | 家から店への接続試作 | 今のアプリへつなぐための比較用。別作品として仕上げない |
| 昔のもの | Nature Townの別画面、旧探索、旧遊園地、以前のホーム | [過去の資料](archive/README.md)から参照。今の標準画面を決める根拠にはしない |
| まだ決めていないもの | 再設計案、未決事項 | 確定仕様として実装しない |

## 位置づけの読み方

| 表示 | 意味 |
|---|---|
| 現行の正本 | 今のアプリの挙動を決める文書 |
| 採用済み仕様 | 方針として採用済み。実装・検証・公開の完了は別に確認する |
| 旧モードの正本 | 今も残る旧機能のルール。標準画面の根拠にはしない |
| 開発用試作 | 比較や検証のため、開発版だけで動かす機能。本番の挙動とは分ける |
| 次期案 | 将来候補。現在の実装を説明する文書ではない |
| 提案・未決 | 採用前の案や判断待ち。確定仕様として実装しない |
