### 初期実装の境界 — 2026-09-27

`VITE_ISLAND_FANTASY_ENABLED=true` で候補 `living-fantasy-garden-v2` を選ぶ。Three.jsの地形・枝葉・家・相棒、本人ごとの昼/夕/夜、通常の庭の水タッチ、実表示に基づく思い出と同じ庭の再演を実装した。`npm run dev:island-fantasy` は専用port 5230を使う。通常の入口と公開設定をこの候補へ自動切替しない。[実装タスク](../tasks/active/2026-09-27-living-fantasy-first-playable.md)が継続範囲を持ち、[実画面と検査記録](../design/2026-09-27-living-fantasy-first-playable/README.md)で今回の到達点を確認できる。

この段階は**既存のLife v20の保存・経済・住人・発見規則へ新しい表現を接続する実装**である。学習によるしずく、購入と配置、既存の住人利用・食料・土・水路を継続する。水の星は既存M4の到達距離4以内を使い、F-D03の新規則への移行済みとはしない。時間帯は表示だけに使い、財布・成長・発見条件を変えない。発見snapshotへ `gardenTime` を任意項目として保存し、既存snapshotのhash・原本を変更しない。新しい水の思い出は当時の庭・時間帯で開き、再演の実表示は `replay` として記録する。

初期セット、一通貨化、新しい成長式・住人招待・発見/精霊、3タブへの統合、全保存の移行・復旧・写真/共有は、以下のv1契約に従う次段階。初期候補の動作検査をv1全体や公開の合格と読み替えない。

## 1. 作る体験

> **ぽこもこと、小さな世界を育てる。育てた場所には暮らしが生まれ、ときどき、その場所だけの不思議が見つかる。**

算数・英語の練習を、自分で選んだ庭の変化と結び付ける家庭用PWA。主対象は現在の教材を使う子どもとその保護者。読みの発達や操作経験に幅があることを前提に、文字だけ・音だけ・ドラッグだけを必須にしない。庭の操作を学習能力の判定に使わない。

子どもにとっての価値は、前に育てていた物を確かめること、配置を変えて試すこと、相棒に会うこと、自分の場所の思い出が残ること。保護者にとっての価値は、自分から学習と遊びを往復できることと、正確な学習記録が残ること。継続率や学習効果の改善は検証する仮説であり、現時点の実証結果ではない。

## 2. 今回決めること

| 項目 | 次期仕様の決定 |
|---|---|
| 世界観 | 大きな枝葉に包まれた小さな家と庭。親しみのある暮らしに、場所に結び付く不思議が現れる |
| 美術 | 絵本のような柔らかな立体。草・木・生成りを基調に、青緑の陰と琥珀の灯り。昼にも魅力がある |
| 相棒 | 既存のぽこもこの顔・頭身・耳・布・配色を維持。説明係より、一緒に気付く相棒 |
| 遊び | 植物・水・灯り・休む物を自由配置し、住人が使う「居場所」を育てる |
| 学習連携 | 通常の有効な問題完了1件で2しずく。支援完了と独力習得は区別。獲得の受取操作なし |
| 成長 | 植えた後は時間と環境。直近の学習件数による成長倍率を次期境界以降で廃止 |

| 時間 | 成長時計と景色の時間を分離。景色は端末の時刻で朝・昼・夕ぐれ・夜へ自動切替（仕様52 §2）。夜の利用を要求しない |
| 記録 | 見た出来事・本人が保存した思い出・写真を一つの入口から扱い、実体と出典を区別 |

| 表現技術 | 造形した地形と自由配置の3D。既存のReact / Three.js / ローカル保存を土台にする |
| 保存 | 現在の学習・所有・配置・写真・履歴を保持。既存Lifeから検証済み境界で移行 |
| 共有 | v1は本人操作による画像保存。URL共有・応援・予定イベントは後続仕様として境界を定義 |

## 5. 一周の標準体験

1. 島を開くと、家・ぽこもこ・最初の植物がある。無料で眺め、移動し、置き直せる。
2. 本人が「まなぶ」を選ぶ。既存plannerの同じ予約を進める。島の演出で回答を止めない。
3. 帰島時、保存済みのしずく増加を短く示す。材料を選ばず眺めることもできる。
4. 水・植物・ベンチなどを選び、置く。葉の向きや水のつながりがすぐ返事をする。
5. 時間がたつと植物が育ち、住人がその場所を使う。休んでいた日数を責めない。
6. いつもの場所に小さな不思議が現れる。気付いた子が近づき、何度でも試せる。
7. 気に入れば思い出や写真に残す。遊びを続けても、同じ学習へ戻ってもよい。

最初の3問がすべて有効な完了なら6しずく。例えば水ばち4＋花2、ベンチ4＋花2、木4＋花2から選べる。次の通常6問で12しずく増える。問題数を通貨のために増減させず、実際の完了数から計算する。

## 6. v1の完成範囲

新規購入10種、主住人3人、小さな環境生物、通常発見6種、精霊2種、昼・夕ぐれ・夜、既存3段の土地拡張、家と学習との往復、思い出・写真、移行と完全バックアップを完成範囲とする。装飾の異なる大量の商品、四季、地形彫刻、オンライン共有はv1完了条件に含めない。既存の所有品は全種類が互換対象。

v1内でも段階を切るが、最初の評価単位は「学習→選択→配置→住人→不思議→記録→再学習」が一周する縦切りとする。水のshaderだけ、無料の完成庭だけ、実保存を通らない画像だけでは方向の実証にしない。

## 7. 決定と検証の区別

上の体験・ルール・範囲は本仕様で決める。以下は実物で確認し、結果に応じて仕様版を更新する。

- 既存のぽこもこが新しい庭でも同じ姿に見えること、枝の曲がり方、花や精霊の最終モデル。B案の相棒をコピーしない。
- 390×844で場所・主役・操作が同時に見えるか。枝の遮蔽と夜の暗さを実画面で判定する。
- 初回の材料選択、待つ楽しさ、再会が次の遊び・学習につながるか。作者の感想を子どもの評価にしない。
- 初期価格、成長時間、来訪間隔、描画予算が妥当か。検証前から「最適」と表現しない。
- 実機の起動・操作・電力負荷と、移行の完全性。現行の検査PASSを次期のPASSへ流用しない。

詳細な検証条件と変更手続きは[08章](living-fantasy/08-delivery-and-acceptance.md)。未承認の美術や未測定の性能を残しても、データ・操作・経済の規則を未定義にはしない。
