# 育つ島のスターターとアチーブメント — v1仕様

- 状態: **採用 / 2026-10-01**。ユーザーの「実装して」に基づくv1仕様。実装・検証・公開の状態は[実装タスク](../tasks/active/2026-10-01-island-guidance.md)で区別する。
- 対象: [仕様52](52_growing_island_game_spec.md)の育つ島。旧Explore・旧Lifeの導入を自動的に置き換えない。
- 効く柱: **くふう**（規則を試す入口）、**にぎわい**（次の育成）、**愛着**（自分の出来事を残す）。**ふしぎ**は条件を試す楽しさを保ち、結果を全部先に明かさない。弱める・削る柱: なし。
- 仮説: 最初の一周と、今できる遊びが見えると、説明や大人の指示がなくても島で試し、本人が「まなぶ」を選びやすくなる。
- 正本の境界: [憲法](../../CONSTITUTION.md)、[親仕様01](01_app_spec.md)、52の時計・費用・入居・解放・学習・保存を維持する。本書は導きと記念の詳細仕様。機能・画面・保存の境界は01・52・46・43・13から参照する。

## 1. 採用する構成

**スターターで最初の一周を導き、その後はアチーブメントから気になる遊びを選べるようにする。**

| 仕組み | 役割 | 子ども向けの名前 |
|---|---|---|
| スターター | 種を置く、開く、迎える、学ぶ、通常の種が育つ、を実際に体験する | はじめての しまづくり |
| アチーブメント | 次に試せる遊びの絵とヒント。できたことは残る | しまの できごと |
| 既存のしまのあゆみ・写真 | 島の昔と今を見返す | 既存の名前を使う |

遊び方の本に「ためしてみる」と「できたこと」の二つの面を用意する。未達を失敗や不足として扱わず、試せる遊びとして見せる。住人の依頼・日課・期限・連続ログイン・正答率の目標を追加しない。

## 2. 既存仕様との調整

- 52 §14には、最初の「すむ」の種が無料で、学習なしで家と最初の住人が準備される導入がある。この即時の楽しさは維持する。
- 無料の家だけでは「学ぶとまちの時間が進む」が体験できたとは判断しない。通常の種を、学習由来のまち時間で育てるところまで別に案内する。
- [既存のその場の案内](46_island_tutorial_spec.md)の一文・閉じる・学習へ割り込まない原則を引き継ぐ。対象が違う旧案内と同時に表示しない。
- 花の色は既存のはなずかんへ、島の過去の景色はしまのあゆみへつなぐ。同じコレクションを別に増やさない。
- 「橋を架ける」「水を好きな方向に引く」は新しい遊びとして導入しない。土地は52 §9の「ひろげる」、水は既存の水ばち・みずみちの契約に従う。

## 3. スターター

### 3.1 流れと完了条件

順番は案内の順番であり、操作の制限ではない。先に満たした条件は保存し、順番どおりにやり直させない。

| 段階 | 見せるもの・ひとことの例 | 完了の根拠 |
|---|---|---|
| S1 種を置く | 桟橋の旅人と家の絵。「すむの たねを おいてみよう」 | 最初の無料home種の配置が本人の島へ保存された |
| S2 家を開く | 島の光るつぼみ。「さわると ひらくよ」 | S1の家を本人が開いた。ぜんぶひらくも可 |
| S3 仲間を迎える | 船の子。「ふねを さわってみよう」 | 最初の住人の下船操作が保存された。ぜんぶひらくも可 |
| S4 学んで戻る | 通常のまなぶ。「まなぶと しまの じかんが すすむよ」 | 本人が通常学習を選び、有効な完了が島へ一度だけ取り込まれ、帰島した |
| S5 通常の種を育てる | 種の完成見本と、育った場所。「つぎは どこに おこう？」 | 無料導入以外のhome/farm/play/market/festival種が、学習由来のまち時間で建ち、本人が開いた |

- 最初にぽこもこや花へ触る・ベンチで遊ぶのは自由。これを必須の前段階にしない。
- S4で種がまだ育っていなければ「しまの じかんが たまったよ」とだけ伝える。実際に増えていない家・住人を成長の例として描かない。
- S5の種は本人が選ぶ。解放済み・所持資源・置ける土地で候補を絞り、同じ場所・同じ形を指定しない。
- S4より先に通常の種を置いた、すでに学習をした、複数の種を開いた場合も、実際の保存済み事実を使って進む。
- S5は自然の種を対象にしない。自然時計とまち時計を取り違えないため、自然の育成は後の任意の遊びで扱う。
- 学習は既存の出題・区間・予約を使う。スターター専用問題、強制的な3問への短縮、支援を使わない条件、独力正解の条件を追加しない。
- 無料種の特例は既存の一度だけ。案内の再開・見直し・閉じるで増やさない。命令処理の既存 `tutorial: done` をS5の達成状態として扱わない。

### 3.2 足りない・待っている・中断したとき

| 状況 | 案内 |
|---|---|
| 通常種を買うしずくがない | 絵の見本は見られる。「いまは ベンチで あそべるよ」など、無料の遊びも示す。自動で学習を始めない |
| まちの時間が足りない | 種は待つ。学習を選べる既存入口は保ち、追加の学習案内を繰り返さない。「あと何問」は出さない |
| 時間がすでに残っている | 既存の時間を使う。学び直しを完了条件にしない |
| 配置先に歩いて行けない | 既存の配置予告と修正手段を使う。案内の完了扱いで無効な配置を通さない |
| 島がいっぱい | 移動・収納・拡張の現在使える手段へ案内する。土地や品を自動で動かさない |
| 閉じる・退出・日を空ける | 達成済みの段階は保持。起動時に自動で学習や案内画面を開かない |

最初の5分でS1〜S3を楽しめることを目標とする。S4〜S5を同じ訪問で終えるノルマにしない。途中でも、通常の遊びと全解放済み機能を利用できる。

### 3.3 出し方

- 新しい島で自動案内を有効にする。島の描画・操作が準備できてから、一文と対象の静かな強調を出す。背景の操作は保つ。
- 実操作で一段進んだとき、その流れに必要な次のひとことへ切り替えてよい。動きのある祝福と次の案内を同時に重ねない。
- 自動案内は一訪問につき一つの連続した導入の流れまで。閉じた・別の遊びを選んだ後は、その訪問で再開しない。
- 「とじる」は達成や特典を取り消さない。次回も自動で同じ案内を催促せず、メニューから本人が再開できる。
- 既存の島は自動スターターなし。現状で満たせる段階を記入済みにした本を、本人が開ける。無料種は追加しない。

## 4. アチーブメント

### 4.1 目標を選ぶ

スターター未完了で他の目標を選んでいないときは、**次の一手を一つ**大きく見せる。他の遊びは「ほかの あそびも みる」から任意に開ける。選んだ遊びがあればその詳細を主役にし、スターターと重ねない。スターター完了後、目標を選んでいないときは、今試せるものを最大3つ見せる。

- 「これを やってみる」で目標を一つ選ぶ。選ばなくても遊べる。変更・解除は無料。
- 島では、選んだ目標の小さな絵を一つだけ出す。触ると短いヒントが開く。常時の長文、全体の達成率、残り件数、赤い未達表示は出さない。
- 選ぶと既存のたね・配置・色選択などの入口へ進む。購入・配置・塗り替え・土地拡張を代行しない。無料操作も本人が決める。
- 候補は「解放済み、今使える対象があり、必要な資源と場所がある」を優先する。同じ状態なら順番は安定させ、開くたびに抽選しない。
- 一度選んだ目標は資源不足や収納で勝手に変更しない。詳細に理由と現在できる手段を表示し、別の目標も選べる。
- 今できない遊びは、しずくの実価格と所持数、空き場所・到達できる配置先、対象の有無、解放のどれを待つかを具体的に示す。「あとで やることにする」で目標だけ保存し、本を閉じたり島の操作を開いたりしない。選択済みでも条件を満たすまでは「しまで やってみる」を無効にする。
- 達成を前提に機能を封鎖しない。機能の解放は52の条件だけで決める。

### 4.2 v1カタログ

初回の実装はA1〜A6の6件。スターターでできたことも同じ達成記録を使い、二重の賞にしない。

| ID | 絵・名前 | ヒントの例 | 達成の根拠 |
|---|---|---|---|
| A1 | はじめての おとなりさん | 「すむの たねを おいてみよう」 | 本人の島で住人1人の入居と下船が成立。未開封のarrivalだけでは不可 |
| A2 | たねが そだった！ | 「くらしの たねを おいてみよう」 | S5と同じ、学習由来の時間で建った通常種を開く |
| A3 | じぶんの いろ | 「はたの いろを えらんでみよう」 | 本人が旗または家の屋根を、元と異なる色へ変更して保存 |
| A4 | ばしょを かえてみた | 「ベンチを うごかしてみよう」 | 本人の配置済みの品を別のマスへ移動して保存。キャンセル・同じ位置は不可 |
| A5 | みんなで えんそうかい | 「おんがくの ひろばを さわってみよう」 | 自分の島の完成したひろばを触り、実際の演奏場面が開始。音OFFでも達成可能 |
| A6 | しまが ひろがった | 「ひろげる ほうを えらんでみよう」 | 52 §9の土地拡張が本人の島へ保存。方向は問わない |

| 候補 | 扱い |

| まなびを かざった | 既存の独力判定で届いたきねんひんを本人が配置して保存。新しい習得基準・追加の学習報酬を作らない |
| 木かげで ひとやすみ | 木陰と到達可能なベンチの条件、および実際の住人利用を判定できた後に追加。木とベンチの距離だけで、休んだことにしない |
| 珍しいお客との出会い | 後続検討。希少種を集める必須目標、夜だけの課題、学習を増やす抽選にはしない |

### 4.3 達成と記念

- 達成は**記念の絵・スタンプと、その島の対象**で残す。v1では追加のしずく・まち時間・性能を持つ家具・専用機能解放を付けない。既存の学習報酬やきねんひんは通常どおり届く。
- 絵は未達の時から魅力的にする。達成後はその子の旗の色・住人・育った家など、記録できる範囲で本人の内容を反映する。
- 再配置・収納・塗り直し・住人のおでかけで達成を取り消さない。同じ動作を繰り返しても追加取得しない。
- 記念を触ると「この場所へ」など、今ある対象へ戻れる。対象が収納中なら「しまってあるよ」と収納一覧へ進む。削除済みなら思い出として残し、存在しない場所へ案内しない。
- 自動写真を各達成へ追加することは初回範囲に入れない。既存写真・しまのあゆみへの参照があれば利用し、画像生成失敗で達成を失わない。
- 本の全項目を終えても島の成長は続く。「島をクリア」「もう遊ぶことがない」と表示しない。

## 5. 画面と通知

| 場所 | 内容 |
|---|---|
| 家 | 室内overviewに触れる本と「あそびかた」の直接入口を置く。メニューにも「しまの あそびかた」を残す。家の中で読み、閉じると家に戻る。「やってみる」を選んだ場合は島の実操作へ進む |
| 島のメニュー | 「しまの あそびかた」を近道として残す。スターターとできごとを一つにまとめる |
| 島 | 既存のぽこもこのひとことと、任意の選択目標の絵。追加の常設操作列やゲージは作らない |
| 本 | 「ためしてみる」「できたこと」。スターター未完了なら最初の一周を先頭に見せる。本人が選んで通常の遊び候補へ進める |
| 学習 | スターター・達成通知・本・受取操作は出さない |

- 案内・選択目標・既存の成長のひとことは、同じ表示場所を取り合わない。優先は復旧/エラー → ひらく/迎える → 選択中の実操作 → スターター → 任意目標。
- 達成が同時に複数起きたら、記録は全部残す。ひらく等が落ち着いてから、一訪問につき一度の短い知らせにまとめる。既存の開花・入居通知に記念の印を添えられる場合は同じ出来事を二度知らせない。
- 「できごとを みる」は「できたこと」の通知対象の思い出を直接開く。通知が複数なら表示中の先頭の対象を開き、他の記録も本に残す。通常入口では「ためしてみる」を開く。
- 「できたこと」は最も新しい記録（日時不明なら安定した順）を大きな記念の絵と次の操作で見せる。他の思い出はその下に小さく並べ、選ぶと主役が切り替わる。絵の色・姿は達成時点の固定snapshotを使い、現在の塗り替えで更新しない。
- 達成の知らせは閉じられ、次の操作に必要な追加タップを要求しない。学習・編集・撮影・見せる・他人の島の閲覧・背景化・保存/読込/復旧中には表示しない。
- 通知を見なかった達成は、本で確認できる。起動ごとに祝福を再生しない。成長した事実と、本人が見た事実を混同しない。
- 家で本を開いている間も本人の保存更新を読み取り、別タブでの達成・選択・対象変更を反映する。読書・表示更新は島の時計や学習完了の取込を進めない。閉じると購読を解除し、別プロフィールの更新を表示しない。
- [UI仕様07](07_ui_design_guideline.md)の既存トークンと44px以上の操作領域を使う。文字付きの閉じる・戻る、focus、読み上げを用意する。音なし・reduced motionでも目標・達成・次の操作が分かる。
- ぽこもこの顔・頭身・耳・布・配色は変更しない。島の画面を本や暗幕で恒常的に覆わない。

## 6. 保存と既存の子への導入

本人のGrowing recordの専用境界に保存する。保存版とwriter互換の実契約は[保存13](13_data_storage_migration_spec.md#育つ島の案内と記念2026-10-01)に従う。

- 大きな状態をUserProfileへ追加せず、本人の育つ島recordの専用 `guidance` 境界に置く。旧 `tutorial` の無料種利用権はそのまま保つ。
- 保存するもの: 案内版、スターターの達成済み段階、閉じた/自動案内を停止した印、選択目標ID、達成IDと最小限の根拠、通知済みID。
- 根拠は本人・達成ID・発生元の操作/学習完了/対象IDと、記録時点の必要な値だけ。学習履歴全体や動画を複製しない。記念の対象の見た目は最小の固定snapshotを使い、現在の品の色替えで過去の記念を書き換えない。
- 種配置・開く・下船・色替え・移動・拡張などの保存操作は、成功した状態変更と達成更新を既存のrevision/intent IDを使う同一transactionで保存する。失敗・取消・再送・複数タブで重複しない。
- 演奏開始等の前景操作はrendererの実開始を確認した受領記録を使う。クリック予定、背景時間、失敗した描画だけでは記念を作らない。通知の読了・表示済みも実表示を確認してから記録する。
- 前景記録はプロフィール切替・revision競合・対象消失を確認し、受理できるまで達成表示をしない。保存失敗で学習や演奏を待たせず、記録未確定と再試行を区別する。
- 既存の島の初回導入では、現在の保存だけで確実に分かる入居・拡張等は記入済みにしてよい。「これまでの しま」と示し、過去の日時や本人の操作は推測しない。色変更・移動・演奏・通常種を開いた事実が不明なら未記録として今後の操作で達成できる。無料導入を再利用できない旧島はS1〜S3の案内を省く。有料通常種のまち時間による建築が既存の確実な時刻から分かる場合でも、過去の開封を推測せず、本人の今後の開封でS5/A2を記録する。
- 既存島に通知をまとめて配信しない。自動スターター、無料種、しずく、まち時間をさかのぼって追加しない。
- 未知版や破損した案内記録から、未検証の達成・報酬を復元しない。島・学習の正本を保持して案内を止め、互換復旧の契約へ従う。
- 新版の保存・旧writer拒否・一度だけの移行・削除は[保存13](13_data_storage_migration_spec.md)に従う。本人の削除に追随し、他プロフィールや訪問先に達成を書き込まない。

## 7. 受入条件

### 7.1 規則とruntime

1. 無料導入・通常種・自然種を区別し、通常種を開くまでS5/A2を達成にしない。先に学ぶ・先に置く・ぜんぶひらくも同じ結果になる。
2. 有効な学習完了の支援/独力はどちらもS4に使える。誤答・お手本のみ・無効完了は使わない。SRS・採点・解放・既存予約と報酬は変わらない。
3. 資源不足・土地不足・時間不足でも無料の遊びを選べる。閉じる・目標の解除・別の遊びで進行や権利を失わない。
4. 操作成功・前景の実開始・保存・表示済みを区別し、キャンセル、描画/保存失敗、再送、二重タップ、複数タブで偽の達成を作らない。
5. 再読込・offline・プロフィール切替で本人の目標と記念を保持。既存島では架空の行動/日時・無料導入の再配布・通知の連発なし。
6. 学習へ入ると案内が退き、同じ予約に戻れる。UI通知を待って次問が遅くなることや、受取確認はない。
7. 混色・稀な来訪の確率と時計、土地拡張・入居・育成の条件は既存規則どおり。目標の選択や本の開閉で抽選回数を増やさない。

実装の確認は[検証matrix](../ai/verification_matrix.md)のUI・純粋ロジック・保存・学習接続の該当行を適用する。390×844・768×1024の実画面、新規/既存の島、途中再開、offline、音なし、reduced motionを確認する。

### 7.2 子どもの体験

| 独立に判定すること | 観察する内容 |
|---|---|
| 視覚の魅力 | 未達の絵を見て「これをやりたい」と選ぶか。記念と島を見返したがるか |
| 無文字の理解・安全 | 絵と実際の反応で次の操作が分かるか。閉じて自由に遊べると分かるか。「全部やらなきゃ」と受け取らないか |
| runtimeの整合 | 正しい本人・版・flagの実画面で、根拠のある達成だけが保存され、学習・成長・通知と一致するか |

最も見たいのは、本を見たあと自分で置き方を試し、自分でまなぶを選び、翌日も島へ戻るか。達成数やスターター完了率だけで成功とはしない。人の観察結果と自動テストは分けて記録する。

## 8. 比較した案とv1範囲

| 論点 | 採用 | 理由・体験リスク |
|---|---|---|
| 導入の長さ | 最初の一周を一つの流れとして案内 | 無料家だけでは学習との関係が弱い。一方、長い案内が宿題に見えるリスクは中断可と段階分離で検証 |
| 未達の見せ方 | 導入中は次の一手、完了後は今できる3候補、選択目標1つ | 全件チェックリストの圧力を抑え、選ぶ楽しさを残す。子どもが本の存在に気付くかは実画面で確認 |
| 報酬 | 本人の出来事が残る絵・スタンプ | しずく追加による育成ペース変更と、機能の再封鎖を避ける。記念だけで魅力があるかは未検証 |
| 発見のヒント | 規則を試す配置を示す | 具体的な行動は分かり、全部の結果は先に明かさない。混色等は確定結果を約束しない |
| 初回範囲 | スターター＋A1〜A6＋本＋保存 | 現在の操作へ接続できる。木陰の実利用など、観測の追加が大きいものは後続 |

v1の絵は既存の布・紙・島の配色を使うSVGで用意する。新しいキャラクターやぽこもこの造形は追加・変更しない。本はメニューから開くシートで、未達の結果の絵と達成のスタンプを同じ絵柄で示す。混色、学習記念品の展示、木陰の実利用、珍しい来訪は後続範囲とする。公開済みかどうかは実配布の記録で確認する。
