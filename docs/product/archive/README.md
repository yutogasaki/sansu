# 過去の案・試作の置き場

今のアプリの方針は[今の島への統合](../island-nature-integration.md)、現在の仕事は[タスク一覧](../../../.agents/tasks/TASKS.md)を参照してください。

ここは「消す場所」ではなく、今の方針と取り違えずに過去の資料を探す入口です。リンクや保存契約を壊さないため、参照されている仕様・コードは元の場所に保持します。

| 過去のもの | なぜ残すか | これからの扱い |
|---|---|---|
| [Nature Townの独立試作](../nature-town/00_START_HERE.md) | 水・植物・運搬・人口の計算とテストを再利用する | 別の町としては仕上げない。今の島へ必要な機能を取り込む |
| [Nature Townの旧作業記録](../../tasks/archive/2026-09-16-nature-town-s1.md) | 当時できたこと、失敗、未確認事項を失わない | 統合後の合格証拠にはしない |
| [旧ホーム](../08_home_ikimono_spec.md) | 過去の仕様を調べる | 現行ホームの根拠にしない |
| [旧探索](../10_exploration_game_spec.md) | 今も任意で選べる遊びの保守 | 現在の島とは別モード。削除・公開終了はしていない |
| [旧遊園地](../22_shared_subject_build_and_play_spec.md) | 公開終了後の作品と保存契約を守る | 再開発は現在の優先作業に含めない |
| [ぴったり連鎖](../27_gameplay_first_pittari_spec.md) | 算数ゲームの検討を残す | 限定範囲の試作。今の島の主導線ではない |

「過去の資料へ退避」は、ゲーム内データやコードの削除とは違います。
