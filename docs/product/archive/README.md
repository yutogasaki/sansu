# 過去の案・試作の置き場

ここは今の方針と取り違えずに過去の資料を探す入口です。記録を残すことと、旧試作の実行コードを保守し続けることは分けます。保存データの扱いは各項目の契約に従います。

| [Nature Townの旧作業記録](../../tasks/archive/2026-09-16-nature-town-s1.md) | 当時できたこと、失敗、未確認事項を失わない | 統合後の合格証拠にはしない |
| [旧ホーム](../08_home_ikimono_spec.md) | 過去の仕様を調べる | 現行ホームの根拠にしない |
| [旧探索](../10_exploration_game_spec.md) | 直接URLで開ける旧モードの保守 | 島の入口から外した。画面・直接URL・保存データは維持 |
| [旧遊園地](../22_shared_subject_build_and_play_spec.md) | 公開終了後の作品と保存契約を守る | 再開発は現在の優先作業に含めない |
| [ぴったり連鎖](27_gameplay_first_pittari_spec.md) | 当時の試作仕様と検証を参照する | 2026-09-27終了。開発用入口・コードを撤去した |
