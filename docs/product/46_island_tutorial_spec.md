# 島のあそびかたとその場の案内

## 採用範囲

2026-09-09のユーザー承認に基づく。[親仕様](01_app_spec.md)、[島](28_mystic_island_spec.md)、[成長](30_living_island_growth_spec.md)、[レイアウト](44_display_layout_spec.md)の学習開始・連問・保存契約を維持する。説明専用の必須チュートリアルは設けない。

- 新規プロフィールだけに自動案内を有効化する。初期設定前に追加しない。設定直後の学習へ割り込まず、本人が帰島してから表示する。
- ホームの自動案内は最初の眺め操作と最初の保存済み成長。成長を優先し、一訪問一つ。画面を開き直すまで次を出さない。
- あそぶ・きせかえは初めて本人が開いた場面で案内する。遊び開始／プレビューの実操作で終了し、交換や正答を完了条件にしない。
- 一文、必要な操作、とじる。暗幕、フォーカス強制、強制スクロール、自動カメラ移動はしない。対象の強調は安定した操作領域に限定する。44px以上の操作、音なし・reduced motionで理解できる。
- 学習・背景化・退出で即座に退く。エラー／復旧、既存成長通知を優先し、保存中・メニュー中・編集／撮影の確定中には自動案内を出さない。表示した案内は退出・学習・背景化で終了した後は自動では再表示しない。同じ画面の短い背景保存では同じ案内を保留し、保存後に戻す。
- 成長は現在の保存状態に基づいて伝え、特定の花の開花を一律に約束しない。収納・古い姿を変更せず、明示操作で比較画面へ進む。成長未達では次の姿の予告へ進む。開発用の家・庭表示には未対応のドラッグを案内せず、操作できる島のあそぶ画面へ案内する。

## 見直し

しまのメニューの「あそびかた」から、ながめる／学ぶと育つ／どうぶつと遊ぶ／きせかえ／みつける／写真／家具を動かすを選べる。短い説明とやってみるで既存機能へ進み、その画面で案内する。戻るは既存ナビゲーションに従ってあそびかたへ戻る。学習へ進んでも既存の予約を維持する。対象がない場合は理由を表示し、実行を無効にする。見直しによる成長・報酬・発見・案内リセットはない。

## 保存

新規作成時にプロフィールの任意フィールド islandTutorialVersion: 1 を保存する。既存の省略値は自動案内なし。案内イベントは localStorage のプロフィール・案内ID・イベント別キーに分離する（pokomoko:tutorial:v1）。表示済み／実操作済み／閉じたを単調追加し、別タブで古い状態が新しい状態を上書きしない。表示していないものを表示済みにしない。学習・島の保存transaction、revision、SRS、報酬と独立する。保存失敗時は同一起動中のメモリで重複を防ぎ、再起動後の再表示の可能性は許容する。保存のために学習を待たせない。プロフィール削除・全消去では既存の端末データ消去契約に従う。

## 検証

初回・既存プロフィール、案内の優先／閉じた直後の連発なし、実操作と表示の区別、見直し、未達条件、別タブ、保存失敗、背景化と同予約への復帰を検証する。390×844・768×1024の実画面で操作領域と横溢れを確認する。core、smoke、島、初回導入、PWA、固定10問を確認し、未実行は明示する。視覚、無文字理解／安全、runtimeは別の判定で、作者の操作を子どもの理解の証拠にしない。

実装の検証結果と既知の受入保留は[チュートリアル検証記録](../design/audits/2026-09-09-island-tutorial/README.md)を参照。
