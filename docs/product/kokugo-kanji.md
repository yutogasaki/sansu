# 全配当漢字の教材

## 目的と範囲

2026-10-25、利用者の全配当漢字実装依頼により採用。短い学習から島へ戻る流れと、本人の取り組みが残る愛着を支える。島の遊び・既存の学習判定を弱めない。[国語コース](kokugo.md)の追加教材である。

文部科学省の平成29年告示に対応する1,026字を、小1 80／小2 160／小3 200／小4 202／小5 193／小6 191字で収録する。現行の配当、代表音訓、各字2用例・計2,052用例、各字2本・計2,052本の場面文と、読む／読みを入力／漢字を選ぶ／紙に書くの学年別24コースを静的教材として同梱し、通信不要で利用する。全ての語義・音訓や教科書の網羅、字体の自動採点は意味しない。用例は本アプリ独自の選定であり、官公庁による教材推薦ではない。

## 入口と教材

漢字の領域から学年・字を選ぶ。字／用例／読みで検索し、配当学年を越えて選べる。学年全体の3問と、一字に絞った練習を用意する（単字の音訓を小学校段階に置かない「媛・岐・滋・阪」も地名と場面文で3問）。読む・漢字を選ぶ・紙に書くを分け、読みを練習したことを筆記技能の習得にしない。漢字の単字読みは複数の正しい音訓を持つので、選択肢から中高段階も含む常用音訓の別読みを除き、短答では収録した音訓を全て許容する。語の課題は示した語全体の読みを問う。配当学年は字の配当であり、用語の全音訓が同学年の学習段階という意味ではない。身近な熟字訓や後の段階の音訓を使う語は、その旨を校閲台帳で区別する。未知の短答は既存契約どおり自動誤答にしない。

用例の読みを表示する教材一覧を見た直後の同じ例を、未見の独力証拠にしない。一字の詳細では、例を表示する前に学ぶ操作を選べる。例・読みの開示は専用の接触記録を既存進捗へ保存し、予定を先送りせず、独力判定用の接触revisionと露出を更新する。紙の練習は手本を閉じて書き、再表示して本人が見比べ、作品・メモへ保存する。筆順動画・認識・画像や録音の外部送信は追加しない。

## 進捗・選定・互換

進捗は字×設問形式×要求様式で分離する。読み選択・短答・表記選択の証拠を合算しない。同じ語の露出は形式をまたいで新しい文脈にしない。単字と同じ字だけの用例、県名の「県」を足した表記等も同じ露出にまとめる。単語と場面文を合わせて全字で3露出群・2編集文脈群以上を供給する。同じ例を反復した回数で独力の例数を補わない。学年の練習は期日到達／未見の例／練習済みの順で、同順位では未接触の字を先にし、同じ字では未見の例を先にし、特定の先頭字だけを繰り返さない。復習予定は既存の24時間・1/3/7/14/30日を維持し、見た手本から即座に独力判定へ戻さない。

学年の件数は未着手・取り組んだ字・復習のめやすを持つ字を示す。国語の最低確認条件を満たさない課題に習得済みを付けない。字の練習範囲は設定と予約へ固定し、再読込・更新で他の字へ切り替えない。旧46単元・保存済みの問題本文・選択順・正答・下書き・報酬を変換しない。DBは既存v11の6表を使い、追加migrationを行わない。

## 校閲と例文・後日復習（2026-10-26）

AIによる全字・全用例の校閲と一次資料の音訓照合を行い、修正理由を台帳へ残す。配当学年と音訓の学習段階を混同せず、日常的な熟字訓・連濁・活用は表面一致検査だけで誤りにしない。難しい文語や中高段階の読みに偏る用例は、身近な語へ差し替える。人の国語校閲者の採用審査とは区別する。

全1,026字へ、各2本の独自の短い場面文を追加する。場面文は実際の用法・状況を持ち、文字を差し替えただけの共通枠を新文脈に数えない。単語と文中の読みを区別し、同じ場面の選択／短答／表記選択は一つの露出として共有する。県名の接尾辞等を増やすだけの例は従来どおり同じ露出にまとめる。各字に最低3素材・2構成群があることを検査する。手本や答えを教える支援を見てから24時間未満は、別場面でも独力確認に数えない。

教材を使い切った後は、既知の例でも期日到達・最後の接触から24時間・支援なしの初答正答を満たせば「後日の思い出し」として復習期限を進める。新文脈の独力件数・構成群・後日確認件数には加えない。新しい例での確認と、既知例の保持を別記録にする。予定は既存の1/3/7/14/30日を使い、早い練習・支援・再回答・時計の逆戻りで先送りしない。新文脈か既知例かにかかわらず期日が来た教材を選定の先頭に置く。

旧版で予約済みの本文・選択肢・正答・素材IDを保持する。改稿した語は新教材版・新IDで供給し、過去の誤答や独力事実を訂正後の本人の誤りへ置き換えない。旧版の桜色／桜、一丁目／丁目等の露出groupは、保存済みの文字列を残して同じ語根として比較する。旧予約と新教材のどちらを先に開いても、新文脈へ数え直さない。新しい保存fieldは任意項目とし、既存v11の表を引き続き使う。

2026-10-26の監査修正：露出の同一性と出題素材が単字であることを別々に保持する。「桜色」「頭の上」を字単独の音訓として問わず、語の穴埋めとして出題する。場面文には文脈に合う許容読みを指定でき、人数を数える「何人」は「なんにん」に限定する。文脈なしの語では正当な別読みを引き続き許容する。新しい漢字教材版は `kokugo-kanji-3` とし、同じ素材のID・露出は維持して独力の例数を増やさない。旧予約に固定された本文・許容読み・過去の解答事実は変更せず、修正は新しい予約へ適用する。
