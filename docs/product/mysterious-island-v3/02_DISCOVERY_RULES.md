# 発見ルール・初版制作カタログ

版：v3.0-rc1／状態：提案。**本書の個数・距離・結果の一覧は開発用。子どもの画面へそのまま出さない。**

## 1. 共通の判定契約

### 1.1 条件に使ってよいもの

確定した所有と配置、現在の育ち、物の系統タグ、利用位置間の歩行距離、現在参加している住人、住人の姿勢、本人の操作を使う。学習量・正答率・島ランク・実時間の夜・乱数は、初版の関係／魔法／レアの成立条件にしない。

可変の条件を後から追加すると、同じ試し方で結果が出なくなる。条件変更は`ruleVersion`を上げ、古い記録の意味を変えない。

### 1.2 空間と状態

同系統のまとまりは、物の占有セルが上下左右で連結する成分で評価する。斜めだけでは結ばない。水鉢・植物等、別系統の物が間に入っても橋渡しにはしない。アーチは花の個数に含めない。砂場は遊具へ含め、かざぐるまは含めない。

通常の関係は、相手の利用位置どうしの最短歩行距離4歩以内。複数の利用位置がある場合、実際に予約できる組み合わせの最短値で評価する。距離は家具の中心の直線距離ではない。全ての利用点、通過点、席の向きをモデルごとに定義する。

近さの目安は、対象の向き、光の届く地面、道具を運ぶ方向等で分かるようにする。内部の「4」の数字は先に教えないが、物理的に利用できない理由は隠さない。

### 1.3 再評価と可逆性

確定配置、移設、収納、成熟の境界、対象住人の状態変更で再評価する。仮表示やメニューを開いただけでは確定状態を変えない。

構造条件は純粋関数として、同じ入力に同じ結果を返す。自動行動の選択は別層にし、住人の好みで構造条件そのものを変えない。

移設後に関係が成立しなくなれば、現在の見た目や行動先を戻す。既得の所有・成長・思い出は維持する。

これらの成立は商品を解放せず、贈与を新規発行しない。景色の変化と本人の記録が主な価値である。

## 3. 通常の組み合わせ6ルール

共通条件：対象が配置済み、必要な成長と経路が成立、利用位置間4歩以内。元の個体・通貨・成長速度は変えない。

| ID | 関係 | 同じ席での普通との違い | 比較するとき | 段階 |
|---|---|---|---|---|
| R1 | 花1個以上＋ベンチ | ベンチに座った住人が花へ顔を向ける。開花前も芽を見る | 花を離せば通常の休憩、戻せば花を見る | A |
| R2 | 成木1本以上＋テーブル | 木陰側へ体を向けて、おやつを置く。木立なら背景の陰も広がる | 苗／成木、木と机の距離 | B |
| R3 | 遊具＋ベンチ | 休みながら遊具を見る。利用中の住人がいればそちらを見る | ベンチを離す、遊具の位置 | A |
| R4 | 水鉢＋ベンチ | 水面へ顔を向けて休む | 水鉢を離す／戻す | B |
| R5 | 図書室＋ベンチ | 図書室から本を持って歩き、そのベンチで読む | ベンチを離すと図書室入口で読む | B |
| R6 | 園芸小屋＋植物 | 道具を持って対象へ歩き、手入れの仕草をする | 遠い場合は小屋の入口で道具の手入れ | B |

R2は木3本を必須にしない。1本の成木でも意味を返し、3本で「まとめる」の別の変化が重なる。R1も花壇の完成まで反応を保留しない。

R6の手入れは暮らしの表現であり、隠れた成長ボーナスを与えない。成長を加速する操作として案内しない。

### 関係が複数重なる場合

自律利用は、現在対象で成立した関係について、利用位置間の距離が短いものを選ぶ。同距離なら`R5 → R1 → R4 → R3 → R2 → R6`の固定順、さらに同じなら対象IDの辞書順。これは制御用の順序であって、価値の序列ではない。

「みてみる」で周囲の対象を触って選んだ場合は、その**現物**との成立関係を試す。たとえばベンチを選んだ後に水鉢を指すと、R4が成立すれば水を向く。未成立なら通常反応。関係名の正解候補リストは表示しない。

住人ID・利用状態を揃えた比較で同じ通常反応が返ることを受入条件にする。住人を替えた場合の付加的な表情差はよいが、当たったり外れたりする抽選にしない。

## 4. 魔法4ルール

| ID | 条件ときっかけ | 結果 | 持続・戻り方 | 制作の境界 |
|---|---|---|---|---|
| M1 | 灯りの利用点から歩行距離2以内の地面を、ぽこもこが歩く。行き先変更が入力 | 足もとの跡が星になる | 1エピソード最大6秒。各跡は約2秒で消える。領域外・停止で新しい跡は作らない | 地上経路と足位置に追従する短命表示。飛行や移動速度変更はしない |
| M2 | 配置済みの花または木を観察状態でタップ | 葉／花びらが上へ落ちる | 約3秒で消える。芽は葉、開花は花びら。元の個体は変わらない | 既定の上昇軌道。葉を実際に個体から削除しない |
| M3 | ベンチを利用している住人の影をタップ | 本体は休んだまま、影だけ挨拶する | 約4秒後に通常影へ。住人が離れたら中断 | 独立した影の素材。身体の姿勢や席予約は変更しない |
| M4 | 灯りと水鉢の利用点が4歩以内。水鉢をタップ | 水の中だけ星空になり、触れた所から波紋 | 約5秒後に通常水面へ。灯りを離せば普通の波紋 | 水面範囲内の表現。別の3D世界・実空の反射を描画しない |

M1の範囲は明るい地面の範囲と一致させる。光だけ届いているのに足あとが出ない、または暗いところでも出る状態は避ける。

M3の影には十分なタップ領域を持たせる。影が小さく押しにくい場合、対象の観察面に同じ影の拡大表示を出す。未発見時に「影が手を振る」という説明ボタンは置かない。

どの魔法も学習量、正答率、既得の魔法ポイントを条件にしない。最初の現象も再現も無料。物がなくなれば現在条件は外れるが、過去の記録は保持する。

### 連打と観察

表示中の同じ魔法への連打は同じエピソードにまとめ、無限に時間を延ばさない。終了後は短い500msの入力整理を経て再試行できる。この待ちは演出の重複防止であり、日次回数・課金・回復待ちではない。

新しい対象の明示操作は古い演出を安全に終え、今触った対象を優先する。学習・編集・退出は常に優先する。自然なレア演出が魔法の比較を割り込んで遮らない。

## 5. 特別な出会い3ルール

全て条件型・再現可能。プレイヤーごとの抽選順、排出率、天井、日替わり当選を実装しない。**珍しさは、普段は揃っていない状況や仕草の珍しさ**とする。

| ID | 条件 | 出会い | 操作と再確認 | 制作 |
|---|---|---|---|---|
| X1 | GF6の花畑と水鉢。水鉢から花畑外周の利用点まで4歩以内 | 白い蝶が花と水の間を渡る | 花畑の通常観察後の小さな羽の気配に触る。同じ条件なら再び来る | 小さな蝶の表示と定形経路 |
| X2 | GT3の木立と水鉢。外周利用点間4歩以内 | 斑点のある小鳥が水をのぞいて枝へ戻る | 木立の通常観察後、枝の気配に触る | 小鳥の小さな表示、止まる姿、定形経路 |
| X3 | R5で、実際にカワウソがベンチで本を読んでいる | 本を逆さにしていることに気づき、持ち直す | 読書中のカワウソを観察。同じ対象状態なら同じ仕草 | 既存読書姿勢と本の向きの差分 |

X1・X2の気配は条件成立後に出る操作上の手がかり。未成立時に「花6本と水が必要」と案内しない。見逃しても条件が残る間は再び操作でき、アプリを開く時刻を要求しない。

X3はカワウソを外から強制操作する新機能ではない。自然にR5へ参加したときに成立する。カワウソが別の活動中なら、その現在状態を表示する。普通のR5が動くかどうかの検証には、X3の出現を必要としない。

初版のレアは出会いの記録であり、新しい所持品・能力・報酬ではない。将来、珍しい外観の所有を導入する場合は、購入内容が分からない抽選や学習の周回報酬と混同しない別仕様を作る。

## 7. 一つのルールを完成とする条件

**きっかけが分かる／主要な結果が見える／条件を変えると違いが出る／元へ戻して確認できる／通常利用を壊さない／記録を正しく分ける／学習へ即移れる**、の全てを確認する。

`data/rules_registry.json`は上記の制作台帳であり、既存アプリがそのまま実行できる定義言語ではない。独立モデルが検証する範囲は`validation/TEST_SCOPE.md`を参照。
