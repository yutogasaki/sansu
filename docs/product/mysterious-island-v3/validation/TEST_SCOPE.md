# この一式で実行したこと／していないこと

## 実行済み

- `python -m unittest -v test_reference`：38テスト。実行ログは`test_run.txt`。
- `python reference_model.py`：30日収入8条件、8構成×3学習量×2頻度の48経路、4成長条件、4つの2D代理配置を`results.json`へ出力。
- 4配置は家からの到達、枠内、重複、各物の利用点を確認。草木の通行可能化等で無理に通したものではなく、アーチだけ指定どおり通行可能にした。

## テストの意味

報酬の簡易台帳、重複キー、支援と対象終端、旧価格返金、有限ひかりの算術、成長積分、成熟花の地区の一部、可逆な配置、予算、経路、表示事実の最低条件を独立モデルで確認した。

`rules_registry.json`は制作台帳であり、`reference_model.py`が全21ルールを実行するわけではない。M1〜M4の描画、R1〜R6の住人の演技、X1〜X3の実際の演出は未実装・未検証。レアのテストはX1の一部条件が抽選で変わらないという簡易モデルに限る。

## 未実行・未確認

元リポジトリのビルド／全テスト／最新HEAD、実DB移行、復旧、PWA更新、複数タブ、3D姿勢、入口モデルの方向、住人の同時予約、成熟時の見た目、FPS、アクセシビリティ実画面、子どもの観察、学習復帰や教育効果。

このモデルはゲームサーバーや本番の不正防止実装ではない。画面に表示したことから本人の注意・理解・学習成果を判定しない。価格や時間の楽しさを計算だけで認定しない。
