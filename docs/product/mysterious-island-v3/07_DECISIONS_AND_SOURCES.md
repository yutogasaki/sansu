## 1. 決定記録

| ID | 決定 | 根拠と区分 | トレードオフ |
|---|---|---|---|
| D01 | 完成見本・景色目標を割り当てない | ユーザーの直近の修正「何になるかわからないのがいい」 | ゴールの明示で誘導できないため、単体反応・操作説明が重要 |
| D02 | 試す→反応→比較→再確認を中心にする | ユーザーの「こうなるんだってわかる」「勉強とはちがう学習」 | 気まぐれな普通の反応や長い待ちは不適合 |
| D03 | まなぶの適切な取り組み・定着を主目的として維持 | 以前から明示された学習優先。直近の探索的学習と両立 | 島が楽しいだけでは成功としない |
| D04 | まとめる・組み合わせ・住人・レア・魔法を区別 | この対話で整理した価値 | 機能の全てが同じ一列の成長段階にはならない |
| D05 | 魔法をPで配らない | D01/D02を実装可能にする今回の設計判断 | 所持物が揃えば早期から魔法を見つけられる |

| D07 | レアは条件型3種、低確率の配布を初版にしない | 再現性と開発量を優先した今回の設計判断 | 低排出率の景品収集とは違う希少性になる |
| D08 | 1終端2しずくを維持。重み2は今回停止 | 現行48の保存契約。v2重み2は未検証案 | 問題構造による負荷差は残り、別途の検証が必要 |
| D09 | 新規初完成贈与をやめる | 発見を報酬回収へしない今回の設計判断 | 無料で次の材料が増える速さは落ちる。安い材料と価格で調整 |
| D10 | 成長の基礎0.5＋学習最大0.5を推奨として継承 | 9/12統合案、v2。現行48からは変更 | 休止を罰しないが、成長待ちだけでは学習動機にならない |
| D11 | 新しい追加品と土地を値下げ、初版12品186D | 今回のバランス試算に基づく開始値 | 少量層の停滞を減らす一方、素材は早く揃い得る |
| D12 | 記録は成立／表示／本人保存／理解を分ける | 初回依頼の学習事実と観察の分離、最新の発見方針 | 自動で「法則を理解した」とは報告できない |
| D13 | ひかりは旧2色の有限補充へ | v2の推奨案を継承。保存移行が必要 | 旧残高の使い道を無理に増やさず、主資源をしずくへ整理 |
| D14 | 初版12品、21制作ルールを段階投入 | 現行4品からの実装現実性 | 本書の全機能をすぐに公開できるとはしない |

ユーザーが個別数値まで承認したという表ではない。思想の反映と、今回選んだ設計値を分けて記録している。

**S2：9/12の統合レビュー案**  
`pokomoko-integrated-spec-review-20260912.zip`。会話内で読まれた統合本文・バランス・保存等を参考にし、現行と未実装の区別、既存家・学習・写真等の保護を継承。旧価格やファンタジー案は本書の差分を優先する。

**S3：9/13のv2改訂案**  
`pokomoko-learning-island-v2-20260913.zip`の01、02、03、04、06。今回、完成目標、Pゲート、魔法P条件、レアのマイルストーン配布等を明示的に撤回した。v2の提案を、実際に導入済みとみなさない。

**S4：このチャットの直近の設計対話**  
完成形を選ばせない、子どもが試して因果に気づく、勉強とは異なる学習にもする、という本人の修正を優先。直前の「発見体験の基本仕様」は叩き台として取り込み、レア・魔法を上下の段階に置く点、夜間に見に来させる例、表示だけで「発見した」と扱う点を精密化した。

S1/S2/S3の全てが最新リポジトリそのものではない。今回46文書の全件監査を新たにやり直したものではなく、既存レビューと島の該当原文を基にした仕様策定である。学習の入力形式・単元表・SRSの細部を島のために再定義しない。

ファイルのSHA-256と読み取った根拠箇所は`evidence/SOURCE_REGISTER.json`、`evidence/SOURCE_EXCERPTS.md`に記載。
