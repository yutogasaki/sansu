# 国語の年齢別体系と単元案

[包括仕様案](README.md)の一部。年齢は入口の提案であり、くもん公式配当・学校の学年別到達認定ではない。各技能を初めて扱う年齢を限定せず、文章・語彙・関係の複雑さを段階的に上げる。

## 年齢別の体験

| 入口の目安 | 主な内容と必要な前提 | 問題・活動 | 次を提案できる証拠の例 |
|---|---|---|---|
| 3〜4歳 | 身近な名詞・動作・性質、簡単な話、音や文字への興味。文字の読解は要求しない | 声を聞いて絵を選ぶ、絵の順を確かめる、まねして話す、読み聞かせ | 新しい絵や異なる文脈でも対応。声による表現は人の観察として別記録 |
| 5〜6歳 | 音とかな、濁音・半濁音・拗音・促音・長音、語から短文。身近な語の意味 | かなと音、語と絵、一文の意味、なぞり・見写しの任意活動 | 評価対象の読み上げなしで別の語を読む。見本なしの書字とは区別 |
| 小1 | かな・カタカナ、基本漢字、助詞、主体と動作、順序。短い語・文が読める入口 | 助詞、だれが/何をした、二文のつながり、一文で知らせる | 新しい文で主語・述語・対象を取り違えずに選ぶ/構成する |
| 小2 | 語彙と漢字を広げ、修飾・参照・順序・簡単な理由を扱う | 指示語、似た文の意味の違い、物語の前後、説明の手順、短い手紙 | 初見の短いまとまりで二つの情報を結ぶ。理由と本文根拠を対応させる |
| 小3 | 段落、中心、具体例、場面・心情。複数文の関係が分かる | 段落の要点、場面変化、根拠選択、辞書の引き方、短い説明 | 別題材で要点/詳細を分け、根拠を示す。人物の感じ方の自由な感想は採点しない |
| 小4 | 段落間の対比・因果・役割、事実と意見、話の整理 | 構造図、比較表、文の推敲、資料と本文、発表の構成 | 語彙や題材を変えた文章でも関係を特定。文章構成の選択と自作は分ける |
| 小5 | 文章全体、主張と根拠、複数資料、要約、相手と目的に合う説明 | 不要な情報を外す、要約の構成、図表を根拠に読む、質問を考える | 別資料で要点を落とさず根拠を対応。条件を満たす自由要約は人の評価 |
| 小6 | 立場の違い、資料の一致/食い違い、表現の効果、意見の構成 | 二文書比較、根拠の範囲、意見文の計画、引用と自分の考えを分ける | 初見の複数資料を比較して根拠を示す。意見への賛否そのものを正誤にしない |

小6の出口は「複数の資料から根拠を捉え、文章を整理し、考えを表す」。中学以降の文法の深化、古典の本格読解、批評の体系は別の拡張とする。幼児から全員が同じ順で小6の内容へ到達する保証をしない。

## 6系列の単元カタログ

下記IDは設計上の単元候補で、実装済みskillや制作済み問題IDではない。単元内のターゲット文字/語/関係条件を教材台帳で細分化する。「前」は学習順の参考。必須にできるのは、課題の成立に不可欠な前提だけであり、他系列全体の修了は要求しない。

| 系列 | 単元候補と段階 | 主な前提・境界 |
|---|---|---|
| K かな | K01 音と文字の対応、K02 清音の語、K03 濁音/半濁音、K04 拗音/促音/長音、K05 カタカナ、K06 語のまとまりと句読点を意識した短文 | K02は対象文字との出会い、K04は短い語の読字。K05はひらがな全修了を必須にしない。音読の流暢さは選択式から認定しない |
| H 漢字 | H01 身近な語の中の読み、H02 文脈による読み分け、H03 熟語の構成と意味、H04 送り仮名・同音異義、H05 漢字を使う表記、H06 見本なしの書字 | 学年別配当を各ターゲットへ付ける。文字単体の音訓と語の読みを区別。H05入力とH06手書きは別経路 |
| V 語彙 | V01 名詞/動作/性質、V02 場所/順序/数量の語、V03 語の仲間・反対/類義、V04 多義語と文脈、V05 気持ち/抽象語、V06 慣用句/ことわざ、V07 敬語・場面の言葉遣い | V01は聴解入口可。未知語の意味を覚えたことと、その語を文に使えることを分ける |
| S 文構造 | S01 主体と動作/対象、S02 助詞、S03 修飾のかかり先、S04 指示と参照、S05 時間/順序、S06 理由/結果/対比/条件、S07 複文と言い換え、S08 文のつながりと推敲 | S04には参照される語の理解、S06には対応する語彙。語順が複数成立する問題は全て正答として設計するか形式を替える |
| R 読解 | R01 明示情報、R02 二文の統合、R03 出来事/手順、R04 場面と根拠付き心情、R05 段落の中心/詳細、R06 段落の役割/関係、R07 全体の要点/要約構成、R08 主張/事実/意見と根拠、R09 図表と文章、R10 複数文章比較、R11 根拠の範囲/表現の効果 | R01→R02→R05→R06→R07が推奨幹。R03/R04は物語、R09は説明資料の枝。R10には比較操作、R11には根拠対応。各課題の語彙/読字負荷を別指定 |
| E 表現 | E01 伝える語を選ぶ、E02 一文を構成、E03 順序と理由をつける、E04 相手・目的に合う手紙/説明、E05 要約を自作、E06 意見と根拠、E07 推敲と引用、E08 話す/質問/応答/話し合い | E01認識→E02構成→E03以降の自作を区別。Rの確認からEの自作を認定しない。発話・交流は対話相手が必要な活動を明記 |

## 横断内容を落とさない

| 内容 | 学習への配置 | 初期の評価と供給範囲 |
|---|---|---|
| 聞く | 幼児の語彙、伝言、手順、複数の発言の比較 | 音声が必須刺激。聞いて選ぶ力を評価。文字の読字へ合算しない |
| 話す・話し合う | 絵の説明、質問、順序立てた説明、意見交換 | 任意の「声に出してみよう」。録音なし。本人の実施記録と保護者/教員の観察だけ。相手のいる話し合いはアプリだけで完結しない |
| 書字・書写 | なぞり、見写し、見本なし、漢字、句読点と原稿の整え方 | 紙/ペンでの活動案を用意。初期は自動合否なし。タイル操作を字形の産出にしない。毛筆は将来の人の活動として供給計画に残す |
| 言語文化 | 音の響き、昔話/ことわざ、詩・短歌/俳句、言葉の由来、古典への親しみ | 年齢に合う原作/権利確認済み文章で親しむ。暗唱は自動認定せず、古典の本格習得とは区別 |
| 情報と言語活動 | 辞書/索引、引用、出典、図表、目的に応じた記録 | 固定の小辞典や版付き資料を使う。インターネット検索や外部サイト訪問を子どもの必須操作にしない |
| 読書 | 物語・説明・自然・科学・生活・文化などを各帯で用意 | 読む/聞く/しおり/感想の任意記録。読了操作から理解や習熟を認定しない |

学校国語との完全対応表は未作成。上表は抜けを見えるようにした範囲設計で、学習指導要領の全事項を供給できるという宣言ではない。漢字の配当台帳・全1,026字の教材は[全配当漢字教材](../kokugo-kanji.md)へ採用し、文字数・読み数・供給済み数を混同しない。

## 原作の代表問題

以下は形式を明確にする設計例。教材採用には[校閲](content-and-data.md)が必要。正解位置は保存時に決めて固定する。

| 入口・主評価 | 刺激と問い | 解答・根拠 | 支援と未提示確認 |
|---|---|---|---|
| 3〜4歳 V01/聴解 | 音声「ねこが ねています」。同じ猫が寝る/走る/食べる3枚から選ぶ | 寝ている絵。物体名だけで解けない選択肢にする | 「ねています」の動作の小さな例。確認は別動物・別描写で同じ語義を扱う |
| 5〜6歳 K04/読字 | 文字「きって」。音声ボタン「きて」「きって」「きいて」を聞いて対応を選ぶ | 「きって」。評価は提示語と音の対応、本人の発音ではない | 対象語の読み上げは答えを教える支援。確認は未提示の「らっぱ」等、清音対比を別途校閲 |
| 小1 S02/助詞 | 絵は犬が猫を追う場面。「いぬ（が/を）ねこ（が/を）おいかけます」の二欄を選ぶ | 「が・を」。追う側と追われる側を絵に対応。逆の「を・が」も文として成立するが、この絵とは異なる意味 | 「だれが、だれを？」に注目。確認は別の動詞・別の登場物で役割と語順を変える |
| 小2 R02/統合 | 「はるは赤いかさ、なつは青いかさを持っています。青いかさの子が先に帰りました。」先に帰ったのは、はる/なつ/二人とも | なつ。所有と帰った子の情報を結ぶ | 青いかさの持ち主を探す。確認は人物/色の置換だけでなく、持ち物と渡し先等に関係を変える |
| 小3 R05/中心と詳細 | 「池では、いろいろな生き物がくらしています。水面にはアメンボがいます。水の中では小魚が泳いでいます。」全体を表す一文を選ぶ | 1文目。後の2例を含む範囲。例の一つだけを全体の要点にしない | 共通する場所と複数の例を示す。確認は中心が末尾にある別文も含む |
| 小4 R06/対比 | 「Aの種は風に運ばれます。一方、Bの種は動物の体について運ばれます。」共通点と違いを表の二列へ入れる | 共通は移動、違いは運び手。単なる単語抜き出しと関係理解を別記録 | それぞれの運び手に注目。別題材で対比の位置・表現を変える |
| 小5 R09/資料 | 表「火曜12人/水曜18人/木曜15人」。文「水曜は火曜より利用者が多かった」。この文を確かめる二つの数を選ぶ | 火曜12、水曜18。差の計算は要求しない | 対応する曜日に注目。確認は別グラフ形式。算数負荷を主評価に混ぜない |
| 小6 E06/意見構成 | 提示資料を読んで「どちらの案をすすめるか、理由と根拠を一つずつ挙げる」 | 自由な立場に単一正解なし。資料の引用・理由・意見を本人が見直す | 構成の枠と別題材のお手本。自動正誤なし。人の確認は観察として別保存 |

## 単元を制作へ渡す条件

各単元に、主評価・対象項目・必須前提・推奨前提・条件coverage・導入・支援・練習・未提示確認の候補・後日確認の候補・音声/ルビ方針をそろえる。確認教材の数が足りなければ、その段階の自動到達判定を無効にする。

「全学年の地図あり」「単元の設計あり」「教材が校閲済み」「アプリで供給可能」「別問で確認できる」は別の状態とする。教材制作数は目標達成の代用にしない。
