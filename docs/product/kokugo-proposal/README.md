# 国語の包括仕様案

2026-10-25：入口・初期教材・専用保存・支援・作品・報酬の実装契約は[国語コース](../kokugo.md)へ採用。全配当1,026字の追加は[全配当漢字教材](../kokugo-kanji.md)へ採用。以下の検討案には教材供給拡大などの後続候補も含む。

状態：提案 v0.1。2026-10-25。幼児〜小6の教材体系と本体への接続条件を具体化するための検討資料。採用済み仕様・実装・教材供給・公開を表さない。

## 目的と製品への効果

ことばを聞き、文字や文を読み、内容をつなぎ、自分のことばで伝える練習を、本人が選んで続けられるようにする。島の「愛着」に効き、読める手紙や楽しめる物語が増える入口になる。学習の都合で島のくふう・にぎわい・ふしぎを削らず、島の不足や困り顔で国語を迫らない。題材は島に限定しない。

公文式を、本人に合う入口、小さな段階、反復、文構造から読解・読書へつなぐ設計のベンチマークとする。設問・紙面・作品の利用権を引き継がず、独自教材を編集する。公文式と同等の学習効果や学校国語の完全代替をうたわない。

## 推奨する仕様の骨格

1. 「かな・漢字・語彙・文構造・読解・表現」の6系列に分ける。聞く・話す・読書・言語文化は横断タグで供給と評価の有無を管理する。
2. 子どもの入口は「ことばを きく」「もじを よむ」「ぶんを よむ」。内部の6系列すべてを最初に設定させない。初回以外は保存した続きへ入る。
3. 各単元は、出会う→練習→未提示の別教材で確かめる→必要に応じ後日確認。いつでも中断でき、全手順の通過を帰島の条件にしない。
4. 選択・構成・自力産出、読字・聴解、独力・支援、直後・後日を別の証拠として保持する。一つの総合国語レベルで代用しない。
5. 語彙や文字の反復と、別の文章に同じ読み方を使う確認を使い分ける。速さや正解数だけで次段階を決めない。
6. 自由作文・音読・手書きは活動として残すが、初期の自動合否の範囲から外す。タイピングの速さを国語力へ混ぜない。
7. 本文を見返せるまま答える。長めの文章は一つのまとまりを保ち、演出や教科切替で途中を切らない。
8. 固定教材と人の校閲を先に用意し、端末内で採点する。子どもの作文・声・写真を外部AIへ送らない。

## 既存仕様との境界

現行の正本は[憲法](../../../CONSTITUTION.md)、[親仕様01](../01_app_spec.md)、[29](../29_learning_progression_spec.md)、[31](../31_learning_units_spec.md)、[34](../34_learning_reinforcement_spec.md)。この提案はそれらを上書きしない。

現行コードの `SubjectKey` は math/vocab、`SubjectMode` は mix/math/vocab。国語の保存・学習コースは未接続で、既存enumへ一語追加すれば完成する機能ではない。[英語基礎](../english-foundation.md)は専用の予約・証拠・保存・outboxを持つ参考実装だが、その教材やwriter、進級規則を国語へ流用しない。

採用時には、国語の識別子 `kokugo` を教科選択・集計・本体adapterで認識させ、専用repositoryで評価する。既存math/vocabのキー・主レベル・復習・未完予約を再分類しない。国語を既存利用者のmixへ自動追加しない。
