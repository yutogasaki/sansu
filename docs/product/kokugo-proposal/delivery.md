# 国語の導入と受入案

[包括仕様案](README.md)の一部。全体仕様の具体化と、実装・教材供給・公開の完了を分ける。公開・push・DB移行・外部送信は各実行範囲の明示承認を要する。

## 段階の計画

| 段階 | 作るもの | その段階で確かめること | まだ言えないこと |
|---|---|---|---|
| G0 全体設計 | 8入口/6系列/横断内容、単元前提、形式/評価/保存/受入の仕様案 | 抜け、循環、未決の所在。代表問題の編集点検 | 全教材の完成、学校準拠、学習効果、本体統合 |
| G1 縦の一巡 | 聴解・読字・文理解の小さな校閲済みパック、読書/表現の最小活動、専用保存の試作 | 入口→導入→回答/支援→別教材→中断/再開。形式ごとに子どもの観察を始める | 幼児〜小2全範囲の供給、全年齢の確認 |
| G2 本体の限定接続 | 本人が選んだ国語、短い課題とoutbox、既存算数/英語との境界 | 実回答、既存保存、本人切替、音なし、offline、更新、二重配送 | 3教科mix、長文/作文の報酬の合意 |
| G3 年齢の幅を拡張 | 中高学年の段落・文学・説明・資料、各帯の書く/話す/文化/読書の供給 | 本文再開、条件coverage、非自動採点、内容の独立性と負担、経済との整合 | 全配当文字/全教材の完成、教育効果の一般化 |
| G4 進行の統合 | 試用で調整した確認/復習、本人が選ぶmix、保護者の範囲 | 個人別の進み方、欠測/不足、ジャンル偏り、旧予約/新予約の並存 | 自発的再訪の保証、長期定着の保証 |

G1を自動的に3帯全教材制作へ広げない。最初は小さな能力ごとに導入・練習・別教材・後日の候補をそろえる。対象はそのパックを利用できる範囲で明示し、他の年齢の設計を削らない。観察を最終段階だけにまとめない。

## 初期値と変更管理

| 項目 | 仮初期値 | 見直す材料 |
|---|---|---|
| おためし | 最大6問、最大2系列、中断自由 | 負担、入口の適合、誤分類 |
| 最初/通常短問 | 3問/最大6問、期限の確認は最大2問 | 自分で始める/やめる、理解、疲労 |
| 読解 | 本文1つ＋1〜3問、時間制限なし | 本文を読み切れるか、見返し、操作、実時間 |
| 別教材確認 | 独力初答3件、2内容family、対象単元の必須coverage | 偶然正解、教材供給、条件の適切さ、過剰な確認負担 |
| 後日確認 | 最終関連接触から24h以上＋期限後に独力1件 | 時計の信頼性、接触台帳、別文理解、実際の保持 |
| 間隔 | 1/3/7/14/30日の候補 | 語彙/文字と読解の違い、後日の実回答 |
| 本文長 | 固定の字数上限なし。短文/段落/複数段落を台帳で宣言 | 年齢だけでなく前提語彙、構文、画面、実読書時間 |

値と評価規則にversionを付ける。規則変更で過去回答を新しい独力として作り直さず、当時の条件を読めるようにする。しきい値が未実証であることは内部仕様/保護者詳細で示し、子どもには分析条件を常時説明しない。

## 受入シナリオ

| ID | 入力・条件 | 期待結果 |
|---|---|---|
| A01 | 年齢/入口だけ指定、他系列は未出題 | 指定は開始候補。全系列の習得を作らない |
| A02 | 読字は弱いが音声で物語を理解 | 聴解/支援付き理解は楽しめる。読字の成功へ合算なし |
| A03 | 文字→音の問題で対象読みをヒント再生 | 以後その課題は独力読字から除外。再生を止めても復活なし |
| A04 | listeningの必須音声を2回聞く | 再聴だけでは支援にならず、独力聴解が成立しうる |
| A05 | 同じ本文の3問、別のitemIdで回答 | 3実回答は保存、3つの独立familyとして確認を作らない |
| A06 | 別文で名前だけ変えた同じ話、直前に答え接触 | 露出group照合で確認資格なし。通常練習として保持 |
| A07 | 同じ漢字targetを別の未提示文脈で問う | 学習targetの繰返しだけで初見確認を拒否しない |

| A10 | 23:59に練習、翌日00:01に回答/時計逆行 | 後日確認にしない。誤答にも変えない |
| A11 | 期限前の早い復習、音声/お手本接触 | 期限の先送りなし。該当対象の最終接触と資格を更新 |
| A12 | Aタブで答え閲覧、Bタブで確認回答 | IDB transactionで照合し、Bの確認資格なし。欠測も保留 |
| A13 | 未提示の確認教材が尽きる | 確認保留、練習/別単元/読書/帰島あり。降格/架空進級なし |
| A14 | 助詞/語順に別解、自由短答がリスト外 | 閉じた正答集合の校閲、開いた短答はunscorable。未知別解を自動誤答にしない |
| A15 | 自由作文・音読・紙の書字を実施 | 活動/下書き/人の観察だけ。選択式と同じ自動習得なし |
| A16 | 本文3設問中2問目の入力中に閉じ再起動 | 旧本文版/順/入力/初答/支援/位置保持。済んだ1問を再採点しない |
| A17 | 下書き/回答/接触/完了/outboxの各保存を失敗させる | 成功表示なし、答え保持、資格不明を隠さず、再送で一度だけ確定 |
| A18 | 同一完了を連打/再送/島移動/ack失敗後再配送 | 1つのreceiptと1回の財布/まち時間更新 |
| A19 | 本人A回答中にBへ切替、古い音声/採点が完了 | Aへだけ保存、Bへ表示/加算なし。保存失敗では切替を保留 |
| A20 | 本人削除とoutbox配送が競合 | tombstoneに従って復活/再加算なし。作品/予約の削除境界も一致 |
| A21 | offlineで新規/未完を再開、必須素材欠損 | 供給可能な予約だけ出す。欠損は採点停止/再試行/別活動 |
| A22 | 旧/新の二つの実buildでPWA更新、旧タブも残す | 予約/採点版保持、旧writer遮断、ログ/下書き/報酬保持 |
| A23 | 教材の採点誤り判明、既に回答済み | 新規供給停止、過去履歴に訂正注記、本人誤答/罰/報酬回収なし |
| A24 | 320幅/短横/200%文字/音なし/reduced motion/キーボード/reader | 本文・回答・閉じる・支援へ到達、DOM順/ルビ/焦点保持、操作代替あり |
| A25 | 既存math/vocab/英語基礎の予約・Due・所有あり | 国語未選択で挙動不変。国語を選んでも旧記録を再分類しない |

## 人による受入

教材ごとに国語の校閲者が別解・根拠・自然な文・前提を確認する。子どもの小規模観察では、説明なしに始められるか、何を問われたか、答えの根拠、支援からの回復、本文への戻り、未提示教材、やめる/再開を観察する。本人が自分の言葉で説明できるかは任意の人の観察であり、自動正解率と別に記録する。

初期は各形式の問題点を発見できる少人数から始め、人数/年齢/既習条件/補助/既接触を明記する。比較条件のない前後正答率や少数の翌日訪問で効果を証明しない。長期定着と自発的な再訪の評価は別期間で実施する。

教材が複数の解釈を生む、文章を読む必要がない、入力が主な障壁、支援で帰れない、保存が不確実、報酬目的の細切れが起きる場合は該当範囲の配布を止めて修正する。技術PASS、教材採用、操作理解、学習上の有用性、再訪、公開を別々に判定する。

## レビュー時に残す判断

| 論点 | この案の推奨 | 採用前/配布前の判断 |
|---|---|---|
| 対象 | 体系は幼児〜小6、開始位置は能力別 | 最初の供給パックと対象の既習条件 |
| 書く/話す | 地図から外さず、初期から小さな活動。自動評価なし | 人の確認導線、紙活動の提供、縦書き/書写の導入順 |
| 漢字 | 配当タグと読み/意味/表記/手書きを分離 | 全配当台帳と読み・送り仮名の校閲、供給済み範囲 |
| 確認 | 小能力単位の仮3件/2family/coverageと後日事実 | 試用での妥当性と供給不足の頻度 |
| 表現/長文の経済 | 短問の現行契約を維持、活動は別記録 | 長文と表現を配布する前に報酬単位の公平性を判断 |
| 記念品/演出 | 新規の賞状・トロフィー・連続演出を自動追加しない | 学習証拠と記念の対応、既存演出の適用形式 |
| mix | まず明示国語。本人の追加後に区間単位 | 3教科の推薦・Due・希望の調停、長文保護 |

仕様案のレビューは、上表の推奨と保留箇所が読め、重大な状態矛盾がないところで閉じられる。正式採用、教材台帳の全件完成、実装、児童試行、公開はそれぞれ別の作業であり、未実施を完了としない。
