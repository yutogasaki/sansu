# 国語の画面と操作案

[包括仕様案](README.md)の一部。[現行UI方針07](../07_ui_design_guideline.md)、[ナビゲーション43](../43_island_navigation_spec.md)、[画面44](../44_display_layout_spec.md)を採用時の整合対象とする。新しいホームや常設タブを増やす提案ではない。

## 入口と画面遷移

| 画面 | 見えるものと主操作 | 戻り先・保存 |
|---|---|---|
| 学習の教科選択 | 算数/英語/国語。国語未選択者は本人が追加。既存利用者の通常学習を勝手に置換しない | 閉じる→開始元。既存の予約はその教科のまま保持 |
| 国語の初回 | 「どれから やってみる？」と、絵付きの3入口。主「はじめる」、副「ちょっと ためす」 | あとで→開始元。未選択から学力を推定しない |
| 国語の続き | 原則そのまま前の区間/問題へ。「ほかを えらぶ」は任意 | 学習開始前の画面をreturnToに保存 |
| 単元を選ぶ | 子どもには短い活動名と絵。6系列や学年一覧は必要時だけ開く | 選択変更は未完予約を上書きしない。保存して別の内容へ切替、後で元へ戻れる |
| 出会う | 対象の例・音・絵・短文。「やってみる」。読むだけ/再生だけでは採点しない | 途中保存し、再開して任意に導入を見直せる |
| 問題 | 本文、短い問い、回答、音/補助、ヒント、とじる。能力名や内部IDは常時表示しない | 下書きと表示状態を保存。とじる→開始元 |
| 区間の終わり | 「ここまで やったね」、主「つづける」、副「しまへ」。全問正解の強要なし | 次区間は本人の継続意思で開始。未配送報酬は別に保持 |
| 読書 | 作品一覧、本文/音声、しおり。「とじる」。クイズや読了ノルマを置かない | 最後の箇所と本人の任意記録を保存 |
| 表現 | テーマ、任意の構成カード、下書き、見直し、「ここまで保存」 | 自動正誤なし。自分で終えた記録と人の観察を区別 |
| きろく | 学んだ日と内容、別教材/後日で確かめた例、読書/作品 | 国語総合点・他人の順位・学年からの遅れを表示しない |
| 保護者の詳細 | 取り組み量、形式/補助条件別の証拠、教材の供給状態、開始位置と範囲 | 未制作/未確認を本人の不得意にしない。適用先と保存時点を明示 |

mixは後の接続段階で、本人/保護者が明示して加えた教科だけを使う。途中の本文で割り込まず、予約境界で次の教科希望を適用する。国語を外しても記録/未完予約を消さない。旧mixの配分を国語導入だけで変えない。

## 問題画面と入力

短問では問題・相棒・回答を同じ視野に置く。読解では本文を主役にし、飾りや相棒で段落を隠さない。新規配色を独自に足さず、既存デザインシステムの文字・余白・操作を用いる。

| 形式 | 解答の確定 | 操作上の条件 |
|---|---|---|
| 2〜4択 | 選択で一回答を確定 | タップの二重発火を抑止。採点前に初答を消さない |
| 語句/文の並べ替え | 「これで おくる」で確定 | タップで入れる/戻す、キーボードで選ぶ/移動する。ドラッグは任意。要素の仮置きは初答でない |
| 根拠/抜き出し範囲 | 範囲選択→確定 | 文/語句ごとのボタン、始点/終点のタップ代替。指で細い文字をなぞることを必須にしない |
| 短答 | 入力→「おくる」 | IME変換中のEnterは提出しない。読みにかな入力、意味課題には範囲選択等の代替。形式が変われば証拠も分ける |
| 複数欄/比較表 | 全体を確認して一度確定 | 部分正解を全問独力へ足し合わせない。誤答の修正でも元の初答を保存 |
| 自由表現 | 下書き/見直し/本人の区切り | 空欄保存は可能だが完成記録にしない。文字数で上手さや習得を判定しない |

短問は保存後、短いfeedbackから次問へ進む。読解の設問は本文を見直せる「つぎへ」を置き、読みの途中を自動で飛ばさない。これを短問と同じthroughput要件で落とさず、次問readyまでの技術遅延と本人の読書時間を分けて測る。

## 本文と回答を行き来する

- phone縦は本文→問い→回答の順。本文はいつでも展開/スクロールで見返せ、回答中に消去しない。「本文へ」で元の読書位置へ移り、戻ると下書きを復元する。
- tablet/広い画面は本文と設問を2列にできるが、DOMの読み順は本文→問い→回答。独立scrollの焦点と現在の列を分かるようにする。
- 本文のページ分割は段落/場面に従う。設問の根拠を含むページへ戻れる。一文を不自然な位置で切らず、ページめくりだけで報酬を付けない。
- 初期は横書きを基準にする。縦書き作品は専用renderer、ルビ、句読点、キーボード、screen readerを受入できた配布段階から加える。横書き初期版で縦書き経験まで供給済みとしない。
- 本文1つの設問を途中で終えても、残りの設問・版・本文位置を保持する。再開で本文を別の版へ差し替えない。

## 支援と子ども向けの言葉

最初の誤答は「もういちど みてみよう」。必要時に「ここを みてみよう」→小さな別例→「いっしょに たしかめよう」のお手本へ。正解を教えた後は「たしかめられたね」とし、独力正解の表示をしない。

本文の通常参照はヒントではない。正解箇所だけを強調する/候補を減らす/答えに必要な対応を教える操作から支援記録を残す。「あとで」「しまへ」は全段階で使える。悲しい顔、誤答音の連打、時間切れ、罰、島の破壊を使わない。

補助の全文音声とルビは使ってよい。使ったことで責めず、記録でどの条件の理解だったかを分ける。ルビを隠した直後の再回答で独力に戻さない。

## 中断と例外

| 条件 | 画面の結果 | 保持するもの・採点 |
|---|---|---|
| 未完でとじる/背景へ | 保存できれば開始元へ。再開時は続き | 本文位置、設問、下書き、初答、支援、版。未完報酬なし |
| 保存失敗 | 「まだ保存できていません。答えはこの画面にあります」＋再試行 | メモリ上の入力を保持。保存済み表示/次問の確定なし。破棄して帰る場合のみ明示確認 |
| 素材/音声が欠損 | 再試行/利用可能な別活動/帰る | 誤答にせずassetUnavailable。未完予約は保留。必須音声のない聴解を黙って読字へ替えない |
| 音オフ/聞こえない | 音声を使う確認では採点開始しない。明示操作で一時再生、または別活動 | 代替体験は元課題の聴解成功にしない。音声必須以外は音なしで継続 |
| 初見確認の候補不足 | 「新しいたしかめは、またこんど」＋練習/別単元/読書/帰る | 不足理由。降格/架空の確認成功なし |
| 既に別タブで進行 | 「別の画面でつづきが変わりました」→最新へ | 古い入力を別問へ適用しない。競合下書きは元assignmentに紐付けて退避 |
| 本人切替 | 元本人の保存を完了して音を止め、新本人の入口へ | 元予約を消さない。保存失敗は切替を保留。破棄する場合の対象を確認 |
| 教科/単元を変える | 元予約を中断保存し、選んだ活動へ | 同じ本人に未完予約が複数あってもactiveは一つ。元の続きへ戻る選択あり |
| 旧版が表示できない/採点誤り判明 | 「この問題はいま開けません」＋別活動 | 回答は保持、採点停止。新しい問題へ下書きや正答を流用しない |
| 自由な短答を判定できない | 「いま自動でたしかめられません」＋お手本/あとで | unscorable。誤答・苦手・独力成功なし |
| 時計や接触情報が不明 | 問題自体は練習として継続可能 | 後日/未提示の確認資格は付けない |

## アクセシビリティと負荷

320×568、390×844、768×1024、568×320、文字200%、OSの大きい文字、音なし、reduced motion、キーボードとscreen readerを対象にする。主要操作44px以上、本文は初期20pxを候補とし、ユーザー設定で拡大可能。ルビと行間を含む実寸で折返し/欠け/横はみ出しを確認する。

色や音だけで正誤・選択状態を示さない。画面readerの語順、漢字の読み、ルビの重複読みを実機で確認する。readerや外部読み上げ利用は完全観測できないため、アプリログだけで補助なし読字を証明しない。補助条件の申告を保存でき、学校等の診断用途に使わない。

読み上げは重ねて再生せず、設問変更/退出/背景化/本人切替で停止。読み上げの音量・速度をゲームの効果音と分けて扱う。制限時間や速さランキングは付けない。
