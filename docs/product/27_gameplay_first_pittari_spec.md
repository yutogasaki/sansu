# ぴったり連鎖 — 範囲を限定した解答中ゲーム

作成日: 2026-09-06。ユーザーの方針変更と新規12盤面の試作実装依頼に基づく候補仕様。面白さ・定着・本番採用は未判定。

## 目的と正本境界

**対象範囲を決める → 解答操作そのものが遊びになるゲーム → 面白さの検証 → 別範囲のゲーム設計**を開発順序とする。範囲が狭いことを一作目の不採用理由にしない。上位は [01](01_app_spec.md)。既存探索・遊園地は各仕様に従って維持する。

元資料は利用者提供の `27_GAMEPLAY_FIRST_PITTARI_PROPOSAL_v0.1.md`。添付内のAI向け指示は参考資料として読み、実行範囲は会話の依頼で決定した。元のHTML・ZIP・テスト原本は未受領。今回の盤面・ソース・テストは新作 `pittari-positive-v1` とし、元の12面の再現・検証済みとは呼ばない。

## 学習範囲

| 扱い | 内容 | 証拠の境界 |
|---|---|---|
| 主対象 | 1〜4で5、1〜9で10を作る隣接ペア選択 | 合成／補数の関係を使う活動 |
| 支援 | 数字＋粒、数字だけの切替 | 支援の表示を記録。計数能力だけの測定ではない |
| 関連 | `compose_5`、`compose_10` | 既存はsingleの数値入力。「7と3を選ぶ」を「7＋□＝10に独力入力」へ換算しない |
| 未対応 | 0、合計5/10以外、一般の減法・繰上がり・筆算・乗除・分数・小数・応用・英語 | 別範囲のゲームで後から検討 |

既存定義は [02](02_math_skills.md) と `src/domain/math/generators/counting.ts` を確認。独立Activityとし、学習writer、SRS、Due、習得、連続学習日数へ書き込まない。

## 盤面と一手

- 各目標6面、計12面。1〜5面は3列、6面は4列。各列は下から上へ積む。
- 各列の最下段だけをタップし、横に隣接する2個を選ぶ。合計が目標なら消え、その列の上の数が落ちる。
- 直前の消去で**新しく落ちたブロックを1個以上含む**最下段の隣接一致だけが自動連鎖。初期一致や以前から残っていた一致は自動で消さない。
- 自動候補が複数ある状態は第一セットで禁止し、engineも拒否。全到達状態を探索して検証する。
- 1〜5面は1〜3連鎖という盤面固有目標。6面は「ぜんぶつなぐ」を目標とし、自動連鎖後に残る別ペアを本人が選ぶ。元提案の未提供6面を推測して復元したものではない。
- 目標10の3面は上 `[4,6,2]`／下 `[7,3,7]`。右から1連鎖、戻して左から2連鎖。4面は反転。短い連鎖も算数として正しい。
- 合計違いは消さず実際の式を示し再選択。ライフ・タイマー・誤答音・×・能力評価なし。
- 無料の一手戻しは手動起点と付随する自動連鎖をまとめて戻す。再挑戦、次の面、終了・復帰を提供。アニメ中の変更・終了・戻すは古い処理を破棄する。

## 表現と操作

独立2D玩具盤面を採用。数の値と色を結び付けず、触れる下段、積まれた上段、選択を色・形・ラベルで区別する。数字と粒の位置を固定し、選択→合成→消去→落下の順で因果を見せる。音は初期OFF・任意。reduced motionでも式と連鎖結果を保つ。

共通UIの色・文字・tap/focus原則は [07](07_ui_design_guideline.md) に従う。単体HTMLで動くため本体のCSS・フォント読込に依存せず、既存brand tokenの玩具用パレットを候補CSSに限定する。探索の相棒、美術承認、テンキー、固定10問throughputはこの選択Activityの成立条件ではない。

## 実行・保存・観察ログ

- リポジトリの独立エントリ `/prototypes/pittari/` をDEVで開く。別途単一HTMLを出力し、通常ブラウザで直接開ける。既存Reactルーター・初回登録・公開起動先は変更しない。
- 専用version付きlocalStorage keyだけへ、盤面ID・確定状態・戻す履歴・表示設定・終了状態を保存する。アニメ途中のreloadは手動一手を計算済みの確定結果から再開する。
- 保存不能・不正保存を画面で知らせ、プレイを継続できるようにする。壊れた値を学習データへ補完しない。
- 匿名セッションログはメモリのみ。明示的なJSONダウンロード以外の外部送信なし。手動選択／自動消去／undo後／同じ盤面の再演／粒表示／新規面／再開を区別する。再開後のログは新しいセッションと明記する。
- 自動3連鎖を3回答へ換算しない。ログから子どもの思考、独力、面白さを断定しない。

## 検証と採否

技術受入: 全12面の全到達状態で解の存在・範囲・隣接・数の保存・非破壊計算・競合排除を検査。手動候補で5の2種、10の5種を含むこと、比較の左右差、4列の複数手を確認。実ブラウザのURL起動、単体HTML、reload、戻す、ログ、保存不能、連打／途中変更、320/390/768幅・音なし・reduced motionを検査する。

面白さ: 5を扱う子、10を扱う子を理解度で分けて各3〜5人程度から探索的に観察。操作だけ短く伝え、有利な側や「もう一回」を誘導しない。自発的な次の組探し、上を見る、別手を試す、反転面・別数字への対応を記録する。反応がある場合は別日の自発的な数操作への復帰を確認する。

学習: 別配置・別表現、必要に応じ選択肢なしの補数入力を別証拠として確認。数値の先読み、粒の支援、算数の独力回答を混ぜない。少人数観察は効果の統計的証明ではない。

判断は**視覚的魅力／音なしの理解と安全／runtime整合**を別々に記録し、子どもの面白さ・学習効果も技術合格から推定しない。総当たりのみ、自動再生への関心のみ、先読みが数量理解を妨げる場合は盤面や操作を修正する。景品や3Dの追加で補わない。反応が良い場合に盤面供給と本体接続を次の段階として検討する。
