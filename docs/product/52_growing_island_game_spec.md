## 0. このゲーム

> **置くと、島が自分で育つ。学ぶと、島の時間が進む。育った島は、その子だけの形になる。**

### 0.1 一周：あそぶ・しこむ → まなぶ → ひらく

| 段階 | 子どもの気持ち | 起きること |
|---|---|---|
| **あそぶ** | 「うさぎをブランコに乗せよう」 | 住人をつまんで運ぶ。何を触っても返事がある。しずくも学習もいらない |
| **しこむ** | 「あのカワウソの家を、水のそばに建てよう」 | 桟橋で住みたい子が待っている。たねを置くと、その子が跳ねて喜び、育った姿の影が出る |
| **まなぶ** | 「たねが2つ待ってる」 | 普段どおり学習する。完了するたびに島の時間がたまる |
| **ひらく** | 「ポン！ 家が建った！ カワウソが来た！」 | 戻ると、しこんだ所がつぼみになっている。自分で触って開ける。船を触ると住人が降りてくる |

寝る前に種をまいて、朝に見に行く。それを学習1回ごとに、自分の指で味わう。

### 0.2 目指す瞬間（この仕様の合否はここで判断する）

1. 開いたらすぐ、触って遊べる。
2. 待っている子のために家を建て、学習から戻ると、その子が住んでいる。
3. つぼみを開けるのが楽しみで、学習に行く。
4. 置いたたねから、思っていなかった形の町ができる。きょうだいの島と全然違う。
5. 前に置いた小さな木が、いつのまにか大木になっている。
6. 島を見せると「これ、じぶんで つくったの？」と言われる。

### 0.3 設計のものさし

- **子どもは決めて、遊ぶ。島が働く。** 建てる・道を引く・運ぶは島の仕事。
- **何を触っても、すぐ返事がある。**
- **欲しいものは、数字でなく「人」で見せる。**
- **置く前に結果が見える。開けるのは自分の指。**
- **島で冒険させない。** 探す・頼まれる・集めに行く、はない。
- **何も減らない。** 飢え・枯れ・退去・荒廃・期限はない。
- **大人の仕組みは裏に置く。** 人数の余裕・すみごこち・げんきは数字で見せず、住人・つぼみ・ひとこと・おまつりで見せる。
- **縛りすぎない。** 遊んで楽しい方を選ぶ。

## 2. 島の時計

| 時計 | 進み方 | 動かすもの |
|---|---|---|
| **しぜん** | 実際の時間。1回の不在は最大7日分 | 植物の成長、土の湿り、しぜんの広がり、木の年齢 |
| **まち** | **学習の完了でだけ進む**（§10）。たまった時間は「ひらく」で使う | 家が建つ・育つ、引っ越し、道、しまのげんき |
| **くらし** | 島の画面を開いている間 | 住人が歩く・座る・運ぶ・食べる、つまんだ住人の遊び |
| 景色 | 端末のローカル時刻で朝・昼・夕ぐれ・夜を自動表示 | 見え方だけ |

景色は朝5:00〜10:00、昼10:00〜16:00、夕ぐれ16:00〜19:00、夜19:00〜翌5:00。手動の時間選択は表示せず、以前の選択を使わない。開いたままでも30秒以内に時刻を再確認し、画面への復帰時も更新する。庭・家overview・訪問先・見せるモードに同じ時刻の光を使う。時刻やタイムゾーンの変更は景色だけに反映し、成長・出会い・学習・保存の規則へ渡さない。夜も顔・通路・置く場所が読める明るさを保ち、夜だけの取得条件を設けない。

- まちの時計は0時から始まり、**毎朝6時が夜明け**。引っ越し・すみごこち・げんき・道の判定は夜明けに行う。
- 同じ時刻では、1) たねが建つ 2) 家が育つ 3) すみごこちとげんき 4) 引っ越し 5) 道 の順に処理する。
- 学習しない日も、しぜんとくらしは進む。止まるのはまちの出来事だけで、罰ではない。
- 端末の日時を変えても、まちの時計は進まない。しぜんの時計は、戻った時刻を0として扱い、過去へ戻さない。

## 3. くらしの たね

### 3.1 4種類

| たね | 値段 | 島が育てるもの | 働き |
|---|---:|---|---|
| **すむ** | 4 | テント → こや → いえ → ふたかいだて | 住める人数：1 / 1 / 2 / 2。小さく保ち、新しい子にはたいてい新しい家がいる（しこむ一周を残す） |
| **たべる** | 4 | はたけ（作物は周りで変わる） | ごはんを支える人数：水の影響があれば3、なければ2 |
| **あそぶ** | 6 | あそびば（形は周りで変わる） | あそびを支える人数：4 |
| **しぜん** | 1 | 花・草・しだ（周りで変わる）。少しずつ広がる | 島の性格（§6）、住人の好きなもの |

- 最初に選べるのは「すむ」と「しぜん」。「たべる」は最初の住人が来たら、「あそぶ」はしまのげんきLv2で開く（§8）。
- どれも1マス。家は上へ育つ。
- 空いた土地のマスに置ける。ぽこもこの家・他の物・海には置けない。野生の花の上には置け、花は片付く。

### 3.2 周りで形が変わる

建つ瞬間に、周り2マス以内の環境で形が決まる。**同じたねでも、置く場所で違う物が育つ。**

| 周りで一番多いもの | すむ | たべる | あそぶ | しぜん |
|---|---|---|---|---|
| 水 | 高床の家 | れんこん畑 | 水あそびば | あし・水辺の花 |
| 木 | 木の上の家 | きのこ・木の実 | ブランコ | しだ |
| 花 | 花の屋根の家 | いちご畑 | 花のベンチ広場 | 花 |
| あかり | 窓の多い家 | かぼちゃ畑 | ちょうちん広場 | ほたる草 |
| 特になし | 丸い屋根の家 | にんじん畑 | ひろば | 草むら |

- 点数（§6と同じ重み）：水＝水ばち2・水の通ったみずみち1。木＝成熟木2・若木1。花＝咲いた花1・咲いた野生の花1。あかり＝灯り2・とうだい4。最高点が1未満なら「特になし」。同点は表の上から。
- 建った後に周りが変わっても形は変わらない。**昔置いた家が、その時代の風景を残す。**
- 屋根の色は本人がいつでも塗り替えられる（§1）。形は変わらない。

### 3.5 ふしぎの たね（2026-10-01）

- しまのげんきの**Lv3・5・7・9**に届く（1つずつ）。「たね」に出て、無料で置ける。育つ前にしまうと、たねに戻る。
- 置いてから6時間で、周りに合わせた**ふしぎの品**になる：木・花の近く＝**ハートの木**（ブリットの色面）、水・あかりの近く＝**ひかる みずたまの アーチ**（くぐれる）、それ以外＝**みずたまの かぼちゃの いえ**（草間の水玉）。
- あそび3として働き、島の性格の点数（花・あかり・畑の2点）にもなる。島の目玉になる品で、学習を続けて島がげんきになった証。

### 3.3 しこむときの手応え

1. たねを選ぶと、置ける場所がうっすら光る。
2. 指で動かすと、**育った姿の影**がその場所の形で出る。
3. 水・木陰・あかりの届く範囲が地面に重なる。
4. 置くと**すぐ**：
   - 杭と旗（すむ）、畝（たべる）、囲い（あそぶ）、芽（しぜん）が出る。
   - すむのたねなら、**桟橋の旅人が跳ねて喜ぶ**（§7.2）。
   - 近くの住人が1人、見に来て覗き込む。
5. 建つ前なら、しまうと値段が全部戻る。

### 3.4 建つ・育つ（まちの時計）

| 段階 | 必要なまちの時間 | ほかの条件 |
|---|---|---|
| たね → 最初の形 | 置いてから6時間 | ぽこもこの家から歩いて行ける |
| テント → こや | 建ってから24時間 | 住人のすみごこち平均★1以上、しまのげんきLv2 |
| こや → いえ | 48時間 | 平均★2以上、Lv4 |
| いえ → ふたかいだて | 96時間 | 平均★3、Lv6 |

- 家の段階は夜明けの判定で上がる。たねは6時間たった時刻に建つ。
- 歩いて行けないたねは建たず、ひらくの最後にぽこもこが「ここまで いけないみたい」と言い、ふさいでいる物を光らせる。
- 育った段階は戻らない。

## 5. しぜん

- **育つ**：植物はしぜんの時計で育つ。速さは土の湿りで変わる（現行式）。枯れない。
- **広がる**：咲いたしぜんのたね・野生の花は、しぜんの12時間ごとに、隣の空いたマスへ1つ広がることがある（土の湿り0.35以上、確率0.5、決まった乱数）。家の前・たね・目印・ぽこもこの家の前には広がらない。島の土地の4割が上限。野生の花は、タップで「つむ」と消え、上にたねを置くと片付く。
- **年を重ねる**：木は成熟から7日で大木（木陰+1マス、住人が下に集まる）、30日で「ぬしの木」（島の目印になる大きさ、ひらくで一度だけ特別に映す）。

### 5.1 まざる花（2026-10-01）

- 花のめじるしには色がある。子どもが植えられるのは、あか・きいろ・しろ（最初から）、あお（Lv2）。
- 咲いた花のうち、色の違う2つが2マス以内にあると、しぜんの24時間ごとに4割の確率（決まった乱数）で、2つの間の空いたマスに**新しい色の花**が芽を出す。1回で1つの花は1組だけ親になる。花は島の土地の25%まで。
- 色の組み合わせ：あか＋きいろ＝オレンジ、あか＋しろ＝ピンク、あか＋あお＝むらさき、あお＋しろ＝みずいろ、きいろ＋しろ＝クリーム、きいろ＋あお＝ミント。オレンジ＋むらさき、ピンク＋みずいろ、クリーム＋ミントで**ふしぎな みずたまの花**（差し色 §19.1）。
- **はなずかん**（メニュー）：咲いた色が載る（全11色）。親の2色がどちらも載っている色には「◯◯と ◯◯を ならべてみよう」とヒントを出す。
- 新しい色が咲いた日は、ひらくの最後にぽこもこが「あたらしい いろの はなが さいたよ！」と言う。色を持たない昔の花はピンクとして扱う。

## 6. 島の性格

土地の点数（§3.2と同じ数え方を島全体で行う。畑は1つにつき2）で、最も多いものが全体の3割以上、かつ合計6点以上なら、その性格になる。

| 最も多い | 性格 | 来やすい住人 |
|---|---|---|
| 水 | みずべの しま | カワウソ・カモ |
| 木 | もりの しま | キツネ・リス |
| 花 | はなの しま | うさぎ・ことり |
| 畑 | はたけの しま | ハリネズミ・うさぎ |
| あかり | ほしあかりの しま | ことり・キツネ |
| 条件に届かない | いろいろの しま | 全員が同じくらい |

性格は島の名前の下に出る。変わった日は、ひらくの最後に「しまが、もりの しまに なったよ」。

## 7. 住人

### 7.1 顔ぶれと性格

| 種類 | 状態 | 好きなもの |
|---|---|---|
| ぽこもこ | 最初から。姿は変えない（CONSTITUTION §4-9）。ぽこもこの家に住む | — |
| うさぎ | 既存 | 花・あそび |
| カワウソ | 既存 | 水・ごはん |
| キツネ | 骨格が既存 | 木・あかり |
| カモ | 新規 | 水・あそび |
| リス | 新規 | 木・ごはん |
| ハリネズミ | 新規 | 畑・しずか |
| ことり | 新規 | 花・あかり |
| **えま**（女の子） | 新規・一人だけ | 水・あそび |
| **えいた**（男の子） | 新規・一人だけ | 木・ごはん |
| ペンギン | 珍しい（2026-10-01） | 水・しずか |
| ふくろう | 珍しい | 木・あかり |
| かえる | 珍しい | 水・花 |

- **動物は同じ種類が何人来てもよい。** 個体は色6種 × 小物4種 × 性格4種で見分ける。来た子には種類ごとの候補から名前が付き（島の中で重ならないもの）、あとで付け直せる。
- **えまとえいたは島に一人ずつ。** 名前・姿・好きなもの・性格（げんき）は決まっていて、名前は付け直さない。2番目と3番目の船で1人ずつ来る（どちらが先かは島ごとに違う）。それより前に別の子が来ていた島では、まだ来ていない方が来やすくなる（重み3）。
- **性格**：げんき（よく走る・ブランコ好き）、のんびり（ベンチで長く座る）、はずかしがり（家の近くにいる・触ると照れる）、くいしんぼう（食卓によく行く）。歩き方・ひとこと・よく行く場所が変わる。
- **珍しい住人**（ペンギン・ふくろう・かえる）は船に来る重みが小さい（0.35）。それぞれ水辺・森・花の島では3倍。
- **触ったときの返事**：げんきな子はくるっと回り、はずかしがりはそっぽを向いて照れ、ほかの子は手を振る。歩くと腕を振り、えんそうかいでは両手を上げる。
- 住人は本人が付けた名前を呼ばれると手を振る。夜の景色では家に入って眠る。好きなものが同じ住人同士は「なかよし」になり、よく一緒にいる。
- 「しずか」は、家の周り2マスにあそびばがないこと。

### 7.2 桟橋の旅人と、次の船

- 島の桟橋に、**住みたい子が一人**、船で来て待っている。釣りをしたり、島を眺めたりしている。頭の上に家の絵。**悲しまない・急かさない・期限なし。一度に待つのは一人だけ。**
- 遠くの海に、**次の船のシルエット**が見える。どの種類かは影の形で分かり、珍しい色なら影が光る。
- **次の船は、前の子が引っ越してから「24＋2×住人の数」まちの時間で桟橋に着く。** 海の上で少しずつ近づいて見え、学ぶと近づく。村が大きくなるほどゆっくりになり、学習を増やさせずにペースが整う。
- 旅人の種類は、その船が現れた時点の島の性格で、重み付きの抽選で決まる（性格の「来やすい住人」は重み3、それ以外は1）。一度決まった旅人・次の船は変わらない。
- 珍しい色（きらきら）は**島全体の豊かさ**（§6の点数の合計）で5〜15%。**学習の回数・まちの時間の長さでは変わらない。**
- 乱数は島ごとの種・種類・通し番号で決め、開き直しても同じ結果になる。

### 7.3 引っ越し（夜明けごと）

- 船が桟橋に着いていて、次の二つがそろうと、旅人が引っ越す（夜明けごとに1人まで）。ぽこもこの「おすそわけ」で、最初の2人分のごはんはいつもある（畑がなくても2人までは来られる）。
  - **すむ**：空いている家がある（住める人数の合計 ＞ 家に住む住人の数）
  - **たべる**：ごはんに余裕がある（ごはんを支える人数の合計 ＞ 住人の数）。畑・鉢は、ぽこもこの家かピクニックテーブルまで歩いて行けるときだけ数える
- 来た子の後ろに、新しい次の船が現れる。
- 家は、空いている家のうち、旅人の好きなものに近い家を選ぶ（同点は建った順）。
- 引っ越しは船が島に着いた状態で止まり、**子どもが船を触ると降りて家へ歩く**（§11）。
- 退去はない。「おでかけ中」にはできる。

### 7.4 すみごこち（★0〜3。夜明けに判定）

- ★ 好きなものの1つが、家から3マス以内にある（「ごはん」は、ごはんに余裕があること）
- ★ ごはんに余裕がある
- ★ あそびば・ベンチ・ブランコ・きねんひんのどれかが家から3マス以内にある（「しずか」好きは、あそびばがないこと）

★は画面に数字で出さない。住人の表情と、触ったときのひとことで伝える（「おはなが ちかくに あったら うれしいな」）。低くても出て行かない、悲しまない。

### 7.5 くらし（島を開いている間）

住人は歩く・座る・運ぶ・食べる・なかよしと並ぶ。現行の運搬（鉢→かご→食卓）を使う。画面に見えている住人から最大12人が動き、他は家の中で過ごす。つまんだ住人は、置いた所で遊んでから普段のくらしへ戻る。

## 9. 土地

- 初期は現行の `x=0..5, z=0..4`。ぽこもこの家・既存の所有・座標は変えない。
- 拡張1〜3は現行の東・西・南（12 / 24 / 48しずく）。拡張4・5は東西へさらに3列ずつ（岬、72 / 96しずく、Lv5 / Lv6）。岬の段を高くしすぎると「人が増えないとレベルが上がらず、土地がないと人が増えない」行き詰まりになるため、この段にする。
- 広げる前に、新しい土地の形が見える。権利は取り消されない。

- **拡張6以後は地区を増やし続けられる。** 東・西は外側へ3列、南は3行を加える。方向は毎回本人が選ぶ。価格は拡張6が120、以後24しずくずつ増える。追加のレベル条件・回数上限はない。初期座標、既存5段階の価格・形・権利は保持する。装飾と家が同じ有限土地を奪い合って終わる状態を避け、しずくを任意の地区づくりに使えるようにする。維持費・退去・学習の報酬減額は足さない。

## 10. 学習とのつながり

| 学習の結果 | 島 |
|---|---|
| 有効な完了1件（独力・支援とも） | **2しずく** と **まちの時間4時間** |
| 誤答・途中でやめた・お手本だけ | 0。減らない |
| 単元を独力で身に付けた | **まなびの きねんひん**が1つ届く |

- 6件でまちの1日。出題・採点・支援・独力判定・復習期限は変えない。同じ完了は二度数えない（現行の完了IDを使う）。
- **上限は設けない。使える仕事がなくなったまちの時間は、使い切らず残す。** たねの建築、条件を満たした家の成長、次の船の到着、新規入居、げんきの更新に使う。船が着いても空き家・ごはんがなく、ほかに進められる仕事がなければ止まる。次の配置・経路回復・自然の成長で条件がそろうと、保存した時間を使える。学習前に仕込まなかった分も捨てない。残高・時間・完了IDは同じtransactionで保存する。同じバッチ内の重複完了も二度数えない。
- **きねんひん**：単元ごとに決まった形（かずの つみき、けいさんの ふんすい、くくの とけいとう、ことばの ほん など10種）。さんすう・えいごの**主レベルが上がった**とき、そのレベルに1つ届く（主レベルは独力の証拠でだけ上がる。[34](34_learning_reinforcement_spec.md)）。島を始めた時のレベルは基準にするだけで、さかのぼって配らない。同じレベルに二度届かない。「しまってある」に届き、置く場所は本人が選ぶ。あそび2として働く。
- **学ぶ前**：下の「まなぶ」に、まだ開いていないたねの数（🌱2）。「あと何問」は出さない。
- **学習中**：画面の上端で小さな太陽が完了ごとに進む。設定で消せる。
- 学習の途中で島へ戻っても、それまでの完了分はひらける。

## 11. ひらく

学習から島に戻ると、たまったまちの時間を**まとめて一度に計算**し、結果を「開ける物」として島に置く。途中で閉じても結果は同じ。

残っている時間があるときは、たねを置く・移動して道を戻す・供給を置く操作の保存と同時に、進められる分だけひらく。「たね」の面に、時間が残っていることと置けば育つことを伝える。学習へ戻る操作を要求しない。

### 11.1 流れ

1. 空が夜明けになり、太陽が昇る（2秒）。
2. 島に、変化した場所ごとの**光るつぼみ**が現れる。カメラは一番近いつぼみへ寄る。
3. **子どもがつぼみを触るとポン！と開き**、建った家・育った家・畑が現れる。音と小さな紙吹雪。
4. 引っ越しがあれば、**船が桟橋に着いている。触ると住人が降りて**、自分の家へ歩き、振り返って手を振る。名前を付けるか聞く（あとでもよい）。
5. 全部開けると夕方になり、灯りがつく。ぽこもこが一言でまとめる。レベルアップの日はおまつり。新しい品・性格の変化・来なかった理由（§11.3）もここで伝える。
6. 次の船のシルエットが遠くに現れる。

- 右下の「ぜんぶ ひらく」で一度に開けられる。開けずに遊び始めてもよく、つぼみは残る。
- 大木・道の成長・小さな出来事は、つぼみにせず、夕方の場面に入れる。
- 何も変化がなかったときは、住人が遊ぶ3秒の「のんびりした じかん」を見せる。
- 動きを減らす設定では、ポンの演出を短いフェードにする。

### 11.2 小さな出来事

見ていれば起きる驚き。条件のそろった日に、決まった乱数で1つまで。

| 出来事 | 条件 |
|---|---|
| 雨上がりの虹 | 土の湿りの平均が0.42以上 |
| なかよしが並ぶ | 好きなものが同じ二人の家が2マス以内 |
| 流れ星 | 景色が夜、あかりが2つ以上（見ている間に時々。記録しない） |
| まれな おきゃく | みなもの たびどり：あかりから2マス以内の水ばちと、その近くの咲いた花。こもれびの おきゃく：成熟木の2マス以内に行けるベンチと咲いた花2つ（仕様51 F-V01/F-V02を簡単にした）。住人にはならず、一晩だけ来る |
| ちょうちょの群れ | 咲いた花が6つ以上 |
| くじら（一晩のお客） | 水ばち・ふんすいが2つ以上、またはとうだい。海から現れて潮を吹く |
| にじいろの とり（一晩のお客） | はなずかんが5色以上 |
| つきの うさぎ（一晩のお客） | あかりが3つ以上 |

- 小さな出来事の時計は**実時間**。島に参加してからの24時間の区切りごと、開いたときに1回だけ判定する。学習完了・まち時間・往復回数で抽選回数を増やさない。日ごとの決まった乱数で6割、まれなお客はその中の3割の日に候補となる。留守の日をまとめて抽選しない。結果があれば表示待ちとして保存し、表示前の再読込で失わない。表示開始後に同じ日を確認して表示済みにする。表示待ちがある間は新しい抽選をせず、先の結果を保持する。時計を戻しても引き直さない。旧保存の切替当日は追加で抽選しない。

### 11.3 来なかった日

理由を一つだけ伝え、その場所を光らせる。責めず、「つぎは きっと」で終える。

- 「おうちが いっぱいで、とまれなかったみたい」
- 「ごはんが とどいてないみたい」
- 「ここまで いけないみたい」

### 13.1 ぽこもこの いえ：学んだもので もようがえ（2026-10-01）

「いえ」は、島で育てた日々と学んだことを**とっておく場所**。家の中で別の遊びや買い物は作らない。

- **壁紙は、覚えた英単語の水玉でできている。** 独力で答えられた単語（仕様34。旧記録は強さ3以上）1語につき水玉1つが、3面の壁のどこかに決まった位置で増える。数が増えるほど水玉は小さく濃くなり、1年で部屋じゅうが水玉になる（草間彌生の差し色）。
- 水玉の色は単語のまとまり8色（たべもの・どうぶつとしぜん・ひと・まち・ものとかず・うごき・ようす・そのほか。教材の60以上の分類をまとめる）。
- **水玉を触ると、その単語を読み上げ**、英語と日本語が画面に少し出る。問題は出さず、正解・不正解もない。
- **模様の形は算数で増える**：みずたま（最初から）、いろの ブロック（算数Lv8）、とけいの わ（Lv13）、ほし（Lv19）、ケーキ（Lv21）。判定は島が記録した算数の主レベルの最高値。
- 子どもが選べるもの：模様の形、使う色のまとまり（隠せる）、ラグの色6色。無料・いつでも。回数だけでは増えない。
- 家の中は「いえの メニュー」の「もようがえ」から。保存は島の状態（`room`）。

### 13.2 なかまの てがみ（2026-10-01）

- ぽこもこの家の「いえの メニュー」に、島の住人からの手紙が届く。引っ越してきた時、家がふたかいだてになった時、きねんひんが届いた時（ぽこもこから）、きょうだいが花を置いた時。
- 手紙は島の状態から作り、新しく保存しない。触ると読み上げる。読んだ印だけ端末に残す。

### 13.3 いえに あそびにくる なかま・まどの しま（2026-10-01）

- 島の住人のうち1〜3人が、毎日ぽこもこの家に遊びに来て、ソファやラグにいる（その日のうちは同じ顔ぶれ、日が変わると入れ替わる。おでかけ中の子は来ない。えま・えいたは少し来やすい）。触ると名前とひとことが出て、その子の音が鳴る。
- 家の窓の外には、しまの あゆみの最新の写真（今の島）が見える。

### 13.4 なぞって かざる（2026-10-01）

- メニューの「なぞる」。覚えた英単語の頭文字3つと数字1つから選び、指でなぞる。文字の6割を塗ると「はたに かざる」で、その子の描いた絵が島の旗に付く。採点しない・何度でも描き直せる。

### 13.5 ぽこもこの つくえ・家の動き（2026-10-01）

- 家のテーブルのカードに、その日に独力で答えた単元と単語が並ぶ（なければ「ここから まなぶ」）。カードを触ると学習が始まる。
- 家に入ると、ぽこもこが前まで歩いて迎えに来る。遊びに来た住人は触ると跳ねる。
- 壁紙の模様に、英語のレベルで開く「アルファベット」（Lv3。単語の頭文字で描く）と「ハート」（Lv6）を足した。英語のきねんひんは、ABCの つみき・ことばの ほん・ことばの ふうせん・えいごの ちきゅうぎ・ことばの ぼうえんきょう。

### 13.6 そのほか（2026-10-01）

- 住人が品を使う：すべりだいを登ってすべる、畑の横でかがんで手入れ、食卓で食べる。ふしぎの品が開くときは水玉が渦を巻いて飛ぶ。
- えんそうかいの曲は4つ（きらきら ぼし・かえるの うた・メリーさんの ひつじ・ぶんぶんぶん。いずれも伝承・著作権の切れた曲）を順に。きょうだいの島でも、ひろばを触るとえんそうかいになる（何も保存しない）。
- しまカードの枠を選べる（みずたま・いろの ブロック・ほし・シンプル）。メニューに「なぞる」「もちもの」「せってい」。

## 14. 最初の5分

1. プロフィールを決めると島に着く。家、ぽこもこ、花とベンチ。**すぐ触って遊べる**。ぽこもこをつまんでベンチに置くと座る。
2. 船が桟橋に着き、うさぎ（またはカワウソ）が降りて、島を見回す。頭の上に家の絵。ぽこもこ「ここに すみたいって」。
3. たねのボタンが光る。**すむのたねの最初の1つは無料。** 置くとうさぎが跳ねて喜ぶ。
4. **最初の1回だけ、学習なしでつぼみになる。** 触るとポン！とテントが建ち、うさぎが入って手を振る。名前を付ける。
5. 遠くに次の船の影。ぽこもこ「あの子も すみたいみたい。まなぶと しまの じかんが すすむよ」。「まなぶ 🌱0」が光る。
6. 本人が通常の「まなぶ」を選び、有効な完了を一度だけ取り込んで帰島する。学習量と報酬は既存の区間・仕様のままで、スターター用の強制短縮はしない。
7. 本人が無料導入以外のhome/farm/play/market/festival種を選び、学習由来のまち時間で建ったものを開く。これで最初の一周が記録される。自然の種はこの条件に使わない。

説明画面は必須にしない。ぽこもこのひとことと、対象の静かな強調で進む。S1〜S3を最初の5分の目標にし、S4〜S5を同じ訪問のノルマにしない。順番を操作制限にせず、先に満たした保存済み事実も使う。閉じると自動案内を停止し、メニューの本から本人が再開できる。既存の島には自動案内や無料種を追加しない。旧 `tutorial: done` は無料種の特例だけを表し、スターター全完了には使わない。詳細は[スターターS1〜S5](island-starter-achievements-proposal.md#3-スターター)。

## 18. 実装の形

### 18.1 状態の持ち方

- 新しいエンジンは、**島の今の状態をそのまま保存する**。過去の操作記録を毎回再生しない。
- 保存する状態：土地、置いた物（めじるし・たね・家・きねんひん）、住人の個体、桟橋の旅人と次の船、まちの時計（たまった時間・使った時間）、しぜんの時計の最終時刻、土の湿り、道の踏まれ具合、げんきの最高値、開けていないつぼみ、しずく、取り込んだ学習完了ID、処理した操作ID、乱数の種。
- 操作は「操作ID付きの命令」として一度だけ反映する（二重タップ・複数タブ）。
- 導きと記念は本人のrecordの専用 `guidance` 境界へ保存する。島の命令成功と同じtransactionで根拠を記録し、前景の演奏は実開始の受領後に記録する。案内はUserProfileや旧案内localStorageへ追加しない。版・writer互換・削除の契約は[保存13](13_data_storage_migration_spec.md#育つ島の案内と記念2026-10-01)。
- 規則はすべて純粋関数で、同じ状態と入力なら同じ結果になる。

### 18.2 今の島からの引き継ぎ

- 切り替える時に、今の島（保存版21）を現行の仕組みで一度だけ再生し、その瞬間の状態を新しい形へ写す。**元の記録は書き換えず残し、戻せるようにする。**
- 再生前に検証済みの再生キャッシュを復元し、留守中の進行は旧島の保存済み時計に実経過を加える（最大7日、時計が戻ったら0）。実時刻を旧島の時計として直接使わない。
- 旧島の読み取り・再生中はPWA更新を妨げない。同期の更新保護は新しい島への書き込みtransactionが始まる直前からsettleまでとし、読み取りで止まっても修正版へ切り替えられる。55%の読み込みが15秒続いたら「もういちど ひらく」を表示し、通信できる場合は同じURLの最新アプリを開く。書き込み中・オフラインでは再読込せず、島と学習の保存を削除しない。
- 読み取り準備全体（新旧DBの取得と引き継ぎ再生）は120秒で打ち切れる境界を持つ。タイムアウトした試行のWorkerを終了し、遅れて返った読み取り結果から保存へ進まない。再試行は新しい読み取りから始め、書き込みtransaction自体の完了待ちはタイムアウトで解禁しない。
- Growingの自然・町・学習完了・贈り物の同期計算もWorkerで行い、DBの書き込みtransactionへ重い計算を入れない。計算元の島と贈り物をtransaction内で照合し、他の画面の保存が先に進んだら最新の記録から計算し直す。3回競合した場合は保存を上書きせず再試行を案内する。学習・贈り物は島への反映と受領を同時にcommitし、二重に渡さない。
- 島をまだ表示できない読み込み・失敗画面は読み取り待機として扱う。画面や再起動ボタンに触れても通常の島遊びのセッション保護を開始せず、修正版への更新を許す。島を表示できた、または読み込み画面を離れたら通常の保護へ戻す。全画面共通の学習・保存transactionの更新保護は常に優先する。
- 引き継ぎの再生はWorkerが使える端末では画面とは別の処理で行う。起動・再生が失敗、または120秒で終わらない場合は処理を終了し、保存を消さず「もういちど」でやり直せる。失敗したWorkerから画面上での重い再生へ自動で切り替えない。
- Growing有効時は旧Lifeの更新controllerを起動しない。画面が非表示なだけで旧時計を進めたり、引き継ぎと並行して元の保存へ書いたりしない。家の旧処理も同じ境界に従う。
- 学習画面の取得済みのぽこもこの色は旧保存の適用済み着替え命令から読み取り、着替えのために旧島の再生や更新を行わない。
- 写すもの：土地、全ての所有品（めじるしとして同じID・位置・成長）、しずく、うさぎ・カワウソ（ぽこもこの家に同居。§19）、土の湿り、食べ物の在庫。
- 切り替え以後の学習完了だけを新しいエンジンが数える。切り替え前の完了は既にしずくに反映済みなので二重に数えない。
- 旧「ひかり」は、しずくへ合算しない（仕様51 06章の変換を正とし、決まるまで保持だけする）。

### 19.1 ふしぎカラフルの差し色

「ふしぎな島」らしさとして、ぽこもこ（パッチワークと水玉）の系譜にある、草間彌生のような水玉と、ロメロ・ブリットのような太い黒ふちの色面を**ところどころ**に入れる。全体には塗らない。入れる所：岸の水玉きのこ、きのこ畑のかさ、かぼちゃ畑の一部、おまつり広場、船の帆、つぼみ、ぬしの木の花の輪、きらきらの住人の小物、一部のきねんひん、しまカードの縁、選べる「ふしぎな やね」2種。普通の家・畑・花は落ち着いた色のまま。

- 2026-10-01：家の5つの形に個性を足した（水辺＝丸窓・桟橋・小舟、木＝屋根を突き抜ける木とはしご、花＝つる、あかり＝大きな丸窓と星の風見、まるい家＝えんとつと生け垣）。

### 19.2 レベルで選べるもの（§8）

Lv7 旗の模様（むじ・しま・みずたま・ほし・ハート）、Lv8 住人の服の色（6色）、Lv9 帽子（むぎわら・ベレー・はなかんむり・ニット・おうかん）、Lv10 しまカードの特別な枠。旗の色と屋根の色は最初から。
