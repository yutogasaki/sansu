# 少ない操作から、深く遊べる島へ

2026-10-27。利用者の「チャッピーと相談して、シンプルだけど奥深い企画に整理し、具体案をポータルへ反映」による改善方針。**方針として採用し、アプリへの反映・実測はこれから。** この文書を理由に、現在の保存・時計・解放・画面を切り替えない。

効く柱は「くふう・にぎわい・ふしぎ・愛着」のすべて。弱める柱はない。成長や人口を小さな固定上限で止めず、3教科の学習の正しさ、所有・住人・土地・過去の姿、本人が選ぶ学習を守る。[憲法](../../CONSTITUTION.md)、[親仕様01](01_app_spec.md)、[遊び52](52_growing_island_game_spec.md)の下で、改善の目的・入口・具体例・受入をまとめる。

## 1. 企画の芯

> **置いてみる。さわってみる。学んで育てる。昨日の続きを、自分の島で。**

「置く・さわる・まなぶ」は理解の入口で、操作を三つに制限する規則ではない。眺める、迎える、飾る、思い出す、旅することも遊びの目的として残す。5タブは「しま・いえ・まなぶ・きろく・設定」のまま。

奥深さは、**同じ持ち物でも、位置・接続・高低・成熟・入口・実際に使う仲間によって、違う良さが生まれること**。品数・条件数・達成数を増やすだけでは合格にしない。新しい通貨、技能ツリー、友情ゲージ、日課を加えない。気に入った配置を保ち、そこで過ごすことも成功とする。

- 触ると、原因のわかる返事がある。
- 置き直すと、使われ方や景色に意味のある違いがある。
- 待っている間も、今ある物で遊べる。
- 次の日も、昨日の工夫と仲間が続いている。

## 2. 重複を整理する五つの判断

| 気になる重さ | 整理すること | 維持すること |
| --- | --- | --- |
| 家・土地・住人・場所目標・学習Lv・航路・達成を並列に追わせる | 今触った場所の変化を最優先。任意の「つぎのたのしみ」は既存どおり1件、閉じられ、本人の構想を上書きしない。記録は必要な時に開く | 学習の証拠と各達成を一つの総合レベルへ合算しない |
| 価格と複数の時計の理由が読めない | 購入前に価格と「まなぶと建つ／時間で育つ／すぐ遊べる」の対応を短く示す。現在の妨げを一件と直せる実対象で示す | 1完了の2しずく＋2まち時間、自然時間、余剰時間、既存の価格・成熟・入居条件 |
| 仕掛けが一度だけの正解レシピになる | 固有種の獲得条件は残し、獲得後も配置で光・音・動き・見える景色を作り直す。通常の島では実給水・歩行・利用も変わる | 条件を崩しても取得済み種・達成・所有を失わない。演出で新しい資格や資源を発行しない |
| 7島で同じ準備を繰り返す | 到着種を触る入口を先にし、仕掛けを触るために家・畑・入居の再建を追加条件にしない。家・町・拡張は本人が望む発展として続けられる | 家の島＋特別6島、通常の購入・自然成熟、既存の航路と所有。新たな無料材料は配らない |
| 思い出と記念の入口が増える | 家を思い出の主入口とし、同じ選択資料から「見る・飾る・見せる」を辿る。写真・島カード・あゆみを別々の進行体系にしない | 写真・作品・賞状・記念品・当時の状態・既存直接操作。任意チャレンジは学習や島解放の条件にしない |

「しまのきろく」1冊、つぎのたのしみ1件、道具の段階表示は[航路仕様](island-journey.md)で既に整理した方針。今回新しく発明した機能として数えない。[SG1〜3](island-system/experience-design/03-play-and-residents.md)の木の返事・実通水の波紋・実参加者との音遊びにも実装記録があり、その存在と児童による理解・再訪の合格を区別する。

## 3. 何を待つかを、操作の場所で理解する

| 対象 | 置く前の短い案内 | 操作後に見るもの | 追加しないもの |
| --- | --- | --- | --- |
| 家・畑 | 価格＋「まなぶと建つ」 | 置いた予告と建築状態、到達できない時はその対象 | 学習を強要する不足表示、受取時の再課金、別の時間消費ボタン |
| 木・花 | 価格＋「時間で育つ」 | 若い形と、今の配置に返る反応。成熟は自然の時計 | タップで即成熟、学習量による自然成熟の早送り |
| ベンチなど | 価格＋「すぐ遊べる」 | 実際の空席・通路と、その場所での利用 | 木陰や花庭への必須席の再導入、空席がないのに利用成功の演出 |

三つの時計と朝夕の景色を統合・削除しない。「ひらく」は既存の完了を開く行為として残す。物の現在の条件に応じて案内を変え、条件が複数あるときも今直せる理由を一つ示す。残り時間が不明な場合は秒数・進捗率を捏造しない。

## 4. 同じ持ち物で試す二つの短い体験

以下は**材料を既に持つ場面で約3分以内に二つの配置を試せることを目指す設計例**。初回から成熟木を持つ、3分で自然成熟する、固有種まで獲得できる、という約束ではない。所要時間・説明なしの理解は未実測。

### 木陰と仲間の居場所

前提：取得済みの成熟木4本と、任意のベンチ1つ。元の床・入口と住人を保持する。ベンチは休み方を増やす品で、木陰・場所を成立させる必須材料にしない。

1. 木を離して置く。独立した木陰のどこで過ごすかを選ぶ。
2. 同じ4本を列にし、木を触る。現在の接続に沿う返事と、通れる木陰の道を確かめる。
3. 入口と内側の空床を残して囲む。内側に過ごす場所を作り、実際にそこへ行く。ベンチがあれば置き直し、見る景色と実利用を比べる。

列は通り抜け、囲いは内側に滞在する良さがある。大型の中空幹・空中回廊が必ず出るとは言わない。有限部品が適合しなければ成熟した通常形の木陰・庭で遊べる。[成長と実床](island-system/growth-rules.md#場所と大型の判定)の安全条件に従う。

### 水をどこへ届けるか

前提：取得済みの水源1、水路4、畑1と、任意のベンチ1。新しい水量・水圧・消費資源を作らない。

1. 水路を畑へつなぐ。触ると通水済みの範囲に波紋が返る。実給水に応じる畑の供給と、自然時間で変わる土の湿りを区別する。
2. 同じ水路を岸へ回して水辺の形を変える。畑への給水が切れた場合はその事実を示し、岸や席へ行ける配置を比べる。
3. 畑へ戻す、岸の形を選ぶ、後日持ち物を増やして両方を作る、のどれも選べる。既存の住人を取り上げない。

畑への供給と、居心地のよい水辺は違う良さ。水路の波紋だけで土を湿らせたり花を開かせたりしない。住人が座る・運ぶ・食べる描画は、実際の給水・到達・利用に従う。

## 5. 特別6島は、着く・工夫する・遊び直す

| 島 | 到着直後に触れるもの | 初回の工夫と固有種（現行条件） | 獲得後に試す配置（改善方針） |
| --- | --- | --- | --- |
| しおかぜの小島 | 必ず届く貝の花を触る。今ある浜と入り江を見る | 貝の花を掘った水の隣へ → 葉舟ヤドカリ | 花と掘った水の位置を岸沿い／内側へ変え、潮だまりの景色とヤドカリのいる眺めを作り直す |
| こだまの森 | 鈴の実の木に触り、若木の姿を見る | 育った木3本以上を辺で接続 → こだま鳥 | 同じ成熟木を列／枝分かれへ。光と鈴の返る順を比べ、鳥のいる森の構図を選ぶ |
| ひかりの入り江 | 透ける水草を触り、初期の池を見る | 段上の水を池へ落とす滝 → ひかり貝 | 取得済みの水路を曲げ、つながる光の道と滝を見る位置を選ぶ |
| わたぐもの高原 | 風船花を触り、高低差と雲を見る | 1段以上の上に2×2広場 → わたげ羊 | 高い広場の形と花の位置を変え、その日の風に揺れる花と羊のいる風景を比べる。風向きは本人が設定しない |
| ぜんまい島 | ねじまきそうの鍵と動きへ触れる | 水路から5つ以上の持ち物を辺で接続 → ぜんまいどり | 同じ品を直列／分岐へ組み替え、動力が届く枝と歯車の動きを比べる。新しい電力・燃料は作らない |
| 星の島 | 星の実の木を触り、常夜の景色を見る | あかり3つ以上の星座 → ほしくらげ | 同じ灯りを三角／長い列へ。夜空の線と海へ映る構図を作り直す。夜は見た目で、成長時計を変えない |

島名・獲得条件・一度だけの付与は[航路の正本](island-journey.md#4-特別な島と固有種)に従う。若木の成熟や通常の材料取得を待つ前から全条件が試せるとはしない。初回は到着種への返事、育成後は条件の工夫、取得後は配置の遊びとして区別する。

取得条件を満たした時だけ来る2種目と、獲得後の遊びは別。条件を崩しても所有・記録は消えない。取得済みの資格と現在の接続・通水は別に判定し、切れた枝や乾いた水路に成立した反応を出さない。空き区画がなければ既存規則どおり持ち物へ送る。再配置から種・通貨・食・人口・航路を追加発行しない。固有種を通常の食料供給者や住居人数へ換算しない。家・畑・入居・土地拡張を望んだ時の通常の島づくりは続けられる。

## 6. 入口をまとめ、資料の違いは残す

- **しま**：実物を触る・置く・動かす。任意のつぎのたのしみ。海図は航路と島選択の入口。
- **いえ**：思い出の主入口。アルバム・写真・作品・島カード・あゆみ・記念を、同じ資料の選択から「見る／飾る／見せる」へつなぐ。
- **まなぶ**：本人が選ぶ3教科の通常開始・直接再開。
- **きろく**：既存の学習活動・教科別進捗・確認と復習。島の写真や全達成をここへ無断で移さない。
- **設定**：本人と教科・音などの環境、保護者への入口。

思い出の一か所化は、全種類を同じ画像や保存表へ変換する意味ではない。写真は写真のまま、作品は保存版のまま、島のあゆみは当時の状態のまま見せる。「飾る」は対応する既得の品だけ、「見せる」は今の端末内の表示として扱う。対応しない資料へ使えない操作を並べない。外部共有は追加しない。

「しまのきろく」1冊には実際に起きた達成を残し、写真数・賞状数の別ゲージは作らない。着替え・手紙・任意チャレンジ・撮影の既存の直接操作は残す。主入口をまとめても、既存の近道は同じ表示・同じ資料へつなぎ、別の一覧を作らない。閉じる・戻るは、元の家／一覧／選択資料と位置を保つ。

| 状態 | 表示と次の操作 |
| --- | --- |
| 0件 | 種類ごとの空を短く示す。撮る・作品を残す等の実在する任意入口と、閉じるを残す。架空の見本を所持品として出さない |
| 満杯 | 写真保存枠、置く空地、住居/食の余裕など、何が満杯かを区別。既存の収納・移動・本人の明示削除等を案内。自動削除・自動購入しない |
| 未到達・使用中 | 届かない実対象や空席なしを一件示し、配置の見直しや別対象へ。利用したと捏造しない |
| 保存失敗 | 成功表示を出さず、選択・入力・既存所有を保持して再試行。保存先の本人/島を照合し、反復で複製しない |
| 未対応の大型形 | 対応する通常の成熟形へ。失敗の罰、没収、追加の必須購入を作らない |

## 7. 実装する順と合格条件

| 順 | 変更単位 | 合格条件 |
| --- | --- | --- |
| P1 | 価格・待つ理由・次のたのしみの説明を整える | 購入前から変化の理由が読め、操作の途中でも任意の遊びへ戻れる。値・時計・学習・保存の差分ゼロ |
| P2 | 木と水の同素材比較を通常操作から通す | 取得済みの同じ材料で二つ以上の良い配置、即時反応と実利用の違い。追加購入・自然時間加速を条件にせず、元に戻せる |
| P3 | 特別6島で獲得後の配置遊びを確かめる | 到着種の即時反応と初回獲得条件、獲得後の再配置を分ける。種/通貨/人口/資格を重複発行しない |
| P4 | 思い出の入口と資料選択を整える | 同じ資料から使える行為へ進み、元の一覧・家へ戻る。0件/満杯/保存失敗と全既存の記録・近道を保持 |
| P5 | 子どもの理解と再訪を観察する | 説明なしで「何を変えたら何が変わったか」が伝わり、自分で次を試す。後日の自発的な再訪を別に確かめる |

P1〜P5はこの改善の依存順であり、共有キューへ新しい同時作業を割り込ませるものではない。P1は新しい画面を足すより既存表示を整え、P2/P3は既存の反応を新機能数に数えず、成立と理解を確かめる。

## 8. 受入とポータルの表示

- 同じ所有・成熟・しずく・まち時間から、配置だけを変えて比較する。見た目だけでなく実給水・入口・到達・利用の違いを確認する。
- 若木の初回体験と、成熟した材料の短時間比較を混ぜない。準備済みの入力を本人の自然取得と呼ばない。
- 音off、動き抑制、狭幅・キーボードでも、変化の理由と次の操作が残る。
- 全部完成させる・毎日来る・全項目を埋めることを、成功条件へ加えない。
- ポータルは10章・97項目の出典付き索引を保ち、改善対象に「今回の整理」を添える。現在の挙動と、今回採用した未反映の計画を区別する。
- ポータルの木と水の図は説明用の配置比較で、本体の成長・通水・住人のシミュレーションではない。図を切り替えた合格をアプリの受入へ流用しない。
