# 育つ島のバランス修正と保存互換

2026-10-04の20問/日を基準とする新規経済を含む。価格と時間は下記が現行で、保存2の切替は過去の互換境界として保持する。柱はくふう・にぎわい・愛着。既存品の無料の試し直しを維持し、新規増築を学習へつなぐ。

正本は[仕様52](52_growing_island_game_spec.md)。この文書は2026-10-01の監査B1〜B6に対する修正と互換境界を定める。柱は、地区によるにぎわい、経路を直すくふう、学習量から切り離したふしぎ。既存の所有・住人・愛着と、学習の出題・採点・独力/SRSは保持する。

## 経済・時間

- 最初の5回の拡張は120/240/480/720/960しずく。6回以後は1200から240ずつ増え、東・西・南の同じ境界へ3列/行ずつ加える。レベル10以後も回数上限なし。
- 有効完了1件の2しずくは保持。新規取り込みはまち2時間（旧4時間）。保存済みのclock/bankは再計算しない。同じIDを同じ入力バッチへ重複して渡しても1件。
- 仕事が残らないと時計を止め、未使用時間をbankへ保持。次の配置や供給、道の復旧で使える。旧版が既に使った時間はさかのぼって払い戻さない。
- 到達できない空き家は新規入居に使わず、到達できない好み・遊びをすみごこちに数えない。取得済みの住人・段階・最高げんきは下げない。

- 1日20問で40しずく・まち40時間を設計の基準にする。家/畑40、あそぶ60、しぜん10、いちば120、おまつり160。花10・ベンチ20等、めじるしは従来の5倍。強制ノルマ・日次ボーナスは設けない。
- 保存形式は変更しない。既存残高・所有・土地・完了IDを保持し、再取り込みで旧報酬を発行しない。未建築種の払戻しは現価格ではなく保存されたpaid。無料の移動/収納/再配置と初回の無料家は保持する。

## 出来事

参加時刻からの実時間の24時間区切りで、開いた日の1回だけ判定する。土・花・住人などその時の状態を条件にするが、完了数・まちの時計は抽選回数・乱数へ渡さない。未表示結果を保存し、表示を開始した日IDを確認して消す。再読込・他タブ・表示済みの再送で再抽選しない。

## 保存2への切替

- `GrowingRecord.version` を1→2へ同一transactionで進める。Dexieを保存境界3へ進め、DB名・既存のindexは保持し、保存正本を `balancedIslands` へ一度だけ複製する。旧 `islands` は切替時の元データとして残し、新writerは読み戻さない。schema upgradeと複製は同じtransactionで、中断時は旧tableを保持する。
- 追加は `land.districts`、出来事の判定日・表示待ち。1の所有品・座標・住人・履歴・残高・clock/bank・完了ID・旧ひかりは保持する。追加値は欠損時の既定値で読む。
- 同期だけでなくcommandのwriterと読み取りも未知版を拒否する。旧command writerにはrecordの版検査がなく、Dexieは旧schemaでも接続するため、版番号だけでは防止できない。旧writerは旧 `islands` にしか書けず、新正本を上書きできない。切替後のロールバックには2を読めるbuildが必要。DB削除・旧版への降格で戻さない。
- 写真・きょうだいの贈り物・学習のnative DB・旧Life DBは切替のために変更しない。新版のprofile削除は旧 `islands` と新正本の両方を削除する。

## 必須検証

同一/別バッチの完了再送、時間の保存/再起動/次の配置、全5段階保持/6回以後の各方向/配置と歩行とカメラ境界、孤立空き家と経路回復、同じ実日で学習量・往復頻度を変えた出来事、未表示の再起動/日をまたぐ保持/表示済み再送、保存1→2/未知版拒否/失敗transactionの保持を確認する。

長期シミュレーションは少量・通常・まとめ学習と装飾優先を分ける。有限土地による停止をなくし、拡張を含む消費先を確認する。余剰しずくの完全消滅や、全利用者の平均進行、自発的な継続を数値テストだけで認定しない。

## 成長の配分（2026-10-04）

20問/日は40まち時間。来訪は新しく出発する船から48＋2×住人数へ調整する。保存済みdockAtとclock/bankは書き換えない。遊具はブランコLv2・演奏Lv4・すべりだいLv6・トランポリンLv7・ふんすいLv8とし、既得unlockedを削らない。取得済みの品も使用できる。げんきと土地の条件はそのままで、島の固定上限を追加しない。

家は24/48/96まち時間と従来のすみごこち/レベル条件を維持。時間を3倍にした比較でも初回成長はレベル条件に左右されたため、一律に延ばさない。自然は実時間で育つ楽しみを保つ。独力習得に基づく記念品の資格は変更せず、受け取り案内の品名と収納の優先順で学習の成果を見つけやすくする。

検証は20問/日、6問/日、週まとめ、装飾優先と365日までの成長を比較する。これは配置を決めたシミュレーションで、子どもの自発的な学習・再訪を示すものではない。
