# 島の航路と まなびの節目

獲得後も同じ島を工夫して遊ぶ具体化は[簡素化と奥深さの改善方針](island-simple-depth-plan.md#5-特別6島は着く工夫する遊び直す)を参照する。到着種への即時反応、現行条件での一度だけの工夫種、獲得後の配置遊びを分ける。6島、下の航路・成熟・獲得条件を保持し、家/畑/入居の再建を仕掛けに触るための追加条件にはしない。新たな無料材料は配らない。固有種への反応差は改善計画で、実装・児童の理解は別に確認する。

2026-10-26採用。利用者の「100点の仕様でない認識。考えたうえで魅力的な提案まで詰め、一気に実装まで」に基づき、[島とアチーブメントの検討案](island-achievements-unlock-proposal.md)と[共通レベル](learning-levels.md)・[国語のレベル](kokugo-levels.md)を、遊びとして成り立つ形へ組み直した正本。くふう・ふしぎ・愛着に効く。

## 1. 検討案から変えたこと

| 検討案の弱いところ | この仕様での答え |
| --- | --- |
| 特別島を「探訪・発見」の行き先にすると、島で冒険させない方針（[仕様52 §0.3](52_growing_island_game_spec.md)）とぶつかる | 特別島も**自分で育てる島**。固有種は探しに行かず、**その島の環境を工夫すると来る**（置くと自然に育つ） |
| 節目がLv2・5・9・13・17だけだと、次の航路まで何週間も「次」が見えない | 海図に**20個の星**を置き、どの教科でも内容を確かめたレベルごとに1つ灯る。節目の星（2・5・9・13・17）に船の印 |
| 固有種の持ち帰りが未決 | 見つけた固有種は**おみやげ**として、どの島にも1つずつ連れて行ける（買わない・増殖しない） |
| アチーブメントの6分類とふしぎずかんが重なる | 「**しまの きろく**」1冊に、しまづくり・くらし・ふしぎ・まなび・こうかい の5つをまとめる |
| 「設定したLv」と「確かめたLv」が混ざりやすい | 航路と星は**確かめたLv**だけを読む。設定・閲覧・本を開く・受け取りボタンは条件にしない |

## 2. 一周

```text
自分の島で 置く・工夫する ─→ 暮らしと景色が育つ
        ↑                              │
        │                     任意で学ぶ → しずく・町時間
        │                              │
  おみやげを置く              内容を確かめる → 海図の星が灯る
        ↑                              │ （節目の星）
  固有種が来る ←─ 環境を工夫 ←─ 特別な島を選んで作る ←─ 航路の枠が開く
```

## 3. 航路の枠

> 2026-10-28 改訂：枠0（最初の住人→しおかぜ）は新しく開かない。枠1〜5は学習の節目に加え、いちばん新しい島の広さと育ちがそろって開く。行き先は選ばず、育ち方で決まる。詳細は§3.6。下の表は既に開いた枠の扱いと学習の節目として残す。

| 枠 | 開く条件 | 行き先 |
| --- | --- | --- |
| 0 | 最初の住人を迎えた（スターターS3と同じ実操作）。案内を飛ばしても同じ | しおかぜの小島（固定） |
| 1〜5 | どれか一教科で Lv2・5・9・13・17 の内容を確かめた | こだまの森・ひかりの入り江・わたぐもの高原・ぜんまい島・星の島 から、まだ選んでいない1つ |

- 枠は「開いた」と「選んだ」を分ける。開いた枠は残り、選ぶのは本人。出航は強制しない。
- **一度に開くのは1つ**（2026-10-27）。学びの枠は、前の枠で島を選んでから次が開く。上の学年から始めた子が最初の進級で複数の節目を満たしても、資格は残り、島を選ぶたびに次が開く。
- 同じ節目を別の教科で確かめても、枠は増えない。どの教科・どのLvで開いたかと、開いた時刻を一度だけ残す。
- 一度開いた枠は閉じない（範囲変更・不在・復習期限が来ても）。上の節目を正当に確かめたら、その段までの枠をまとめて開く。
- 学習より先に枠が開いても（S3前に学習した子）、資格は残り、S3の後に選べる。
- 既に住人がいる旧利用者は、次に島を開いたとき枠0を開く。開いた時刻は実際に開いた時刻で、過去の日時を作らない。
- 枠は全島で共通（しずく・学習と同じく、島の往復で増えも減りもしない）。

### 確かめたLv（表示Lv1〜20）

| 教科 | 確かめた とする根拠 |
| --- | --- |
| 算数 | 進級テストに合格した記録（保存済みの `testHistory` の合格した進級テスト）で、表示Lvに対応する内部レベルの最後（[共通レベル](learning-levels.md)の表）まで合格している。設定画面や始めた時に選んだレベルは根拠にしない。合格したレベルより下は、上位から始めた子も含めて確かめたものとして航路に数える（下位の学習記録は作らない） |
| 英単語 | 表示Lv＝語彙レベル。同じく進級テストの合格記録で読む。ABC・音の基礎コースは換算しない |
| 国語 | [国語のレベル](kokugo-levels.md)の対象単元が**すべて**確認済み。単元の確認は、その単元の採点対象の問題が持つ「対象・形式・様式」の組すべてで、既存の確認条件（独力初答3件・文脈2群以上・単元別の必須条件）を満たしたとき。自由活動5単元は数えない。下のLvから順に、確かめていないLvがあればそこで止める |

## 3.1 島の数（2026-10-27）

> 2026-10-28 改訂：しおかぜの小島は家の島と雰囲気が近いので新しくは来ない。特別な島は5つ（こだま・ひかり・わたぐも・ぜんまい・星）。既に作ったしおかぜの小島は残る（§3.6）。

家の島1つと特別な島6つの**計7島**。ふつうの島（花・森・水辺の始まり）を新しく作る機能は終える。既に作った島は消さず、海図から行き来できる（既得の権利）。数は増やさない。1島ずつ作り込み、終盤は島を増やさず§3.3の仕上げで締める（2026-10-27、利用者の「島たりてる？」への判断）。

## 3.3 星の色と Lv20 の仕上げ（2026-10-27）

- 海図の20個の星は、確かめた教科ごとの小さな色の印を持つ（さんすう・えいたんご・こくご）。灯る条件はこれまでどおり「どれかの教科」。2教科目・3教科目で確かめても航路は増えないが、印が増えて見える。
- どれかの教科で **Lv20** を確かめると「しあげ」が起きる。島は増やさず、作った特別な島それぞれの海の「しるし」が光り、海図では作った島どうしが光の線で結ばれる。しまの きろくの まなびに残る。後から作った島も、着いた時から光る。
- しあげは景色だけで、成長・取れる物・学習の条件には使わない。

## 3.4 ひとつの群島（2026-10-27）

> 2026-10-28 改訂：まだの島は霧でも見せない。光る飛び石・条件の文字をやめ、見えるのは作った島と、育ちはじめた浅瀬だけ（§3.6）。

利用者の「しまとしまが独立してるのやだな」を受け、7つの島を海図の並びのまま**ひとつの群島**として見せる。冒険や探索はしない（[仕様52 §0.3](52_growing_island_game_spec.md)）。

- いる島の外側に、となりの島が海図と同じ向きで見える。遠景の簡単な形（島の色の土地と、その島のしるし）で、いる島だけを細かく描く（スマホの描く量を増やしすぎない）。
- 作った島へは**橋**がかかり、選べる島へは光る**浅瀬の飛び石**が続く。まだの島は霧に隠れて形だけ見える。
- となりの島をさわると、作った島へは橋を渡って移る（海図の「ふねで いく」と同じ）。選べる島は、その島を作って移る。霧の島は次の条件を言うだけ。
- 家の島からは6島、特別な島からは家の島とほかの島が見える。前に作ったふつうの島と、きょうだいの島を訪ねている時は、群島を出さない。
- 距離は見た目だけで、移動の時間・費用・条件はない。

## 3.5 とくさんを届け合う（2026-10-27）

特別な島のしかけを完成させると、その島の「とくさん」が**ほかの全部の島**に届く。島どうしが助け合って、ひとつの群島になる。景色だけで、成長・取れる物・学習・住人の規則には使わない。

| 完成させた島 | ほかの島に届くもの |
| --- | --- |
| しおかぜの小島 | 浜に貝がらが打ち上がる |
| こだまの森 | 育った木に金の鈴の実がなる |
| ひかりの入り江 | 水路・水ばち・掘った水がきらめく |
| わたぐもの高原 | わたげが風に乗って舞う |
| ぜんまい島 | 水路に小さな水車がついて回る |
| 星の島 | あかりの上に小さな星が浮かぶ |

- 届いたものは しまの きろく の しま のページに「とどいた とくさん」として出る。完成させた島には届けない（その島には本物がある）。

## 3.6 よっぽど育つと、沖に島が育つ（2026-10-28）

利用者の「島が増えるのは魅力が分散する」「よっぽど育てないと次の島解放しないようにしたい。学習だけじゃなくて、島のサイズや開発も」「この島がくるみたいなの見せすぎない、配置もあんまり固定しすぎないで増えても破綻しない」を受けた正本。島の数ではなく、1つずつの雰囲気の違いで魅力を作る。

**芯：自分で決めたこと（買う・置く・待つ）は理由がわかる。世界のふしぎ（次の島・その正体）は予告しない。**

### 次の島が育つ三つの条件

いちばん新しい島（特別な島をまだ作っていなければ家の島）の沖に、浅瀬が育つ。三つがそろうと浅瀬が島になり、渡れる。

| 条件 | 初期値（遊んで調整） | どこで見るか |
| --- | --- | --- |
| まなぶ | どれか一教科で確かめたLvが、n番目の島で 2・5・9・13・17 | 全島共通の確かめたLv（§3の根拠） |
| 広さ | いちばん新しい島を3回以上広げた | その島 |
| 育ち | いちばん新しい島に住人5人以上、育った木3本以上 | その島 |

- 一つそろうごとに浅瀬が変わる：海の下にうっすら見える → 砂州が出る → 草の小島になる。数字・ゲージ・残り条件は島の上に出さない。どれが先でもよい。
- 広さと育ちは、その島にいる間に一度そろえば残る（後で減っても戻らない）。学習のLvも下がらない。
- 島の上での知らせは「おきの ほうで、なにかが そだったみたい」程度。何の島かは言わない。
- 学習は条件の一つだが、学習量で回数や確率を増やさない（[憲法 §1.2](../../CONSTITUTION.md)）。学習しないと島が育たない、とは言わない。

### どの島になるか

- 選ぶ画面はない。浅瀬が島になった時の、いちばん新しい島の育ち方で決まる。木が多い→こだまの森、水→ひかりの入り江、あかり→星の島、畑→ぜんまい島、花と高い地面→わたぐもの高原。まだ来ていない島の中で一番強いもの。
- 差が無い時や同点は、その子の島ごとに決まった順で決める（運の要素。学習量では変わらない）。外れはない。
- 着くまで名前も形も見せない。渡った瞬間に正体がわかる。

### 場所は固定しない

- 浅瀬は、いちばん新しい島から、ほかの島と重ならない開いた海の方向に生まれ、その場所がそのまま島の場所になる。何島に増えても同じ方法で置ける。
- 海図は実際の並びを、全部が入る大きさに縮めて描く。この日より前に作った島は§3.2の表の場所のまま。

### 前からの子

- 作ったしおかぜの小島・特別な島・見つけた固有種・とくさん・開いた枠は取り上げない（[憲法 §2](../../CONSTITUTION.md)）。
- 開いていて、まだ島にしていない枠は、条件なしで浅瀬がそろった状態として扱う（行き先はしおかぜ以外から上の決め方で）。
- 特別な島は合計5つまで新しく来る（しおかぜを作った子はしおかぜ＋5）。

### 保存

`journey.shoal`（浅瀬の場所・そろった広さ/育ち・その時の育ち方・決まった島）と、`journey.chosen[].at`（島の場所）を任意で足す。無ければ旧の扱いで読む。版・表は変えない。

## 4. 特別な島と固有種

特別な島も、ふつうの島と同じ規則で育てる（配置・水・自然・住人・土地拡張）。違うのは、**始まりの地形と、そこでだけ来る固有種**。

| 島 | 始まり（地形） | 着いた時に来る種 | その島だけの仕掛け | 仕掛けの完成（工夫で来る種） |
| --- | --- | --- | --- | --- |
| しおかぜの小島 | 手前に浅い入り江 | 貝の花 | **しお**：潮が満ち引きし、引き潮には浜に貝が打ち上がる。1日に約50分ずつ遅れる | 貝の花を掘った水の隣に置く → 潮だまりに 葉舟ヤドカリ |
| こだまの森 | 一段の丘に若木2本 | 鈴の実の木 | **こだま**：育った木が辺で3本以上つながると、林が順に光って鈴の音を鳴らす | 育った木を3本つなげる → こだま鳥 |
| ひかりの入り江 | 内側に池 | 透ける水草 | **ひかりの水**：水路・水ばち・掘った水が光り、つながった流れが長いほど明るい | 段の上の水を池へ落とす（滝） → ひかり貝 |
| わたぐもの高原（空の島） | 一段と二段の丘 | 風船花 | **かぜ**：日ごとに風向きが変わり、わたげと雲の影がその向きへ流れる。島のしるしに風見 | 一段以上の上に2×2の広場 → わたげ羊 |
| ぜんまい島 | 二段の機械の台 | ねじまきそう | **からくり**：水路（水車）から、辺でつながった持ち物へ動力が伝わり、つながった物に歯車が回る | 水路から5つ以上つなげる → 時計塔が鳴り ぜんまいどり |
| 星の島 | 景色がいつも夜 | 星の実の木 | **せいざ**：あかりの並びが夜空に星座として写り、近いあかりどうしが線で結ばれる | 3つ以上のあかりの星座を作る → ほしくらげ |

- どの仕掛けも、適当に置いても何かが起きる（光る・回る・写る）。工夫するともっと良くなり、完成すると2種目が来て、島のしるしが最終形になる。失敗・時間切れ・探しに行くはない。
- 仕掛けは景色と遊びのためだけで、成長・取れる物・学習には使わない（[仕様52 §20](52_growing_island_game_spec.md)）。潮と風は本当の天気ではなく、島の時計の景色。
- 仕掛けの完成は「しまの きろく」に残る。

- **島ごとの景色**（見た目だけ。2026-10-26、利用者の「もっとメカメカしたしまとか圧倒的な個性をだしていい」を受けて強めた）：島を開いた瞬間に別世界と分かるよう、地面・岸・崖・海の色、画面全体の光、ふつうの草むらに代わるその島の植物、海の向こうの大きな「しるし」、その島だけの動きを持つ。
  - しおかぜ：白い砂の岸・青緑の浅い海・浜の草と貝殻・波打ちぎわの泡・海から立つ巨大な巻き貝。
  - こだま：濃い緑・シダと赤いきのこ・木漏れ日の光の筋・落ち葉・島より古い大樹。
  - ひかり：ミント色の地面・透きとおる水色の海・光るこけ・水のきらめき・光るガラスのアーチ。
  - わたぐも（空の島）：海の代わりに一面の雲の海で、島が空に浮かぶ。わたげの花・流れる雲の影・空に浮かぶ雲の小島。
  - ぜんまい（からくりの島）：鋼色の地面と真鍮のふち・油色の海・地面で回る小さな歯車と真鍮の管・ふちの蒸気・海から突き出て回る巨大な歯車と時計塔。
  - 星：いつも夜・紺色の海に映る星・光る夜の花・海に立つ三日月のアーチ。
  - 置いた物は、形はそのままで島の素材に着せ替え、光も島ごとに傾ける（なかま・固有種は着せ替えない）。島の側面もその島らしく変える（珊瑚と貝・根と苔・水晶・雲の寝床・歯車と管・星の結晶）。2026-10-27 に6島すべてへ入れ、画面で確かめた。
  - 固有種は持ち物より一回り大きく、それぞれ動く（ヤドカリは横歩き、こだまどりとぜんまいどりは跳ねる、ねじまきそうの鍵は回る、ほしくらげは漂う など）。
- 着いた時の種は必ず来る（その島の持ち物として置かれる）。工夫で来る種は、条件がそろった時に一度だけ、着いた時の種の近くの空いた区画へ来る（空きがなければ持ち物に入る）。乱数・学習量・時間の待ちはない。
- 見つけた固有種は「しまの きろく」に残り、**おみやげ**として、どの島にも1つずつ連れて行ける。置く・動かす・しまうは持ち物と同じ。ほかの規則（ごはん・住める数・場所の判定）には数えない。
- 固有種は島の主役として、生き物には顔（光る目と頬）、植物には水玉などの差し色を付ける。さわると跳ねて回り、説明に自分の一言を添える（2026-10-27）。
- 星の島の夜は景色だけで、成長・出会い・学習には使わない（[仕様52 §2](52_growing_island_game_spec.md)）。

## 5. しまの きろく（アチーブメント）

子どもが見る本は**1冊**（2026-10-27）。今の「はなずかん」とアチーブメントA1〜A6もここに入る。どれも**実際に起きた事実**から一度だけ残し、通貨や航路の条件にはしない（航路は§3の学習事実とS3だけ）。本は子どもの1冊で、島を移ると引き継ぐ。

| ページ | 中身 |
| --- | --- |
| つぎの たのしみ | いま一番近い目標を1つだけ（スターターの次の手 → 育った浅瀬へ渡る → 仕掛けの次の一歩 → そだつ場所）。次の島の条件は書かない（§3.6） |
| こうろ | 作った島を順に（1つめの しま…）と、沖の浅瀬の今のようす（海の色・砂の道・霧の むこう）。条件・残り・まだの島の名前は出さない（2026-10-28、§3.6） |
| しま | 作った特別な島ごとの仕掛けの進み具合と完成（まだの島は出さない） |

- スターターの手順（S1〜S5）とA1〜A6も子どものものなので、新しく作る島へ引き継ぐ。特別な島に着いた子へ「たねを おこう」をやり直させない（2026-10-27）。

### 5.1 道具は要る時に増える（2026-10-27）

メニューは「なかま・じめん・海図・しゃしん・きろく・あそびかた」と、条件を満たした時の「はし」。道具は次の時に出る。既にこの段階を過ぎた子（住人3人以上・地形を変えたことがある・特別な島がある）は最初から全部出る。

| --- | --- |

## 6. 保存

[保存13](13_data_storage_migration_spec.md)。島の状態に任意の `journey`（開いた枠・選んだテーマと場所・見つけた固有種・沖の浅瀬・いる島、全島共通）と `theme`（その島のテーマ）を持つ。旧保存は無しとして読み、版・表・indexは変えない。表示Lvの集約は読むだけで、学習の保存（教材ID・進級・独力と支援・復習）を書き換えない。

## 7. まだ決めていないこと

- 学習画面の「Lv」の表示を共通20段階へ切り替えること（この仕様は島の航路でだけ使う）。
- 英語の基礎コースだけの子の後続航路。
- 算数のLv20など、次の進級がない最上位の確認方法。

## 8. 受入

2026-10-28：学習・広さ・育ちのどれか一つでは浅瀬が一段だけ育ち、三つで島になる。広さと育ちはいちばん新しい島でだけ数え、一度そろえば残る。最初の住人では枠が開かない。開いていた枠はそのまま渡れる。決まった島以外へは作れない。しおかぜは来ず、特別な島は5つまで。何島になっても重ならず、家から見て他の島の陰にならない。海図・群島・きろく・知らせのひとことに、まだの島の名前・条件・Lvが出ない。


S3→枠0→しおかぜの小島を作る→貝の花→ヤドカリ→おみやげを元の島へ、の一往復。学習の確かめで枠が一つだけ開くこと、別教科の同じ節目で増えないこと、上位開始の最初の進級でまとめて開くこと、旧利用者の枠0、島の往復で枠が増減しないこと。児童の理解・ペース（次の枠までの日数）は観察で別に判断する。
