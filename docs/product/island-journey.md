# 島の航路と まなびの節目

2026-10-26採用。利用者の「100点の仕様でない認識。考えたうえで魅力的な提案まで詰め、一気に実装まで」に基づき、[島とアチーブメントの検討案](island-achievements-unlock-proposal.md)と[共通レベル](learning-levels.md)・[国語のレベル](kokugo-levels.md)を、遊びとして成り立つ形へ組み直した正本。くふう・ふしぎ・愛着に効く。

## 1. 検討案から変えたこと

| 検討案の弱いところ | この仕様での答え |
| --- | --- |
| 特別島を「探訪・発見」の行き先にすると、島で冒険させない方針（[仕様52 §0.3](52_growing_island_game_spec.md)）とぶつかる | 特別島も**自分で育てる島**。固有種は探しに行かず、**その島の環境を工夫すると来る**（置くと自然に育つ） |
| 節目がLv2・5・9・13・17だけだと、次の航路まで何週間も「次」が見えない | 海図に**20個の星**を置き、どの教科でも内容を確かめたレベルごとに1つ灯る。節目の星（2・5・9・13・17）に船の印 |
| 固有種の持ち帰りが未決 | 見つけた固有種は**おみやげ**として、どの島にも1つずつ連れて行ける（買わない・増殖しない） |
| アチーブメントの6分類とふしぎずかんが重なる | 「**しまの きろく**」1冊に、しまづくり・くらし・ふしぎ・まなび・こうかい の5つをまとめる |
| 「設定したLv」と「確かめたLv」が混ざりやすい | 航路と星は**確かめたLv**だけを読む。設定・閲覧・本を開く・受け取りボタンは条件にしない |

## 2. 一周

```text
自分の島で 置く・工夫する ─→ 暮らしと景色が育つ
        ↑                              │
        │                     任意で学ぶ → しずく・町時間
        │                              │
  おみやげを置く              内容を確かめる → 海図の星が灯る
        ↑                              │ （節目の星）
  固有種が来る ←─ 環境を工夫 ←─ 特別な島を選んで作る ←─ 航路の枠が開く
```

## 3. 航路の枠

| 枠 | 開く条件 | 行き先 |
| --- | --- | --- |
| 0 | 最初の住人を迎えた（スターターS3と同じ実操作）。案内を飛ばしても同じ | しおかぜの小島（固定） |
| 1〜5 | どれか一教科で Lv2・5・9・13・17 の内容を確かめた | こだまの森・ひかりの入り江・わたぐもの高原・ぜんまい島・星の島 から、まだ選んでいない1つ |

- 枠は「開いた」と「選んだ」を分ける。開いた枠は残り、選ぶのは本人。出航は強制しない。
- 同じ節目を別の教科で確かめても、枠は増えない。どの教科・どのLvで開いたかと、開いた時刻を一度だけ残す。
- 一度開いた枠は閉じない（範囲変更・不在・復習期限が来ても）。上の節目を正当に確かめたら、その段までの枠をまとめて開く。
- 学習より先に枠が開いても（S3前に学習した子）、資格は残り、S3の後に選べる。
- 既に住人がいる旧利用者は、次に島を開いたとき枠0を開く。開いた時刻は実際に開いた時刻で、過去の日時を作らない。
- 枠は全島で共通（しずく・学習と同じく、島の往復で増えも減りもしない）。

### 確かめたLv（表示Lv1〜20）

| 教科 | 確かめた とする根拠 |
| --- | --- |
| 算数 | 進級テストに合格した記録（保存済みの `testHistory` の合格した進級テスト）で、表示Lvに対応する内部レベルの最後（[共通レベル](learning-levels.md)の表）まで合格している。設定画面や始めた時に選んだレベルは根拠にしない。合格したレベルより下は、上位から始めた子も含めて確かめたものとして航路に数える（下位の学習記録は作らない） |
| 英単語 | 表示Lv＝語彙レベル。同じく進級テストの合格記録で読む。ABC・音の基礎コースは換算しない |
| 国語 | [国語のレベル](kokugo-levels.md)の対象単元が**すべて**確認済み。単元の確認は、その単元の採点対象の問題が持つ「対象・形式・様式」の組すべてで、既存の確認条件（独力初答3件・文脈2群以上・単元別の必須条件）を満たしたとき。自由活動5単元は数えない。下のLvから順に、確かめていないLvがあればそこで止める |

## 4. 特別な島と固有種

特別な島も、ふつうの島と同じ規則で育てる（配置・水・自然・住人・土地拡張）。違うのは、**始まりの地形と、そこでだけ来る固有種**。

| 島 | 始まり（地形） | 着いた時に来る種 | 工夫で来る種と条件 |
| --- | --- | --- | --- |
| しおかぜの小島 | 手前に浅い入り江 | 貝の花 | 葉舟ヤドカリ：貝の花を、掘った水の隣に置く |
| こだまの森 | 一段の丘に若木2本 | 鈴の実の木 | こだま鳥：育った木を3本、辺でつなげる |
| ひかりの入り江 | 内側に池 | 透ける水草 | ひかり貝：段の上の水から池へ滝を落とす |
| わたぐもの高原 | 一段と二段の丘 | 風船花 | わたげ羊：一段以上の上に、2×2の平らな広場を作る |
| ぜんまい島 | 二段の機械の台 | ねじまきそう | ぜんまいどり：二段以上の上に、あかりを置く（とうだいが ともる） |
| 星の島 | 景色がいつも夜 | 星の実の木 | ほしくらげ：掘った水の2区画以内に、あかりを3つ |

- **島ごとの景色**（見た目だけ。2026-10-26、利用者の「もっとメカメカしたしまとか圧倒的な個性をだしていい」を受けて強めた）：島を開いた瞬間に別世界と分かるよう、地面・岸・崖・海の色、画面全体の光、ふつうの草むらに代わるその島の植物、海の向こうの大きな「しるし」、その島だけの動きを持つ。
  - しおかぜ：白い砂の岸・青緑の浅い海・浜の草と貝殻・波打ちぎわの泡・海から立つ巨大な巻き貝。
  - こだま：濃い緑・シダと赤いきのこ・木漏れ日の光の筋・落ち葉・島より古い大樹。
  - ひかり：ミント色の地面・透きとおる水色の海・光るこけ・水のきらめき・光るガラスのアーチ。
  - わたぐも（空の島）：海の代わりに一面の雲の海で、島が空に浮かぶ。わたげの花・流れる雲の影・空に浮かぶ雲の小島。
  - ぜんまい（からくりの島）：鋼色の地面と真鍮のふち・油色の海・地面で回る小さな歯車と真鍮の管・ふちの蒸気・海から突き出て回る巨大な歯車と時計塔。
  - 星：いつも夜・紺色の海に映る星・光る夜の花・海に立つ三日月のアーチ。
  - 固有種は持ち物より一回り大きく、それぞれ動く（ヤドカリは横歩き、こだまどりとぜんまいどりは跳ねる、ねじまきそうの鍵は回る、ほしくらげは漂う など）。
- 着いた時の種は必ず来る（その島の持ち物として置かれる）。工夫で来る種は、条件がそろった時に一度だけ、着いた時の種の近くの空いた区画へ来る（空きがなければ持ち物に入る）。乱数・学習量・時間の待ちはない。
- 見つけた固有種は「しまの きろく」に残り、**おみやげ**として、どの島にも1つずつ連れて行ける。置く・動かす・しまうは持ち物と同じ。ほかの規則（ごはん・住める数・場所の判定）には数えない。
- 星の島の夜は景色だけで、成長・出会い・学習には使わない（[仕様52 §2](52_growing_island_game_spec.md)）。

## 5. しまの きろく（アチーブメント）

メニューの1冊に、5つの系統をまとめる。本は子どもの1冊で、どの島で起きたことも島を移ると引き継ぐ。どれも**実際に起きた事実**から一度だけ残し、通貨や航路の条件にはしない（航路は§3の学習事実とS3だけ）。

| 系統 | 例 |
| --- | --- |
| しまづくり | 土地を広げた・地面を変えた・場所を育てた（そだてる） |
| くらし | なかまが3人・ふたかいだての家・はしを架けた・はたに字を描いた |
| ふしぎ | [ふしぎずかん](52_growing_island_game_spec.md)（滝・にじの木・月 など） |
| まなび | 算数・英単語・国語の Lv2・5・9・13・17 を確かめた（教科ごと） |
| こうかい | 航路が開いた・特別な島を作った・固有種が来た |

- 同時に起きたものは、短いひとこと一件にまとめ、詳しくは本に残す。学習中・操作中は出さない（島を開いた時・操作の後に出す）。
- 既存のA1〜A6（[スターターとアチーブメント](island-starter-achievements-proposal.md)）は、そのまま案内の目標として残し、機能解放の条件にしない契約も変えない。航路の枠0はA1の称号ではなく、S3の実操作そのものを読む。

## 6. 保存

[保存13](13_data_storage_migration_spec.md)。島の状態に任意の `journey`（開いた枠・選んだテーマ・見つけた固有種、全島共通）と `theme`（その島のテーマ）を持つ。旧保存は無しとして読み、版・表・indexは変えない。表示Lvの集約は読むだけで、学習の保存（教材ID・進級・独力と支援・復習）を書き換えない。

## 7. まだ決めていないこと

- 学習画面の「Lv」の表示を共通20段階へ切り替えること（この仕様は島の航路でだけ使う）。
- 英語の基礎コースだけの子の後続航路。
- 算数のLv20など、次の進級がない最上位の確認方法。

## 8. 受入

S3→枠0→しおかぜの小島を作る→貝の花→ヤドカリ→おみやげを元の島へ、の一往復。学習の確かめで枠が一つだけ開くこと、別教科の同じ節目で増えないこと、上位開始の最初の進級でまとめて開くこと、旧利用者の枠0、島の往復で枠が増減しないこと。児童の理解・ペース（次の枠までの日数）は観察で別に判断する。
