# 島で見つける・試す・暮らす・残す体験

Date: 2026-09-08

親仕様は[01](01_app_spec.md)、島は[28](28_mystic_island_spec.md)、成長・暮らしは[30](30_living_island_growth_spec.md)、ほし・きせかえは[35](35_island_customization_spec.md)。本仕様は[104項目](../wiki/game-experience-benchmark.md)と[追加報酬分析](../wiki/reward-customization-benchmark.md)から採用する改善の契約。進捗は[全体タスク](../tasks/active/2026-09-08-island-experience.md)と[対応表](../tasks/active/2026-09-08-island-experience-coverage.md)で追い、仕様の存在を実装済みの証拠にしない。

## 目的と学習契約

学ぶ → 同じ世界が育つ → 暮らしが変わる → 気づく → 自分で試す → また育てたくなる、を実際の行動でつなぐ。所有・自己表現・収集・完成・愛着・手応え・発見・見せたい気持ちを、ほしの数だけで代替しない。

回答・予約・支援・復習・独力判定と、仕様30/35の自動成長・ほしを維持する。報酬は保存された予約の契約に従い、現行 `answers-v1` は完了した区間の問題数、旧予約は10ほしを保持する。新しい遊びはホームの任意操作で、学習開始前や通常連問に追加操作0。誤答・中断・欠席・支援による損失/倍率なし。遊びだけで学習実績を増やさない。音off/reduced motionでも意味を保ち、学習へ戻る操作を演技の終了で待たせない。

住人が実際に道具で過ごし終えた時だけ、暮らしの成果として `ひかり` を島の財布へ加える。帰島後に前回表示から増えた時は「みんなが あそんだ +N ひかり」を短く一度だけ示し、任意で「いろ」へ進める。しずくの獲得と同じ帰島で起きた時は、内訳を一枚の通知へまとめて重ねて知らせない。ひかりの獲得は回収操作・連続日数・学習の正誤とは結び付けず、再読込や支出で同じ増加を再演しない。残高の数字だけで住人の活動を推測させず、通知と住人の現在の活動表示を同じ島画面で読めるようにする。

2026-09-11の暮らし試作では、置いた花を持ち物から「めが でた／つぼみ／さいた」の3段階で確認でき、次の段階までのおおよその時間を示す。時間が進んで段階を越えた時は「おはなが つぼみになったよ」「おはなが さいたよ」を同じ通知カードへ一度だけ加え、持ち物へ戻れる。初回表示で既に育っている花は通知せず、収納中は時間の約束を表示しない。これは大物5段階・小物3段階へ広げる前の代表花の見える化で、成長値・学習量・所有を表示から変更しない。

同じ暮らし試作では、花や遊具を置いた直後に住人が気づいた時だけ「うさぎが おはなを みつけたよ」「カワウソが ブランコを みているよ」のような短い観察通知を同じカードへ加える。既存の `! / ?` のしぐさと対応し、初回表示・再読込・同じ気づきの再演では知らせない。通知は持ち物を開く任意導線であり、学習量・しずく・ひかり・住人の好み・保存される活動履歴を変更しない。

## 採用する6作業群

加えて、分析の主要な未充足だった本人の道具操作・未知物・制作・仕掛け・自由な試作を、[仕様37のおためしの入江](37_island_workshop_spec.md)としてE7/E8へ採用する。以下の6作業群だけで分析全体のGoalを閉じない。

入江で調べた物/作品を主島の暮らしへつなぐF01/F02は、[仕様38](38_island_shared_memories_spec.md)として採用する。選んだ実住民の得意仕事と共同記憶、独立3展示枠、同じ標本/作品snapshotへの再訪、画像bytesを学習writerへ混ぜない写真棚が対象。個別報酬セット・新家具・季節等の残るF03/F04/F05はこの採用だけで満たしたことにしない。

F03の個別報酬と景色の組合せは[仕様39](39_island_appearance_sets_spec.md)へ追加採用する。空遠景/地面岸道/水/家/植物/橋の6部位、12装備箇所、単品と完成セットの未所持分交換、衣装/音/旗も含む3つの景色保存を対象とする。旧テーマ利用権と過去の姿を保持し、F04/F05を含む分析全体の実装・検証完了は別に追う。

F04は[置いた道具から始まる暮らし40](40_island_life_furniture_spec.md)へ採用する。任意の3家具を確定交換し、本人の配置と選んだ住民の実利用へつなぐ。基本家具の成長と旧所有を維持し、F05や全体の検証をこの採用で閉じない。

F05は[身支度と観察記念の仕様41](41_island_expression_collection_spec.md)へ採用する。10品の衣装/模様/足跡/音/外装と無料の朝夕・季節を、無料試用・明示取得・明示装備・景色保存へつなぐ。既存観察、無料設定、旧景色と写真を保持する。F01〜F05の仕様が揃うことを実装・実画面・全分析の合格に置き換えない。

### E1 発見帳と観察の入口

ホームの任意「みつける」から、既存10発見と追加発見を場所別に見る。未発見はシルエットと短い身体/環境の手掛かりで示し、成長不足・収納・配置条件不足を区別する。無料の段階ヒントから対象を選び、必要なら配置編集へ進み、観察へ戻れる。

「ためす」は同じ対象・発見ID・実条件で行動する。通常の確定行動は未発見でも試せるが、押しただけで記録しない。段階不足には次に育つ姿と用途を示す。全成熟/全所持後も観察・組合せ・再演を続けられる。

### E2 因果のある組合せと住民の個性

既存3組のおすそわけを維持し、判定相手・見る地点・実演技・再演で同じ家具ID/位置を使う。複数の噴水で条件判定と演技の相手が変わる余地も直す。

花×噴水で花びらが水に乗り輪が広がる、灯り×噴水で水面に光が映る、という2つの観察を追加する。実際の対象間から動きが始まり、水面に結果が見える。無関係な粒子や説明文だけで因果を代替しない。到達した成長と実配置で成立し、配置を変えると反応も変わる。

カワウソは水、ウサギは花、キツネは灯りを好む。実際の遊び候補/住民選択へ反映し、到達可能性と既存占有を優先する。好物がなくても全住民が暮らせる。任意の住民紹介から好きな場所へ進める。学習能力や報酬差にはしない。

### E3 珍しい来訪と再訪の新鮮さ

庭のリボン模様の蝶、水辺の光る虫、木かげの葉のような小鳥を追加する。常住3住民を置換しない。実来訪先の安定した家具IDと来訪IDのhashから0〜3の位相を決め、保存済み完了区間数のmod4が一致する時に来訪候補となる。適切な配置済み家具と到達段階2を必要とする。条件を維持すれば連続する4区間の値に1回、最大3追加区間で再来候補が来る。reload・連打・時計変更で抽選を回さず、既に観察した来訪の再演は周期不問とする。複数候補があっても目立つ出来事は同時に1つ。具体的規則はdomainに一元化し、UIで次までのカウントや急かす通知は出さない。

基本成長は確定、来訪は追加の外見/発見。待ち時間、日付限定、失効、有償抽選、能力優位なし。実際に見えた時だけ記録し、発見後は何度でも再演できる。実家具を来訪先とし、無関係なitemIdを代用しない。学習・編集・履歴・背景化では新しい来訪を止める。

葉鳥の明示観察は、中心点が見えるだけの後ろ姿や、眼と嘴が数pixelに潰れた顔で完了としない。固定18のqualified-06では正面から約46度・仰角約40度の画角が眼/嘴の可視率を通ったが、phoneの眼の投影外形は約1.8×2.2 CSS pxで判別しにくかった。新候補 `leaf-bird-face-observation-v2` は、実鳥の向きから正面・斜め前±約31度、仰角約11〜27度の有限15候補を調べる。鳥・実止まり先の傘・足との接点を含む近い範囲を使い、全島向けの最低高さと大きな余白で顔を縮めない。物の輪郭と小さな周辺は残し、元の模型・姿勢・着地先・素材・明るさを引き継ぐ。旧03/06の遠い背面/斜め上の構図は引き継がない。話の中心は「同じ鳥が降りる→同じ足が傘へつく→顔と嘴を見つける」で、学習入力・問題間の追加操作・時間契約には変更を加えない。

可読性は実geometryへの光線だけでなく、実canvasのCSS寸法から求める投影外形と見える面積を合わせる。初期の**設計仮説**は、少なくとも片眼の可視率75%以上・外形の短辺3px以上・見える面積6px²以上、嘴の可視率80%以上・短辺5px以上・見える面積24px²以上。正面度0.85以上、仰角30度以下とし、隠れたfeatureや実viewport不明は合格にしない。これらは人の判別を実証した値ではなく、旧03/06を拒否して次の実画像を比較するための下限である。遮蔽判定は眼/嘴を覆う頭・胴・他住民・前景の実meshを含む。画角のために鳥を拡大・反転・移動/非表示にせず、鳥をカメラへ向けるbillboard回転もしない。

開始時の画角は着地まで固定し、最終的に描画した姿勢でも同じ寸法/可視面積判定をrender後に行って、そのframe時刻・各featureの寸法・面積・保留理由を診断へ残す。初期判定が通っても、降りた後や後から前景が重なったframeでは明示観察の新発見登録を保留する。毎frameの画角探索や他住民の歩行停止は加えず、同じ画角で次に実際に見えたframeから1回だけ登録できる。全候補で成立しない場合も既存の発見記録は消さず、本人の再配置・再観察で回復できる。この条件はdiscoveryIdを指定した明示観察に限り、自発的なホーム来訪の既存観察条件は変更しない。学習・背景化・既登録には登録用判定を走らせない。phone/tablet、通常/reduced、実旧cameraの拒否、回転した来訪先、前景遮蔽と着地後の変化を検査し、実画面で顔・嘴・止まり先の読み取りを別途確認する。葉鳥の画角改善を、蝶や来訪全体の魅力の合格へ読み替えない。

蝶の明示観察では、花の上の来訪者が住民の胴に付いた飾りに見えない構図を選ぶ。中心点までの手前遮蔽だけでなく、実際に描画する胴・左右の羽と、前後にある実住民のシルエットとの重なりを調べる。既存の飛行軌道・羽ばたき・観察時の羽の向きを同じ計算で投影し、開始から静止した結果までの代表姿勢と羽角の極値を通じて、花との関係が読める一つの固定画角を使う。画角の都合で住民・蝶・家具を移動/非表示にせず、蝶の拡大や新しい向き補正で代替しない。有限候補で安全な構図がない場合は理由を観察診断に残し、明示観察の新発見だけを保留する。既存記録・自発ホーム来訪の条件は保ち、再配置・再観察で回復できる。phone/tablet、通常/reduced、背後の住民との重なりと前景遮蔽を別々に検査し、実画面の輪郭・花との関係は新しい固定版で確認する。

画角探索は明示観察の開始/resize時の有限候補・通常8代表姿勢/reduced1姿勢に限定し、不適合候補は早期棄却する。30fpsの全軌跡検査は回帰テストで行い、毎frameの全探索や他住民の未来の移動予測を行わない。画角を選んだ時点の可視性は、後の実描画を証明しない。明示蝶の未登録観察ではrender完了後の現在の羽・実住民・前景だけを1姿勢検査し、そのframe時刻と可視性・保留理由を診断に残す。後から住民が重なったframeは保留し、同じ画角のまま次に実際に見えたframeで登録できる。学習・背景化・既登録の来訪にはこの登録用検査を走らせず、学習入力と他住民の歩行を止めない。

### E4 育った後の姿と用途の実景予告

育成選択面で次の成長段階を現在の島の実景にプレビューする。成長/予約/所有/発見を保存せず、形の変化と新しい過ごし方を一緒に示す。プレビューで操作可能な土地や家具を増やさない。現在へ戻す、閉じる、学習開始で解除する。全成熟では未実装の次章を予告しない。

選んだ場所を固定画角で示し、次の姿と現在を同じ倍率で見比べる。通常の全景へ微小な差だけを出して予告完了とはしない。まだ開いていない場所は実景予告を約束せず、育てられる場所の選択へ案内する。

### E5 自分の島・仲間・音

プロフィール名とは別に任意の島名と旗印を付け、実世界の看板へ表示する。既定名のまま全機能を使える。名前は長さ・空白・制御文字を検査し、HTMLとして解釈しない。仲間にも個別の呼び名と装いを選べる。既存の顔/耳/布/身体/座面/手渡し接点を保ち、衣装専用の形を切り替える。

仲間の装いを選ぶ間は、選択した実住民を正面寄りの近い画角で見せる。衣装間の倍率を変えず、住民の姿勢/位置は動かさない。別タブや学習へ移ると通常の画角へ戻す。全景の小さな色差だけで衣装比較を完了扱いにしない。

風/水辺/夕方の3環境音を任意に選ぶ。既定off、端末音off・学習・背景化で停止し、英語音声や判定音を覆わない。多重再生を防ぎ、停止/再開/disposeを検証する。

### E6 景色の保存・創作・見学

3つまで名前付き配置を残す。家具の位置/向き/収納、所有済みテーマ/飾りを保存し、成長/学習/ほし/過去は巻き戻さない。試し見と取消を持つ。後で得た物を削除せず、今の物と衝突する場合は部分適用せず戻して編集できる。

UIを退ける見学表示と、実際の描画から島名/旗/景色のローカル記念写真を作る。成長アルバムの自動snapshot枠とは分離し、外部へ自動送信しない。見学から元の遊びへ戻れる。

見学では家具の編集を無効にしつつ、住民と自然の暮らしは続く。見学中の実際の新発見は通常の実観察と同じ保存経路で残す。編集/過去の比較を止めるreadOnly条件を見学へ一括適用して暮らしまで静止させない。

実観察中にも任意でその瞬間を撮れる。撮影要求は実frame取得時に消費し、アルバム往復やrenderer再mountで勝手に再撮影しない。プロフィールを離れた後に画像の変換が完了しても新しいダウンロードを起こさない。

## 保存・資源

新しい任意表現状態はIsland v1の任意`experience`へ分離する。旧省略値を受け入れ、domainと保存repositoryを独立させる。所有権、revision/CAS、操作IDとatomic保存を維持する。未知形式を黙って初期化して上書きしない。読み取り/試着/再演は保存を増やさない。

追加発見は既存の安定ID・実描画callback・背景再試行を使う。新たな保存失敗を回答失敗へ変換しない。Threeの実景を再利用し、常時第2rendererと学習中の自動カメラ切替は増やさない。看板texture・衣装・一時来訪・環境音は所有元で破棄し、反復切替で資源が増え続けない。

## 移さない仕組み

中断での枯死、都市破壊/維持費、放置罰、支援通貨、課金ガチャ、能力優位の希少品、時刻限定の取り逃しは非懲罰の学習契約に合わない。オンライン交換/ランキング/自動訪問はローカル保存契約の外とし、共有は同じ端末の見学とローカル画像で扱う。通常入力のMinecraft風操作への一括置換は意味/速度を壊すため採用しない。その他の見送りは対応表に個別理由を残し、実装を省くために採用を取り消さない。

5. E4のプレビュー/取消/予約中切替で保存不変、現在との差を実景で確認。
