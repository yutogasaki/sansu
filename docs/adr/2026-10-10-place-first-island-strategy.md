# 2026-10-10 配置から場所が育つ島づくりへ制作戦略を改める

- Date: 2026-10-10
- Status: Accepted as production strategy; runtime mechanics and final art pending
- Related spec: [構築戦略](../product/island-construction-strategy.md), [美術戦略](../product/island-art-strategy.md), [52](../product/52_growing_island_game_spec.md), [51美術章](../product/living-fantasy/01-world-and-art.md)
- Related task: [幻想の庭 — 最初の遊べる一周](../tasks/active/2026-09-27-living-fantasy-first-playable.md)

## Context

ユーザーが繰り返した「初期の明るく丸い3D」「幻想性」「小物の増加では足りない」「隣との合体で大きなものが育つ」「デザインと島構築を根本から見直す」を受けた制作方針の決定。ゲーム規則・保存・配信の切替は未実施。新しい数値と最終の造形採用は後続の比較から決める。

### 問題

直近の美術は丸さ・光・生成全景を個別に改善したが、構築の見返りと描画構造の再設計が不足した。現仕様の1マスの種、建築時のstyle、矩形の土地と単体モデル中心の描画は、個体の成長を実装しても場所全体が育つ体験を強くしにくい。[構造監査](../design/2026-10-10-island-design-strategy/construction-audit.md)。

## Decision

1. 島の設計単位を、個体に加え、土地・水辺・植物の場所・集落・固有の不思議へ広げる。
2. 隣への配置による即時の形の適応、既存時計での場所の成熟、異なる役割の関係からの発見を分け、一つの成長体験へつなぐ。
3. 同じ所有物・成熟で、列/塊/開いた中庭など複数の配置が別の魅力を持つことを比較する。単なる個数閾値と密度の最大化へ収束させない。
4. 初期のかわいさ・ぽこもこのidentity・所有/成熟/履歴・無償の置き直し・学習正本・成長の継続を保つ。北極星と四つの柱を変えない。
5. 美術は成長の状態列と一緒に設計する。固定大背景・粒子・商品追加を主な完成基準にしない。
6. 世界全体の構築戦略を先に整え、実装は木の一系列の配置比較→成長と利用の一周→水/新しい地区の地形→複数の場所/集落→発見と全体採用の順で進める。

## Alternatives Considered

| 選択肢 | 判断 |
|---|---|
| 造形と光だけを改善 | 小物の列と構築の見返りが残るため、全体戦略としては不足 |
| 一律の3個消費合成 | 所有と履歴を消し、レシピを追うだけになるため初期方式にしない |
| SimCityの都市経営を丸ごと移す | 管理負担・退去・維持費が憲法に合わない。周辺条件からの景観成長だけ借りる |
| 自由彫刻/CADを最初に実装 | 子どもの操作と既存保存/通行に大きな負担。新しい地区の地形契約から段階導入 |
| 配置から場所が育つ方式 | くふう・にぎわい・ふしぎ・愛着を同時に支える方針として選択 |

## Consequences

[島構築戦略](../product/island-construction-strategy.md)が制作方針を持つ。[美術戦略](../product/island-art-strategy.md)、成長案、仕様52/51/13/43/44はそれぞれの責任を持つ。詳細数値を複数文書へ複製しない。

個別の模型生成に加え、派生した場所と共有空間の境界が必要になる。地形と保存の高リスク変更は水/新地区の段階へ分け、最初の木の試作で全体の完成を認定しない。既存の不在の無罰、無償の置き直し、人口/地区の継続成長を維持する。

## Verification

今回の検証は文書とショーケース。実装時は同じ材料/違う配置、同じ配置/違う成熟、同じ人口/違う場所、移動/分離/復帰、両幅と小さいシルエットを比較する。新候補の魅力・無説明理解/安全・runtimeを別判定し、自発的学習と翌日の再訪は実利用で確かめる。未測定の効果を達成済みとしない。
