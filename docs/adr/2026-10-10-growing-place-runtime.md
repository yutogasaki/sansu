# 育つ場所を本体へ統合する保存と空間の境界

- Date: 2026-10-10
- Status: Accepted; local implementation and runtime verification complete. Native05 visual completion, independent child/device observation and publication remain open.
- Related spec: [目標の契約](../product/island-place-goals.md), [育つ島](../product/52_growing_island_game_spec.md)
- Related task: [幻想の庭](../tasks/active/2026-09-27-living-fantasy-first-playable.md)

## Context

採用した全島3D native-05を、自分の配置から場所が育つ本体の仕組みへ統合する。派生形を所有物と混同せず、前景の実利用と成立・過去を区別する保存境界が必要になる。

## Decision

本人の配置から場所を純粋に導出し、同じ出力を本・配置予告・3D・利用へ渡す。個体、価格、成長時計、家の建築時style、学習正本を変更しない。完成模型のGLBは配信しない。

新しい `placeProgress` は選択、成立した目標の最初のsnapshot、本人の前景rendererで実際に使った対象の受領を保持する。P01〜P06はA1〜A6と別のID。旧保存の初期値は空で、既存の取得や時刻から実利用を捏造しない。保存版4、Dexie版5の `placedIslands` を本人の正本とし、旧 `guidedIslands` をコピー後も保全する。旧writerは新しい正本を知らない。写真/贈り物/学習のstoreは変更しない。受領は本人・revision・現在の対象/到達/成長を照合し、CAS失敗時は再読込する。

元の初期6×5セルとぽこもこの玄関は水平のまま。拡張土地の斜面は固定の所有座標から決まる共有の高さ関数で、北の森から南の低い湾へ緩く下がる。地区を追加しても既存の高さを変えない。地表mesh、品の足元、歩行、raycast、配置予告は同じ地面の三角形を使う。高さと回廊の公開座標は1e-9単位で丸め、JSエンジンの超越関数の末尾差で同じ配置のrevisionや診断が変わらないようにする。供給は既存の最大8セルを使い、段泉の落水は現実の下りの接続にだけ作る。平地は水庭になる。

新しい屋根は通路の上にあり、柱/幹は元の所有セル内に置く。大樹の回廊は同じルートの床・段・手すり・歩行サンプルを持つ。途中の移設/収納は元の有効な入口へ退避してから次の形を使う。派生形の占有で既存の玄関や橋を塞がない。

造形v2では、回廊の円床も実際の到達できる開いたfootprint内で両足幅を確保し、同じ歩行routeへつなぐ。丸い家は保存済みのstage/style/屋根色を使う。育った家の玄関と場所の入口を結ぶ道は、既存の歩行可能セルだけを共有BFSでつなぐ地表の装飾で、新たな通行権や仕事を生まない。水路セルは舗装しない。外周の岬/石岸は所有床の外へ足し、地面の選択や配置可能セルは増やさない。初期庭の大きさと背景の木は維持する。

造形v3では、元の4根と4冠を中空の木胴へつなぎ、実回廊を内部の居場所として扱う。安全な所有セルと全身経路が成立しない場合は既存の開いた木の形へ戻す。貝屋根は厚い閉曲面と実入口、花は同じ所有の茎・重なる厚い花弁と地表の花床を持つ。浅い水庭は元の供給/到達/所有footprintに限定し、畑・野草・家具・別owner・玄関・実道を覆わない。actor最大耳高は実モデルから測り、新しい木胴/葉と回廊の全身sweepを検査する。既存手すりの全尻尾幅やhopの全poseまで無接触という認定にはしない。

## Alternatives Considered

固定の完成GLBは配置と利用を表せない。旧writerの正本を共用すると新しい利用履歴を保全できないため、新たな正本へ一度コピーする。初期庭を斜面に変える方式は既存玄関の位置を変えるため採用しない。

## Consequences

旧保存と写真・贈り物は保持するが、版4の島を編集するには新しいwriterが必要。元の家具と種が機能の正本で、派生形から入居枠や資源を追加しない。未受領の利用から記念を作らない。

## Verification

15配置、4関係、成熟/分離/再接続、通水/到達/接地、本人分離、旧writer、保存abort/CAS、学習復帰を検証する。最新の本体画面とnative-05を比較する。実取得と成熟fixtureは別に記録し、実時間の数日成長・実機・作者以外の観察・公開はローカル実装完了と区別する。

ローカルのD1〜D4統合は検証済み。[実画面・ゲート](../design/2026-10-10-growing-place-runtime/README.md)に固定NEWの通常取得3旅程と成熟40組の集約、core 564 files/4,966 tests、旧writer隔離と実SW通常/中断4ケースを保存した。取得と一部成熟の元run全体は観察timeoutでFAILのまま保全し、完了済みの行と明示した残範囲から重複なく集約する。一つのrun全体のPASSや、native05全景の完全再現は主張しない。
