# 学習アプリの宣伝サイト — 完成イメージを掲載

2026-10-10 / `promotion-learning-complete-v3` / `/promo/`。

利用者の添付写真に対応する全島3D `whole-island-native-3d-05` を、宣伝サイトの完成イメージとして採用。ゲーム本体への統合はこの変更に含まない。算数・英語・ヒント・復習の入口を保ち、heroと成長比較に全景、森・水庭・入り江に同じモデルの近景を掲載する。

| 引き継ぐ | 引き継がない |
|---|---|
| 青紫の大樹、丘から続く泉、入り江と橋、まとまった街並み | 制作ツールのUI、ファイル取得ボタン、既存ゲームとしての機能約束 |
| 同じモデル・材質・昼の光・カメラプリセット | 違う模型の混在、生成画像による追加、小物を増やす表現 |

画像はモデルの実描画をブラウザーで撮影した静的PNG。宣伝ページはGLBや3Dランタイムを読み込まない。出典と同一モデルSHAは[source-evidence.json](source-evidence.json)。ローカル制作モデルは他タスクの未コミット資料のため、このコミットはモデルを含めず、撮影画像と出典hashを自立した成果物として保持する。

完成イメージのすぐそばに「開発中」「現在のゲームにはまだ登場しません」と表示。最初の2段階は現在のゲームの紹介用fixtureと明記し、選択に合わせて出典も変更する。学習・家の実画像は前版と同じ。

## 受入の境界

- 視覚：利用者が指定した完成像を掲載。作者レビューは全景/近景の一致、森/泉/入り江の読みやすさ、mobileでのcropを確認。宣伝ページ全体への利用者の最終評価は別。
- 独立した理解/安全：実参加者のテストは未実施。ゲームの無文字理解・成長ルールへの合格としない。
- Runtime：静的宣伝ページの画像/操作/4幅を検証。ゲームの学習・保存・PWA・育つ地形は変更していない。
