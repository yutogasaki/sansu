## 今回の変更

同じ4本の成熟した木の配置から、元島の北東に高い肩、東に低い岬、両者を結ぶ外側の岸を組み立てる。橋の先の追加小島ではなく、元の海岸境界へ直接つなぐ。北東と東で別の形・方向を持てるよう組立て規則を拡張し、対応する床・岸・接続部を制作した。

元の10床・73配置権を保つ設計で、中央丘の移動や、島全域を自由な形へ変形する仕組みまで実装したものではない。新しい床は歩行用で、新しい配置権を自動で与えない。

| 木の配置 | 試作の結果 |
| --- | --- |
| 北東に4本をまとめる | 高い肩が海へ伸びる |
| 東に4本をまとめる | 低く広い岬になる |
| 両者の間へ4本を連ねる | 2つの岸がつながり、内側に入り江を残す |

診断は既存35所有物・8軒の固定成熟状態を使う。比較前にベンチを一度移し、同じ4本だけを動かす。通常の学習からの成長や本人の保存を、この診断で確認済みとは扱わない。
