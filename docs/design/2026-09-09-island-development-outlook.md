# ぽこもこと自分の家から育つ島：統合検討案

2026-09-09。状態：検討案。ここまでのユーザーの方向指定と、助手の提案・未決事項を分けてまとめた。実装・配布の承認や採用済み製品仕様ではない。既存の入江・配置・写真・学習機能はこの文書では変更しない。

## 1. 中心となる体験

**自分が学ぶ → ぽこもこと暮らす家が育つ → ご近所と島が豊かになる → 住民の新しい暮らしや特別なものを見つける → さらに学んで育てたくなる。**

発展の中心は同じ家とぽこもこ。庭、ご近所、島全体、島の外へ世界が広がっても、家に成果・思い出が戻る。本人の主な行為は学習。制作・運搬・遊具遊び・遠征などは住民が自発的に行う。

「中身が豊富」は子どもの作業量ではなく、施設の用途、住民の個性、行動の組合せ、集まる品物、残る景色の豊かさ。学習で暮らしが増え、本人は任意に眺め、好みを少し選べる。

## 2. 方向指定と提案を分ける

| 区分 | 内容 |
|---|---|
| ユーザーの明示した方向 | 学習が主、住民が自発的に遊ぶ。ぽこもこが主役で自分の家が起点。島の大きな発展と内容の充実を両立。大物5段階・小物3段階を先に決め、運によるレアを重ねる |
| 今回の推奨 | 家の発展を中心に地区を順次開く。大物と小物の変化をずらす。通常の豪華な完成形とレアを独立させる。主島を優先し、小島と他人の島は後段へ置く |
| 検討候補 | 外観分岐、地区ごとのテーマセット、住民の小さな物語、天文台などの大建築、他人の島の目標登録 |
| 未決 | 問題数、抽選確率と保証、住民数、土地寸法、全施設数、既存成長の移行対応、オンライン共有の仕様 |

アイデアとして会話に出たものを全て必須機能にしない。未決項目には以下で推奨と判断材料を示す。

## 4. 三つの成長を分ける

| 軸 | 進むもの | 意味 |
|---|---|---|
| 島の発展段階 | 家からご近所、地区、港へ | 世界の広さ・密度と暮らしの種類が増える |
| コンテンツの等級 | 大物1〜5、小物1〜3 | 同じ物が立派になり、用途が豊かになる |
| 外観・レア | テーマ、珍しい形・模様・記念品 | 同じ進度でも自分の島の個性が出る |

さらに本人の習得は別の軸。島の等級を教材のレベルや学習能力と呼ばない。レアを6段階目として扱わず、例えば家の等級4にレアな屋根を装備でき、等級5へ成長しても所有を保持する。

## 5. 家から広がる発展順

| 発展 | 追加される景色と内容 | ぽこもこ・家への返り | 解放の考え方（提案） |
|---|---|---|---|
| 家と庭 | 家の序盤アップグレード、花壇、灯り、ベンチ | 家の中の過ごし方と庭での休息が増える | 選ばず通常学習で始まる |
| ご近所 | 道、店、公園。ぽこもこを訪ねる住民 | 花やおやつが届き、友達を招ける | 家の序盤成長で開く。等級5完成までは待たせない |
| 森と工房 | 新しい地区、材料を運ぶ住民、水車や工房 | 家や公園に使われる物ができる | ご近所の節目で開く。全小物の完成は要求しない |
| 港と往来 | 港、船、島同士を結ぶ生活 | 住民の持帰り品が庭や棚に残る | 主島の発展から確定で開く。レア取得は条件にしない |
| 豊かな島 | 各施設の上位等級、地区の個性、象徴的な大建築 | 同じ家が街の中心として残る | 既存の家を維持して大きな完成へ。小島追加は別に検討 |

土地を広げる→必ず同じ作業をやり直す、とはしない。古い地区の施設も続けて育ち、新地区から物や住民が来る。全施設等級5で行き止まりになる前に、次の地区/用途と主島の有限の完成形を設計する。無限成長や未制作の新章は予告しない。

## 6. 大物5段階・小物3段階

[コンテンツ全体表](2026-09-09-island-content-catalog.md)に各段階の姿・住民利用・連動・レア候補をまとめた。

各段階は「輪郭/規模の差」と「暮らしの差」の両方を持つ。工事中の土台・柱・屋根などは保存された進行を表し、時刻だけで完成しない。子どもが建材を集めたり配置しないと進まない契約にはしない。

最終形だけでなく途中も完成品として魅力を持たせる。豪華さは金色や装飾密度の増加に限定せず、庭の豊かさ、素材の違い、造形、住民の居場所で表す。大物の5段階と小物の3段階を、島全体の5章と同じ意味にしない。

## 7. バランスの推奨

| 論点 | 推奨 | 理由/確かめ方 |
|---|---|---|
| 島の広さと量 | 現在地が充実→施設が立派になる→新地区が開く、を交互にする | 拡張のたび空地だけ増えることを避ける。全景と家の近景で確認 |
| 発展中の目標数 | 大物1件と小物1件を進行中の見せ場にする案 | 全物を薄く同時に育てず、大物の待ちを小物の変化でつなぐ |
| 学習成果の反映 | 一つの完了成果が大物/小物の二つの進行へ寄与する案。通貨消費とは分ける | 二度学び直したり、小物を選ぶと家が遅れることを避ける。二軸への配賦は明示設計で、回答を二度記録しない |
| 進行間隔 | 初期は早く、後半は長期目標。小物・途中の姿・大きな完成をずらす | 実時間と問題型/支援を含めて調整。現行63問を新方式の正解としない |
| 育成の選択 | 選ばなくても進む既定順。好きなら次の対象を変える | 現予約は固定し、学習前の設定を必須にしない |
| 視点 | 家とぽこもこの近景を基点に、任意の全景/地区表示 | 拡張のたび主人公が豆粒にならない。全景比較は同倍率 |
| 行動量 | 注目すべき出来事は一つ、周囲は穏やかな生活 | 賑わいを常時大量のアニメーションと混同しない |
| 個性 | 成長等級と外観分岐を分離し、後から変更できる | 強さと好みの混同、取り返しのつかない最初の選択を避ける |

具体的な問数・土地寸法・住民数の確定前に、予定する通常状態/最大発展/狭い画面を比較する。成長の進み方は通常の3/6問区間、複雑問題、支援ありで別に見る。

## 8. ぽこもこと住民

ぽこもこは住民の一人に埋没させない。帰島の基点、家の生活、節目の反応を担い、外出しても家へ帰る。既存の家の写真・学習記念・最初の家具が、ぽこもこと本人の積み重ねになる。

性格は動作で示す。好きな椅子を使い続ける、友達の作った物を眺めるなどの候補を絞る。具体的な好みは未決で、人物像を無制限に追加しない。学習を休んだり誤答したりした時に寂しさや不機嫌を見せて学習を促さない。

ほかの住民は好み・役割を分ける。基本住民は確定の発展で増える。レア来訪者と、永続的な住民の加入は別にし、主人公を抽選対象にしない。

施設の接続は、庭の花→店→家のテラス、工房→公園の遊具、港→庭の植物など、同じ物が移動して使われる連鎖で見せる。本人による配送指示・経営・配置パズルを成立条件にしない。

## 9. 通常・特殊・レアの役割

| 種類 | 入手の提案 | 用途 |
|---|---|---|
| 通常 | 学習で確実に成長 | レアなしでも豪華な島に完成する基盤 |
| 特殊な大物 | 大きな学習の節目で確定解放。天文台など | 遠い目標と島の象徴。抽選待ちで主要な用途を止めない |
| レア外観/記念品 | 学習量に応じた抽選＋一定量での保証を推奨 | 意外性、所有、収集、好み |
| 珍しい出来事 | 成立環境で住民/自然の変化として見せる | 暮らしの新鮮さ。演技を見た事実と所有権を分ける |

抽選設計の未決と推奨：

- 抽選回数は短い区間の連打で有利にならないよう、保存済みの学習量の区切りで数える。例えば6問分ごとなら3問区間2回と6問区間1回を同じに扱い、余りを持ち越す。この6問は説明例で採用値ではない。
- 同じ完了問題は一度だけ計上し、誤答の連打で回数を増やさない。支援完了を一律に除外せず、速度や連勝倍率も付けない。
- 確率と保証までの量は未決。通常plannerの問題負担で比較し、運が悪い子にも届く上限を設計してから採用する。
- 初期の少数コレクションは未所持を優先し、使い道のない重複を出さない案を推奨。所持対象を揃え終えたら、その集合の新規抽選/保証は終了し、未制作の次集合を予告しない。日々の違いは既得品の住民利用・配置・演技で作る。
- 確定した獲得品は受取不要で保存し、後から確認できる。アプリを開き直したり演技を再生しても再抽選しない。
- 獲得した外観は成長しても失わず、通常外観へも戻せる。レアによる島の成長速度/学習能力の優位は付けない。
- 見ていない出来事を図鑑に「観察した」と記録しない。未読の獲得品、実観察、再演は別に扱う。

## 10. 主島・小島・他人の島

主島のアップグレードを優先する。港が育つと住民の船が小島へ行き、主島に植物や品物が届く案。本人の遠征操作・派遣・時刻管理は増やさない。背景での放置だけで恒久品を量産せず、学習で得た資格と一度だけの所有付与に結び付ける。

他人の島は、成長した家や施設を知り、自分の島を見せる役割。最初は同じ端末の家族プロフィール/既存写真の見せ合いを検討。次に招待した相手の見学。オンライン閲覧はローカル保存の現行契約を超える別機能で、実装済みとはしない。

見学で新しい品を集める、訪問回数で報酬を得る、順位を上げることは主ループへ増やさない。見学時間が学習へ戻る期待を作るかを確認し、滞在の長さを成功とはしない。

## 11. 学習の主役を守る

通常の問題間は追加0操作。島の演技を入力待ちにせず、問題中は島の眺めを要求しない。帰島は任意で、最新の変化をその場所で見られ、同じ学習の続きへ戻れる。通知や受取を順に処理する作業は作らない。

島での本人の任意操作は眺め、外見/次の育成先の選択、写真や記念の確認を中心にする。既存の工作などを削除・再ロックする判断は別とし、新しい必須ミニゲームは追加しない。

学習の独力正解・支援後の再確認・後日の定着は島成長と別に残す。既存トロフィーは区間完了の記念であり、習得を表す賞へ読み替えない。新しい習得記念を作る場合は学習の実証条件を別途定義する。

## 12. 最初に作る範囲と後段

| 順 | 範囲 | 目的 |
|---|---|---|
| A 設計と成立性 | 家5段階、庭の小物3段階、ぽこもこの生活、最終主島の構成、進行/レア候補 | 家が主役として育ち、先に何があるかを一続きにする |
| B 最初の制作単位 | 家＋店の大物2種、小物3種、住民の自発連鎖、レア外観1系統 | 学習→家が育つ→ご近所ができる→暮らし/所有が増える→再学習まで成立させる |
| C 主島の充実 | 公園、森/工房、小物追加、施設間の暮らし | 種類と密度を増やし、家へ成果が戻る |
| D 長期展開 | 港/小島、確定の大建築、他人の島の招待見学 | 主島で成立した魅力を広げる |

Bの制作量と全体候補数はコンテンツ表を参照。まず家と庭で保存/描画の縦の経路を作り、その後店・レアへ接続する。途中の限定完成をB全体の完成とはしない。日数の見積りは主人公の3D接続、家の5段階化、土地互換の調査後に行う。

## 13. 検討結果と確認するリスク

方向としては採用を推奨する。理由は学習の成果、家への愛着、世界の発展、収集が同じ場所へ戻り、本人に別ゲームの操作を要求しないため。効果は設計仮説で、人の観察は現時点でN=0。

優先する懸念は次の5点。

1. 主人公と家が脇役になる：帰島の近景と、家へ戻る住民の行動で確認する。
2. 後半の待ちが長い：大物/小物/工事途中をずらし、各問題型と支援を含む実時間で調整する。
3. レアだけが楽しみになる：通常の最終形を魅力の基準にし、基本成長に抽選を混ぜない。
4. コンテンツ数が制作可能量を超える：等級×外観×住民×用途の組合せを数え、最初の対象を限定する。
5. 島への滞在だけ増える：学習への自発的な復帰、別日の再開、独力/定着を別に観察する。学習を減らす島操作は見直す。

技術チェックと子どもの評価は分離する。同じ端末幅・実buildで初期/途中/完成と、帰島/学習再開を見る。初見の反応だけで長期意欲を認定せず、自然な学習からの成長と別日の再開も観察する。参加者に誘導した発言、自動入力、成熟fixtureは別に記録する。

## 14. 採用時の仕様と保存

今回はこの提案とコンテンツ表、indexのみを編集。親仕様・学習・保存・アプリの挙動は変更しない。

採用時には親01、島28/30、住民36/38、家42、外見35/39〜41、保存13を更新する。現行3段階から新5段階へ移す際は既得の見た目・用途・配置・予約・写真を保持する対応表が必要。単純に既存levelを新levelへ読み替えない。

主人公のモデル/リグ、住民ID、常駐位置と既存役者を確認する。土地の0/1/2だけを増やさず、配置域・歩行・カメラと新施設を照合する。レア判定と進行は保存済み学習イベントに結び付け、再送・競合・再読込で重複させない。学習の成功を演技/乱数/画像の成否へ依存させない。
