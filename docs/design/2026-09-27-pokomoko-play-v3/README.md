## 参考の再分析

[原投稿](https://x.com/grmchn4ai/status/2103807453406388538)は2026-09-26。x-readで本文・動画を取得し、53秒の動画をブラウザーで再生、約2/6/17/27/44秒で構図を確認した。調査対象はこの1投稿のみ。音と子どもの学習効果は評価していない。「勉強中毒」は投稿者の表現であり、検証された効果ではない。

| 観察 | TRANSFER | DO NOT TRANSFER |
| --- | --- | --- |
| 入力位置へキャラの動作が伸び、入力数字のそばから報酬が飛ぶ | 操作した場所と相棒の反応を一本の移動でつなぐ | 伸びる身体、キャラの模倣、正誤の先読み |
| 大きな数字が短く飛び出す | 読ませる常設説明より、短い大きな変化 | 桁数が無限に膨らむ数値報酬 |
| 進行で背景・旗・キャラ数・キー配色が変わる | 局所の紙吹雪ではなく画面の状態が変わる | 問題と入力を覆う大量の粒子 |
| EX開始で大きな横断バナー、問題カードにも動き | 節目で移動範囲とシルエットが変わる | 問題カードの回転、制限時間、入力待ち |

v2は「小さな風景を見る・ゲージを読む」に分離され、答える手触りと因果が切れていた。今回の主動作は「入力したところから光を集める → 星が埋まる → 星に乗って飛ぶ」。元の全身atlasを維持し、体を変形して意味を作らない。

## 構図と契約

常設72pxの開放舞台（旧148px）。細い説明行と下段ゲージは撤去。全身・連続数・5個の星に絞る。失敗/支援の短い文言は16px以上で表示。入力の光は未採点の受理反応で、正解の報酬とは区別する。普通の反応、3連続ジャンプ、5連続横断飛翔を別動作にする。問題・テンキーそのものは移動せず、演出はクリックを取らない。保存・採点・SRS・音設定は変更しない。
