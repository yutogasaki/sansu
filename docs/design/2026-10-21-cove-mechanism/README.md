# 岸を変えても、同じ庭として使えるか

2026-10-21。追加依頼「次やることやって」に基づく、一つの隔離検証。目的は完成した一枚絵ではなく、同じ家・六本の木・ぽこもこを保ち、入り江を変えた結果へ描画・支持・経路・行き先が一緒に追従するかを確かめること。

## 制作前の契約

- 既存の島モデルの部品と既存ぽこもこを使う。家一軒・木六本、個体と位置・向き・倍率は編集で変えない。
- 三つの編集を累積して実行し、各状態から現在の岸を探して歩く。定点へ行く演技で代用しない。
- 家・根・現在の足の支持を守る。不通の目的地は到達不能として返し、編集を戻せる。
- Undo/Redoは現在の足場を失う場合に事前拒否し、家へ戻る操作を案内する。無言の瞬間移動で補わない。
- 比較のcameraと光は固定。自由操作でも同じ編集処理を使う。
- 本体や既存試作を上書きせず、通常保存・学習・所有規則・PWAへ接続しない。自由掘削を本体の取得済み土地へ採用した扱いにしない。
- 候補 `cove-mechanism-v1`、配布 `standalone-study-only`。現試作の高さ場と歩行探索を限定再利用する。本体の共通worldへ移植済みとは扱わない。

既定30分・追加エージェントなし。美術、無説明理解・安全、仕組みの整合を別判定する。

上の観察点は編集ごとの固定座標として実装したものではなく、同じ探索処理が現在の地形と選択地点から選んだ結果。行き先の先に実際の水面があることも確認した。三つのショートカット、地図、画面タップ、キーボードは同じ編集処理を使う。

家・木は原本から取り出した実モデル。家の壁や曲がる幹・樹冠の三角形から、高さ別の保守的な障害物範囲を作る。上げた土地でも人物の高さに重なる範囲を調べ、体が重なる経路を使わない。根元の頂点から支持地点も取り、中心一点が陸なら十分とはしない。これは厳密な人体物理ではなく、通行を狭く見積もる簡略判定である。

地面と水際の描画は同じ高さ場から生成する。歩行点も同じ高さ場へ接地させ、描画された三角形面へのrayで差を確認した。390幅の通常歩行264サンプルで、足の基準高と可視地表の最大差は約0.00126 world unit（検査上限0.015）。全ての任意地形・全ての姿勢の検証ではない。

今回の地形変更は即時反映。歩行は距離に応じた足運びと終点での減速を行い、停止後に対象へ向く。動きを減らす設定では、同じ検査済み経路の終点を直接表示する。水の流入アニメーションや実音は追加していない。

## 止める操作と、直せる状態

- 家の足場、木そのもの、根を支える隣の土地を削る操作は拒否し、状態と履歴を変えない。
- 新しく盛った土地にぽこもこが立っているとき、その土地を消すUndoは事前拒否する。同じ位置を保ち、家へ戻ってからUndoできる。
- 離れた海に土地を盛ること自体は許す。そこへ道がない場合は歩行を開始せず、編集を戻せる。無人の陸が分離することまで禁止しない。
- 歩行中に別の土地を編集すると、古い経路を停止する。後からその経路が再開したり、相棒が位置を飛ばしたりしない。
- 「はじめから」は、本人が選ぶ試作全体のリセット。通常のUndoとは区別して、庭と相棒を初期状態へ戻す。

相棒が家から切り離された陸に残る全ケース、そこでUndoも拒否される場合の回復の分かりやすさは未検証。今回確認した回復手段を、任意の閉じ込め状態への保証に広げない。

## 何が分かり、何がまだ足りないか

| 判定対象 | 今回の結果 |
| --- | --- |
| 既存部品と編集地形の組み合わせ | この一角・三編集では成立。実モデルを保持したまま、岸・足場・行き先・経路が追従した |
| 操作整合 | 対象PASS。三編集、帰宅、Undo/Redo、拒否と回復、歩行中の編集、タップとキーボードを確認 |
| 美術 | **HOLD**。部品の形は揃ったが、湾の長い直線、平坦な空地、離れた木の配置が残る。木陰と家前が一つの場所になったとは判定しない |
| 子どもの理解・楽しさ・再訪 | **未確認、児童N=0**。自動検証や作者の説明から推定しない |
| 本体への適用 | **未接続**。本体の共通world・本人の配置・成長・保存・所有規則を通した検証ではない |

この試験で確認できたのは、部品を載せた絵を固定するだけでなく、実編集へ接地・歩行を追従させられること。一方、違う家・成長段階・別の樹木配置でも魅力的な場所になる仕組みは、まだ実証していない。全島への一般化は未完。

次に修正すべき対象は、同じ三編集で見比べられる**岸の形と木陰・玄関前の関係**。一枚だけの装飾追加や、撮影のために毎回配置を動かす方法では直さない。採用後に本体の共通worldへつなぐ工程も別に必要であり、この高さ場を本体へそのまま導入する判断はしていない。
