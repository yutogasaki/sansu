## 実装した作り方

高さ・材質を持つ同じ入力から、境界の接合、地面の膨らみ、草の丸い縁、土の側面、砂浜、浅瀬を作る。見た目と接地は同じCPU上の三角形を参照する。外部作品の内部ソースやアルゴリズムを特定したものではない。

| 参考から移す性質 | この試作への実装 | 移さないもの |
| --- | --- | --- |
| 草と土と水の素材差 | 草の厚み、土の断面、低い砂浜、水深に応じた色 | 参考のモデル・テクスチャ |
| 角の丸い上面と岸 | 境界付近の高さを滑らかに下げ、外側の縁と連続させる | 平面画像を置いて形を隠す方法 |
| 草や石と地面の関係 | 世界座標に固定した種から生成し、実床へ接地 | 毎回ランダムに全景が変わる配置 |
| 地形変更に伴う浅瀬 | 最下段の境界から浅瀬と光の模様を作る | 参考の正確な水シェーダーだという断定 |

既存の `native05-owned-kit-v1` の柳を1本使用。これはGLBから取り出した既存モデルであり、今回生成した画像ではない。根元の実頂点437点を地表へ照合する。植生表示を切れば地形だけ、灰色表示を選べば形だけを確認できる。

比較画面の左は前回H2の仕上げ、中央は新しい仕上げ。同じ地形入力・同じカメラ・同じ照明で表示する。旧H1を改善前として扱わない。参考画面は実操作からの画像で、画角や島全体の形まで厳密に同一ではない。改善後には植生も加わるため、個別の要因を確かめる際は植生チェックを切る。

## 推定 → テスト → 修正

1. 接続を保ったまま色・水際・植生を変更した。`evidence/iteration-1.jpg` ではまだ薄い縁と直立した側面が残った。
2. 上面の肩を丸め、草の厚みと砂浜の幅を変更。前回の「高台の全点が高さ0.69±0.03」という検査が対角経路で失敗した（revision `9600521d18eeedfc`）。この失敗は角を丸めた結果で、穴が開いた失敗とは区別した。
3. 平坦さの代わりに、実床の有無・半径0.17の足裏12点の高さ差0.08未満・経路上の隣接高さ差0.08未満を検査。60区間の対角経路と逆向き経路で成立し、切れた道は不成立になった。世界単位の診断値であり、子どもの安全性や本体歩行全般の合格ではない。
4. 水の光の模様が沖まで網のように目立ったため、浅瀬近くへ絞り、強さを不均一にした。木は実モデルの柳へ変更。UI上の「制作画面」では比較用の旧地形を再計算しない。
5. 地形の直接クリック、掘削、材質変更、歩行、途中編集、Undo／Redoを実操作。390px幅では改善後を先に表示する。

## 検証基準と結果

| 基準 | 結果と証拠 |
| --- | --- |
| 単独・隣接・L・四角・対角・逆対角・隙間・穴で地形が壊れない | 8形状を実描画。密な独立floor gridで、陸の欠落・隙間の見えない高台を検査。`results.json`、`browser-cases-final.json` |
| 実際の地面と接地計算が一致する | 8形状×2仕上げ×5地点のCPU floorとThree.js raycastを比較。最大誤差は約2.8e-8 world unit |
| 草・木が地面へ接地する | 地形ごとの草86〜87群、柳の根元437頂点を確認。支持がない装飾は表示しない。所有物の編集拒否仕様とは別 |
| 編集とUndo／Redoが一致する | 材質塗替えは高さを維持、次の石操作で上昇。Undo／Redoで入力一致。水面pixelsと草の根元も再生成一致 |
| 通れる道だけ実際に歩く | 対角経路完走、掘削後は停止、Undoで復元。歩行中編集で古い歩行が再開しない。`browser-walk-cut.json`、`browser-interrupted-walk.json` |
| 狭幅で操作できる | CSS390×844、横はみ出しなし。地形を直接クリック→Undo成功。実機タッチではない |
| 編集の待ち時間と歩行を測る | 同じ1280×720でも比較再計算は観測300〜580msと変動。単独制作画面の観測252〜277ms。歩行フレーム間隔P95約18ms。特定のローカル環境の診断値で、端末性能保証ではない |

対象ロジック検査は10件。初期の非推奨shadow設定の警告を修正した。前回のH1反証も維持する。最終結果の日時・コマンド・hash・未確認範囲は `verification.json` を参照。

## 判断の範囲

編集に合わせて岸・素材・水際・植生を再構成し、同じ地表で歩行するところまで実装した。初期の平板な格子模様から改善していることは比較画像で確認できる。一方、参考作品に並ぶ最終美術の採用は未確定。土の層の細かな造形、島全体の構図、家・木陰・水辺の関係、任意の所有配置や大きな島での成立は、この小入力だけでは証明していない。単に検査件数が増えたことを目標到達の根拠にしない。

本体の `src/`・`public/`、保存・所有・成長・学習UI・配布設定は変更していない。本体統合、実端末、reduced-motionの実操作、長時間GPU試験、PWA更新、児童の無説明理解は未検証。
