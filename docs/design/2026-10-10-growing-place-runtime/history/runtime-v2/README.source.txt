# 育つ場所v1 · 本体の実装と実画面

採用した[全島実3D native-05](../2026-10-10-island-final-3d/README.md)を、本人の配置から育つ実際のアプリへ統合する。6つの自由な目標、同じ材料で変わる15配置、4つの場所の関係を一続きの島として扱う。[実装契約](../../product/island-place-goals.md)と[保存ADR](../../adr/2026-10-10-growing-place-runtime.md)が正本。

**最新状態：造形v2へ更新、全島美術はHOLD。** 利用者が採用した全景を再提示し「このイメージにむかってるの？」と確認した。丸い家、丘と不規則な岸、琥珀の上胴、実円形回廊、歩ける入口をつなぐ道、広げた実供給水を本体へ実装した。[最新DEV全景](whole-dev-art-v2-final.png)と[並べた比較画面](native05-v2-comparison.png)を残す。作者と独立UI担当は方向への進歩を認めるが、広い水と湾を囲む暮らし、大樹/回廊/花庭の一体感は完成像へ未到達と判断した。仕組みの検査で美術のHOLDを埋めない。以下のv1とv2の証拠は別の版として保全する。

## 実装した範囲

- D1〜D4：木陰の庭/大樹と枝の回廊/段泉または平らな水庭/入り江の共同広場/花の屋根。各形を現在の所有・接続・成熟・到達から純粋に導く。
- 本、配置予告、実3D、住人の歩行と利用が同じ場所・高さ・対象を読む。屋根を付けるだけで利用済みにしない。
- 木/花/家のID、支払い、育成時計、家のstyleと住人、学習を保持する。現在の場所は分離で戻り、初回の記念は残る。
- record4/専用`placedIslands`へ一度移行する。前景の本物の利用だけを対象・revision・本人と照合して受領する。旧writerは新しい正本を編集できない。

## 実画面の対象

最新の本体候補は`native-05-place-runtime-v2`、Island/Growing ON、Nature Town OFF。完成模型のGLBを固定背景として配信せず、本人の各配置からThree.jsで造形する。

`whole-dev-art-v2-final.png`は造形v2を再読込したDEV実画面。4系列、既存stage4の8軒と8住人を明示した成熟診断で、自然取得・7日成長の証拠ではない。[実際のアプリ版と配置の版](whole-dev-art-v2-final-metadata.json)を伴う。`whole-dev-final.png`とmetadataはv1のbaseline。固定したproduction候補の操作/保存検証は別に記録する。

v2の[保存・実SW更新証拠](storage-evidence/native-v2/index.json)は、独立したNEW/ROLLBACK、旧writer隔離、390/768幅の通常/中断4ケースがPASS。実際の学習・予約・所有・住人を保ち、offline継続から互換writerへ戻る。元の利用者の状態を使わず、生成QAのみ。技術PASSを全島美術の完成としない。

`whole-dev-first.png`、`whole-dev-round.png`、`whole-dev-before-shallow-water.png`は途中の画面として保全する。旧画面を最終候補へ昇格させない。

## 全島の美術比較

[ゲートの記録](gate-review.json)はnative-05と最新本体を並べた作者・UI/geometry担当の画像レビュー。当初の本体v1レビューは履歴へ保全したが、利用者の全景再提示を受け、現在はnative-05との整合をHOLDとし、造形を改めている。高い矩形の壁を低い湾へ下がる丸岸にし、平たい傘を入口と肋骨を持つ曲面屋根へ、小さな青い水鉢の列を一続きの浅い水面へ改めた。森・水辺・入り江・花の大形と多色の透ける葉を昼の造形で区別する。

native-05より所有床は規則的で、主大樹・高床の中心性、深い泉/洞窟と複雑な海岸の迫力は控えめ。これを完全再現の認定にはしない。水路は既存の歩けるセルなので、水面を実地面+3cm、渡り石とactorの足を+4cmに統一した浅い渡り場にする。個体の座標・通水・到達・所有を動かして模型へ合わせない。

## 独立したゲート

| ゲート | 扱う証拠 |
|---|---|
| 視覚 | native-05の全景と最新runtime全景を並べ、明るさ・丸み・4地区の形/空間・幻想性を作者が比較する |
| 理解/安全 | 44px操作、学習往復、取り消し/分離・記念の読み取りを検査する。子どもの無説明理解と再訪は別 |
| Runtime | 固定sourceのcore、通常取得旅程、明示成熟診断、実利用/接地、保存4・旧writer隔離・実SW更新/中断/互換復旧 |

公開、実機、独立した参加者の無説明理解/再訪、実時間で数日待つ成熟は未実施。自動検査のPASSでこれらを代用しない。
