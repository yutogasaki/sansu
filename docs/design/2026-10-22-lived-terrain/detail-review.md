## 実際に見つけて修正した点

| 観察・反例 | 修正 |
| --- | --- |
| 土壁に細い縦筋。輪郭の三角形の大小が陰影に現れる | 面積依存の頂点法線から角度加重へ。材質の色が切り替わる頂点でも、位置が同じなら法線を共有 |
| 草の上面と崖の接続部で、高さの計算方法が微妙に違う | 境界の上面と崖に同じ高さを使い、数値上の隙間を閉じる |
| 草・土が広い色むらだけで平滑、砂浜が均一な線 | 世界座標に固定した素材別の細かな濃淡、土の層、草縁と砂幅の変化。色の処理だけでは床を動かさない |
| 歩き終わると足を一律の高さへ戻し、傾斜補正が消える | 元の足モデルの下半分の頂点から左右別に接地。停止・再探索・地形変更後にも適用 |
| 角を直進しながら身体だけ回り、横滑りして見える | 安全な角だけ実床検証した曲線にする。鋭い方向転換ではその場で向いてから進む。歩幅は経過時刻ではなく実移動距離に同期 |
| 現在地を再指定すると小さな寄り道を作る | 同一点なら移動を発生させない |
| 編集例の再生中にも移動ボタンが押せる | 再生中の移動・編集・履歴操作を揃えて止め、再生終了で復帰 |
| 空の水面を掘ると、変化がないのに履歴が増える | 入力を変えず、これ以上掘れないことを表示 |
| 編集計算中に反応がない。拒否時の選択表示も更新されない | 確認中の表示を先に描き、二重入力を抑止。拒否した位置を色で知らせ、その場で再描画 |
| 同じ水際の再計算や同じ材質の探索が毎回走る | 水の模様・逆座標を再利用し、岸が変わったときだけ水面を更新。上面の高さ計算も共有 |

キャラクターの顔・身体・配色、家と木の所有ID・モデル・水平位置・尺度は維持。例の再生では人物の向きも初期化し、同じ画角で比較できるようにした。

## 判定方法

- 純粋ロジック：従来11反例に、同一点・陰影の三角形依存・傾斜と各方位の足裏・安全な曲線・空の水面の5件を追加。
- 実ブラウザ：平地/L字/入り江それぞれ木陰→水辺→家前。各旅程を個別JSONで保存し、到着・全歩行サンプルの支持・所有物保持を確認。
- 接地：接地式だけで合格にせず、実際の足Meshの行列を通した下部頂点と、描画地形へのThree.js下向きraycastを到着時に照合。
- 編集：歩行中の道の切断→Undoで再開→対岸で再切断→帰宅不能→復旧、支持を壊す掘削、上限と空掘り、狭幅の直接編集とUndo/Redoを操作して確認。

具体的な結果・日時・入力hash・証拠一覧は [detail-verification.json](detail-verification.json)。同一版の9本の生traceを個別保存し、前回の配列書出し失敗を引き継がない。

## 比較と限界

縦筋と接合不良は修正され、草/土/砂の区別と、停止時の足裏が改善した。遠景では素材の細かさを弱め、細部がちらつかないようにしている。今の家1軒・木6本という固定条件での仕上げであり、参考作品との美術同等性、児童の無説明理解、再訪、端末GPU、全島規模や本体への組込みをこの検証だけで合格とはしない。

別の足モデル・所有物配置を追加する場合は、そのモデルの実支持点と障害から同じ検査をやり直す。今回はキャラクターや木の造形を別物に変えて結果を良く見せる操作は行っていない。
