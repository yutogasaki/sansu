## 実装前の契約

- 物の数・モデル・ID・水平位置・向き・尺度を固定。高さだけ同じ実床へ接地する。
- 平地/L字/入り江は同じ初期入力からの編集記録を適用。入力を隠して手置きの別世界へ切り替えない。
- 家・木の実根元と人物の現在の足場を失う編集は確定前に拒否。未来の経路を切るだけの編集は許可。木/人物の非表示、勝手な水平移動はしない。
- 歩行は実床と物体の障害から経路を探索。途中編集は現在位置で止め、同じ目的地へ再探索。到達不能ならその場に残り、地形修復後に再び歩ける。
- Undo/Redoも現在の支持を検証し、現在の足場を失う場合は理由を表示して保持する。未実行を復元成功に数えない。
- 実画面で全景と近景、編集→歩行→切断→復元を比較。技術・美術・独立理解の判定を分ける。

## 結果と触れる成果物

[動く試作](index.html) / [同じ画角の3状態比較](comparison.html)。初回candidateは `lived-terrain`、revision `5c5ed935e657af07`、deliveryは `standalone-study-only`。

今回の試作で、**同じ家・木・人物を保持して地形を変え、変わった岸へ実際に歩く**ところまで接続した。家・木が単に追加された飾りではなく、編集確定前の支持判定と人物の障害判定に入っている。

- `terrain.mjs`：前回の丸い区画の接合を17×17の共通座標へ拡張。長い格子辺を滑らかな写像で曲げる。CPUで曲げた後の三角形が描画・接地・支持の正本。水際とクリック位置にも同じ写像と逆写像を使う。
- `world.mjs`：以前の試作から家1軒・木6本のID・モデル・位置・向き・尺度を継承。人物の足裏と体の高さに重なる実モデルの範囲を使って経路を探索。経路は実床を再検査して直線化し、格子ごとの細かな折れ曲がりを減らす。
- `viewer.js`：家・木・人物を非表示にする解決を廃止。編集時にその場で止め、元の目的地への経路を再計算。到達不能なら待つ。地形を戻すと停止位置から再開する。足の動きと向きの変化を付け、既存キャラクターのモデル・顔・配色は変更しない。
- 編集例のボタンは、比較のため初期地形・人物の初期位置へ戻して実編集履歴を再生する。通常の掘る/盛る/Undo/Redoで人物が初期位置へ戻る仕様ではない。木・家のObject3Dは作り直さない。

## 失敗から直した点

1. 初回の画角で木の上が切れた。全景は高さと幅の両方から画角を決めるよう修正。近景は意図的な部分表示として別扱い。
2. 岸の低い壁まで草色になっていた。草縁・土壁・砂浜の断面を分け直した。
3. 最寄りの経路格子点が岸の外側にあると、立てる水際でも到達不能になった。始点/終点の複数接続候補を実床で調べ、要求した正確な行き先へつなぐよう修正。独立した岸の反例を検査へ追加。
4. 丸い板と細い溝の構図が残ったため、岸全体の連続した曲がり方と、湾の入口が広く奥へ細くなる編集履歴へ変更。草石を増やして隠す変更にはしていない。
5. 水辺の選択が毎回手前の岸へ偏った。家・木陰に近い実際の水際から導出し、地形ごとに行き先が変わることを実測。
6. 最後に選択リングだけを編集後の実床へ追従させた。9旅程・切断/拒否/直接編集の詳細検証は `b37ce43457f9cd9f`。最終 `5c5ed935e657af07` の差分はこのリングの位置更新のみで、地形・所有・経路のコードは同じ。最終版で3状態の描画/支持、内側の岸への移動、三段盛土と復元を追加確認した。

CUAの複数移動をまとめた待機が期限に達することがあったが、実際にはその後到着した。到着済みの画面と記録を再確認し、未完をPASSへ丸めていない。9旅程の配列一括書出しも記録側で失敗したため、`journey-summary.json` は完了したツール出力の要約であると明記し、完全な9本の生traceだとは扱わない。残した個別trace・切断/復旧・支持照合は別ファイル。

## 判定の範囲

- **今回の制作方式の検証**：同じ7所有物と人物の保持、編集後の実経路、切断と復旧、任意の直接編集まで確認。前回の「木や人物を消して成立」「固定直線だけ」という穴は解消した。
- **美術**：全景の平地・L字・入り江の違い、近景の家前・木陰・水辺を実画面で比較できる。参考より土壁の単調さ、植生の素材密度、島全体の高低差は残る。参考作品と同等の最終美術、全島の採用は認定していない。
- **独立理解・製品**：子どもの無説明理解/再訪、実端末タッチ/GPU、reduced-motion設定での実操作、所有物を移した別配置、広大な島、成長・本人保存・PWA統合は未確認。既存製品への組込み・公開はしていない。
