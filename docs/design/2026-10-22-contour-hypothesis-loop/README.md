# 地形の推定とテスト：境界をつなぐ仮説の検証

2026-10-22 JST。依頼「推定とテストのループで検証して」への独立した実験。[同じ入力で2案を触る](index.html)。対象版は `source-manifest.json`。候補 `contour-hypothesis-loop`、配布区分 `standalone-study-only`。製品の保存・学習・所有物・通常配布は変更していない。

## 結果

**丸めた各区画の単純な結合だけでは観察を説明できない。近い区画の境界をなめらかにつなぐ仮説は、今回の接続条件を説明できる。**

ただしこれは同じ挙動を作れる候補が見つかったという結果。Little Habitatsの内部コードを特定した結果ではない。隣接マスクで曲線部品を選ぶ方式でも似た結果を作り得る。美術の再現は未達でHOLD。地面の大きな形、細かな起伏、草の境目、土の素材感、水面、光はまだ参考作と違う。

## 実装した仮説

編集の1区画を幅1、角の半径0.28の丸い四角として表す。各区画までの符号付き距離 `d` は、内側が負、外側が正。H1は最小距離、H2は滑らかな最小値を使い、その0境界を形にする。

```text
H1: d = min(d1, d2, …)
H2: d = m - k × log(sum(exp((m - di) / k))), m = min(di), k = 0.25
```

単独の形は変わらず、近い境界だけが膨らんで接合する。対角の中点をつなぐには、おおよそ `k > 0.28 × (sqrt(2)-1) / log(2) ≈ 0.167` が必要。今回は0.25で検査し、0.50では中央の穴が埋まる反例を確認。これは広範な最適化探索ではなく、接続と穴の保存を両方試した値。別の区画寸法や密度へそのまま使える保証はない。

高さごとに同じ境界処理を行う。描画は細かい格子の各四角を中心で4分割し、0境界の交点を共有する。固定の片対角線だけを使わない。上面、草の肩、土の胴、裾、水際を生成し、同じ実三角形からCPU床を求める。

断面・草縁・色・照明はH1/H2で共通。「灰色で形だけ」「仕上げを外す」で輪郭を分離して見られる。[灰色](evidence/diagonal-clay.jpg)・[仕上げなし](evidence/ell-no-finish.jpg)。なお石は今回の候補では材質色の切替までで、参考作の石積みの目地は再現していない。

## 検証の内容と限界

- `node check.mjs`：H1の反証、H2の8条件、90度回転・入力順の不変性、材質と高さの独立、Undo/Redo入力と再生成一致、全8メッシュの有限座標と区画中心の支持、2段の輪郭維持、過剰平滑化による穴の消失、半径0.17の診断用足形の支持。詳細は [results.json](results.json)。
- 足形は2本の対角線上それぞれ41地点×8周縁点を実三角形へ照合したもの。実キャラクターの歩行アニメーション、家や木との衝突、取得権・編集制限・保存統合は未実装。この診断を本体の歩行合格へ読み替えない。
- 実ブラウザ：8入力×2方式×5地点で、描画メッシュへのraycastとCPU床を比較。H2では全地点に床があり、最大差は約2.5e-8。H1では意図せず開く穴の地点は床なしであり、そこを誤差ゼロの合格へ含めない。[ケース](browser-cases.json)。
- 実UIで石の塗替えは高さ2を維持し、次の操作で高さ3。Undo/Redoはセル全体のJSONがそれぞれ元の状態と一致。[編集](browser-edit.json)。L字の1か所を掘って対角にし、Undoで元の入力へ一致。[掘削](browser-cut.json)。
- CSS 390×844で横はみ出しなし、同じ版の描画を確認。[画面](evidence/phone-diagonal.jpg)・[計測](browser-phone.json)。実機タッチ試験ではない。ブラウザのerror/warnログは空。
- `node --check`、bundle build、`npm run docs:check`。対象版・ファイルhash・実行結果は [verification.json](verification.json)。本体変更ではないので全アプリのtest/build/releaseは行わない。

初回の成分数サンプリングでは「境界ぴったり」を除いたため、接触した辺を分離として数えた。メッシュ上では辺を共有するので境界を含めるよう測定を修正した。H1棄却の根拠はこの測定の誤りではなく、四角の穴と対角の非接続。初回の実画面は保持し、現在の再現測定は陰影修正後のソースhashを持つ。初回バンドル全体の保存はしていない。
