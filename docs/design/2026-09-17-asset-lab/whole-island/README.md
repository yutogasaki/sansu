# 島全体の素材置換ベンチマーク

既存の島・家・住人を共通にし、木・岩・ベンチを生成1K版へ置換。ゲーム全体の起動ではなく、共通のproductionビルドを使った独立シーン比較。アプリ本体は変更していない。

Mac上のheadless Chromium、390×844/DPR1.5、10Mbps/遅延50ms、毎回キャッシュ無効の新規context。各3回の中央値。両モードのカメラ座標が完全一致することを記録から検査した。

|項目|既存素材の島|生成素材へ置換|
|---|---:|---:|
|総転送量|0.21 MB|12.82 MB|
|初回表示まで|1.24 秒|10.96 秒|
|JS heap（GC後）|5.12 MB|5.05 MB|
|形状配列|7.65 MB|7.13 MB|
|画像展開サイズの推定|5.77 MB|56.01 MB|
|回転中フレーム間隔・中央値|53.40 ms|66.70 ms|
|回転中フレーム間隔・95%点|67.30 ms|68.50 ms|

生成版は約12.62MBの追加転送と、推定約50.24MBの画像展開増加がある。形状は軽くなっている。次の軽量化対象は三角形よりテクスチャ。キャッシュ後の再訪問は今回対象外。

画像メモリはRGBA8＋mipmapを仮定した概算で、実GPU使用量ではない。JS heapに画像のGPU領域は含まれず、列の足し算をブラウザ総メモリとして扱わない。フレーム間隔は今回のheadless環境で両方とも遅く、実スマホのfpsや滑らかさの合否には使えない。CPU/OS/GPU全体の使用量は未測定。

既存モードにも共通バンドルのGLTFローダーが含まれる。通信はビルドされたJS/CSS/HTMLとGLBの実転送量で、元のTypeScriptファイルサイズとは異なる。初回表示指標は全素材ロード・描画呼出後2RAFまででGPU完了の厳密な時刻ではない。
