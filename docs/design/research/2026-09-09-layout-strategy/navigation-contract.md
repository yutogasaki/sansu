## 1. 判断の軸

画面ごとの「主役」「常設操作」「一時操作」「戻り先」を先に決め、余白や大きさはその役割から決める。ブランドの色や形を共有しても、島・入力・一覧・設定を同じ大きなヘッダーとカード列へそろえない。

下部の3項目は、同じ役割の3タブではない。

| 項目 | 役割 | 操作の結果 |
|---|---|---|
| しま | 行き先 | 島の先頭へ移動。未完了の問題があっても開始しない |
| まなぶ | 開始・再開アクション | 開いている画面に学習を重ねる。現在の問題があればその予約へ戻る |
| きろく | 行き先 | 記録の先頭へ移動 |

行き先の選択状態と、中央の開始アクションの強調は別の意味として設計する。「まなぶ」を現在地として扱わず、終了したら元画面へ戻ることを伝える。設定は通常画面の右上から入る現在の導線を維持する。

## 3. 六つのレイアウト種別

これは画面の見せ方の分類であり、URLや保存ドメインを六つへ統合する案ではない。また、レイアウト種別と「下部タブを隠す集中状態」は別の軸として扱う。同じ種別にも通常閲覧と集中操作がある。

| 種別 | 主役 | 常設するもの | 一時的に開くもの | phoneから広い画面への展開案 |
|---|---|---|---|---|
| A 世界にいる | 島、住民、実際の暮らし | 小さな現在地表示、必要な移動、通常時の下部ナビ | 対象を選んだ時の操作、見学、撮影 | 世界の面積を広げる。操作は片側へまとめられるが、住民や接点に重ねない |
| B 見つける・選ぶ | 見つけたもの、所有物、比較する候補 | 題名、一段戻る操作、選択状態 | 詳細、実物の試用、取得条件 | phoneは一覧から詳細へ、広い画面は一覧と詳細を並べる候補 |
| C 作る・変える | 変更対象の実物と作業結果 | 題名、取消／閉じる、確定操作、保存状態 | 素材や道具の選択、詳細な調整 | phoneは実景と操作シート、広い画面は実景と操作欄を左右へ。確定は常に到達可能に |
| D 学ぶ | 問題と解答 | とじる、短い進行、全入力、支援、意味のあるフィードバック | 長い問題・筆算履歴・お手本 | phoneは上下、横向きtabletは問題と入力を左右へ。キーを小さくして収めない |
| E 思い出を見る | 保存済みの写真、成長、発見、賞状 | 題名、一覧への戻り、記録の文脈 | 一枚表示、過去／現在の比較、撮影、明示削除 | phoneは一覧→一件、広い画面は一覧と一件の併置を検討する |
| F 管理する | 設定項目、学習の分析、本人・保護者の判断 | 題名、一段戻る操作、明確な保存・反映状態 | 編集フォーム、保護者確認、テスト設定 | 内容の読める幅を制限し、広い画面はカテゴリと詳細を分ける候補 |

例外状態として、初回設定・読込・復旧・保存失敗・確認ダイアログも各種別の同じ戻り先へ所属させる。これらのために学習や島へ自動遷移する新しい入口を作らない。初回設定からの明示的な学習開始は維持する。

## 5. 遷移・終了・保存の契約

以下の「維持」は仕様43または現在の実装を継承する項目。「提案」は六種別に適用する追加の配置原則であり、採用前のもの。

| 操作・状態 | 契約 | 区分 |
|---|---|---|
| トップを開く | Island有効なら島、Island無効・BuildPlay有効ならpark、それ以外はbattle。旧探索runや未完了問題で行き先を変えない | 維持 |
| しま／きろくへ移動 | 目的地の先頭へ。通常タブ切替では縦・横スクロールをリセットする | 維持 |
| まなぶを押す | 現在画面に集中学習を重ねる。元の詳細、選択、縦・横スクロールを保持し、通常面を操作不能にする | 維持 |
| 学習をとじる | 開始前の画面へ戻す。同じ起動中・同じプロフィールの現在問題と入力下書きを保持する。閉じるだけで回答を記録しない | 維持 |
| 詳細で「もどる」 | 一段上へ。ブラウザの戻る・進むも同じ遷移へ対応する | 維持 |
| 集中画面で「とじる」 | 開く前の文脈へ。単に全画面を島へ送る共通処理にしない | 維持 |
| 配置を取消 | 選択元へ戻す。未保存の位置・向きを確定しない | 維持 |
| 配置の保存成功 | 島へ戻す。完了した一時エディタを「進む」で復活させない | 維持 |
| 写真一覧→一枚表示 | 一枚表示中はタブを隠し、閉じると一覧へ。撮影済み画素と撮影時の名前を保つ | 維持 |
| 履歴のない直接URL | 学習はlearn指定を外した通常画面、写真は写真一覧、配置は持ち物、設定詳細は設定一覧等の定義済みfallbackへ | 維持 |
| 保存中 | 画面内の移動を無効にし、保存完了前の内容を履歴移動で破棄しない。PWA更新holdを維持する | 維持 |
| 保存失敗 | 現在の問題・編集文脈と再試行可能なエラーを残す。成功したような表示や移動を先行させない | 維持 |
| 学習後の設定・記録 | 保持された画面に最新データを再読込する。古いプロフィールsnapshotの全体上書きを避ける | 維持 |
| プロフィール変更 | 他人の問題・下書き・選択を引き継がない。変更後のトップも学習を自動開始しない | 維持 |
| 背景化・隠れた世界 | 観察・音・操作を実行しない。通常面を見えなくするだけで済ませない | 維持 |
| 一時的な選択・確認 | 題名、対象、戻る／取消／確定を共通位置に置く。重要操作をスワイプやアイコンだけへ隠さない | 提案 |
| 活動を閉じた後のfocus | 開始元の操作へ復帰。元要素が存在しない場合は、意味の通る現在地・開始操作へ戻す | 維持・適用範囲の拡張は提案 |

現在の戻り先と保存成功時の置換は[useIslandNavigation.ts](../../../../src/components/island/useIslandNavigation.ts)の50–81行、直接URLのfallbackは[navigation.ts](../../../../src/domain/island/navigation.ts)の29–40行。元画面と学習の表示関係は[Layout.tsx](../../../../src/components/Layout.tsx)の34–56行。

## 6. リサイズとスクロールの契約案

| 状況 | 維持する状態 | 配置の提案 |
|---|---|---|
| phoneの高さ不足、ブラウザUI表示、安全余白あり | 現在地・予約・入力・選択・編集中の値 | 操作を小さくして収めず、通常面は必要な箇所へスクロール可能に。44px以上の操作領域を維持 |
| A 世界が広くなる | 選択地区、手動カメラ、住民・家具のidentity | 世界に空いた領域を渡す。外枠面積だけでなく対象の実際の見え方を確認し、勝手にカメラを初期化しない |
| B/E 一覧を広い画面へ展開 | 選択項目、絞り込み、表示中の記録 | 二列化や一覧＋詳細へ変えても、新しい履歴を積んだり選択を解除したりしない |
| C 作業面を左右配置へ変える | 未保存プレビュー、取消可能性、保存結果 | 同じ作業内容を再配置する。幅の変更を保存・取消の契機にしない |
| D 学習を縦から横へ変える | 同じ予約・slot・入力・支援段階 | 問題と入力を左右へ再配置。数字キーと支援を画面内に確保し、長い問題やお手本だけを内部スクロール |
| F 設定を二領域へ展開 | 開いているカテゴリ、編集中のフォーム | カテゴリと詳細を併置する場合も同じURL・戻り先を維持し、同一フォームを二重マウントしない |
| リサイズで旧スクロール位置が成立しない | 選択対象・入力中の要素 | 対象を見失わない位置に収める。リサイズ自体をタブ移動と扱わず、先頭リセットしない |

ここで提案する状態保持は**同じ画面のリサイズ時**の原則。通常タブの移動で先頭へ戻す既存契約とは区別する。単純に全要素を拡大するレスポンシブではなく、主役の面積と操作位置を六種別ごとに決める。

学習の既存配置は[IslandLearningFocus.css](../../../../src/components/island/IslandLearningFocus.css)と[IslandLearningPanel.css](../../../../src/components/island/IslandLearningPanel.css)の84行以降。現在の通常面は[ScreenScaffold.tsx](../../../../src/components/ScreenScaffold.tsx)で見出しと内部スクロールを分けている。これらを壊さず段階的に検討する。

## 7. コード調査で確認した小さな不整合

記録の「もっと見る」は、新規のlocalStorageで押しても追加領域が出ない。`DEFAULT_SECTIONS`はsummary／calendarだけtrueで、追加領域のweak／review／tests／parentはfalse。「もっと見る」は`showMore`だけをtrueにするため、ボタンが消える一方、各領域の条件はfalseのままとなる。`sections`のsetterや変更UIもない。テスト履歴には空状態表示があるので、0回答専用の非表示処理ではない。

根拠は[Stats.tsx](../../../../src/pages/Stats.tsx)の82–90行、227–233行、538–551行、687–694行。現在のファイルと調査対象preview 5294の固定元ファイルが一致することも確認した。**この資料の作業では修正していない。** 全体の記録画面再編と、小さな表示不整合の修正は別の変更として扱える。

## 8. 採用前の確認

六種別それぞれにphone・tablet・短い画面の代表画面を作り、「最初に見るもの」「次に押すもの」「閉じた後の場所」を実画面で比較する。学習は全入力と支援、世界は対象の見える大きさ、編集は取消と確定、記録は実際の内容、管理は項目の意味で判断する。

レイアウトの魅力、文字を読まなくても分かること・安全、入力・保存・PWAを含む実装の整合は別々に判定する。コード上の構造が整っていることを、実画面や子どもの体験が優れている証拠にはしない。
