# 学習アプリの公開レイアウト比較

調査日: 2026-09-09。対象: Duolingo / Khan Academy Kids / ANTON / Brilliant / Lingokids。

これは公式ヘルプ・公式制作記事・開発元がストアに掲載した画像の調査である。ログイン後の実機操作、子どもの観察、終了時の保存検証は行っていない。公開画像は実際に開いて目視したが、現行配布版との完全一致や全端末への提供を保証するものではない。宣伝用の外枠・文字・拡大を含むため、他社のタブ高や画面占有率は数値化しない。以下の「Sansuへの示唆」は調査者の提案であり、採用済み仕様を上書きしない。

## Sansuのレイアウト戦略に変換すると

1. **ホームは「いる場所」、学習は「していること」として扱う。** 島に戻っただけで問題は始めない。島は住民・育った場所・触れる対象が主役で、明示的な「まなぶ」が集中面へ入る入口になる。Khan Academy Kidsの分離が最も直接的な参考になる。
2. **画面を3種類に分ける。** 島は広い世界とその場の操作、学習は問題と入力、記録・持ち物・設定は読める一覧。Duolingoの刷新から得られるのは、各面の用途を保ちながら見出し位置・文字・余白の規則を揃えること。すべてに同じ大きなカード、背景模様、ヘッダーを配ることではない。
3. **常時表示は少数の目的地に絞り、世界の操作は対象へ寄せる。** 全操作をさらに小さい横スクロール列へ押し込むだけでは、見つけやすさとの交換になる。家の入口は家、住民の遊びは住民、着替え・整理は明示的な短いメニューという比較案を作る。直接タップだけに依存せず、同じ操作へ行ける文字付き一覧も残す。
4. **学習中のタブ非表示と退出の自由をセットにする。** 集中させるための面積確保と、子どもを閉じ込める操作は別。閉じる位置と意味を一定にし、元の画面・入力・スクロールへ戻す。これは他社の保存挙動の観察結果ではなく、Sansuで保持すべき要件である。
5. **タブの小型化は絵を大きくするための一手に留める。** ラベルと押しやすさを残し、島カメラの実物サイズも合わせて評価する。キャンバスが広がって海だけ増えた状態は成功にしない。タブ高の「業界最適値」は今回の宣伝画像からは導けない。
6. **タブレットは拡大したスマホにしない。** 公開横長画像は空間的なホームや活動の存在を示すが、レスポンシブの正解を証明しない。Sansuでは島＋必要時だけの側面パネル、問題＋入力の左右配置、記録の一覧＋詳細をそれぞれ実機相当幅で比較する。首や視線の往復、片手の到達、筆算入力の全体表示は別途検証する。

## 残る調査の境界

5製品の資料だけで「最良」を認定しない。特に、途中で閉じた際の回答下書き、ホームのスクロール、オフライン再開、横向きでの入力、タブ切替のアクセシビリティは未検証。Sansuの候補は同じ端末幅・同じ成長状態で並べ、世界の魅力、説明なしの理解、入力と保存の整合を別々に評価する。広告・課金・ランキングによる継続率を、子どもが自分でまた遊びたいと思う証拠として転用しない。
