`ray_query64.py` computes all ray/triangle intersections from the same original point. Binary64 interval arithmetic uses `math.nextafter` to round every interval operation outward. Ray/AABB rejection and Möller–Trumbore determinant, barycentric and distance predicates carry those bounds. A crossing counts only when its barycentric coordinates are strictly inside a triangle and its distance interval is strictly positive, within 100 and disjoint from every other crossing. This intentionally favors unresolved results over false inside results.
