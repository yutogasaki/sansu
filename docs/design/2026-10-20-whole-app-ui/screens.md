# 全画面の仕様

この文書の寸法・構成は実装前の提案。共通の見た目は [画面枠](visual-and-layout.md)、gesture・戻る・非同期の意味は [操作の契約](interaction-and-states.md) に従う。各節は現在の入口・データを使い、未実装の世界や報酬を実装済みと扱わない。

## 1 島ホームと現在地

**主役**は実在する住人と家、配置から育った場所。上に島名としずく、右にながめ、左上に小さな「そだつ場所」、下に「おく／もちもの／メニュー」、最下端に現行5タブを置く。世界は常に背面全域へ広がる。

初期構図は家の周囲を魅力的な近さで見せる。拡大・縮小・回転・移動・住人運搬を保ち、初回全景アニメーションを追加しない。画像内の「まなぶ」の囲みは現在地と混同されない通常表現にし、選択中タブだけに青い印と選択下地を使う。

| 状態 | 表示・操作 |
| --- | --- |
| 目標未選択 | 小さな場所の絵＋「そだつ場所」。選択を迫る大きな案内にしない |
| 目標選択済み | 本当の場所名＋現在配置に合うヒント一つ。押すと既存の本へ |
| 来訪・つぼみ | 実対象の近くの手掛かりと、未処理操作の小入口。カメラ外にも入口を残す |
| 島が大きい | 初期構図は家のある地区、全景では取得済みの全島を見られる |
| 長い名前・大残高 | 名前は省略可、残高は桁を隠さず必要なら情報帯を折り返す。hitを縮めない |
| 情報面・編集中 | 通常の島づくり入口を背後から誤操作できなくする |

下部タブの意味は「しま＝島をつくる」「いえ＝自分の部屋」「まなぶ＝既存の学習開始・復帰」「きろく＝学習の記録」「設定＝本人・学習・表示」。押すだけで新しい学習設定や報酬受取を挟まない。

## 2 ながめ

望遠鏡の既存入口を維持。中は上から題名・閉じる、`− ちいさく／＋ おおきく`、`しま全体`、左右の回転を並べる。拡縮は1回ごとに現在値の1.15倍／1÷1.15倍を候補とし、連続pinchと同じ可動範囲に制限する。回転刻みは既存の30度を維持する。

「しま全体」は方位を勝手に戻さず、その方位で全所有地と描画形状を収め、panを適切な中心へ戻す。小さすぎる住人を近く見たいときは任意に拡大できる。上限・下限ではそのボタンだけ不可、理由は「これが いちばん おおきいよ」等を短く示す。閉じても視点を保持する。

## 3 しまをひろげる

**主役**は広がる方向と岸の変化。カメラ操作とは別入口を維持し、開くだけで購入しない。上から島Lv条件、現在残高と正規費用、既存の取得可能方向の絵付きbuttonを置く。

方向の絵は今の方位と対応し、文字も併記する。費用は方向buttonの近くへ置き、押したときに取得が確定する現行手順を変えない。新しい確認画面を加えない。検討中の岸を示す場合は未取得の点線previewと明記し、歩ける確定土地として描かない。

| 状態 | 表示・操作 |
| --- | --- |
| 解放前 | 入口は残し、現在／必要Lvと既存の案内を表示。方向の購入buttonは出さない |
| 費用不足 | 残高・正規価格・不足を読める。学習へ強制誘導せず、閉じられる |
| 取得可能 | 実際の可用方向だけ表示。方位と費用が同じ面で分かる |
| 処理中 | 二重購入を止め、完了するまで既存の保存保護を維持 |
| 失敗 | 所有地を増やした表示にせず同じ方向から再試行 |

## 4 補助メニューとそのほか

現在の構造を磨く。見出しと閉じる、実住人の横長入口、6つの絵付き入口、そのほかの順。6つは「海図と ふね」「はたを つくる」「しゃしん」「はなずかん」「はし」「あそびかた」。現在の進行でまだ提供しない入口は現行条件を保つ。空欄を架空の機能で埋めない。

なかまは実際の最大3人の姿を一枚の小さな舞台に接地させ、実人数と最大2人の名前を添える。人数が増えても架空の群衆は足さない。0人では人物を描かず足跡の絵と0人の状態。橋は実状態で「はしを つくる／はしを みる」を変え、未可用理由を本文で読めるようにする。

「そのほか」は本人名、本人切替、音、現行のお知らせがある場合その入口。展開しても同じシート内をscrollし、上端の閉じるは動かさない。設定・記録・買物の大きな重複カードをここへ戻さない。本人切替は島を訪問する操作と分ける。

メニュー外の最初のpointer操作は閉じるだけ。背後の住人を同時に運んだり、土地を購入したりしない。6入口の一つを選ぶとメニューを置換して対象面へ。戻る／閉じるの違いは [共通契約](interaction-and-states.md) に従う。

## 5 あたらしくおく

**主役**は購入できる品物の実物。見出し＋閉じる、`あたらしく おく／もちもの`、実際に存在する分類、2列の品物の順。画像96px以上、名前、短い用途、価格または無料の順序をそろえる。通常のタイルを1回押すと現行の仮置きへ入る。

成長v0.4の販売可否は現行の `canPurchase` 等を参照し、UI側に古い販売リストを持たない。表示件数が少ないときは「すべて」や中身のない分類列を出さない。レガシーsnapshotで販売・解放条件が異なる場合も、本人の状態に対して正しい一覧を出す。

価格は実残高と対応させるが、不足を理由に絵や名前を読めないほど薄くしない。家と畑の違いは実モデルと短い用途で示す。成長時間や機能は現在の規則に合う文を使い、すべての品を「まなぶと そだつ」と一律表示しない。

## 6 任意の品物説明

通常の流れに詳細の必須画面を増やさない。**説明が必要な品だけ**タイルの主buttonと分かれた48px以上の「くわしく」を表示する。buttonの入れ子や主面に重なる透明hitを使わない。アイコンだけにせず可視ラベルも付ける。

押すと同じカタログシートを詳細状態へ切り替える。上から「もどる／閉じる」、実物画像160px以上、品名、できること、成長の仕方、正規価格・状態、`おく`。戻ると元のタブ・分類・scrollへ復帰。詳細からおくでも同じ仮置きへ。

画像は本人の実状態と対応する既存モデル／静止画像。新しい回転viewerや別の品物イラストを必須にしない。説明が名前と用途だけで足りる品には詳細入口自体を出さない。

## 7 もちものと記念品

収納済みの本人の物を主役にする。旧品、成長済みの家、学びの記念品、受け取った花を実際の個体で見せる。新規商品と混ぜず、価格の代わりに再配置が無料であることを示す。

同じ見た目でも所有ID・成熟・名前・由来が異なる物を勝手にstackしない。全所有数を収納個数に読み替えず、この面は現在の収納品一覧とする。配置済みの物は島の実物から選ぶ。記念品には実際の科目・Lv・由来を付け、新規商品として売らない。

空状態は「しまってある ものは まだ ないよ」＋閉じる。何かを買う・学ぶ・しまうことを必須にしない。タイル選択は1回で無料の仮置きへ。元の一覧のscrollは取消時に復元する。

## 8 仮置きと移動

島を全画面に戻し、選んだ品のghostと接地影を表示する。通常入口は編集中の道具へ置換する。下部に品名、現在の理由、正規価格または無料、`ここに おく／やめる`。必要な品だけ任意説明を参照できる。

| 状態 | 表示・操作 |
| --- | --- |
| まだ位置を選んでいない | 「おく ばしょを さわってね」。確定不可、取消可 |
| 有効 | 足元の輪郭＋チェック＋「ここで いい？」。確定可能 |
| 占有・島外 | 場所の輪郭と理由。色だけで判断させない |
| 到達不能 | 実判定に合う「ここまで いけないみたい。まわりを あけてみよう」 |
| 費用不足 | 現行と同じ選び直し、または取消。学習開始buttonへ置換しない |
| 保存中 | 「しまを たしかめているよ」。二重確定と本人切替を保護 |
| 保存失敗 | 同じ個体・仮位置・価格を保ち「もういちど／やめる」。未確定を購入済みとしない |
| 保存成功 | 確定物を接地させ、島へ。残高と所有の実結果を一度だけ示す |

配置を始めても新規品を取得せず、確定時に現行commandで取得する。移動中の旧個体は保存成功まで元の権利・成長を保持する。取消は購入元カタログまたは実物の選択面へ戻す。二本指で拡縮してもghostを破棄しない。

## 9 実物の選択と収納

物に触れると現物を軽く示し、品名・実際の状態・主な操作を小面で読む。大きな商品カードを改めて重ねない。

| 対象 | 表示と現行操作 |
| --- | --- |
| ぽこもこの家 | 家の絵／「いえに はいる」 |
| 入居中の家 | 名前と実入居者、移動。収納は提供しない |
| 空き家・完成品 | 成長状態、移動／収納 |
| 未完成の種 | 成長の短文、移動／既存の取消と返却。完成品の収納と区別 |
| 花・木・水等 | 実種と育ち、現行の触る／移動／収納／摘む等を対象条件に従い表示 |
| 演奏の場 | 現行の「おとで おはなし／えんそうかい」。汎用の成功演出に置き換えない |
| 記念品 | 科目・実Lv・取得由来、移動／収納 |
| 旗 | 既存の色と模様、なぞる入口。色名・模様名を併記 |
| 橋 | 現在の橋と使い方、既存の収納確認 |

色替え・名前・衣装などの即時反映はそのまま。新しい一括保存を足さない。破棄や返金の確認有無は既存command・確認契約に従い、かわいさを理由に手順を減らさない。

## 10 そだつ場所

名称と既存の6目標を維持する。任意の目標帳として `いまの しま／そだった おもいで`。大きな場所のイメージ、実際の段階、今試せるヒント、目標の選択／解除、実在する場所への移動の順。

段階は現行の `おく→つながる→そだつ→あそぶ`。絵は到達の期待を示し、「場所のイメージ」と明記。現在の島の写真として扱わない。配置例と場所どうしの関係は折畳みで読み、普段の主操作を押し下げない。

実anchorがある場合だけ「この場所へ」。対象が収納された記憶は「もちものへ」、対象が失われても記憶そのものは残す。現在成立していない場所を完成済みとして演出しない。選ばなくても育ち、変更・解除で失うものがないことを短く示す。

## 11 なかま一覧と住人の選択

一覧は実人数、実住人の姿・名前・性格・好きなものを見せる。2列の肖像は88〜112px高目安。長い名前は2行。多人数でも一人ずつの絵を縮めずscrollする。メニュー用画像と一覧画像は同じ本人の服・姿を反映する。

通常の住人を押すと現行と同じく島の本人へ寄り、対象小面を表示する。小面は本人の姿120px目安、名前、性格、実際の家、好きなもの、現在の状態。住み心地の内部点数を人物評価として出さない。訪問者と居住者を混同しない。

おでかけ中は空の場所へ偽focusせず、「おでかけ中」と既存の戻ってきてもらう操作を示す。運ぶ遊びは世界上で継続する。dragが難しい人の任意の「はこぶ→実対象を選ぶ」は [入力の契約](interaction-and-states.md) の同じ安全規則へ接続する。0人のときは0人の状態と閉じる・海図等の既存入口に留め、悲しい顔や学習要求を足さない。

## 12 船の到着とつぼみ

到着した船や未開封のつぼみの実物を、短い輪郭・吹き出しで見つけやすくする。自動cameraで編集を奪わない。対象が小さくても、同じ操作へつながる文字付き入口を残す。

現在の `open-all` は `unopened` と `arrivals` を両方処理する。この意味を守り、状態により文言を変える。

| 実状態 | 操作ラベルの案 |
| --- | --- |
| つぼみのみ | 「つぼみを ぜんぶ ひらく」 |
| 到着のみ | 「なかまを むかえる」 |
| 両方 | 「まとめて ひらく・むかえる」 |

必要ならbuttonの直前に「つぼみ Nこ・ふねの なかま Mにん」を2行で示す。幅が足りなければ操作面を伸ばす。一括操作と実物を触る操作を同時に二重実行しない。処理成功時だけ未処理状態を消す。初回のまなぶ入口との重複を避ける現行専用段を維持する。

## 13 海図とふね

**主役**は本人の複数の島。現在のmodalの意味を維持する。実輪郭の小さな島、名前、実住人数、「いまここ」を並べる。海図の距離・大きさが目安であることは維持。存在しない成熟建物を地図に足さない。

既存島は現行どおり選んで出発し、確認を追加しない。現在島は現在地として示す。新しい島は現在のはじまり3種、名前任意、無料で作っていくform。選んだはじまりの差は既存規則に合わせる。

読込中・失敗・出発中を分け、失敗は同じrequestから再試行する。出発中の連打・本人切替・二重作成を防ぐ。閉じると元の島へ戻る。実際に島を切り替えた後は新しい島に属するcameraを使い、元の島を消去しない。

## 14 橋

未建設かつ建設可なら既存の確認文と `やめる／つくる`。不可なら「なかまが きてから」等の実理由。建設済みなら現地へ寄る。収納は既存の確認を経る。

世界の橋の形を使った絵で、向こう側と通れることを見せる。建設の演技は実際のbridge成立と同期し、演技だけ先に成功扱いしない。取消はmenuまたは選択元へ、処理失敗は既存橋状態を保つ。

## 15 家と家のメニュー

**主役**はぽこもこと本人の部屋。床、壁紙、飾った物が見える全画面を残し、常設操作はアルバム・写真・メニューの小さい直通にする。床タップとUI操作を取り違えない。

家menuは現在のmodalを保つ。大きな入口は「かざりと きおく」、その下に「まなびの きねん／おしらせ」、暮らしの「なかまの てがみ／もようがえ」、既存のチャレンジと学習入口。あそびかたへの経路も維持する。全て同じ大きさの巨大カードにしない。

家の外観・室内・学習のぽこもこは同じidentityを使う。入室のために着替えや学習の設定を要求しない。初回のプロフィール未作成時は現行契約どおり、家の入口から島の遊び方へつなぐ。

## 16 着替えと模様替え

着替えは本人の現在の姿を大きく残し、色・帽子・衣装の既存選択を使う。取得／未解放／装備中を文字とチェックで区別し、無料変更を有料風にしない。元の顔や布を別キャラクターへ変更しない。

模様替えは現在の壁模様、学んだ語群の色と実個数、ラグを順番に見せる。各色は色面＋名前＋選択印。部屋で変化を見られる面積を残す。未解放理由を読むことができ、選択可能な物は現行と同じ即時反映。新しい「保存」や購入確認を挟まない。

失敗は前の確定状態と試した選択を区別して示す。未取得の語を壁へ増やさず、模様の選択で学習済みと認定しない。

## 17 英語壁紙と手紙

壁紙の英語は本人の既存学習データから表示し、触れた語・意味・読み上げを現在の契約どおり示す。文字の上に装飾の水玉を重ねない。読み上げ中でも閉じられ、退出・本人切替で音声を止める。音声が使えなくても文字が残る。

手紙は封筒の小さな絵と実差出人を使い、未読数は実件数だけ表示する。本文を読める幅で並べ、押したときの既読処理と音声を維持。架空の住人の手紙や、学習しないことを責める手紙を足さない。空なら「しまに なかまが すむと、てがみが とどくよ」。

## 18 賞状とお知らせ

賞状・トロフィーは大きな実物の絵、名称、取得の事実、`かざる／しまう`。実取得と展示を別に扱う。未取得を展示済みの景色へ足さない。「もっているものを ぜんぶ かざる」等の既存一括操作も個別操作と同じ実状態へ反映する。

お知らせは実際の贈り物数と既存の受取画面へつなぐ。島のつぼみ・船の一括処理と家の報酬を勝手に統合しない。保存失敗中は再試行を操作の近くへ。報酬の中身を見る・展示するだけで追加取得しない。

## 19 写真とアルバム

写真一覧は実画像を主役にし、名前・日時・由来等の現在の情報を控えめに添える。1枚表示は大きな画像、戻る、現在ある保存・削除等の操作。削除の既存確認を保つ。表示・選択でデータを書き替えない。

撮影は被写体と撮影buttonが同時に見え、cameraの近くに余計なmenuを出さない。短い横画面では一覧を横のscrollへ、撮影と退出は固定領域へ。アルバムの完成比較や記念写真は本人の画像と実履歴だけを使い、島のあゆみと学習記録を自動合算しない。

画像がない場合は空の写真枠一つと「しゃしんを とる」等の現在ある入口。読込失敗では画像枠と再読込を残し、本人写真を別の挿絵にすり替えない。

## 20 しゃしんとみせる

現在の4入口を維持する。

| 入口 | 主役・操作・退出 |
| --- | --- |
| みせるモード | 島を最大にし、既存の展示camera。退出48px以上固定。戻れば元の自分の視点 |
| しまカード | 実画像を大きく、既存の枠選択、画像保存、閉じる。生成中は保存不可・取消可 |
| しまのあゆみ | 実snapshotを時系列に。日付／何日目、停止・再生・もういちど・閉じる。動画演出で捏造しない |
| きょうだいのしまへ | 端末内の実プロフィールの名前。訪問と本人切替を分け、訪問先を常に明示 |

あゆみの停止／手動送りは表示制御として設け、reduced motionでは自動送りをしない。履歴がない場合は現在の空案内。カード保存失敗では同じ画像を保持して再試行。OSの画像保存・共有は実際の操作でのみ起動する。

訪問中は「だれのしま」と `かえる` を固定し、自分の島の編集道具は出さない。花を置く既存機能は `未送信／送信中／済／失敗` を分け、1回の権利と実受信先を維持。相手がいない場合は空状態と戻るだけにする。

## 21 旗づくり

候補の文字を選ぶ、240px基準のなぞる面、本人の現在の線、`はたに かざる／けす／とじる`。短い画面ではcanvasを縮めるより操作とcanvasを左右へ分ける。作りかけは「できあがりの めやす」と区別し、実旗は明示確定後だけ変える。

なぞる判定・選択候補・既存の確定条件は維持し、能力採点や学習実績へ転用しない。候補を変えたときの線の扱いも現在の規則を維持。製作の手触りは旗の布の縁と線が増える反応で出し、完成待ちを追加しない。

## 22 花図鑑

現在の発見色を実際の花の絵へ。知らない花は中立の未発見表現で、色や名前を先に明かさない。既知の親の組合せだけ現在のレシピヒントを示す。花の色名も文字で読めるようにする。

全種を等しく光らせず、発見済みの花に形・花弁・色の楽しさを持たせる。未発見の灰色一覧が主役にならないよう発見済みを最初に見せるが、元の図鑑の種別対応は保持。新しい全取得報酬や日次課題を足さない。

## 23 遊び方と初回

遊び方は既存の本、スターター、実際の達成と思い出を使う。1ページに一つの動作と結果の絵を置き、対象があれば既存の現地へつなぐ。読了・達成checkを遊び始める条件にしない。

新規初回は採用済みの顔、正式名、「しまへ いく」。挨拶の反応を保つ。その後同じ本人の島で遊び、`まなぶ` を選んだ時だけ現行の設定へ。学年・名前任意・科目・到達目安を一問一面で読み、各面から島へ戻れる。設定の草稿を学習済みと認定せず、再読込後も既存の段階へ復帰する。

初回だけの学習入口と一括処理の専用段を維持。入居・チュートリアル完了を学習開始の条件にしない。既存本人がいる場合の追加プロフィールは、任意名の新規初回と混同しない。

## 24 学習入口と問題

通常の `まなぶ` は現行の開始または予約復帰へ直結する。新しい選択カード、科目選択、確認を毎回挟まない。学習中は島を隠し、現在の採用済みの学習デザインとぽこもこの演技を使う。

| 入力・教材 | 具体的に守ること |
| --- | --- |
| 数値入力 | 大きな式と答え欄、789/456/123/⌫0C、現行の自動確定 |
| 小数・分数・複数欄 | 必要な補助行・欄移動・確定を隠さない。記号を装飾にしない |
| 筆算 | 位・繰上がり・欄の関係が読め、現在の入力順を変えない |
| 選択・比較 | 問題と選択する実記号・図を大きく。選択肢の並び・意味を保持 |
| 数直線・図形・文章 | 図と問題の関係を保持。長文だけ内部scroll、全キーを常時表示 |
| 英語 | 問題の音声・再生・例文・短文リスニングの現行契約。UI音より音声を優先 |

問題、入力、支援、退出を同時に確認できる。相棒・装飾・成功の数字が教材やキーを隠さない。短い横画面は問題・支援を左、答え・全キーを右へ。学習の内容・採点・復習予定は島の都合で変えない。

## 25 ヒントと誤答

ヒントは問題のすぐ近くで一つずつ読み、現在の問題に対応する図と説明を使う。お手本と本人の解答を区別し、支援の使用を独力と扱わない。

誤答は入力近くで短く次の手を伝える。赤一色の全面、落胆した相棒、能力評価を使わない。再入力できる時点を演出で遅らせず、入力位置を動かさない。ヒントが長い場合も閉じる・キー・退出へ届く。

## 26 正答と区切り完了と帰島

正答は既存の即時反応を保ち、次の問題へ自動進行。新しい「つぎへ」、受取、スタンプ確認を毎問追加しない。連続正解等の演技は既存の短い山場で、平常時の操作を覆わない。

区切り完了は実際の結果、しずく、まちの時間を表示。本人の報酬処理を再実行するbuttonを作らない。帰島は本人が選んだ既存導線を使い、戻った島の視点を保持。実成長があった場合だけその場所の反応を示す。成長が無い時に架空の家を育てない。

中断は現在の予約・問題・下書きに従う。閉じると開始元へ戻り、再開は同じ予約を開く。保存が終わっていないときは既存保護と再試行を維持する。

## 27 チャレンジと確認テスト

家の学習チャレンジは独立した記録・賞のまま。開始条件、時間、終了、中断、既存の結果と再挑戦を維持する。通常学習の報酬や独力判定へUIだけで合算しない。

レベルアップ・確認テストは現在の導線と結果を保ち、問題と入力を同じ可読性へそろえる。保護者テストの制限時間、紙の採点待ち、点数入力、取消を別状態で読めるようにする。終了を本人の能力や人格の評価にしない。

## 28 記録とカレンダー

全画面の明るい読書面。上から本人名・今日のまとめ・カレンダー、その先の詳細。0回答ではゼロの繰返しを減らし、ここに何が残るかを伝える。

成長グラフ、練習するところ、復習、スキルマップ、レベルアップ・確認の記録、保護者向け情報への現行経路を保持。詳細の閉じるは元の一覧位置へ戻す。カレンダーの未実施日は失敗の赤印にしない。日数・回答・正答・支援等の数値を見た目の都合で変えない。

グラフは色に加えて文字・線種等でも読み、タブレットは文章と図の余白を広げすぎず意味ある二列へ。島の写真の履歴と学習カレンダーを同じデータとして扱わない。

## 29 設定と保護者

現在の4分類 `プロフィール／学習／みためとおと／保護者` を維持。スマホは分類→詳細、広い画面は分類と詳細の併置。現在値と変更先が同じ行で分かり、操作後の保存状態を示す。フォームを二重mountして同時更新しない。

プロフィールの切替・追加・改名・削除、科目・学習範囲、表示テキスト・日本語モード・音等の既存機能を残す。初回の仮本人と通常の本人を勝手に統合しない。音を切っても英語読み上げの意味や設定の契約は現在の正本に従う。

保護者面は現在のgate、学習履歴、範囲、確認テスト、印刷・PDF、紙の採点待ち、記念品の復旧、データ管理へ。全リセットや削除の確認を装飾buttonに混ぜない。開発者モードは保護者側の現在の入口のまま。

## 30 既存の補助体験と互換経路

かざりと記憶、家具、共同の思い出、身支度、撮影、ワークショップ等は、現在の本人が持つ権利・scene・入口に従う。共通の読めるシートと選択状態を使い、主役の実景を広く残す。玩具の用途や出来事の固有の演技を一律のカードへ置き換えない。

`home/help/learning/reward/inventory/placement/play/growth/album/customization/guide/experience/expression/showcase/workshop/camera/photos/shared/furniture/keepsakes/challenge` の既存画面識別子とURLの意味を変更しない。各個別体験の確定・取消・試用・保存・退出はその正本に従う。開発診断専用の場所を本番の取得物として表示しない。

旧Exploreや二人遊び等は現行で残る互換経路を守る。本案を理由に島menuへ再追加せず、固有ゲームの世界美術を島の素材へ全面置換しない。終了した遊園地・Nature Townの独立画面を復活させない。

## 31 全面に適用する状態

読込中、空、取得不可、残高不足、保存中、保存失敗、オフライン、更新待ちは [操作と状態の契約](interaction-and-states.md) の表を適用する。かわいい挿絵を置いて操作を消すことはしない。必要な状態の検証は [受入条件](review-and-acceptance.md) へ対応させる。
