## 今回の根拠

現行のGrowingIsland/GrowingSheet/GrowingPanels、場所利用と記憶、[親仕様01](../../product/01_app_spec.md)、[場所体験の設計と実装記録](../../product/island-system/experience-design/README.md)、[別作業の画像レビュー記録](../../product/island-system/experience-design/screen-review-20261020.json)を確認した。相談先へ送ったのは差分とレビュー記録の要約で、新規画像は送っていない。全文・全画面の独立監査ではない。対象入力のhashは追補の検証JSONに記録する。

共有屋根・回廊・大木の入口や実床の読み取りは、画角の改善と美術・runtimeの問題を分ける。画像レビューの美術HOLD、回廊runtime未解決、児童理解未実測は継続し、この相談で解除しない。

## 画角と復帰の確定候補

ユーザーの「魅力的なデフォルト拡大率＋自由な拡大縮小」を維持する。内部zoom1.5、範囲1〜4、人物/家の投影寸法は前案の比較開始値であり、全端末の最適値を実測した数値ではない。初期島は1.5を比較候補、広い島は暮らし中心の対象範囲と安全表示領域で調整する。

| 状態 | 見せる対象 | 移動・復帰 |
| --- | --- | --- |
| 新しく島を表示 | ぽこもこ、家、使える場所 | 初期構図を一度計算。その後の手動操作を尊重 |
| 同じ島の通常・パネル開閉 | 今見ている暮らし | 本人×島のセッション視点を保持。閉じただけで初期化しない |
| 全景を明示選択 | 現在の島と地区のつながり | 実boundsでfitし海の余白を抑える。直前視点を一時保持する候補 |
| 全景からの一時復帰 | 全景直前の構図 | 復帰先がある全景中だけ「さっきの見かた」。手動変更で復帰先を破棄。常設ボタンは増やさない |
| 見やすくする | 初期の暮らし中心 | 従来の初期化の意味を維持し、一時的な全景復帰と混同しない |
| 場所を選ぶ | 対象と入口・実床 | カードを開いただけで強制ズームしない。対象が見切れたら明示の焦点操作で助ける |
| ここで すごす | 移動する本人と対象 | 現行通りカードを閉じ移動を依頼。到着・利用成功は実状態が返すまで断定しない |
| 人物運搬・配置 | つかんだ本人、仮置きと床 | 操作中の自動追尾・再fit・ズーム禁止。二本指と運搬の優先は前案の契約を維持 |
| 会話・自然の返事 | 操作対象と短い返事 | 自動追尾せず、吹き出しの位置で見切れを避ける |
| 端末回転・安全領域変化 | 今の構図 | gesture中の移動なし。操作完了後、明示「見やすくする」で回復可能にする |

「さっきの見かた」は新しいUI候補で、現在の実装済み機能とは扱わない。実装時は既存のカメラ操作・画面内ボタン数・戻る規則を照合して採否を決める。場所の外観だけで「入れる／歩ける」を決めず、現在の実能力を照合する。

## 全画面へ反映する差分

| 対象 | 今回の具体化 | 維持するもの |
| --- | --- | --- |
| メニュー | 実住人と6入口の道具箱。島の居場所が隠れすぎない高さで主従を作る | 既存6入口・遷移・文字/操作の読みやすさ |
| 品物・収納・配置 | 実物と現在の床、接続・干渉を見比べられる。元の家や品物と育った場所を取り違えない | 所有・数量・旧品・仮置き取消・回転・無料再配置 |
| 場所カード | 実対象と「ここで すごす」を主役。元の品物・成長・履歴は補助。家の入口/実床をカードで隠さない | 現在のgallery/garden/shoreなど実利用対象。演奏台の2操作は一つに統合しない |
| 自然・演奏 | 木/花/水への短い返事を操作対象に結び付ける。演奏の共同記憶は実参加だけ | 「おとで おはなし」「えんそうかい」、参加しない自由 |
| 写真・思い出 | 写真自体を主役にし、履歴内「しまの 思い出」と役割を分ける | 自動スライドと折りたたみ。過去記憶は残し、実在する現在地だけ帰還入口 |
| 住人・家 | 本人の姿と実行動、元の家と前庭/共有屋根の成立を見分ける | 好み/最近利用/予約/所有/style。説明や装飾で架空の利用を作らない |
| 花図鑑 | 花の実物と発見を主役にする既存案 | 建築台帳など別機能を新設しない |
| 学習 | 読める問題・回答と短い反応、自然な帰島 | 採点/途中保存/SRS/学習履歴、必須タップ増なし |
| 記録 | 進捗と履歴を読める階層にし、成長量だけを価値にしない | 並べ替え、旧品、学習しない訪問も成功。ランキング化しない |
| 設定 | 保護者向け説明を整理し、状態/回復を分かりやすくする | 本人/別島/保存/既存の設定と回復経路 |

前案の各画面の寸法・色・品物選択・戻り先は、今回差分と矛盾しない範囲で保持する。全画面を一つのカード一覧へ均質化しない。

## 例外と文言

| 実状態 | 表示候補と回復 |
| --- | --- |
| 記憶の現在地が存在しない | 過去記憶は保持し「今の場所を みる」は出さない。必要な説明だけ「このときの ばしょの 思い出だよ」。記憶そのものが消えたように言わない |
| 場所へ移動できない | 現行の短い返事「いまは べつの ところで すごそう」と島上の再選択。閉じたカードへ強制的に戻す制御を追加しない |
| 混雑理由を実際に判別できる | 必要時だけ「いまは みんなが つかっているよ」。理由不明ならこの文言を使わない。新規待ち列は作らない |
| 演奏へ参加しなかった | 警告・失敗文言なし。共同記憶を付けない。見るだけでもよい |
| 空の写真/思い出 | 「まだ ないよ。これからの おたのしみ」。元の戻るを維持し、撮影や成長を義務にしない |
| 保存結果が未確認 | 既存の実保存状態が必要とする場合にだけ案内。未確認を失敗と断定せず、通常時に不安な表示を増やさない。成功は実結果だけ |

## かわいさの優先と抑制

第一は自分が触った木/花/水の短い返事、第二は実住人の暮らし、第三は実際に成立した成長の発見。メニューや編集が前景のときは遊びの演出を抑え、操作の返事と背景が競合したら操作対象を優先する。simulationの状態を演出都合で偽らない。連続タップで音/粒子/吹き出しが積み上がらず、音なし・動きを減らす設定でも結果を理解できるようにする。

## 相談で採用しなかったもの

初回回答に挿入された外部写真/挿絵はアプリの証拠でも採用benchmarkでもなく、取り込まない。「固定倍率を避ける」という全面的な扱い、移動失敗時のカード強制復帰、演奏不参加への警告、達成量を記録先頭へ一律優先、花図鑑への建築情報追加は採用しない。現行の仕様とユーザーの選択を優先し、訂正事項として再送した。

## 実装順と受入

1. カメラと操作優先：初期島/広い島/成熟島、縦横/小型端末、全景→手動→パネル閉じる、運搬→二本指、配置中の対象消滅を検査する。勝手な再fitと別島の視点混入がない。
2. 場所・メニュー・品物：対象、入口、実床、本人が見え、現在の能力と主操作が一致する。閉じる/取消/再選択ができ、既存入口が欠けない。
3. 思い出・住人・家：分離/収納/再接続後の現在地リンク、実参加のみの共同記憶、元所有者の履歴を確認する。
4. 学習・記録・設定：追加義務を増やさず、学習/採点/保存/本人/別島/更新の既存回復を検査する。
5. 演出：同時発生/連打/編集中/音なし/動き減少で、読めて押せて結果を取り違えない。

最初の技術検査とは別に、実画面の美術・全旅程の一貫性、初見の子どもの入口理解・操作・再訪を評価する。画角だけで大型建築の支え/入口/床/出口やruntimeの接続を直した扱いにしない。今回は文書の具体化までで、アプリへの実装とそれらの受入は未実施。

## 訂正後の再回答

再回答では、カード強制復帰・不参加通知・達成量優先を撤回し、自由カメラ優先、移動依頼と利用能力の区別、写真/思い出/保存の保持を確認した。全景の一時復帰はA（全景中だけ「さっきの見かた」）を条件付き推奨、B（追加なし）と実画面で比較する。Aをこの設計の先行候補とし、常設ボタン追加や実装済み判定はしない。数値・美術・runtime・子どもの理解は未確認という整理で相談を閉じる。
