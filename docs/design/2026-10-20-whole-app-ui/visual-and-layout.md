# 見た目と画面枠

## 1 共通のアート方針

小さな玩具を指で扱うような、形と反応のあるUIにする。世界や品物の絵を大きく見せ、文字を読む場所は無地にする。全画面を同じカードの格子にしない。

既存のぽこもこの顔、頭身、耳、布、配色、着替え、本人の所有物の外観を維持する。単なる丸いボタン、装飾用の汎用マスコット、新しい架空の品物でかわいさを代替しない。

### 共通色と素材

新しいパレットを作らず、現在の共有tokenを使う。以下は `src/index.css` の確認値であり、島の海・地面・モデル材質を一括で塗り替える指定ではない。

| 役割 | 既存tokenと値 | 使い方 |
| --- | --- | --- |
| 明るい地 | `--pokomoko-canvas` `#f8f7f2` | 記録・設定・品物を読む基底 |
| 読む面 | `--pokomoko-paper` `#fffdf9` | シート、問題、本文。不透明を基本に背景上の可読性を保つ |
| 主文字 | `--pokomoko-ink` `#30364f` | 題名・本文・価格 |
| 補足 | `--pokomoko-muted` `#606980` | 状態・説明。文字そのものをopacityで薄めない |
| 操作・選択 | `--pokomoko-blue` `#315fb5` | 主操作、現在地、フォーカス。意味は文字と形も使う |
| 局所の色面 | `--pokomoko-rose` `#f4dce4`、`--pokomoko-lavender` `#ded1ef` | 「おく」、住人の台座等。全カードへ均等配分しない |
| 境界 | `--pokomoko-edge` `#cfc5da` | 薄い面の区切り。重要な操作境界の十分なコントラストは別に確認 |
| 縫い目 | `--pokomoko-stitch` `#b6a6c7` | くまのワッペンや外縁の一部。文字・図・入力には重ねない |

深緑・クリーム・真鍮を基調にした別ブランドへ変更しない。黄色は既存の品物や意味のある出来事のアクセントに留める。設定・記録の既存の大きく静止した水玉の世界観は、本文面の外で保つ。

### 形と文字

| 要素 | 最初の候補値 | 伸びる条件 |
| --- | --- | --- |
| 主本文 | 16px、行高1.6 | 文字拡大で面を伸ばす |
| 補足・入口名 | 14px、行高1.5 | 必要な意味を小さな注釈へ追い出さない |
| シート見出し | 20px | 長い題名は折り返す |
| 主操作のhit | 48×48px以上 | 表示絵が小さくてもhitは縮めない |
| 文字付き操作 | 最低48px高、左右12px以上 | ラベル2行なら高さを増やす |
| 主ボタン角丸 | 16px | 共有部品で統一 |
| シート角丸 | 24px | 上辺だけでもよい。内容を丸みで切らない |
| 小さな段差 | 接地影2px、押下1〜2px | キー・行・本文の位置は動かさない |
| 間隔 | 4/8/12/16/24px | 主役の絵の周囲は16〜24pxを優先 |
| ナビ絵 | 27px目安 | 下に14pxのラベル |
| メニュー絵 | 36〜40px | 色面、藍の輪郭、用途固有のシルエット |

物の絵は `IslandToyIcon` と既存世界からの実物画像を使う。橋・花図鑑等の絵が他の入口と揃わない場合は同じ描画規則で補う。閉じる・戻る・拡縮は線画のutility記号でよい。絵文字に統一する案は採らない。

## 2 画面ごとの主役と構図

| 画面 | 最初に目へ入れるもの | 絵の目安と素材 |
| --- | --- | --- |
| 島 | ぽこもこの家と実在する暮らし | フレーム無しの3D世界。UIは小さな道具 |
| メニュー | 実住人の姿、その下の道具の絵 | なかま枠80px以上、人物56〜64px以上。実モデルの身体を切らない |
| 品物一覧 | 欲しい品の実際の姿 | 2列、タイルの絵96px高以上。通常の短いラベルでは面積のおよそ60%を絵へ。長文・文字拡大では比率より読める高さを優先 |
| 任意の品物説明 | 選んだ物一つ | 絵160px高目安。名前・用途・状態を近くに置く |
| なかま一覧 | 住人の姿と名前 | 姿88〜112px高目安、2列。人数増で小さく縮めない |
| 住人の選択シート | その住人と実際の居場所 | 姿120px高目安。短い横画面は文章の横へ |
| そだつ場所 | つくりたくなる場所の形 | 詳細絵160〜200px高。「場所のイメージ」と明示 |
| 家 | ぽこもこと飾った部屋 | 室内全画面。メニューを閉じれば部屋が主面 |
| 花図鑑 | 実際の花弁と色 | 花の絵80px以上。図鑑の紙は縁だけ |
| 写真・カード | 本人の写真 | 余白込みでも写真を最大に。写真を装飾でcropしない |
| 学習 | 問題、答え、ぽこもこの演技 | 採用済み学習の系統を維持。問題図やキーは無地 |
| 記録 | 実際の学習の軌跡 | カレンダーと今日のまとめを先。数字を極小にしない |
| 設定・保護者 | 読むべき項目と現在値 | 明るい読書面。ワッペンは見出しに限定 |

上の寸法は主役が小さくなるのを検出する試作基準。密集した3D世界で全住人を同時にその寸法へ拡大したり、部屋の実モデルの比率を変えたりしない。

## 3 可用領域とsafe area

`V` は現在のvisual viewportの高さ、`T/B` は上/下のsafe area、`N` は通常ナビの実測高さ。島の描画領域 `H = V − T − B − N`。親がsafe areaやnavを既に引いている場合、子で二重に引かない。画面内の座標計算は実測した3D viewportを基準にする。

ナビは64pxを候補にし、文字拡大時は実内容高へ伸ばす。世界はHいっぱいに描画し、重畳面の高さだけcanvasを縮めない。カメラの主役の中心は、上部情報と下部操作を除いた可視領域へ置く。

| 面 | 標準のスマホ縦 | 短い横画面・幅広画面 |
| --- | --- | --- |
| 上端情報 | 左右16px、最低48px高 | 上端に小さく。島名のみ省略表示可、全名は改名面で読める |
| 島の直接操作 | 下部ナビから8px上、左右16px、最低56px高 | 幅最大430px、下端に寄せる。ラベルは縮めない |
| ながめ | 右上の小面、幅最大280px | 同じ角。世界の拡縮を妨げない |
| 補助メニュー | `min(0.60H, H−16px)`以下、左右16px | 右側幅 `min(340px, W−160px)`、高さH−16px以下 |
| カタログ・本・図鑑 | 最大0.85H、左右16px | 右側・左右配置。閉じると世界の視点を保持 |
| 対象情報 | 下部の小面、内容に応じ伸縮 | 短い横画面は右側。絵と文字を横並び |
| 全画面utility | 明るい面、通常ナビを保持 | 画面幅を余白だけに使わずカテゴリ＋詳細へ |
| 重要な確認 | 既存modalを維持 | 本文は内部scroll、確認・取消は常に到達可能 |

`W` はsafe area後の横幅。横に島を160px残す条件が満たせないときは縦配置へ戻す。画面高500px以下・横長を短い横画面の候補とし、実内容高も見る。ソフトキーボードが開いた入力面は、visual viewport内で見出し・入力・決定・取消へ到達できるようにする。

シートの見出しと閉じるは固定。本文だけを `min-height:0` の内部scrollにする。footerがある場合も本文から分離する。末尾に16pxの余白と通常のscrollbarを残し、スクロールできることを読み取れるようにする。

## 4 島ホームとメニューのワイヤー

```text
［島名                 しずく］   ［ながめ］
［小さな場所の絵  そだつ場所／今のヒント］

             実際の島の暮らし
       家・ぽこもこ・花・住人を近く見る
             指で拡縮・移動

       （実対象の近くに短い反応）
［受取等の未処理操作］       ［ひろげる］
［ おく ］［もちもの］［メニュー］
──────── 現在地が一つだけ分かる ────────
［しま］［いえ］［まなぶ］［きろく］［設定］
```

会話・受取・拡張・目標を全部同じ大きさで重ねない。未処理操作が長い場合は補助行を一本使い、拡張入口を小さな別位置へ逃がす。小画面でhideするのは補足文であり、操作そのものは消さない。

```text
               島が背後に残る
┌ しまのメニュー            とじる ┐
│ ［実在住人の姿］なかまに あう     │
│                 実人数・名前     │
│ ［地図と船］［旗の布］［カメラ］  │
│ 海図とふね  はたをつくる しゃしん │
│ ［花の本］  ［橋］    ［本］      │
│ はなずかん  はし      あそびかた  │
│ そのほか                     ▾  │
└──── bodyのみスクロール ─────────┘
```

390pxは3列、360px以下や文字拡大で各入口の文字が収まらなければ2列。3列時の内幅は `(W−32−24−16)/3` を候補にし、固定104pxを押し込まない。住人数0なら架空の人物を足さず、布の足跡アイコンと「なかま 0にん」。入口の順序は幅で変えない。

## 5 品物と仮置きのワイヤー

```text
┌ しまに おく                とじる ┐
│ あたらしく おく ｜ もちもの        │
│ ［実際に存在する分類だけ］         │
│ ┌ 品物の実物 ┐ ┌ 品物の実物 ┐     │
│ │            │ │            │     │
│ │ 名前・状態 │ │ 名前・状態 │     │
│ │ 価格       │ │ 価格       │     │
│ └ おく 詳細 ┘ └ おく 詳細 ┘     │
└────────────────────────────┘
```

ワイヤーの「おく」はタイル主面全体の選択を表す。説明が必要な品だけ「くわしく」を設け、そのbuttonは主buttonの中へ入れず同じarticleの兄弟にする。主面の上に透明hitを重ねない。通常タイルは補助buttonを増やさず、必要な品のタイルは説明buttonの分だけ伸びる。**通常の選択から仮置きまでの必須タップは1回のまま。**

```text
     元の所有物は確定世界に残る
     仮の品物＋足元の輪郭＋接地影
       指で仮位置を選ぶ／拡縮

［品名：ここで いい？　正規価格または再配置無料］
［ここに おく］［やめる］［任意の くわしく］
```

失敗理由や不足は同じ場所で読める。確認操作を押せないときも理由を隠さない。仮置きを確定した世界と同じ不透明度・状態表示にしない。

## 6 本と学習のワイヤー

```text
┌ そだつ場所                    とじる ┐
│ いまの しま ｜ そだった おもいで      │
│ ［大きな場所の絵：場所のイメージ］    │
│ 場所名                              │
│ おく → つながる → そだつ → あそぶ     │
│ いまの配置から試せるヒント一つ        │
│ ［ここをそだてたい］［この場所へ］    │
│ 置き方の例 ▾ ／ となりの場所 ▾        │
│ ［ほかの目標の絵と名前］              │
└────────────────────────────────┘
```

詳細を開く操作を必須化せず、現行の「選択中の詳細＋ほかの目標一覧」のまとまりを磨く。おもいでと今の島は明示して分ける。

```text
［とじる］                         問数
        ぽこもこ：短い反応
┌──────── 大きな問題 ─────────┐
│ 式／文／教材図／選択肢      │
│ ヒント・お手本は問題の近く │
└───────────────────────────┘
             答え欄
          7    8    9
          4    5    6
          1    2    3
          ⌫    0    C
         必要な問題だけ補助行
```

通常のテンキーの配置と自動確定を保つ。短い横画面は問題と支援を左、答えと全キーを右へ。演出中も入力の場所を動かさない。選択・音声の問題はその問題固有の既存操作を使う。

## 7 動きと音

| 瞬間 | 見た目 | 時間の候補・音 |
| --- | --- | --- |
| 押す | 面が1〜2px沈み、接地影が短くなる | 90ms。通常utilityは無音も可 |
| 選ぶ | 輪郭＋小さなチェック。主役の絵が少し持ち上がる | 160ms、単発の軽い音 |
| 開閉 | 出てくる方向と戻る方向を合わせる | 180ms。暗幕の常時演出は足さない |
| 配置確定 | 実際に置いた物が接地、住人の既存行動へ戻る | UIの返事400〜600ms、次の操作を止めない |
| 住人に触れる | 本人の既存の跳ね・視線・遊びを見える構図で返す | 汎用の粒子で覆わない |
| 成長・来訪 | 変わった場所を局所的に見せ、本人の姿を残す | 既存イベントの演技を維持。毎回強制cameraをしない |
| 学習の正誤 | 採用済みのぽこもこの演技と意味のある音 | 既存の入力・再試行・連問時間の上限を優先 |

reduced motionは移動・拡縮・弾みを外し、輪郭・文字・静止した結果で同じ意味を示す。音OFFでも出来事と操作結果が分かる。同じ瞬間の効果音はまとめ、UI開閉音で英語音声を遮らない。
