## 体験の芯

**ぽこもこに会う → 自分の島へ入る → 来訪者の住まいを置く → おとなりさんになる。**

ここまでで最初の導入は完了する。学習は、島で遊んだ本人が「まなぶ」を選んだ時に始める。長い説明や全機能の習得を初回のノルマにしない。

## 原画の後続制作と完了条件

1. Welcome・島到着・入居の3場面を同じキャラクターと島で制作する。依頼書のA01・A02・A05が最初の納品対象。
2. 場所選択と「種→つぼみ→家」の連続性を足す。見た目だけの家を本体の所有物と混同しない。
3. 設定前の保存と学習設定の接続を設計・検証してから、実画面へ統合する。
4. 実画面の美術、説明なしの操作理解、安全、保存と入力を別々に確認する。

仕様案の完了：各場面の操作・短い文言・到達条件・再開先と、絵の制作単位が読めること。アプリ完成の条件ではない。
