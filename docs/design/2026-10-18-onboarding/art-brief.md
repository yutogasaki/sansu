# オンボードの絵 — 制作依頼書

[体験と現行との差](README.md)・[場面の仕様](flow-spec.md)に対応する制作資料。利用者が絵を制作するための依頼書であり、この作業では画像を生成しない。

## 1. 最初に作る3枚

**A01 Welcome、A02 島到着、A05 最初のおとなりさん。** まず画角・キャラクター・世界のつながりを確認する。各場面を別々の新しい島として描かず、A02を位置・縮尺・光の基準にする。

最初の3枚は画面構成の参考原画。実際の配置・歩行・住人の暮らしを、静止した全画面画像だけで実装済みと扱わない。

## 2. 参考から受け継ぐもの

| 受け継ぐ | 今回の扱い |
|---|---|
| 大きなぽこもこと目が合う入口 | 顔・手・布の質感を主役にする |
| 海から島へ入り、船がやって来る奥行き | 同じ桟橋と家の位置を保ち、近景・中景・遠景を分ける |
| 自分で家を置いて住人を迎える喜び | 配置前後を同じ画角で比較できるようにする |
| 明るい空、澄んだ海、丸い家と植物 | 既存の島と整合する材質・輪郭・尺度へ合わせる |

| そのまま移さないもの | 理由 |
|---|---|
| 参考画像の文字・ボタン・数値 | DOM側で表示し、文言変更と読み上げに対応する |
| 常設の黄色い大ボタン、操作3個の固定列 | 既存の操作面を使い、一度に必要な操作へ絞る |
| 全場面で満開の花・密集した家具 | 最初は小さな島。家を置く余白と育つ余地を見せる |
| うさぎの服や家の形の完全再現 | 既存の住人と家具へ合わせる。新しい所有物を勝手に増やさない |
| 全ての場面が光り続ける表現 | 喜びの山場を入居に集中させる |

## 3. ぽこもこの固定条件

「ぽこ」と「もこ」の二人ではなく、パッチワークのくま一人の名前が「ぽこもこ」。顔・頭身・耳・布・水玉・縫い目・配色・既存の着替えを維持する。

基準画像：

- [顔の採用マスター](../brand/pokomoko-icon-master.png)
- [既存の全身](../../../src/assets/natureTown/town-pokomoko-idle.png)
- [既存ポーズ](../../../src/assets/pokomoko-learning-poses.webp)

顔マスターは顔・布の質感、全身素材は体形と配色の参考。同じキャラクターとして整合させ、独断で新しい衣服・帽子・顔・頭身を作らない。左右反転でパッチの配色が入れ替わらないよう注意する。

## 4. 場面ごとの絵

| ID | 原画の内容 | 顔・視線・余白 | 対応する操作 |
|---|---|---|---|
| A01 出会い | 手を振れる大きなぽこもこ。穏やかな背景 | こちらを見る。上にタイトル、下に主ボタンの余白。手と耳を切らない | ぽこもこに触る／しまへいく |
| A02 島到着 | 家・花・ベンチ・桟橋のある小さな島。住まいの候補地を二つ以上 | 島の入口側にぽこもこ。桟橋と候補地を操作面で隠さない | 花・人物・ベンチに触る |
| A03 船 | A02と同じ桟橋に来た船。住人が手を振る | 船上の顔と家の絵が見える。水上の船と陸地を明確にする | 船に触る |
| A04 住まいの変化 | 同じ地点の種、つぼみ、完成した家。地面と接点を揃える | 建物の大きさを既存仕様へ合わせる。予告は完成した家と区別 | 場所選択／置く／つぼみに触る |
| A05 おとなりさん | A02の島へ家が一つ増え、住人が到着。ぽこもこが迎える | 住人が振り返って手を振る。どの家に入ったか分かる。短い祝福が似合う余白 | 下船後の喜び。追加ボタンなし |
| A06 日常・再訪 | 同じ家と住人が残る島。歩く・座る等の普段の姿 | 人物を全員正面へ整列させず、実際の対象へ視線を向ける | 自由遊び、まなぶ |

A05の家の位置は構図検討用の一例。実画面は本人が置いた位置に家を表示するので、固定背景に追加の家・影・住人を焼き込まない。住人の移動経路も実際の道に対応させる。

## 5. 素材の分け方

- 構図確認用に文字なしの合成見本を一枚。可能なら編集可能な元ファイルも残す。
- Welcomeは背景とぽこもこを分ける。通常・手を振るの二状態を同じ位置・尺度で作る。
- 島は原画と本体の3Dの対応確認用。背景画だけを変えて、実物の家や住人が別の姿になる状態を避ける。
- 2D部品を納品する場合は人物・船・種・つぼみ・家の透過素材を分け、足元／地面の基準点と影の扱いを添える。PNGまたはWebP、合成見本はsRGB。
- 文字、吹き出し、残高、学習問題、操作ボタン、手のカーソルは絵に描き込まない。
- 制作開始は縦780×1688（390×844の2倍）を目安にする。顔・手・桟橋・足元が中央の狭い切抜きに依存しない構図とし、768×1024でも確認する。これは原画の作業寸法で、配信用の最終容量ではない。

## 6. そのまま使える制作依頼文

> 「ぽこもこと不思議な島」の初回体験の絵を作ってください。添付のパッチワークのくま『ぽこもこ』の顔・体形・丸い耳・布の質感・配色を維持してください。まず、①こちらを見て手を振るWelcome、②自分の家・花・ベンチ・桟橋と空いた土地のある小さな島への到着、③同じ島に新しい家が一つ増え、最初のおとなりさんを迎える場面、の3枚を作ります。②を島の形・家・桟橋・光の基準にして③まで連続させてください。家を置く余白、海と陸の境界、人物の足元と視線を大切にしてください。明るく入りたくなる世界にしつつ、全画面を花や光で埋めないでください。タイトル・セリフ・ボタン・数値は後から載せるので描き込まないでください。人物と背景を分けた素材も用意できると助かります。参考の11場面の完全コピーや、ぽこもこの描き直しは不要です。

## 7. 原画から実画面へ進む時の確認

美術の魅力、説明なしの操作理解と安全、runtimeの動作を別判定にする。参考原画だけで実装の合格を出さない。

比較するものは「Welcomeの顔」「島の奥行きと余白」「種→家の同じ位置での変化」「船→家へ移る住人の接地」「実画面の操作面を載せた切抜き」。次は実アプリの起動→島→配置→入居→任意学習→再訪のcontact sheetを、app対象・revision・delivery flag・candidate ID付きで残す。子どもの理解と再訪は独立した観察が必要。
