# 入り江をつくって、歩いてのぞく

2026-10-21。利用者のチャッピー相談後の「進めて」に基づく隔離試作。制作前の契約を以下に固定する。本体の仕様・保存・所有・学習・配布は変更しない。

## 制作契約

くふう：掘る・盛ると岸と見通しが変わり、実際に到達できる水辺へぽこもこを呼ぶ。愛着：既存のぽこもこのモデル・顔・頭身・布・色を使用する。試作の地形と履歴はメモリ内だけで、再読込で初期化する。歩行はこの仮地形だけの検証で、本体の住人行動や利用実績には接続しない。

| 参考から移す性質 | 移さないもの |
| --- | --- |
| Little Habitatsの編集で変わる岸・水面・環境の関係 | 他作品の素材、未確認の内部アルゴリズム、発見数を埋める演出 |
| native-05の枝の方向、大中小の尺度、素材差、密度と余白 | 完成画像の家・住人を所有として追加、静止画による動作の合格認定 |
| ぽこもこの接地・重心・のぞく姿勢 | 新しい顔や代替キャラ、瞬間移動を通常歩行に見せること |

最初から家1軒・木6本を保持する。同じ初期形と入り江への操作列を使い、既存1本だけを枝の抜けた水辺の木へ置き換える。同じ状態・画角で旧木と比較できる。既存の木の下を水没させる編集、家と入口、ぽこもこの現在の支持床を失う編集は確定しない。取得経済の新仕様ではなく試作用の保護境界。

物語の一文：岸を掘る→同じ岸が下がる→水面が開く→呼んだぽこもこが乾いた床を歩いてのぞく。派手な反応の自動反復や新しい橋・建物の出現を見返りにしない。

## 受入条件

- 390×844と768×1024の全景／近景で、岸の輪郭・水面・枝の抜け・家との尺度差を確認する。美術の採用と操作整合を別判定にする。
- 掘る／盛るは短く補間し、連打は現在表示中の形から最新状態へ収束する。Undo/Redoで地形と水際が一致し、古い歩行／演技は停止する。
- 水辺へ呼ぶ操作は地形・傾斜・家・木の支持を検査した経路だけを使う。行けない場合は理由を案内する。
- reduced motionは変形・歩行の移動アニメーションを省き、検査済みの行先と経路・静止姿勢で結果を示す。音offでも意味が残る。
- 自動検査は子どもの無説明理解・楽しさ・再訪、実機、音の聴感、本体への採用を認定しない。

候補：`living-cove-v1`。配布：`standalone-study-only`。比較元：[3地形の実験](../2026-10-21-island-shape-experiments/README.md)。相談先：[土地拡張案を比較](https://chatgpt.com/g/g-p-6ad58d0857b881918e46e346350848e7/c/6ad7354d-f4f4-83e8-a296-b462d76d7d72)。相談は文章要約の検討で、画像・動画・実音の独立監査ではない。

## 実装の境界

既存の `makePokomokoRig` と布材質を直接bundleへ取り込み、代替モデルを描き直さない。木は既存の `(9,10)` の1本だけを置換する。ほかの5本と家の粗形は保持。入り江の再生は元の操作列から追加植樹を除き、家1軒・木6本・土+12段へそろえる。水庭や石段などの派生小物を自動追加しない。自由な植樹は本人の明示操作だけ。

歩行は0.175単位の探索格子、0.045以下の間隔での区間検査、足元周囲の乾いた支持と高さ差、家の体積と木の幹の回避を使用する。選択地点付近にある到達可能な水辺を探し、見つからなければ呼出先へ移動しない。描画された地面と同じ高さ関数を足元へ使う。本体の経路探索や取得地の権利を実装したものではない。

編集・Undo/Redo・復元は古い歩行とのぞく姿勢を停止する。Undoによって現在の足場がなくなる場合は、保護された家前へ戻したことを案内する。通常歩行として瞬間移動を見せない。reduced motion時の呼出は検査した到達地点への即時切替と経路表示を使う。
