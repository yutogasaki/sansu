# 家・庭・島の外観定義 v1

2026-09-09。依頼「1：見た目を固める」に対応する制作基準。候補ID：home-growth-layout-v1。既存v2画像から採る形と修正する形を決める。ユーザーによる最終画像承認、実装・公開合格を意味しない。学習量、解放条件、保存の変更は対象外。

## 主役と素材

ぽこもこが暮らす同じ家が、学習の積み重ねで増築され、庭とご近所へ暮らしが広がる。

| 引き継ぐ | 採用しない |
|---|---|
| ぽこもこの左右の顔色、水玉耳、黄色い縫い目 | 顔色・身体比率の段階ごとの変更 |
| 青い丸頭の扉、丸窓、生成りの壁、桃・黄・青の瓦 | 全建物に同じ屋根と同じ顔マーク |
| 木・陶器・石・ガラスの素材差、住民の布 | 家や海まで布にすること |
| 紫の樹冠、青い海、暖かな家 | 全面の花、常時の発光、金色だけの豪華さ |

住民は [identity原画](../brand/pokomoko-icon-master.png) を基準にする。家の扉高をDとし、ぽこもこの耳から足までを0.85Dに固定する制作寸法。住民の学習成長による巨大化は行わない。これは次のモデル制作値であり既存画像からの計測値ではない。

## 家：5段階の形を固定

青い扉と敷居、正面の小屋の壁幅・丸窓、玄関前の石段を全段階で共有する。家全体の拡大縮小で成長を表現しない。

| ID | 形 | 増える部分 | 保持するもの |
|---|---|---|---|
| home-1 | 一室の小さな切妻屋根の家 | 基本棟、煙突 | 最初から清潔で居心地がよい |
| home-2 | 玄関に木のひさし | ひさし、窓の花箱 | 基本棟の高さ・幅、扉 |
| home-3 | 右側に屋外テラス | 屋根、手すり、テーブルと2席 | 玄関、前庭、通り抜け |
| home-4 | 後ろに2階・屋根裏 | 高い後棟、上階の丸窓と張り出し窓 | 前の小屋の屋根、テラス |
| home-5 | テラス奥に温室 | 木枠と透明ガラス、棚と植物 | 手前の屋外2席、横の出入口 |

home-5はv2画像の「テラス全体をガラスで囲う」形から修正する。温室は後ろ半分に接続し、手前を屋外のまま残す。home-4の上階も正面棟を引き伸ばさず、後棟へ足す。花壇・木の段階は家の段階と独立し、家5に満開の庭を必須で焼き込まない。

## 小物：6種それぞれ3段階

| ID | 1 | 2 | 3 | 固定する部分 |
|---|---|---|---|---|
| flower | 小さな木枠に3株、つぼみ混じり | 同じ枠内に2種類、丈の差 | 同じ枠に3種類、高低のある満開 | 枠と足元の範囲 |
| bench | 素朴な背もたれ付き木の2人掛け | 肘掛けと座布団 | 曲線の背板と2つのクッション | 座面高、2人分の座席、脚の接地 |
| lamp | 短い柱に小さなランタン | 同じ根元から高い柱と傘 | 曲線の支え、二重の傘とガラス | 根元、道との距離 |
| tree | 屋根より低い若木 | 横に広がる樹冠、枝分かれ | 豊かな樹冠と木陰 | 幹の根元、最終樹冠用の空間 |
| fountain | 丸い石の水盤、中央に短い水流 | 同じ水盤内に上段の皿 | 2段の皿と複数の細い水流 | 外周、水の落ちる範囲 |
| gate | 低い木柵と開いた入口 | 同じ入口に支柱と小さな屋根 | 曲線の門と控えめな蔓 | 開口幅、支柱位置、通路 |

成長を色替えだけにしない。木の樹冠以外は最大形の敷地を原則共有する。上位段階でも座れる場所・入口が減らない。初期ベンチも2人掛けとし、見た目の等級のために既存能力を奪わない。レアはこの通常段階の別外観として後続設計する。

## 島3段階に置くもの

ここでの初期/途中/発展後は比較用の代表景観。日数・解放条件・全施設の最大化を表さない。

| 対象 | 初期 | 途中 | 発展後 |
|---|---|---|---|
| 家 | home-1 | home-3 | home-5 |
| 花壇 / ベンチ / 灯り / 木 | 各1 | 各2 | 各3 |
| 柵・門 | gate-1 | gate-2 | gate-3 |
| 噴水 | なし | なし | 公園内fountain-3を1つ |
| 店 | なし | 小さな店舗、布の日よけ | 商品棚と休憩テラス |
| 公園 | なし | 木陰とベンチ、開いた芝生 | 小さな演奏台と噴水 |
| 工房 | なし | なし | 右奥、水車と搬入口 |
| 港 | 手前の小桟橋だけ | 手前を保持 | 奥右に荷受け桟橋と灯台 |
| 天文台 | なし | なし | 最奥の低い丘に小さく置く |
| 住民の比較配置 | ぽこもこ＋うさぎ | 加えて配達するカワウソ | 加えて公園のキツネ |
| 庭の植栽占有目安 | 15%以下 | 25%以下 | 35%以下 |

占有率は家・通路を除く庭の地表を分母とした上からの面積。花と低木を数え、樹冠の影は数えない。初期にも自然の低木は少量残す。全景画像の帆のくま印は削除し、船は無地とする。手前の到着桟橋と発展後の港は別の場所として固定する。

## 固定配置とカメラ

制作座標は家の玄関敷居中央を(0,0)、画面右方向を+x、島の奥を+z。単位はD。既存保存座標への移行値ではない。

| 要素 | 固定位置・範囲 |
|---|---|
| 基本棟 | x=-1.5〜1.5、z=0〜2.5 |
| テラス予約地 | x=1.5〜4、z=0.5〜3.5。初期は芝生 |
| 温室 | 上の予約地のz=2〜3.5。手前の屋外席を残す |
| 後棟 | 基本棟後方z=1.5〜3.5、home-4以降に上階 |
| ぽこもこ比較位置 | (0.8,-1.8)。動作時も身体の尺度は同じ |
| 花壇 / 木 / ベンチ / 灯り | (-2.4,-1) / (5.5,2) / (5.3,0) / (3.5,-2) |
| 玄関前 | x=-1〜1、z=-2.5〜0を空ける |
| 奥へ続く道 | 家の左側x=-3.5を通り、z=5からご近所へ |
| 桟橋へ続く道 | 玄関前から左手前へ。初期の海岸と接続を保持 |
| 拡張する土地 | z=5より奥。既存の家と庭を押し退けない |

道幅はぽこもこの身体幅の1.5倍以上、すれ違い場所は2.5倍以上。座面・温室の入口・荷物の置き場を通路に重ねない。これらは制作上の最低寸法で、歩行メッシュの実測は後続。

比較用には正投影・俯角35度・方位固定で、最終の家と庭が入る尺度を全段階へ共用する。全島比較は別カメラを1つ用意し、初期/途中/発展後で同じ投影・中心・倍率を使う。成長時の自動ズームで差を作らない。実際のホームは家に寄る表示と全景を分け、広い島を小画面に詰めて主人公を点にしない。
