# 家と住人：素材・動作の更新2

2026-09-09。[実画面比較](review.html)。DEVの `home-journey-material-motion-v2`。公開切替なし。

## 変更

- ぽこもこの球を重ねた左右色から、既存の布atlasを使った顔・胴体・水玉耳・腕・足へ変更。新たな画像の編集ではなく既存3D素材の再利用。
- 家と家具の角を丸め、初期の木を低くし、海岸を持つ地形と接地する影を追加。
- 配達を等距離で歩く経路、2秒の荷物移動、休息、帰路へ分離。負の時刻と区間境界を純粋関数で確認。
- 住民の座面位置を調整。主人公の足・身体の姿勢を分離。

## 素材の不採用

内蔵image_genで家1〜3のatlasと透過修正を生成したが、両方とも2172×724 RGBで背景に市松模様が焼き込まれていた。透過素材として使えず、アプリへコピーしていない。CLI/APIへの切替なし。[プロンプト](prompts.json)、元画像はこのディレクトリのhouse-atlas-rejected-v1/v2.png。モデルの尺度と扉の位置にもずれがあり、透過だけ直れば完成とは扱わない。

対象7テスト、typecheck、lint、build/assets通過。full testsの最終結果は追補に記録する。source.jsonは共有dirty DEVの選択ファイルhashで、固定production比較ではない。前段のv5実画面検査と開発中のHMRを最終証拠に混ぜず、v6から画像を保存した。
