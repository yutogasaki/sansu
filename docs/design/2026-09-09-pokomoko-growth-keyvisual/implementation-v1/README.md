## 失敗と修正

最初の実UI検査は45問保存後の配達描画で失敗。初回RAF時刻が初期化時刻より前になると負の経過時間から経路添字が範囲外になった。時刻差と添字を下限0へ制限し、通常の実回答から両viewportを再検査した。初回失敗の記録はローカル `output/playwright/home-journey-v2/`。屋根と手すりがテーブルを隠すため、前側の屋根を空け、手すりを柱と横木へ変更した。
