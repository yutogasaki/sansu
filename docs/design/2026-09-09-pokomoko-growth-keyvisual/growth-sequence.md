# 家から島へ：成長順序 v1

2026-09-09。依頼「次」に対応し、作業リスト2の既定成長順を具体化。[外観定義](appearance-definition.md)と[コンテンツ表](../2026-09-09-island-content-catalog.md)を使用する。将来の制作・進行案であり、現行の解放条件・問題数・保存を変更しない。

## 成長のリズム

小物が育つ → 住人が使う → 家が増築される → ご近所が増える、を繰り返す。住人の利用は自動の演技で、見届けたりタップしたりすることを次の成長の条件にしない。

開始時は家1、花壇1、ベンチ1、灯り1、木1、柵1、ぽこもことうさぎ。最初から帰る場所と小さな暮らしがある。以下の番号は出来事の順番で、区間数・学習日数ではない。

## 後半：主島の完成へ

後半は章ごとの既定列を以下の順に進める。小物の完成を全施設解放の条件にはしない。

| 章 | 既定の変化順 | 家へのつながり |
|---|---|---|
| 港のはじまり | 奥右の土地＋港1 → 灯り3 → 港2 → 公園3 | 船が立ち寄り、住人が家へ知らせに来る |
| 庭と仕事の充実 | 木3 → 店4 → 工房4 → 門3 → 港3 | 店のおやつ、工房の家具、港の荷物が届く |
| 島の象徴 | 天文台1 → 噴水1 → 公園4 → 天文台2 → 店5 | 観測の後も家へ帰り、テラスに集まる |
| 豊かな島 | 噴水2 → 工房5 → 港4 → 天文台3 → 公園5 | 運ぶ・作る・休むが施設間でつながる |
| 主島の完成 | 噴水3 → 天文台4 → 港5 → 天文台5 | 同じ家を中心に完成した島を眺める |

後半の港は手前の初期桟橋とは別の施設。噴水は公園内の独立した小物で、同じ噴水を公園成長の報酬として二重配布しない。天文台は確定の長期目標とし、レア抽選を条件にしない。

全体は家・店・公園・工房・港・天文台の各5段階、小物6種の各3段階に到達する有限の既定順。初期の既得6状態から42の新状態へ進む案であり、42区間で完成する意味ではない。レア、衣装、来訪の演技はこの通常列を置き換えない。

## 次の目標の見せ方

ホームには主目標を1つだけ見せる。「テラスができる」など、次の形と用途がわかるものを使う。近い小物の変化は現在の場所で控えめに示す。後ろの未解放施設を全部シルエットで並べない。

成長前後の比較は同じ画角。学習中は受取画面や演技を割り込ませず、帰島したときに最新の景色と直近の主要な変化を示す。複数成長していても全演出を順番に消化させない。見逃した獲得と実際に観察した行動は別に記録する。

主目標の途中には、保存済みの進行に応じた部材・小物などの小変化を置ける。ただし工事状態の画像を際限なく追加せず、必要学習量を決める工程で長い空白が生じる箇所に絞る。

## 選択・停止・実装範囲

上記は何も選ばない場合の順。任意の育成先変更を設ける場合も、現在の予約を変えず次の予約から適用し、途中の成果を失わせない。必須解放の依存関係と、自由に前後できる小物を分ける。具体的な分岐アルゴリズムは学習量の設計とともに定義する。

最初の実装は序盤の家・店と花壇・ベンチ・灯りを中心に成立させる。木・公園以降を制作していない版では、その手前で未制作施設の予告を止める。既存の制作範囲表を越える無限成長は約束しない。

主島完成後は完成を明示し、既得の外観・生活・写真・学習を使い続ける。次の島やオンライン見学を主島の完成条件にはしない。
