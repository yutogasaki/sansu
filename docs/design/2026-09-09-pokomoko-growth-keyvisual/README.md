## 固定する物語

学ぶ→同じ家が立派になる→ご近所が増える→住民が暮らす。ぽこもこは家の前で暮らし、友達の訪問を迎える。主役と家を見た後、その背後に広がった島を眺めたくなる構図。

## 画角と画像の役割

学習画面ではなく、帰島/将来のホームを検討する文字なしの縦長キーアート。各候補はおよそ2:3。phone 390×844 / tablet 768×1024のruntimeを再現した画像とは扱わない。学習入力、通常問題間の追加0操作、速度、保存、PWAは対象外で変更なし。

制作上の3方向：A 家を中心に奥へ広がる街、B 庭から水路沿いに広がる街、C 湾を囲む街。全案でぽこもこと家を第一焦点にする。独立した島を多数浮かせたジオラマや、主人公の巨大な別枠ポートレートにはしない。

## 検証の境界

見る点は、主人公のidentity、家が中心、発展量と粗密、住民の用途、形/素材、初期からの連続性。数値による魅力スコアや子どもの意欲合格は付けない。視覚は制作評価、理解/安全の独立観察は未実施、runtimeは未実装。完成した生成画像を実際のアプリのスクリーンショットとは呼ばない。

## 作者による確認と残差

参考の青/紫/温かな家、ぽこもこの左右の顔・耳・縫い目、家の青い玄関、手前の桟橋を継承した。初期→途中→発展後で奥の土地と施設が増える。主役は家の近くに残り、住民の運搬や休息が見える。公開版の品質・操作・暮らしの演技を証明したものではない。

残る点：初期も花や装飾が多い。発展後の家は温室等が増えるが、5段階全ての差は未制作。人物/家の位置とサイズに生成のずれがあるため厳密な同画角合格とはしない。原画のクリーム面に暖かなピンク寄りの陰影、船の帆の意図しないくま印、背景の追加住民がある。中間には指定より早く噴水が現れる。全段階の物の配置/所有/解放契約は画像から採用しない。高低差・建物追加は現行の平面歩行・保存配置との接続設計が必要。
