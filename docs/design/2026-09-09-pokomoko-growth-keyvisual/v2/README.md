## 制作契約

家は小屋→ひさし→テラス→2階/屋根裏→温室付き。庭は少数の花と小木→花壇と木が育つ→豊かな庭。キーアートの初期/途中/発展後には家1/3/5と庭1/2/3を使う。生成のカメラ・identityの固定は要求であり、画像確認で成立範囲を別途記録する。
