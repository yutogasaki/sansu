# 住人の散歩周期と旧島の歩き方

2026-09-12の「住人があまり動き回らない」「動き方も旧仕様がよかった」に対応。[仕様48](../../product/48_island_life_spec.md)の自発散歩を修正した。

## 変更と境界

- 原因は散歩にも30分の家具活動枠を使っていたこと。数秒で到着すると残りの枠を待っていた。
- 描画専用の経路列を作り、到着後1.8秒で次の空いている住人へ交代する。各自の到着地点から再出発し、家・家具・他の住人と予約経路を避ける。
- 旧島の `sampleResidentStride`、`easeResident`、`turnResidentToward` を再利用。距離に対応した接地・足上げ・腕振り・小さな上下動へ戻し、新しい前傾・左右揺れを外した。歩行全体で加減速し、最終到着時刻と着座・花への接近を保つ。
- 家具を利用している住人や、ぽこもこへの指定先は中断しない。全員が家具利用中の時まで散歩へ切り替える変更ではない。
- 保存・経済の再生処理は変更しない。散歩は報酬、利用回数、学習、発見を書き換えず、同じsnapshotと時刻で同じ地面位置を返す。15秒更新でも現在の活動枠だけを再構成し、何年分もの散歩履歴を追わない。住人の説明も同じ表示用経路を使う。
- 既存の家・色・素材・住人identity・画角を継承。新しい画像生成、配色、カメラの変更はない。

## 判定

視覚は既存美術を保持し、散歩の交代と足運びを実画面で確認する範囲。新しい美術の数値評価は行わない。無説明理解・安全・再訪意欲は子どもN=0で未検証。Runtimeは今回の散歩・表示・学習への復帰に限定する。実機iOS、PWAの二つのビルド間更新、正式throughput、旧島の全専用E2E、全体releaseの合格ではない。公開・commit・pushは実施していない。
