# つくれるものの不足表示 v1

しずくがまだない島でも、制作メニューを開けば「まなぶと しずくが ふえるよ」と分かり、各商品には「あと N しずく」と表示されるようにした。学習を主役のまま保ち、島を見ながら次に作りたいものを選べるようにするための小さな導線である。[仕様48](../../product/48_island_life_spec.md)に表示契約を追記した。

## 変わったこと

- しずく不足の商品は購入できない状態を保ちつつ、必要な差分を表示する。
- 一つも作れない時は、学習へ戻る意味を短い案内で伝える。
- 価格、しずくの獲得量、保存、学習記録、島のワールドサイズは変更していない。
- 学習後の「学んだぶん +N しずく」通知と組み合わせても、島上の「つくる」メニューだけを開く。

## 検証

`report.json` は production preview の phone/tablet（390×844 / 768×1024）で、空の制作メニュー、不足数、実3問による6しずく、学習後通知、花購入、reload、実サービスワーカー制御下のオフライン回答と再起動を一周した結果である。`phone-build-empty.png` と `tablet-build-empty.png` は、島を縮めずに案内と不足数を重ねた実画面。`phone-earned.png` と `tablet-earned.png` は学習後通知の実画面である。

- **視覚**: 水面・島全景・下部ナビを残したまま、制作パネルの案内と不足数が読めることを確認。最終アート評価と子どもの再訪意欲は未実施（N=0）。
- **無説明理解・安全**: 作れない理由が「あと N しずく」と読め、学習で増えることを案内する。購入・報酬・学習記録に副作用はない。子どもによる無説明理解は未観察。
- **runtime**: `report.json` の phone/tablet が PASS。`core.txt` は docs:check、lint（既存 warning 1 / error 0）、typecheck、339 files / 3608 tests、build、assets:check が PASS。`smoke.txt` の通常スモークも PASS。

この証跡は家庭内本番の操作整合を示すもので、経済設定の長期妥当性や実参加者の学習継続を証明するものではない。
