# Nature Town NT-2：成長する一周

2026-09-17。[実画面の一覧](contact-sheet.md)／[対象buildと実測](runtime-report.json)。

## 実装

食たくの入居案内をコアの実判定から表示する。空き家・履歴・供給率・備蓄の不足を短く示し、条件成立を当選保証としない。候補が来た後に空き家を片付けても候補を保持し、復旧の案内を表示する。明示的な開拓操作の後だけ、新地区の入口へ地図を移す。

## 通った一周

`tools/e2e-nature-town-growth.mjs` を本番形式の390×844／768×1024で実行。初期プロフィールだけを作る使い捨て環境で、世界・食料・学習単位・候補・時計は注入していない。世界時間はUIの2倍速のみ。

1. 初期3人から家と畑を配置し、実配送・供給履歴による旅人の到着を待つ。
2. 候補がいるまま家を収納し、再読込して同じ候補を保持。家を戻し、迎えて4人にする。
3. 次の共同食で要求人数が4へ増えたことを確認。
4. 道を北の境界へ伸ばし、東の川には橋を架けて両地区を開く。元の住人IDと初期食料の総投入量を保持し、3地区の上限表示を確認。
5. 北へ食たく・家を配置し、同じ畑を移す。新食たくの在庫は0から始まり、旧食たくの在庫を全域共有しない。既存の家の接続先と道を整える。
6. 通常学習の6区間をUIから完了。停止していた世界へ戻り、水路・台車を各3単位で取得。
7. 乾いた北の畑へ水路を引いて水分上昇を確認。実在庫から4個を台車に積み、北の食たくへ納品する。
8. 再読込後も4人・3地区・6区間の権利・2道具を保持する。

これは決めた手順による技術的な一周で、子どもの自発的な遊びや無文字理解の証拠ではない。9人到達、8／24地区負荷、実機、全受入条件は含まない。
