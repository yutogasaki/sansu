# 島と問題、それぞれを主役にする

12アプリの[比較調査](../../research/2026-09-09-layout-strategy/strategy.md)を[画面目的別レイアウト仕様44](../../../product/44_display_layout_spec.md)として実装した。画面を共通の「島＋カード」に揃えず、世界・学習・一覧・編集・思い出・設定と記録に面積を割り当てる。

[実装した画面の一覧](contact-sheet.html) / [固定ビルドと入力の記録](build-source.json)

## 実装

- 島ホームの残りの高さを世界へ渡す。常設の多段メニューを「あそぶ／ととのえる／おもいで」のダイアログに整理。全入口・旧おくりものを保持し、Escape・とじる・行先選択・履歴移動で適切に閉じる。閉じると入口へフォーカスを戻し、メニューで隠れた島の発見・環境音を止める。
- 通常ナビは「しま／まなぶ／きろく」。高さ60px＋安全余白、44px以上のタッチ領域。まなぶは明示的な開始操作で、トップから自動開始しない。学習を閉じると開始元と入力を戻す。
- 縦phoneの通常ホーム・庭だけを1.3倍の近景にする。手動カメラへ切り替えず、自動演出を保持。「しまぜんぶ」、比較・写真・学習・配置・家の専用構図は保持。
- 選択問題は問題と回答を近接。数値・分数・筆算のキーと支援は固定し、長い問題だけを内部スクロール。予約・採点・学習進行は変更しない。
- 持ち物は品物を先に表示。配置は画面上端の取消・確定と、スマホ下部／横画面右側の操作欄。取消では所有物を変えない。
- アルバムは実景の比較を先にし、分類・場所・時点をコンパクトな選択欄へ。写真や過去のsnapshotは変更しない。
- 設定は4行の一覧、広い画面ではカテゴリと1つの詳細フォーム。リセットは保護者詳細に配置。記録の空状態を整え、既存6詳細を実際に開閉できるようにする。
- 横画面のきせかえ・しまづくり・身支度・家具・発見・育成では、世界を左、道具を右へ。学習から戻ると右欄のスクロール位置も復元する。

## 確認中に修正した点

- 横向き設定の表示指定が狭い画面の非表示指定に負け、フォームが左列へ潰れた。優先度を揃え、回転後もカテゴリと詳細が並ぶように修正。
- hookを追加したメニューを以前の単体テストが直接関数呼出していた。Reactで描画するダイアログと純粋な内容を分け、入口・権利・callback・busy例外を維持した6テストへ移行。
- 右パネルを新しいスクロール面にしたことに合わせ、学習復帰時の保存対象へ追加。実スクロール→学習→閉じるの回帰確認を追加。
- 既存の横画面QAが、以前の筆算用確定キーを常に要求していた。現在の自動入力ではキーを出さず、保存再試行では出す既存契約にQAを合わせた。失敗ログは保持し、アプリの採点や入力処理は変更していない。
- 横向き3択の2段配置ではヒント後に問題下端が4pxはみ出した。幅900px以上の横画面に限り、3択を1段へ変更。2/4択とphoneの並びを維持し、Chromium・WebKitの選択/語彙4診断を通過した。
- 背景保存の診断で、旧「6区間60ほし」と初回未獲得の表現を現在の実予約・完了receipt・63問の初成熟へ適応。その後、中央Learnが背景保存中にも有効な実問題を検出。v5で閲覧ナビとは別の学習開始ロックを追加し、URLによる学習要求も保存後まで待つ。
- DEV URLへproduction専用のversion検査を向けた起動ミスは、固定productionへの再実行と区別する。

## 分けて判定するもの

- **見た目:** 実装者が実画面で面積配分・文字・退出の見え方をレビュー。v5の実画面を確認。右欄のスクロール復帰、家具列指定、横向き3択、保存中の開始ロックを補正した。新しい絵の制作やベンチマーク作品との同等性を認定するものではない。
- **説明なしの理解・安全:** 全入口、既存保存境界、明示的な学習開始、44px操作を確認する。独立した子どもの観察はN=0で、実機iOS・子どもの意欲や理解は未評価。
- **実装整合:** バージョンごとの結果を以下の証拠に紐づける。通常のプロフィールfixture、実UIの予約・保存、明示的な速度fixtureと背景保存診断を混同しない。
