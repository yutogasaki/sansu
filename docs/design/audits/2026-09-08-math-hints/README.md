## 修正

- `compose_5 / compose_10` は「絵のない マスを、かぞえよう。」、数え上げは「絵だけを ひとつずつ かぞえよう。」とし、同じマス図を使う別の問いを区別した。
- `8 + 7` は「8は あと2で10。7を 2と5に わけて、8に じゅんに たそう。」と、分ける目的と元の式の関係を説明する。お手本の計算例は凍結した正解との一致を確認してから示す。
- 左右二組の引き算図、数直線、数の読み、順番と繰り返し模様、基本四則・分数に応じた説明を追加。分数は分子/分母が上下どちらかを明記する。未対応の式では解法を推測せず、お手本へ進めることを伝える。
- 新しい筆算面では演算共通の文だけを繰り返さず、現在の保存済み段の案内をヒントに使う。未回答の段や正解セルを取り出さない。筆算欄自身の段案内との重複は残っており、段別の詳しい教え方の追加までは含めない。
- UIの表示用ロジックだけを変更。生成・予約・採点・支援保存・SRS・入力形式はこの変更の対象外。
