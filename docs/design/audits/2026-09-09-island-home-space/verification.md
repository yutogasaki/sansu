# 島を広く、タブを小さく

ユーザーの「島エリアが小さい」「タブも大きい」に対応するローカル実装。下部タブを小さくし、ホームの任意操作を横送りの1列に整理して、残りの高さを島へ渡す。学習・詳細を閉じるとメニューの横位置も復元する。主仕様は[ナビ43](../../../product/43_island_navigation_spec.md)。

[変更前後・学習と復帰・設定と記録の実画面](contact-sheet.html)、[最終レイアウト検証](layout-verification.json)、[配信対象とソース](build-source.json)。

## 実測

| viewport | 島の表示枠・前→後 | タブ・前→後 |
|---|---|---|
| 390×844 | 338→503px | 82→60px |
| 390×700 | 最終359px | 最終60px |
| 768×1024 | 410→667px | 82→60px |

安全余白なしのChromium測定。端末の安全余白は別途確保し、押せる高さは44px以上。庭のモデル・カメラ倍率は変更せず、表示枠を広げた。短い画面で操作がタブに隠れず、ページ全体には横スクロールを作らない。

- **見た目:** 作者レビューで画面配分の改善を確認。島の枠を大きくし、タブと大きな2段カードの占有面積を減らした。既存の色・モデル・画角を保持し、新しい絵の魅力や子どもの意欲を認定するものではない。

- **実装整合:** 今回の表示・移動・復帰とPWAの検証はPASS。学習ロジック・保存schema・3D表現は変更しない。全成長経路・固定問題の速度測定・実機iOSを今回の結果へ拡張しない。

## 修正した確認中の問題

flex配置の初版では操作欄の自動幅が親を超えたため、幅100%と最小幅0を指定した。通常のTab移動は半分見えているボタンをスクロールしない場合があったため、focus時にボタン全体を表示する補正と実ブラウザ回帰を追加した。初回ハーネスのプロフィールID不足と戻りボタン名の不一致は検証側の修正として区別する。

commit / push / 公開はこの追加調整では行っていない。
