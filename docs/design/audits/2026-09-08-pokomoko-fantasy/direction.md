# ぽこもこ — 不思議な水玉の背景案

## ユーザーの方向修正

単色の紫は違う。細かな水玉は可愛さがない。大きいパステル水玉は可愛すぎる。不思議な感じ、ファンタジーが欲しい。背景を模様の密度調整から、色・奥行き・不可能な空間へ切り替える。これは背景の方向検討であり、3Dゲームの動作や学習の変更ではない。

| TRANSFER | DO NOT TRANSFER |
|---|---|
| くまの左右で違う布、はっきりした青、水玉の大きさの差 | 既存キャラクターを生成で描き直すこと |
| 水玉が表面や奥行きに沿う不思議な空間、少ない大きな形 | 小さな黒い粒、均等な紙吹雪、単なるパステル壁紙 |
| 青緑・群青を中心とする幻想的な色面、少量の温かい差し色 | 暗い恐怖、点滅、全面の光粒、UIに焼き込んだ文字 |
| 情報面の外にも世界が続く画面下部と側面の構図 | 中央の設定カードで隠れる唯一の見せ場 |

## 3案

A 青い夢の空間：大きい水玉を持つ曲面が青緑〜群青の奥へ連なる。
B 水玉の森：大きな点を持つ空想の植物、群青の奥行きと明るい翡翠の前景。
C 宙に浮かぶ布：折り重なる布の島が宙へ連なり、静かな青い空間に浮かぶ。

縦長背景をbuilt-in image_genで制作し、実アプリの捨てプロフィールへ一時CSSで重ねて見比べる。生成素材/仮CSSの比較は、採用済み実装や公開完了の証拠としない。入力・ラベル・正誤・保存・ナビは変更しない。独立した子どもの観察はN=0。ここでは新しい作用/報酬/物語は追加しない。

## 実画面での比較

built-in image_genの原画3枚を無加工で保存。背景案とプロンプト、SHA-256はassets.json/prompts.jsonへ記録。実設定画面に一時CSSで原画を重ね、phone390×844/tablet768×1024で6枚を撮影。背景はcoverで中央下に合わせ、見出しには濃い青緑の面、カード・ナビは既存の無地面を保持。操作は変更せず、横溢れなしと44pxナビを確認した。preview-manifest.jsonは実buildと仮candidateを区別する。

作者の候補はC（布が地形になる接続が強い）。ユーザーには3案の方向の好みを質問済みで、最終採用は未確定。これは生成原画と仮CSSの方向比較であり、アプリへの恒久組込、PWA容量調整、速度、実機の確認は行っていない。原画は各2.2〜2.5MBであり、そのまま3枚を本番配信しない。

過去の細かい黒い水玉と、大きなパステル水玉の候補は、ユーザーの「可愛さがない」「かわいすぎる・ファンタジーが欲しい」により最終背景としては未採用。既存の名前・アイコンの採用とは別に扱う。
