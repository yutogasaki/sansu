# 島のカメラ操作の重なり修正

変更対象は `src/components/island/life/life.css` の操作位置のみ。既存のUIガイドライン07にある操作領域の非重複を回復する不具合修正で、親仕様・ゲーム契約の変更は不要。

カメラ変更後の「もとの ながめ」と「しまの ようす」が同じ左下座標に表示されていた。「ながめ」とリセットを52px上へ移動し、下の制作・島メニューと分離する。「ながめ」を開いている間はパネル内のリセットを使い、外の重複ボタンは非表示にする。狭い画面でパネルとも衝突させない。開いたパネルを内容幅に合わせ、タブレットの「もとの ながめ」が縦に折り返して隣接操作へ溢れる問題も修正する。

ローカルDEV `http://127.0.0.1:5238`、`VITE_ISLAND_ENABLED=true` / `VITE_ISLAND_LIFE_ENABLED=true`、共有作業中のcheckoutで確認。配布build・公開確認ではない。画面と診断スクリプトはローカル `output/playwright/camera-overlap/`。変更前390pxでリセットと島メニューがx=12、y=722.40625、44px高で重なることを再現した。

`npm run verify:core` はPASS（3,645テスト）。CSS位置調整後の `npm run build` はPASS。パネル幅の最終調整後はコンパイル成功、assets検査で共有dist/sw.jsが消失する競合を検出したため、専用の `/tmp/sansu-camera-overlap-dist` にViteを再ビルドしてPASS。320/390/768/1024pxで実カメラ拡大→開閉→外のリセットを操作し、44px高・中央のhit target・全操作ボックスの非重複・リセット後の消失をPASS。390pxの閉状態と768pxの開状態の実画面を目視確認した。初回の320pxでは学習の退出直後に画面が残る待機失敗があり、短い待機後にまだ学習面なら退出を再実行する診断補正を加えた。

このCSS修正では全島進行・PWA・throughputのE2Eは再実行しておらず、リリース全体の合格とはしない。視覚評価は操作の可読性に限定し、アートの再承認・子どもの無説明理解や意欲は評価しない。保存・ルーティング・PWA・学習処理は変更しない。
