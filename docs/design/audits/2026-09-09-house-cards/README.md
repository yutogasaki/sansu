# 家の行き先カード

2026-09-09。アイコン変更後の「UIとしてのカードの見栄えがイマイチ」という指摘への修正。

## 変更

家の行き先だけを対象に、横並びアイコンで説明文が細くなる構造を変更。アルバムは横長の入口、写真/記念品はアイコン→名前→説明の縦並び、おしらせは低い行とした。かざりもある場合は写真と並べ、記念品を全幅の行にする。生成りの面と低い影を共通にし、アルバムだけ淡いラベンダーで焦点を作る。矢印はCSSの装飾で、操作名はDOMに保持する。

短い説明に整え、余白・名前の基線・説明の幅を優先。クリック先、disabled、保存、報酬、問題入力は変更しない。親仕様の挙動契約は変更なし。UI仕様へカードの構成を同期。アイコンCSSから家のカード幅指定を取り除き、カード側へレイアウト責務を戻した。
