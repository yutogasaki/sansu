# 水玉そのものと、色使いでつくる不思議さ

ユーザーは風景画を求めていない。水玉はシンプルなまま、色使いでファンタジーを表す。細かすぎる黒い点、大きなパステルだけの配色、生成した風景は不採用。動きは加えない。

同じ10個の丸・同じ大きさと配置で、配色だけを3案比較する。A:深い青緑/青紫/少量の琥珀、B:生成り/葡萄/青緑、C:葡萄/珊瑚/青緑。Aをローカル試作の基準にする。カード・見出し・問題・入力・ナビの無地面は保持。背景の変更で学習・保存を変えない。

SVGは円と矩形だけ。生成画像・風景・グラデーション・星・animationを足さない。比較は同じ実アプリの設定画面、phone390×844・tablet768×1024で行う。子どもの独立観察は未実施。以前の速度未達を今回の色変更で解消したとはしない。
