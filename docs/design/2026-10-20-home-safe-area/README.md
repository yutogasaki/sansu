# 島の拡張ボタンと下段操作の重なり

2026-10-20。利用者のiPhone画像で「ひろげられるよ」の下端が「おく／もちもの／メニュー」に隠れる問題を確認した。

## 原因と変更

下段の操作列は`safe-area-inset-bottom`で上がる一方、拡張ボタンの位置は下から94pxに固定されていた。390×844、下端余白34pxの明示シミュレーションでは、修正前の操作列の上端680.609pxに対して拡張ボタン下端686pxで、約5.391px重なった。実機での余白値そのものは未計測。

両方が同じ下端余白を参照するようにした。吹き出しと受取案内も同じ位置基準にそろえる。360px以下では縦並びになる操作列の実高さを考慮した余白を取る。横長画面の左右配置、機能、価格、購入条件は維持する。仕様44の既存の操作配置を修復する変更で、製品規則や保存契約の更新は不要。
