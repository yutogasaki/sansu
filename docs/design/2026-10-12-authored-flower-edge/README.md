# 花庭の枝先と、席を包む縁

制作候補 `native05-authored-flower-garden-v3`（先行粗形v2を下記へ保存）。全島M1の制作途中で、包括ゴールは[島構築方針](../../product/island-construction-strategy.md)を維持する。[採用native-05](../2026-10-10-island-final-3d/README.md)と[前候補の実画面](../2026-10-11-authored-flower-garden/contact-sheet.html)から、露出した三叉端と花庭の外にあるベンチの関係を直す。

## 制作契約

- 転写するもの：原本の広葉、枝の曲がりと実接合点、太株と一輪の比例、花の下と縁に暮らす空間。
- 転写しないもの：所有の追加、所有物の自動移動、離れた席へ引き伸ばす枝、全景の不足を補う背景花。
- 同じ32所有物・8軒の保存済み合成入力を使う。新取得・本人保存・32軒拡張の証拠にはしない。
- 体験：「隣の花が育つ → 枝先に葉が広がる → 近くの席が庭の縁に包まれる」。現在のP05条件・所有・時計・住人・実床と利用先を保持する。

三叉の実終点へ原本の広葉を接合する。現在の同じplaceのseat use targetに、原本の上枝が届くときだけ剛体回転・移動で伸ばす。冠を引き伸ばさず、株の位置も変えない。移動予告と確定は同じ生成処理を読み、収納や分離で枝がなくなる。新しい葉と枝も実triangleによる通行・座位・退出検査へ含める。

## 先行粗形c5を比較して変更すること

[実画面2枚](c5-shape/report.json)と[固定core](c5-core/report.json)はPASS。原本14部品の再抽出も一致した。しかし実席上の葉は外側を向き、休む場所を包む面がまだ弱い。内部の暫定美術評価は36/60 HOLDで、露出した株上端も残る。これは制作前進の記録で、全画面旅程や全島美術の受入ではない。

v3では枝終端の葉を座面側へ向け、枝の途中と終端の葉が重なる面を作った。株の上端も同じ原本葉の実接合で覆う。平面投影で実座面の中心が葉の内側に入り、実住人が座る・退出する高さをfocused検査した。原本の比例、所有の位置、実床、主花を保持する。

株の切り口と小さな庇は改善したが、長い支えと薄い葉の面、庭に包まれる構図は未達。二回の粗形比較を受け、葉の枚数を足すだけの反復を止める。[次工程](next-production.md)ではP04の低い殻・実入口・内庭を一緒に扱う。原本の殻を低く置くだけの3候補は、家とあそびばへの経路を切るため数値調査で不採用とした。見た目だけの接地や頭上余白を、暮らせる場所の成立に読み替えない。
