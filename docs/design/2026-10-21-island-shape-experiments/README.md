## 実装前の実験契約

完成した島の取得方式を決めるのではなく、盛る・掘る・植えるの操作列を再生して3つの形を作る。再生後も自由編集・Undo/Redoが使える。中断と「再生前の形へ」を用意し、この試作で作っていた地形を復元できる。通常保存・学習・取得権・住人・PWAへの接続は行わない。

| 実験 | 変える形 | 確かめる景色 |
| --- | --- | --- |
| 入り江 | 深く切り込む水際と、湾を抱く低地 | 水際の樹形・葦・睡蓮が湾の内外を描き分けるか |
| 段の庭 | 平地から段を重ねた高台 | 低木と高木の差、石段と見晴らしが奥行きを生むか |
| 小島の森 | 細い水路で分かれた、小さな森 | 木のまとまりから木陰の場が生まれ、小島が行き先に見えるか |

各形は同じ初期島と家1軒から始め、土の正味増分12段・樹木10本へそろえる。これらは実験の比較条件であり、本体の上限や解放条件ではない。地面に埋もれる苗を初期状態に置かず、全案の樹木を乾いた支持地点に保つ。

さらに同じ形で「環境の反応あり／なし」を切り替える。木の地点・土地の高さ・カメラ・光を保持し、樹形と派生する景色だけを変える。計6条件を実画面で比較する。

## 試す規則

- 水際は垂れる枝葉、標高3以上は背の高い針葉形、それ以外は広い樹冠。同じ種の場所による違いという実験上の仮説。
- 内側の水際と植物から小さな水庭。近接する高台から石段と見晴らし。低い土地の4本以上のまとまりから木陰の場。固定座標ではなく地形・樹木の関係から導く。
- 派生する場は試作用の景色で、購入物や住人の利用実績として数えない。所有を増やしたとの表示をしない。本体の成立条件の採用ではない。
- 土・水・葉の短い音を本人の操作で試聴できる。初期off。聴感の評価は機能検査と分ける。

## 試して分かったこと

実画面からの作者評価であり、児童の理解・好み・再訪を実測した結果ではない。

| 観察 | 次へ残す方向 | まだ足りないところ |
| --- | --- | --- |
| 段の庭は高低差と樹形の差が最も読み取りやすい | 盛る→高台の木と、空いた場所の見晴らし | 建物・水の流れ・住人の実利用 |
| 森は木の中心へ場を置くと隠れた。空いた手前へ置くと行き先が見える | 木の集まり＋空き地、同じ陸の関係で場を作る | 道・橋・住人の経路 |
| 入り江の奥に水庭が見えるが、全体では水面が樹冠に隠れやすい | 地形に応じた植生と、全体／場所の見方 | 岸と水面の余白、外海への接続の読み取り |
| 環境色を強めた案は緑に寄り、元の紫のまとまりが弱く見えた | 紫を残して樹形を変える。葦・睡蓮・高台の木の局所色 | 素材の作り込み、より固有な樹形 |

水庭は内側へ切り込む陸水関係と近くの植物、高台は空いた高い支持地と低い隣接地、木陰は同じ陸の4本以上の集まりと空き地を必要とする。場所の固定座標や実験IDで成立させない。小島の森は編集で本島と接続でき、戻すと分離する。

最初の試作で水没していた苗を含め、初期樹木の2地点を今回の共通初期状態で調整した。3案はこの同じ状態から比較しており、前の試作と同じ植生位置だとは扱わない。
