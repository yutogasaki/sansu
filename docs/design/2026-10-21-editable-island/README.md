## 試作の契約（実装前）

- 同じ小さな地形を盛る・掘る。入り江、丘、離れ小島、再接続を本人の操作で作る。完成島のプリセット選択で操作を代替しない。
- 高さと水位から陸・水際・斜面を描く。植物は同じ地点の地面へ追従し、水没中は表示を休む。Undoで地形と植物・水鳥を一緒に復元する。
- 家と玄関前の小さな床は固定し、その範囲へ作用する編集は理由を示して止める。住人の実歩行・経路探索の試作ではない。
- 編集した地点の近くに陸水の境界ができたら水鳥を表示。音がなくても姿と短い文で結果を把握できる。音は初期off、本人の有効化後だけ短い操作音。常時BGMや外部素材を加えない。
- 道具は盛る／掘る／植える／ながめる。タップで編集、ながめるで回転、ピンチで拡大。キーボードは矢印で地点移動、Enter/Spaceで編集、Ctrl/Cmd+ZでUndo。Redoも持つ。
- メモリ内だけで動かし、IndexedDB・localStorage・本体の保存・学習・取得・routing・service workerに接続しない。再読み込みで試作だけ初期化。通常配布へ組み込まない。
- 試作候補ID：`editable-island-study-v1`。配布：`standalone-study-only`。本体の目標美術を達成したとは扱わない。
