# 親が日付・問題数・回答時刻を確認する記録

期間合計だけでは取り組みの実態が分からないという利用者の指摘を反映。愛着のための量の表示に加え、保護者がいつ何問取り組んだか確認できることを目的にする。理解度の認定や学習の強制には使わない。

- 記録の先頭に7日/30日の日付別一覧を常時表示。0問の日も日付とともに表示する。
- 各日の正答+誤答を回答問題数に数え、算数・英単語を分ける。スキップは別記し、期間合計と日別で同じ定義にする。スキップだけの日を回答日数へ含めない。
- 日付を開くと、実際の月日・時刻、科目、正答/誤答/スキップを新しい順に確認できる。朝4時区切りで前日の学習日に属する深夜の記録も、実際の月日と時刻を示す。
- 解き直しは回答として別に数える。問題の種類数や習得数ではない。別保存の英語基礎は含まない旨を明示する。記録時刻を学習時間と読み替えない。
- 既存の進級・学習・設定の操作は日別一覧の後に保持する。保存形式・既存ログ・SRS・所有・報酬は変更しない。

正本は[親仕様](../../product/01_app_spec.md)と[画面仕様06](../../product/06_screen_specs.md)。前の[期間合計の実装](../2026-10-24-stats-activity/README.md)は制作履歴であり、今回の表示定義へ上書きしない。
