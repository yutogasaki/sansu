## 移すもの・移さないもの

| 移す | 移さない |
|---|---|
| 相棒・問題・キーの近さ、問題カードの縁への接地 | 原型より広い余白、独立した大きな説明帯 |
| 生成りの方眼、白いカード、濃紺の輪郭、青と桃の焦点 | 古いベージュの問題トレー、細かい文字の積み重ね |
| 3列の `789 / 456 / 123 / ⌫0C`、筆算の大きな数字 | デモの固定問題や正解、デモの入力待ち時間 |
| 通常の吹き出しと、節目で相棒を横へ寄せる大きい連続数 | キャラの差し替え、常時のピーク、他作者の音源 |

## 実装

- candidate `pokomoko-pop-live-v6`。通常のIsland学習が対象。幅480px以内の縦の構図を基本に、短い横画面だけ問題とキーを隣接させる。舞台は実フローでカード直上に置き、足の着地点を同じ縁へ合わせる。
- 共通TenKeyにIslandだけが使う3列レイアウトを追加。小数点・欄移動・手動確認/保存リトライは必要時の追加行。Studyの4列配置は維持する。
- ヘッダーの音ボタンが従来の効果音だけを解錠し、学習BGMの別AudioContextへ操作を伝えていなかった。本人のクリック内で両方を開始し、設定保存失敗・ミュート・背景化・退出は取り消す。追加の数字入力なしでBGMを開始する。音量は変更していない。
- 既存モデル、着替え、数字運び、連続/光/スタンプ、3/6/9問の伴奏、通常学習の入力・採点・保存を保持する。
