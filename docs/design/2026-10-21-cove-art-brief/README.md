## アストラに求める判断

目的は、細部を足し続ける前に、目標へ届く制作方法と、一角の見える到達点を決めること。画像・動画と上記の条件を必ず読んだうえで、以下を具体化してほしい。

1. 先入観なしの所見：最も大きい差を、構図／造形／素材／照明／動きの各領域で特定する。物の少なさだけで説明しない。
2. **原本kitを再利用する案を最優先で検査する。** 今の試作の粗形を延々修正するより、既存の家・樹木meshと材質を移す方がよいか。編集地形・尺度・支持床・入口に合わせる際に失う魅力と、追加制作が必要な箇所は何か。
3. 再利用で足りない部分を限定する。コード造形の改良／Blenderでの造形とkitへの追加／両者の併用を比較し、推奨を一つ選ぶ。新しい全島生成器や大量の完成島を前提にしない。
4. 次の一角を、家1軒・木6本の範囲で配置と尺度まで設計する。主景・中景・水面の空き・ぽこもこの見える経路を具体化し、単に小物を増やさない。
5. 入り江の2〜3通りの編集後でも成立するか。地形へ追従する部位、固定してよい美術、支持や経路を失うため止める操作を分ける。毎回同じ決め絵へ自動整列しない。
6. 操作は何を磨くか。土の変形・海面の露出・波紋・視線・重心から、最初に必要な最少の演技を選ぶ。静止画で判断できない点は動画か追加撮影の要求へ分ける。
7. 続行／作り方の変更の判断基準を定める。390と768の全景・近景で見える条件を列挙し、合格まで「もう少し細部を足す」を繰り返さない。

回答は「推奨する制作方法 → 使う既存資産と変更箇所 → 一角の構成 → 操作の流れ → 受入条件 → 残る不明点」。肯定だけ、根拠のない採点、最新画像を見ていないままの美術合格を避ける。

## 現時点の仮説（独立所見の後に照合）

| 領域 | 現画面で気になること | 次に確かめたいこと |
| --- | --- | --- |
| 全体のまとまり | 新木だけ細かく、5本の丸い木と箱の家が粗い。空地が広く、水と暮らしのつながりが薄い | 原本kitの家と樹木を同じ尺度で使った一角の全景 |
| 木の量感 | 個々の葉がばらけ、枝が透けすぎる。水面は抜けるが、木陰や樹冠の厚みが乏しい | 葉を枝ごとのまとまりにし、抜けと量感を両立する造形 |
| 岸と素材 | 地面が角張り、草・土・岩の境目が弱い。幹・葉・地面の素材差も薄い | 丸い岸の断面、接地、局所の材質を少数の素材で成立させる方法 |
| 水と光 | 一枚の海面が露出する仕組みで、水際や奥行きの情報が少ない | 正しい岸の形に沿った水際表現。流体計算や派手な発光を必須にしない |
| 動き | 歩行と接地はあるが、足踏み・身体の向き・のぞく姿勢は単純 | 動画から判断できる弱点と、追加すべき最少の姿勢／演技 |

## 維持条件と止めどころ

ぽこもこの顔・頭身・耳・パッチワーク・色・既存の着替えは維持。本体の学習・価格・時計・所有・保存・routing・PWAは今回は変更しない。未所有の家や人物を増やして密度を演出しない。橋や回廊は実床・入口・通れる経路と一致させる。子どもの配置を理想の構図へ勝手に動かさない。

次の制作判断は「木・岸・家・水面・ぽこもこがそろった一角を、全景でも近景でも触りたい景色にできるか」。美術、操作整合、子どもの無説明理解・再訪は別判定。一角で美術の改善を示せなければ、物量や機能を拡張せず、造形・素材・光・構図または制作方法へ戻る。
