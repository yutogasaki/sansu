# 島を眺めたまま使う住人パネル

2026-09-12。前案の「島を隠す面積・小さな顔・説明量」をユーザーが改訂指示。ローカル実装、公開はしていない。

## 変更

初期表示は3住人の大きな上半身と名前、選択した住人の現在の行動・好み。住人の選択は情報だけを切り替え、移動命令は出さない。最初と再オープン時はぽこもこ。選択は下線とaria-pressedで示す。

育ちと通貨の説明は一つの折りたたみにまとめた。閉じる操作は本文スクロールの外に残す。日次目標・報酬・保存処理は変更なし。画像は既存の実モデルを上半身でフレーミングし、キャッシュと一時WebGLコンテキストの解放を維持。

## 検証

固定production `http://127.0.0.1:5359`、artifact `/tmp/sansu-compact-residents-final-v2-20260912`。島・暮らす島flagを有効化した共有未コミット作業ツリーのビルド。HEADだけを検証済みコミットとは扱わない。

`tools/e2e-island-life-resources.mjs` で実初回設定、3住人の切替、パネルの360px以下の高さ（縦画面）、説明の折りたたみ・展開、閉じる操作、実3問の学習、報酬、保存と再読込を確認する。5桁表示はDOMだけの文字幅診断。tabletはreduced motion。
