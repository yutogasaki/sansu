# 実27／32／35入力の水庭合成比較

固定c2とc3の[比較](comparison.json)で、世界定義・水庭計画・全siteの床／anchor照会・元の全歩行辺の支持結果が3入力すべて完全一致した。各入力は1本の橋を含み、復元した辺IDも一致。元のstateとbase definitionは不変。これは合成したworldの限定診断であり、実renderer・全島編集・本人保存・性能の合格ではない。

35所有物の旧候補は最初の2回、外側harnessの2 GiB／2.5 GiB上限で停止した。アプリ例外はなく、両方の失敗と未取得の出力をそのまま保存した。同じbundle／fixtureで35の前後だけを4 GiB上限へ分けて実行した3回目は通過。途中で制限を変更していない。最初の27／32結果は再実行せず保持。並行作業と重なるため、時間やRSSから製品速度の改善を主張しない。

[原byte保存証明](archive-proof.json)は準備・全試行・初回の未実行draft履歴を含む。プログラム名だけ.txtを付け、内容は保存前後で一致。元の全source dataをここへ複製したものではなく、原入力pathとSHA、compiled bundleとmetafileを保持する。
