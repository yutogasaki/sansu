# 花庭を、一輪を支える場所へ作り直す

現在の続きは[枝先と席を包む縁・v3](../2026-10-12-authored-flower-edge/README.md)。以下はv1の制作と評価の履歴。後続の枝葉や現候補の合格として読み替えない。

制作候補 `native05-authored-flower-garden-v1`。包括ゴールは[島構築方針](../../product/island-construction-strategy.md)が正本。現在はM1の全島一例の制作で、花庭一部分の改修を全島の完成として扱わない。[採用原本と全12実画面の比較](contact-sheet.html)・[美術の評価](art-review.md)・[三ゲート](gate-review.json)・[次の構図](next-production.md)を同じ資料へ残す。

## 造形を変える根拠

[採用native05全景](../2026-10-10-island-final-3d/whole-island-render.png)と[前回の実全景](../2026-10-11-authored-whole-preflight/runtime/mature-32-whole-day.png)を比較した。前回は直列4株から作る5接続pairに同じ主花冠を一組ずつ置き、細い緑の棒で支えていた。主花の面と太い株の関係が失われた。

| 取り入れる | 取り入れない |
| --- | --- |
| 一輪の丸い主花冠、太い木質の株、曲がる接合枝、根と幅のある葉 | 原本の未所有5株や花庭モジュールの背景配置 |
| 原本の素材と `.45` の比例、株から冠へ続く接合 | 直列の長さへ花冠を引き伸ばすこと、色違いの冠を等間隔で増やすこと |
| 元の花の色・成長・選択と、実床の下草 | 花を消費する合算、新しいfloorや配置権利、説明文だけによる成立 |

体験は「隣へ花を置く → 同じ株が育つ → 枝がつながる → 一輪の大きな花が開く → その下の席で休む」。P05の条件・自然時間・利用記録は変更しない。若い白花l31と成熟後を同じ32所有物で比較する。l16はP03へ保持する。

## 抽出と実装の境界

原本GLBを変更せず、幹1・根4・ridge3・冠へ届くstem1・接合bough1・補助branch3・leaf1の計14partsのみを抽出する。[profile](native-flower-support-profile.json)に原本SHA、source名、実接合座標、材質、頂点数と配布SHAを保存する。主花冠15meshは既存owned kitの一組を使う。若い株・個々のcolor/growth/owner IDは保持する。

固定入力は前回の実UI取得診断で保存したyoung/matureの32所有物・8軒。DEVで `?water=wide&reference=preflight32` または `preflight32-young` を明示して読む。今回の新取得・本人保存・32軒拡張の証拠ではない。元の27所有物の既定fixtureは変更しない。

## 通行も同時に確認する

従来のflowerは通行可能で、株中心のquarter walk pointも含まれている。太い株を描いたまま、この点を住人へ渡すと幹と重なる。元のfloor・配置権利・walk grantを残し、実際の描画株と `.45` の実住人の寸法を使って、現在のground上で避ける経路を検査する。入口と全所有物の接近・席への到達が残らない候補はHOLD。移動・収納・分離では占有を更新し、利用中の住人を実床の空いた場所へ退避する。

作者の見た目、美術の独立した理解と安全、runtimeの技術確認は別の判断として残す。性能、本人保存、offline/更新、実機と独立した利用者観察の未達を、source一致や自動検査のPASSで埋めない。

## 実通行と利用の確認範囲

歩行判定は原本の indexed geometry、衣服・耳・帽子・尾・足を読み、歩く足と腕の連続した角度範囲、接地による上下補正、実際の `.01575` のbobを含む。足元へ頭の最大幅を一律に適用した初回候補は、実32所有物のうち7接近を切り離した。部位別の高さと幅を使う現在の候補では、原本native baseの全32接近と全採用辺を保つ。実水庭を合成したworldの確認は最終browser記録へ分ける。

利用と退出の最終姿勢も実株triangleに照合する。衝突した新しい利用姿勢は記録を発行せず、既存の到達可能な実床へ同じ住人を戻す。到達点が空の場合は失敗として計測し、次のframeで勝手に再表示しない。範囲が復旧すると同じActorを戻す。元の床・配置地点・grantを増やしたり削ったりしない。

実rigによるfocused検査は、4株の中心からの放す/取消、普通の歩行からl27の実座面で休む利用と退出、利用中の分離/収納/再接続、ベンチの収納、株の復帰で占有される旧groundの退避を扱う。単なる個数増加を利用へ読み替えず、実際に見せた動作から同じrevisionの記録を作る。これは明示した合成入力による機構と安全の検査で、本人保存と独立児童観察ではない。

## 美術の残件と次の順番

一輪の主花と太株・曲がる枝へ作り直した粗形は、P05の完成ではない。接続群の三叉の終端が露出し、葉が薄いため、仮組みの支柱に見える。l27のベンチは主花の外側にあり、『花の下で暮らす』空間が未成立。分離すると残る接続群に株が残り、孤立l31は元の低い成熟花へ戻るため、単独成熟と接続群の造形の連続性もM2の残件である。

次は、現在のowner位置と実use対象を保持して、**主花・4株・葉の量塊・暮らす場所の関係を全景で決める**。花冠を列へ引き伸ばしたり、所有物を自動整列して補わない。利用場所と共有形の関係が成立しない並べ方には別の接続形を設計し、一輪の完成模型へ全配置を誘導しない。枝終端と葉の量を決めてからP04の内側と入り江、森の面、大樹の実内床とgalleryへ進む。全島一例の美術を通してから三配置・拡張へ進むという包括ゴールの順番を維持する。
