## 転用するもの／しないもの

| 転用する具体的な構造 | 持ち込まないもの |
| --- | --- |
| 白い問題面、濃紺の輪郭、短く硬い影、青・桃・黄・ミントの色面 | 茶色い陰影、全パーツの立体ベベル |
| 大きい見出し数字と安定した問題・キー | 小さいラベルの増設、問題面を覆う常時演出 |
| 押した数字がキー→前足→答えへ届く因果 | 答えと関係なく発生する光の線 |
| 3連続で旗が残り、4で次の節目を予告、5で構図と音を切り替える | 参考のキャラクター、コピー、音源の試作側への流用 |
| 複数の短い接触音と、段階的な伴奏の追加 | 参考の最終盤と同じ密度、誤答の強い否定音 |

動作の一文は「ぽこもこが押した数字を受け取り、答えへ置く」。受け取る→置く→跳ねるの三変化を同じ場所に置く。元モデル由来の8ポーズを使い、顔、耳、配色、パッチワーク、足を保持。絵コンテに生成された時計・吹き出し・別解釈のキャラは実描画に採用していない。

## 元動画の短い動作を観察した範囲

[元投稿](https://x.com/grmchn4ai/status/2103807453406388538) は **2026-09-26 20:22 JST**。x-readで投稿とメディアを取得。今回の比較抜粋は元動画10.5–22.5秒、入力観察は2.2–3.6秒。全Xユーザーや他作品についての調査ではない。

入力付近を10fpsの連続フレームで観察した。以下は約±50msの視覚的な読み取りであり、実装の正確なイベント時刻や耳で測った音の時刻ではない。

| 元動画の時刻 | 見えること |
| --- | --- |
| 約2.4秒 | 入力位置が変わる |
| 約2.5–2.6秒 | 手が2のキーへ届き、数字が移動 |
| 約2.7–2.8秒 | 数字が解答へ届く |
| 約2.9–3.1秒 | 次の6を運び、解答が完成 |
| 約3.2–3.3秒 | 身体が反動をつけ、跳躍と効果へつながる |

試作はキー押下0ms、受け取り220ms、保持50ms、到着470ms。正解時は到着から80msのため、520msの跳躍、160msの着地、余韻を分けた。5連続では上部の色面と大きい5、正解和音を同じイベントで起こす。問題とキーの位置は固定する。

公開ソースは [grmchn/dopa-drill](https://github.com/grmchn/dopa-drill/tree/0720ddfe37334628bab61ba5b3a9282bd6bfb31c) の `0720ddf…` を調査。作者の[公開告知](https://x.com/grmchn4ai/status/2104140595111608639)は2026-09-27 18:26 JST。元動画より後なので、ソースと動画を同一版とは断定しない。詳細は[先行する分解資料](../2026-09-28-dopa-reference-breakdown/README.md)を参照。

## 音の試作

独自の短い旋律、低音、キック、ノイズ系の拍、和音をWeb Audioで合成。112→116→120 BPMで層を追加する。キー・受取・配置・正解・跳躍・着地・5連続の音を分けた。背景の小さい星の拍は音楽と同じ拍時刻配列から描画する。手入力モードは効果音の確認用で、12秒BGMは流さない。

技術測定は試作WAVの最大振幅 **−2.25 dBFS**、RMS **−27.75 dBFS**、クリップしたサンプル **0**、48kHz stereo、12.00秒。参考抜粋のRMSは約−13.1dBなので、比較ページでは参考側を0.18倍（約−14.9dB）にする。これは平均振幅を近づける調整であり、知覚ラウドネスや音色の同等性を保証しない。元の参考ファイルは変更していない。

**エージェントの音声入力が利用できないため、聴感評価は未実施。** 再生可能な音を作り、波形・出力・動画への格納を検証した範囲。音楽としての楽しさ、耳疲れ、スピーカーごとの聞こえ方を合格としない。

## 独立した評価

| ゲート | 結果と限界 |
| --- | --- |
| 見た目・演技 | 実描画4場面で配色、全数字キー、足、問題面、節目の変化を確認。初稿の5連続ジャンプがHUDへ重なったため、跳躍高と大きさを修正。参考同等の演技には未到達。8枚のポーズ切替では連続した手の伸びや表情の芝居が弱い |
| 無説明理解・子どもの楽しさ | 未評価。独立した子ども／観察者のテストなし。意図を書いた説明を理解評価の代用にしない |
| 試作の動作 | ブラウザーで描画・手入力の誤答→訂正→正解→次問、動画／WAV／4場面の出力を確認。アプリ本体の検証とは別 |

今回の成果は、形容詞だけの方向案から、実際に見比べられる音付きの候補へ進めたこと。参考との差を消した、完璧になった、製品として合格したとは判断しない。特に次の判断材料は「手の連続した演技を制作する価値がある配色・構図・音の方向か」。
