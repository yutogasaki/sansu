## 1. 一案に決める

5タブを残し、島の常設は「島名としずく」「ながめ」「おく」「メニュー」にする。独立した「もちもの」、目標カード、大きな拡張カードを外す。「しまに おく」の2面へ購入と収納をまとめる。メニューはカテゴリを押してから項目を探す構造にせず、見出しの下に直接項目を置く。

「きろく・設定」を島メニューへ重複追加しない。家のアルバム・模様替え・手紙・学習設定も引っ越させない。下部タブと家の既存入口を使う。3タブ化は別の改訂候補とし、今回は実装候補から外す。

土地端タップは現コードで確認できない新操作なので、今回の必須案には含めない。ひろげるの確実な入口はメニュー先頭。目標の選択有無に関係なく使える。

## 2. 通常の島

| 位置 | 表示と操作 | 詳細 |
|---|---|---|
| 左上 | 島名・しずく | 一行の短い帯。島名のタップで既存の名前変更。残高は情報表示。島名は省略可能、全文は名前面で読める |
| 右上 | 絵＋ながめ | 48px以上。開いた時だけカメラ操作。拡張や購入を入れない |
| 下部ナビの上・左 | 絵＋おく | 主操作。押すと「あたらしく おく／もちもの」。常設の大きな3等分カード列は廃止 |
| 下部ナビの上・右 | …＋メニュー | 48px以上。押すと下記の一枚の紙。閉じたらこのボタンへfocus |
| 最下部 | しま／いえ／まなぶ／きろく／設定 | 既存5タブ、既存URL、現在地の印。まなぶは1操作で既存開始/再開へ |
| 実景 | 家・住人・物・旗・橋 | 現在の直接操作を保持。住人の運搬、カメラの移動やピンチをタップ扱いしない |

入口の絵は既存の玩具アイコン/実模型。白い紙と既存の淡桃・淡紫・青。本文16px、補助14px、基本操作48px、最低44px。小さくするのは装飾・余白で、文字とhit領域は縮めない。

目標は常設大カードをやめる。選択直後は場所名と短いヒントを一件表示し、閉じるで消せる。同じ目標を毎回自動再表示しない。既存の実達成・初回案内は既存の契機で一件だけ出す。閉じても目標を解除せず、「メニュー→そだつ場所」で常時確認・変更できる。新しい通知保存・毎日起動の催促・点滅は足さない。

## 3. メニューの完成候補

論理的な表示順は下記で固定。海図は現行の初回非表示条件に従い、表示しない時は空欄を残さず後続を詰める。「そのほか」だけ開閉する。見出しは読むだけで、新しいカテゴリ選択の階層は作らない。

```text
しまのメニュー     [既存の音ボタン]     とじる ×

しまを そだてる
  [場所の絵] そだつ場所              ＞
              いま：〈選んだ場所名〉／未選択なら「どんな場所に しよう？」
  [土地の絵] しまを ひろげる          ＞
              〈必要しずく〉／条件未達なら「島Lv〈必要値〉から」
  [実住人]   なかまに あう            ＞
              〈実人数〉にん
  [ふね]     海図と ふね              ＞ （現行の表示条件に従う）
              じぶんの島を めぐる

つくる・のこす                  （2列、項目は直接押せる）
  [旗] はたを つくる       [写真] しゃしん・みせる
  [橋] はしを つくる/みる  [花]   はなずかん

  [本] あそびかた                    ＞

そのほか：〈いまの本人名〉              ∨
  いま あそぶ人：〈本人名〉   きりかえ
  しまの なまえを かえる
  〈既存の成長案内：現在の一時表示がある場合のみ〉
```

4行は最小52px、絵40px、主文16px、補助14px、余白8〜12px。補助文は必要時に折り返す。2列の項目は最低64px、長文や200%文字では1列へ。全件を初期画面へ押し込まない。末尾が隠れる間だけ見出し直下に「下にも つづく ↓」、末尾へ達したら消す。音は**親menuの固定headerだけ**に一つ置き、通常詳細には複製しない。再生中の音offは島からmenu→音ボタンの2操作。200%ではheaderを2行にしても文字と操作を保持し、本文の上へ固定する。音の設定値と実再生readyを同一扱いしない。

portraitは幅 `min(360px, viewport幅−24px)`、高さは島描画領域の60%以下、ナビの上。headerは48px以上で固定。320×568では先頭数行からscrollして全項目へ到達する。568×320等の低い横画面は右寄せ、幅 `min(340px, viewport幅−150px)`、上下8pxを確保。200%文字やソフトキーボードで成立しなければ、文字付き退出と本文到達を優先してほぼ全画面の面へ切り替える。裏の島は見えても操作を受けない。

## 6. 対象を触った後だけ見せる操作

| 対象 | 維持する操作 | menuとの分担 |
|---|---|---|
| ぽこもこの家 | 入室・家内の既存操作 | 下部「いえ」も同じ行き先。家のmenu全体は移設しない |
| 仲間の家/苗 | うごかす、条件に応じたしまう/取消、成熟屋根色 | 入居済みの家を収納する等、禁止操作を新設しない |
| 住人 | 詳細、おでかけ/帰島、解放済みの服/帽子、許可された名前変更 | なかま一覧が文字付き代替。本人モデルidentityを変えない |
| 花/木/水/遊具 | 既存のさわる・あそぶ・ここですごす、うごかす、しまう、花摘み等 | 「全操作」をmenu先頭へ並べない。演奏台の異なる2操作は保持 |
| 旗 | 色・解放済みの模様 | 文字なぞりN10と混同させない |
| 橋 | 見る・しまう | N13は未建築時もたどれる代替 |
| 学習の記念品 | 説明、うごかす、しまう | 収納後はD01もちものへ。資格や所有を取り消さない |

文字付きで選ぶ代替として、N08は住人、D01もちものは収納品、D03は育つ場所、D06の既存近道は主要な実物を扱う。`えから えらぶ` は `IslandDirectActions.tsx` に残るが、現Growingから利用している接続は確認できなかった。現行の配置済み全小物・旗を選ぶ代替の代用にはしない。

この候補では**新しい補助入口「しまに あるもの」**をD01の2タブ直下、商品本文の上へ文字リンクとして置く。長い商品一覧の末尾へ隠さず、menu先頭の項目も増やさない。開くと「配置済み」の実画像・名前を一覧にし、同種多数は実位置/地区等の既存情報で区別。家・plots・landmarks・記念品・旗・実橋を扱い、住人は既存なかま一覧に任せる。全件取得/全件一斉編集/購入はしない。選ぶと一覧を一時非表示にし、同じ対象IDの既存sheetへ。対象sheetを閉じると同じ本人/島の補助一覧の元の位置へ。家への入室や配置確定は明示した行き先へ進み、一覧を強制再表示しない。収納成功後に一覧へ戻る場合は対象を除いて近い項目へfocusする。一覧の「←もどる」はD01の同じtab/分類/scroll。未配置・他人・別島の物や存在しない橋を捏造せず、表示後に対象が消えたら現在一覧を再照合して安全に戻す。新実装はこの到達手段と既存の対象選択へのadapterだけに限定する。

## 7. 戻り・学習・focus

1. メニューは島の上の一面。閉じる/Escape→元の島の画角とmenuボタン。外側tapは閉じるだけで、裏の対象tapに貫通しない。
2. menuから開く通常の詳細はmenuを置き換え、退出はheaderの「← もどる」一つ。押す/Escapeで同じmenuのscroll/項目focus。島へは戻る→menuのとじる。通常詳細に異なる行き先の×を重ねない。家の本など集中画面からの「とじる」はその開始元へ戻す。
3. D08→D09見せるは「おわる」、D10カード/D11あゆみは「とじる」→D08。D12の見学先一覧は「← もどる」→D08。見学に入った後の「かえる」は**見学開始時の本人の現役島の通常ホーム**へ戻し、D08を自動再表示しない。見学reloadも既存の本人島復旧を優先。現行の帰島は維持し、見せる/カード/あゆみのD08復帰だけ新しい親面復帰として明記する。
4. 「おく」は島から直接なので、閉じる→島。仮置き取消は同じcatalog位置、移動取消は同じ対象sheet、配置成功は島の配置物へ。
5. 家の本・実物・一時案内から同じ詳細を開いた時は、その開始元へ戻す。いつでもmenuへ強制帰還しない。入れ子ごとにURLを追加せず、ブラウザーBack/直接URLは既存43の意味を優先。
6. 通常の閲覧面では5タブを残し、まなぶから既存開始/予約を開く。閉じると同じ本人・島の**閲覧開始元**とscrollへ。未確定配置・改名入力・撮影・見学・島移動を学習の裏で維持する契約には広げない。これら集中状態は現行のタブ非表示/開始ロックを守る。
7. focusのownerを1か所にする。復帰先は本人/島一致＋DOM接続＋可視＋有効を検査。消失時は同面の見出し、面が消えていたら島のmenuボタン。本人/島切替・reloadに他人のscroll/入力を持ち越さない。
8. menuのscroll・そのほかの開閉・catalog位置は同一起動中のUI状態だけ。学習ログ・島正本へ新しい永続フィールドを追加しない。

一時panelの画面内退出/Escapeと、ブラウザーBackは別に検査する。URLを変えないpanelのために架空の履歴をpushせず、Back/Forwardは既存43のroute遷移を通す。直接URLの履歴がなければ既存の既定画面へ。本人/島が変わった場合は旧panel復元より現在の正本を優先する。

## 8. 状態の優先順位

- 読込/描画復旧、実保存失敗は既存の復旧操作を優先。世界準備前に対象操作を使わせない。
- 受取/初回/出来事は既存条件で一件。編集中、menu、閲覧面へ吹き出しを重ねない。閉じたら保留中の正しい一件へ。
- menuを開く、一覧を読む、戻るだけでは購入・招待・目標・時刻・写真・学習を保存しない。目標選択/音/改名/旗確定は変更操作として既存writerへ。
- 保存中は変更・本人/島切替を既存境界で守る。閲覧の開閉を一律禁止しない。閉じたことを保存取消や成功とみなさない。海図出発等の既存ロックを緩める改修は今回に混ぜない。
- 保存失敗は対象・入力を保持し、既存の同要求の安全な再試行。結果不明を失敗と断定し、新しい要求を乱発しない。PWA保存holdはUI閉鎖でも解除しない。
- offlineでも端末内の既存menu/島/図鑑を使う。画像downloadや描画失敗の扱いを別にし、ネット接続必須の新機能を追加しない。
