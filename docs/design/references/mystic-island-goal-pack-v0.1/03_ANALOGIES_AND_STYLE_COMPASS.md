# アナロジーとスタイル・コンパス

AI が判断に迷ったときのための、方向づけ用アナロジー集です。

## 1. このゲームは何に近いか
### 近いもの
- **Royal Match の長期蓄積**  
  1セットの成功が、大きな世界の進展へつながる。
- **Animal Crossing の愛着**  
  自分の場所、置く、動かす、住民が使う。
- **ドールハウス / ジオラマ**  
  眺めたくなる、触りたくなる、少しずつ整っていく。
- **観葉植物 / 暖炉 / アクアリウム**  
  世話をすると、静かに応えてくれる存在。

### 遠いもの
- 大規模RTS / 街づくりシミュレーション
- パズドラ型の攻略ゲーム
- マイクラ型の自由工作サンドボックス
- スタミナ制ソシャゲ
- バトルRPG

## 2. アートのアナロジー
### 理想に近い
- Animal Crossing 程度の読みやすさ
- 任天堂系の、整理されたやさしい形
- ミニチュアの島ジオラマ
- やわらかな stylized 3D

### 近づけたい質感
- clean
- readable
- game-ready
- soft but not painterly
- charming but not over-decorated

### 避けたい質感
- 厚塗りイラスト
- 画家風ブラシ
- 過剰なボケやシネマティック演出
- スマホゲームの高級広告っぽい作り込み
- 1枚絵としては美しいが、ゲームとしては読みにくい構図

## 3. 島のアナロジー
この島は、

- 「街づくりボード」ではなく、**息をしている生きたジオラマ**
- 「家を建てる作業」ではなく、**少しずつ暮らしが宿る場所**
- 「メーターの容器」ではなく、**進捗そのものを見せる表現体**

と考えてください。

## 4. ひかりのアナロジー
「ひかり」は、

- 電力ゲージのような硬いリソースではない
- 魔力ポイントのような数値管理対象でもない
- **世界に元気が戻ることの見える化**

です。

言い換えると、

- 花に水をやる感じ
- 暖炉に火が戻る感じ
- 朝になって街が動き出す感じ

に近いです。

## 5. 報酬のアナロジー
報酬は、

- 「+100 コイン」より、**新しい子を迎える**感じ
- 「アイテム一覧」より、**島に小さな暮らしが増える**感じ
- 「レベルアップ報酬」より、**景色の変化**

を優先してください。
