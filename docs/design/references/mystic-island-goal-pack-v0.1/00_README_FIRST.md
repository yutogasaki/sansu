# 不思議な島 学習ゲーム — AI向け Goal 指示パック v0.1

このフォルダは、AIエージェントにそのまま渡しても方向を誤りにくいように作った、**自己完結型の指示パック**です。

## まず読む順番
1. `01_GOAL_FOR_AI.md`  
   - そのまま AI に渡せる主指示書です。
2. `02_WORLD_AND_GAME_REFRAME.md`  
   - 何を作るかを、ゲーム全体として再整理した説明です。
3. `03_ANALOGIES_AND_STYLE_COMPASS.md`  
   - どういう方向に寄せ、何を避けるかのアナロジー集です。
4. `04_IMPLEMENTATION_PLAYBOOK.md`  
   - Blender headless を使う場合 / 使わない場合の実装方針です。
5. `05_AI_FREEDOM_AND_DECISION_RULES.md`  
   - 仕様がまだ甘い箇所に対して、AI が自律的に補完してよい範囲です。
6. `06_REFERENCE_IMAGES_NOTES.md`  
   - 同梱画像の役割説明です。

## このパックの意図
- **学習そのものを複雑なパズル化しない**
- **問題を解いた瞬間の気持ちよさ**と、**島が育つ長期の楽しさ**をつなぐ
- **Animal Crossing ほどの親しみやすく読みやすい3D**を目指す
- ただし完全コピーではなく、**少し不思議なファンタジー島**として独自化する
- **Royal Match 的な蓄積の強さ**は借りるが、見た目や世界観は借りない

## 一番大事な北極星
このゲームは、

> 「算数や英語の問題をゲーム化すること」

よりも、

> **「学ぶことで不思議な島に生命が戻り、自分の島が少しずつ育っていく体験」**

を作ることが目的です。

## 同梱画像について
`images/` の画像は、**方向確認用のムードボード**です。  
どれも「雰囲気の一部」は良いですが、まだ**描き込みが強く、イラスト寄り**です。  
最終ターゲットは、これらよりも **もっとクリーンで、ゲーム内で動かしやすい、どうぶつの森程度の読みやすい3D** です。

## 重要
AI はこのパックを読んだうえで、必要に応じて細部を補って構いません。  
ただし、補うときは必ず次の問いに答えられるようにしてください。

1. 幼児〜小3の子が、何を見て「やりたい」と思うのか
2. 問題を解いた直後に、何が起きると気持ちいいのか
3. なぜもう一度やるのか
4. 何が蓄積されると、自分のものとして愛着が湧くのか
