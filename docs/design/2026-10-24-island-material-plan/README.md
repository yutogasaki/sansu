# 島の素材マップと制作作戦

2026-10-24 JST / 計画案 v1。くふう・にぎわい・ふしぎ・愛着を維持する。柱を削る変更なし。

[画像付き資料を開く](index.html)。画像はHTML内にも埋め込み、ローカルで表示できる。全24画像の原本は images/ に保存。

## 判断

既存戦略を維持し、全島の地形・場所・暮らしを同じ世界として制作する。小物の量産を先行しない。既存native-05を造形の基準、10/24のv15を限定試作の現在地として区別する。新規runtimeの美術採用・機能・配布は今回決めない。

推奨は「既存原本＋共有する地形と接続＋参考から自作する生活小物」。配布モデル・image-to-3Dは、背面・UV・軽量化・接触修正を含む総負担で比較してから選ぶ。

## 優先順位

### P0｜全島と共通の土台

対象：M01–06＋M19/M22。原本と試作の差を、同じ尺度の全景と三つの場所で整理。共有床・保存境界を設計し、既存モデルで全島粗形を作る。

次へ進む条件：岸・上面・坂・水と入口が一致し、配置変更で旧床や所有が壊れない。全景の改善が見えなければ小物へ進まない。

### P1｜同じ島で場所を作る

対象：M07–13。森・水庭・入り江・小さな集落を同じ全景へ。粗形が揃い次第、同所有の列／塊／中庭を作る。

次へ進む条件：配置と成熟から形と暮らしが変わる。元の個体・入口・時計を保持し、分離・再接続で戻せる。

### P2｜暮らしを読めるようにする

対象：M14–17/M20。器・収穫物・かご・箱を必要な場面へ。荷車・井戸の新規機能は仕様判断後。

次へ進む条件：実在庫・経路・利用と見た目が一致し、既存品と一緒に動かせる。

### P3｜拡張と仕上げ

対象：M18/M21＋M02。全島の成立後、16／32軒とその先を比較。灯り・反応・生き物・記念品を整える。

次へ進む条件：中心が残り、地区の輪郭と役割が増える。人口固定上限や見せかけの群衆を使わない。

### 横断｜受入・通常製品への接続

対象：全系統。美術／無説明理解・安全／runtimeを別判定。本人保存・通常取得・学習往復・offline・更新復旧を対象版で確認。

次へ進む条件：未測定の実機・児童の再訪・公開を自動検証のPASSから推定しない。

## 次の一手
