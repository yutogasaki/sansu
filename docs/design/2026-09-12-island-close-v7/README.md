# 暮らしを近くで見る島 v7

ユーザーの「実装」指示に基づき、[レビュー](../2026-09-12-island-ux-direction.md)の最初の一周を実装した。採用契約は[仕様48](../../product/48_island_life_spec.md)。本番への公開・pushは行っていない。

[実画面の一覧](contact-sheet.html)で同じ最終Cの一周を確認できる。

## 変更

- 通常の画角を約1.32倍に寄せ、家・住人・花への接触を大きく見せる。「ながめ」から「しま全体をみる／くらしをみる」を切り替えられる。配置への出入りは手動ズームとパンをリセットし、配置中は全景を使う。メニュー開閉だけでは画角を変えない。
- 島から「つくる」を直接開く。商品は島と共有したモデルを静止画像へ描画する。購入時の花は芽。見本用WebGLは描画直後に解放し、継続描画しない。商品名・価格・不足数は文字でも残す。
- 歩き始めと到着の加減速、角での短い旋回、足と身体の重心移動、花へ顔を近づける動きを追加。セル間の経路と到着時計、座席接触、既存の反応時計を維持する。reduced motionでは追加の揺れを止める。
- 発見通知の折返しと下部操作の重なりを調整。配置のマス一覧が既存のoverflowに隠れて押せなかったため、パネル内に配置して実クリックできるようにした。

素材の継承：家の屋根色、ぽこもこのパッチワーク、住人のidentity、所有物の形・育ち・足元を継承。海の大きな余白、商品を小さな線アイコンだけで表すこと、歩行の急な旋回は継承しない。地形そのものの作り直し、新しい家具や経済調整は含まない。

## 検証と版

固定production targetは `http://127.0.0.1:5325`、配信flagsはIsland/Lifeともtrue、DEV=false。DOMの `data-life-candidate` は `island-life-close-v7`。[artifact.json](artifact.json)に固定ビルドのversionと全ファイルhashを保存する。共有dirty checkoutのためHEADだけでこの変更を識別しない。version.json内の旧島candidateは新島のDOM candidateの代用にしない。

- [core](core.txt)：lint、typecheck、3,651テスト（348ファイル）、build/assets合格。その後の変更は通知/配置CSSと配置開始時のカメラリセット。最後のTS変更後も対象lint・typecheck・固定production buildを通した。
- [smoke](smoke.txt)：全体実行中にHMRと重なった旧探索tabletの1件がtimeout。[該当経路の再検査](smoke-root-retry.txt)は390×844、768×1024、1024×768、1024×1366、1080×1920の5サイズで合格。原因をアプリの回帰と断定しない。
- [PWA](pwa.txt)：classicの更新/保護/復帰4件合格。新島の実SW offlineは別のproduction検証で確認する。
- [最初の配置失敗](first-placement-failure.txt)：マス選択の「つぎのマス」がcanvasに遮られた記録。[修正後B](previous-b-report.json)は両幅の実3問→6しずく→花購入→住人反応→保存→実SW offlineを通過。B以後、手動拡大から配置へ入る際のカメラリセットを追加し、[最終C](report.json)も両幅で合格。手動ズーム後の配置時zoom=1、マス選択の実クリック、画像の実デコード、住人の反応、reload、SW offline回答・再起動を確認した。

QAは既存 `tools/e2e-island-life-production.mjs` を基に、現在の折り畳み住人パネルを開く手順、直接つくると実物画像の確認、手動ズーム後の配置リセットを追加した。元ハーネスや学習のfixtureは置換していない。実参加者・学習効果の証拠ではない。

## 別々の判定

- 視覚：商品と家・住人は大きく読み取れるようになった。初版の局所改善であり、島全体の最終アート合格やベンチマーク同等は認定しない。
- 無説明理解・安全：子どもN=0、HOLD。実装者による理解を観察結果に数えない。
- Runtime：記録した限定経路を検証。正式80runのthroughput、旧島全経路、新旧島をまたぐ全release matrix、実機iOSは今回未実施。完全なリリース合格とはしない。
- 連続性：新しい島→学習→島→購入→反応→再開を対象とする。家の中・写真・設定までの全アプリ監査ではない。
