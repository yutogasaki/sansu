### 作品の核

共同案の中心は、**「自分で育てた不思議な場所の中に、ぽこもこと一緒に入り、遊び、仲間と暮らしながら、自分だけの世界を広げていく」**。

「物が大きくなる」だけでなく、その配置が歩ける場所・遊べる場所・誰かの居場所を生む。ぽこもこは子どもの作品を一緒に体験する相棒になる。操作は、置く・動かす・つなぐ・連れていく・触る/使うという少数の行為を共通にし、場所ごとの専用ミニゲームや隠しレシピを増やすことで深さを作らない。

深さを作る因果は、配置 → 実際の水/日陰/到達 → 成長した空間 → ぽこもことの遊び・実住人の利用 → 次に作りたい景色、という循環。これを全島で見えるようにする。[既存の全島制作方針](../../product/island-construction-strategy.md)の、同じ所有素材から異なる3つの島を作る要求を再確認した。

### 3つの育て方と質的な成長

最初に職業やコースを選ばせる仕様ではない。好きな配置から方向性が生まれ、混ぜても一方向に留まってもよい。以下の空間・行為は次期候補を含み、全て現行で利用可能という意味ではない。

| 育て方 | 小さな場所を作る | 育った場所の中で遊ぶ | 地区をつなぎ、島を育てる |
|---|---|---|---|
| 森 | 木の列・かたまり・囲みと空き地で、日陰や抜け道を作る | 日陰を歩く・休む。将来候補は幹の中や樹上へ入れる場所 | 森の回廊が泉・家・別の庭をつなぐ。配置し直すと通り方や居場所が変わる |
| 仲間の集落 | 家・届く食料・迎え入れる条件を整え、実住人が暮らす | 家の周りや共同庭で、ぽこもこと座る・遊ぶ・一緒に過ごす | 家を寄せて共同の場を作る、離して複数の生活拠点を作る。実際の往来でつながる |
| 水と花の庭 | 水をつなぎ、花の並びや広場を作る | 水辺を歩く・花を見る・休む。将来候補は花のアーチや包まれる空間 | 泉・花庭・森・集落がつながり、島の場所ごとに違う景色と過ごし方が生まれる |

同じ森でも、木を寄せると囲まれた居場所、間隔を空けると通り抜ける道、水辺へ寄せると岸の休憩所になる構想。家が近ければ住人の生活経路にもなる。あらゆる2品に専用合体を割り当てる方式にはしない。大きな共同形は、子どもの配置を塞いだり元の所有物を消したりしてはならない。

### 時間・学習・拡張・別島をつなぐ全体マップ

| 要素 | 子どもの選択と得られる体験 | 次につながる意味 |
|---|---|---|
| 数分の訪問 | 今ある庭でぽこもこと遊ぶ、動かして違いを試す、暮らしを見る | 成長待ちでも遊びが成立する |
| 今日の構想 | 森にしたい、花を囲みたい、家の前を広場にしたい | 買い物リストではなく、自分の景色を目標にする |
| 学習 | 算数・英語へ自分から出かけ、現在の1問あたり2しずく・2町時間を得る | 作りたいものや進行中の育成へ戻る。島で遊ぶこと自体の許可証にしない |
| 翌日 | 実際に進んだ成長・変化した暮らしを確かめる | 変わらない場合に成長演出を捏造しない。欠席の罰も設けない |
| 1週間程度 | いくつかの場所をつなぎ、以前と違う使われ方に気づく | 単品の成熟から、場所同士の関係へ関心が移る。日数での自動達成を約束しない |
| 長い育成 | 最初の庭を残して、森・集落・水辺を往来する | 新規購入だけでなく、育て直しや再配置にも意味がある |
| 同じ島の土地拡張 | お気に入りの続きに新しい場所を作る | 自分の島の歴史と景色が連続する。面積の増加だけで終わらせない |
| 別島 | 今の島を壊さず、違う構想を試す | 森中心・集落中心・水庭中心等、独立した歴史を育てる。空島の量産や既存島のコピーを目的にしない |

拡張する方向による海岸・地形の違いは、別途世界・床の設計が必要な将来候補。現行の土地取得だけで完成済みとは扱わない。別島の共通財布・学習事実・島別の所有と時間は守り、島間物流や新通貨を暗黙に追加しない。お気に入りの小さな庭に留まる遊び方も成功とする。

### 住人・ふしぎ・置くものの役割

住人には名前・家・好みという現行の土台があるが、お気に入りの場所を繰り返し使い、ぽこもこと過ごした場面が積み重なる体験は次期の設計課題。単なるランダム歩行を「個性ある暮らし」と呼ばない。子どもが配置を変えたら、現在の到達可能性を尊重して行動を変える。思い出の記録と現在の目的地は分ける。ぽこもこの来訪で全員を強制集合させず、自律した暮らしに子どもが参加できることを目指す。

ふしぎは、(1)配置から確かに育つ大きな場所、(2)花の色や実際の使われ方で気づく小さな発見、(3)条件を満たすと可能性が生まれる珍しい来訪、の3層で考える。日々の成長を抽選頼みにせず、珍しい来訪を確定報酬として約束しない。原因を全部目標帳で説明するのでなく、配置と結果の比較で気づけることを目指す。

| 置くもの/資産 | 全体の中で担う役割 | 整理の方針 |
|---|---|---|
| 家・畑・木・花・水 | 生活、自然の成長、場所づくりの基礎 | 基本素材の組み方から異なる島が生まれるようにする |
| ベンチ・遊具・音楽等 | 育った場所で実際に過ごす・遊ぶ手段 | 置いただけの数値加算や次の成長の必須購入に偏らせない |
| 灯り・柵・旗・屋根色・ぽこもこの服等 | 自分らしさ、雰囲気、愛着 | 表現のために選ぶ価値も認める。既存の実効果を削除する採用決定ではない。住人全員の着せ替えが現行にあるとも扱わない |
| 写真・名前・履歴・学習の記念品 | この島で何をしてきたかという記憶 | 進行をリセットして新しさを作らず、元の由来と履歴を守る |
| 土地・海図 | 続きを作る自由、別の構想を作る自由 | 面積や島数だけを目的にしない |
| 交配・条件付き来訪・ふしぎのたね | 発見が次の創作のきっかけになる | 基礎育成を隠しレシピの暗記や低確率待ちへ寄せない |

旧所有品の機能・由来は保持する。役割の近い商品の追加や購入メニューの拡大を主な改善手段にしない。所有ID・花色・由来・土地・住人・学習・写真履歴を保護し、空腹/枯死/退去/不在罰や毎日の義務を加えない。

### 代表する一続きの旅程

最初の花とベンチの庭でぽこもこと過ごす → 自分で森を作りたくなる → 木を並べ、待つ間も今ある場所で遊ぶ → 育った森を歩き、休めるようになる → 水辺や家を配置し、実住人が森を通って暮らす → 一緒に過ごした場所を写真等で残す → 隣の土地へ集落や花庭を広げる → 最初の庭を残したまま、違う場所を巡れる島になる。別島では違う構想を始められる。

これは固定チュートリアル順や実装済みの旅程ではなく、学習・配置・育成・遊び・暮らし・拡張が一つの体験になるかを判断する代表例。水を置くだけで全て瞬時に成長する、最初から満開の花が再び咲く、家が実日数だけで自動成熟するといった、現行の因果に反する説明は使わない。

### 現行から大きく作り直す必要がある3点

1. **所有素材から、実際に入って使える空間が育つこと。** 背景の巨木が主役のままでは自分の木を育てる価値が弱い。二軒の家が条件を満たすだけでも共同庭の魅力は足りない。実際の入口・床・経路・滞在場所と、見える造形を一体にする。地上の木陰・花の中庭・水辺・共同庭から全島を構成し、幹内部・樹上等は別途制作が必要な候補とする。
2. **ぽこもこと、場所全体で遊べること。** 単体ベンチの着座だけでなく、自分の森や庭の中で行為を選べるようにする。カメラを近づけただけでは成立しない。既存の直接操作を土台に、空間・到達・行為を設計する。成長する前の小さな場所にも遊びを持たせる。
3. **住人ごとの過ごし方と、島の記憶が積み重なること。** 人口や歩く数の増加だけで満たさない。お気に入りの居場所、異なる行動、一緒に過ごす場面を世界の実状態に接続する。好感度の世話、毎日の依頼、全行動の記録を義務にはしない。

全島が広がるほど小さな工夫が見えなくなる問題は、全景の違いに加えて、昔の庭へ戻れる経路と場所ごとの体験で評価する。大きな完成形だけを見せて途中を退屈にしない。別島を増やす前に、一つの島の中で構想の違いが成立するかを確認する。

### 次の制作を評価する単位

水の表現一つや単独の遊具だけで全体の完成判定をしない。**同じ所有素材・同じ成熟条件から、「森の回廊」「家と共同庭」「泉と花庭」が主役の、異なる3つの全島を作り、その中でぽこもこと遊べ、実住人の暮らしも変わること**を全体構想の評価単位とする。

色や背景を変えた3枚では足りず、島の輪郭、歩ける空間、遊び方、住人の利用まで差があること。通常の移動・収納・分離・再接続で作り変え、元のIDと履歴を守ること。全島の美術、説明なしの理解、実際の利用と保存、自然な翌日の再訪を別々に判断する。AI同士の合意や自動検査を、子どもが夢中になる証拠にはしない。
