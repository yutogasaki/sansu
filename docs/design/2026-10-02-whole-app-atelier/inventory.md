# 対象の画面と状態

画面単位の棚卸し。全ての無限な保存データや全経済状態を試したという意味ではない。主対象Growing、native回帰、副モードを区別する。実データの生成/注入fixtureはREADMEと各reportへ記載。

| 用途 | 実際に見た画面/状態 | 仕上げ・検証 |
|---|---|---|
| 起動/登録 | 触れる初回島、名前/学年、教科、算数範囲、追加プロフィール | 用紙・大きい選択行。5サイズ、productionの実登録 |
| 島 | 庭、主模型メニュー、折りたたみ操作、回転、種、収納、目印、仲間、見せる、花、なぞる | 実モデルの入口を保持、4サイズ、44px/hit/Escape/保存境界 |
| 本/導き | 初期導入、本、目標/旗の詳細、本人の記念、家の本 | 目的別に読む面。明示表示fixtureとproduction実到達を区別 |
| 家 | 室内とメニュー、飾り、記念、掲示板、写真棚、アルバム/写真拡大、撮影と退出 | 家の既存用紙と実対象。Growing入室/本とnativeの実撮影・履歴・退出 |
| 通常学習 | 正答/誤答/訂正、ヒント/お手本/続行、同じ予約へ戻る、画面回転と下書き | 紙の問題・藍の操作・編集キーの布色。全0〜9/44px/実hit、狭い横画面を修正 |

現行の入口に出さないNature Town、Parkの開発試作、asset lab、引退済みのぴったり等は現行製品の「全画面」の対象へ足さない。既存の専用表現を共通用紙で塗り替えていない。仕様の全保存移行・全家具取得・全語彙の教材校閲は今回のUI変更と別作業。
