人物を欠く source 点を c4 の runtime 点と直接比較し、改善量や悪化量として扱わない。今回の美術的な前進は、中央丘の右寄りに前後の樹冠が入り、左の既存 grove / 上の大樹 / 下の花庭の間に中景の厚みが生まれたこと。全景では 3 木を単独で増やした印象が強く、承認像にある「何本も重なった木陰が家と道を取り囲む」広がりには達していない。

回転像は限界をさらに見せる。新しい肩の面はあるが、手前の既存 grove と後ろの 3 木の間に裸斜面が残り、樹冠が島の骨格として連続しない。右岸の広い余白、平面の直線道、青緑と明緑の段状の材境界が目を止める。小物や草粒を足してこの構造不足を解決したことにはしない。

近景では白樺とspireの幹が実床に繋がり、短い根元が丸い台座として突出していない。柳の太い幹から垂れ葉、水庭への奥行きは保持できた。一方、原spireの低い横枝は細い棒として見え、地面の色境界も形の稜線より強い。この見え方を勝手に原木・床変更で直さず、本体の同じ視点で再確認する。

## 別扱いの証拠

- **source 連続性 / 変換画質：HOLD。** 道の黒い点列は実 c4 に存在しない。171 ray sample が既存 `growing-reachable-paths` へ命中。元 path の同高に逆向きの strip / joint disc が重なり、runtime の polygonOffset は glTF に移らない。淡色PBRは維持される。これを原因候補として [raw](source-path-diagnostic.json) に保存したが、単独修正の対照renderはしていない。肩・根元が黒いという意味ではない。
- **水面・人・照明：source 限界。** ripple 3 line群と住人poseがない。Blender daylight/ocean/cameraはappと同じではない。無人の絵から「安全に理解された」「楽しそうに歩けた」と推定しない。
- **本体の構造 / 操作：この制作では未実施。** source geometry / 接近・支持の独立結果は [別監査](independent-source-audit/README.md)。source検査をpreview/commit、若い姿、収納、本人保存の実行証拠に転用しない。
- **独立児童観察：N=0。** silent comprehension / danger / want-moreは未計測。

次の判定は、この凍結した肩・2材・根元条件を同じ本体frameへ組み込み、全景と回転全景で中景の効果を確認する段階。今回の3木だけを全島完成として採用せず、残る森の面・材境界・道の幾何を別の制作判断として残す。
