# 灯りの届く地面と星の足あとM1

灯りの実利用点から2歩以内の通れる地面を照らし、同じ集合を足あとの判定に使う。複数の灯りの明るさを重ねず、照らされた範囲をまたぐ歩行でも同じ規則で判定する。行き先変更の保存成功後、実際に動いた足の接地点へ星を置く。既存の速度・歩行経路・席予約・キャラ造形/配色/布を変更しない。表示専用の星は地面にとどまり、飛行や移動の加速を加えない。

最初の星から最長6秒、各星は約2秒。最後の2秒は新しい跡を加えず残った跡を消す。停止・範囲外では新しい跡を出さず、同じ行き先への連打で延長しない。別の行き先・編集・学習・退出・非表示・描画喪失で中断。全魔法共通の終了後500msへ水/影もそろえた。reduced motionでは星を移動させず、期限で消す。

灯り・本人・実際の星の1秒可視性を確認して保存。通常の行き先変更はlive、過去の場面から現在の行き先を試す操作はcurrent-context-test、過去の歩行はreplayに分ける。元の表示版/行き先/visit/足位置をhash付きで保持し、現在の配置で過去を書き換えない。新しい行動版や追加報酬はない。
