## 取り入れた指摘

| 指摘 | 仕様案への反映 |
|---|---|
| 年齢ではなく共通の能力IDで到達を持つ | curriculum/assessment。8入口と6系列を分け、学年の上限/自動卒業を設けない |
| 支援なしと、音声/ルビの有無は別 | demandModeと補助条件。聴解の刺激再生は独力可、読字への答え露出は独力読字不可 |

| 教材不足・採点不能を本人の失敗にしない | 保留理由、unscorable、練習/読書/別単元/帰島、支援完了との区別 |

## そのまま採用しなかった提案

- 第1回答は、かな/漢字をまとめ、説明文/文学を別系列に再分類した。前回の6系列を維持し、ジャンルは読解内coverageへ配置するよう補正した。
- 永久的な「安定」判定は置かず、確認済みの履歴と現在の練習提案を分けた。
- 子どもの観察を最終G5まで待つ構成は改め、G1から形式ごとの小さな観察を含めた。聞く/読書/表現の最小活動も後回しの別教科にしない。
- 「翌日」を暦日だけで判定せず、実時間24時間以上・期限後・接触履歴・時計不明を区別した。3件/2family/間隔等は未実証の製品初期値として明示した。
- チャッピーの「仕様化へ進めてよい」という意見を、ユーザーの採用承認や教育的合格へ読み替えていない。
