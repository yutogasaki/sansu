# 遊園地 Blender 素材とアプリ合成

更新: 2026-09-05。作業候補 `park-resin-blender-v1`。配信ID `build-play-v1`。

## 範囲

ユーザー提供のv0.2資料と生成見本Bを基準に、Blender MCPで編集可能な立体を作り、固定カメラの透過素材を既存の遊園地へ組み込む。初期3部品を先に検証し、既存のマット・ベル・ペイントゲートも同じ素材系列で揃えた。リアルタイム3D、学習・保存契約、配信flagの既定値は変更しない。

原本と再書き出し手順: [art/park/README.md](/art/park/README.md)。ユーザー提供資料の原文は `art/park/reference/23-art-brief-v02.md`、`24-image-prompts-v02.md`、`25-blender-handoff-v02.md` に保存。元資料にある段階ごとの承認済みという意味へ読み替えず、今回の続行指示に基づく実装候補として扱う。

## 固定した制作条件

| 項目 | 採用値と理由 |
|---|---|
| 寸法 | 人形1 U、位置間隔1.5 U |
| カメラ | 平行投影、+X側へ25°、俯角15°、ロール0°。素材間で固定 |
| ゲート | 法線−15°、外高1.435 U。足元を開けて地上通過を成立させる |
| 高い跳躍 | 頂点の加算高さ3.2 U。泡外周を含む重なり区間と末端ジャンプを検証 |
| 台座・着地点 | 左端−1.3 U、右端は最終位置+1.55 U。着地点は最終位置+1.25 U |
| 色管理 | AgX / Medium High Contrast、露出0、RGBA straight alpha |
| 尺度 | 書き出し120px/U。3〜6位置で尺度を保ち、長いコースは横スクロールと左右ボタン |
| 元画像 | 生成見本B。顔、色付き樹脂、厚い縁と淡い木を継承。余分な泡や不成立の経路は継承しない |

## 合成と動作

台座、遊具の接地影、遊具の奥側、人形の接地影、泡の奥側、人形、遊具の手前側、泡の手前側を分離する。固定の「人形が常に最前面」ではなく、斜めカメラの奥行きで各レイヤーを整列する。滑り台の厚い手前の縁とゲート前半も遮蔽する。

移動は既存 `simulateCourse` の結果を単位空間へ投影する。人形の姿勢だけをBlender画像で切り替える。トランポリンは踏み切りと着地時に膜が沈む。泡はゲート通過中に付き、跳躍中は保たれ、着地時にはじける。フレーム落ち時も経過時間から現在の状態を求めるため、描画コールバックからイベントを保存しない。

学習中は舞台を描画しない。既存のTenKey、複数欄、筆算、英単語、支援・中断・再開の入力と保存を維持する。

## 検証

`sceneGeometry.test.ts` はカメラの整合、泡を含むゲート越えの全区間、3〜6位置の末端着地、フレーム飛びでの泡の状態、着地点から次の遊具動作への連続性を検査する。`tools/e2e-park-art.mjs` は実画面のB/C比較と6位置の同尺度・横移動・最終着地を撮影する。既存のpark E2Eは初回再演から制作、学習、支援、再開、並べ替え、次制作までを検査する。

見た目、無文字での理解・安全、実装整合は別々に評価する。独立した子ども観察は未実施。公開flagを有効化する根拠にはしない。最終結果は [実画面監査](/docs/design/audits/2026-09-05-park-blender/README.md) に記録する。
