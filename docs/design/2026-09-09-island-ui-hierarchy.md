# 島の機能とUI優先順位の整理

2026-09-09の実装依頼。採用契約は[ナビゲーション仕様](../product/43_island_navigation_spec.md#機能の優先順位2026-09-09採用)。新しい遊びや成長方式の追加ではなく、既存入口の優先順位を整理した。

## 実装

- ホームの育成先サマリーを、メニュー内の閉じた「しまを ととのえる」へ移動。最新の成長案内1件はホームから比較へ進める。
- メニューの先頭は「あそぶ」「みつける」。編集3操作は目的を明記した縦並び。工作/別の遊びは「もっと あそぶ」内。
- 家がある場合、島メニューのアルバム/かざりと記憶を家への入口に統合。家の実写真棚への入口を追加し、写真から元の家へ戻る。
- 家を持たない既存呼び出しの記録入口と、実未受取の贈り物、あそびかたを保持。
- 背景発見保存中は家経由のアルバム閲覧/戻りを許可。展示/撮影/配置などは既存の保存ロックを維持。
- 並行開発中のチャレンジ本体・初回案内・学習入力・3Dを保持。チャレンジ表示の別作業とは所有を分けた。
