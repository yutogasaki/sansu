# Nature Town：暮らしの状態表示

目的：畑を変える→育つ→かごから住人へ渡る→食たくへ届く→共同食で在庫が減る、を同じ世界で追う。

| 引き継ぐ | 引き継がない |
|---|---|
| 現在の格子・川・道の位置、緑の地面と生成りの操作面 | 全面美術の承認という扱い |
| 既存3種の住人肖像と選択ID | 住人の新規造形や瞬間移動による受渡しの偽装 |

| 任意選択と固定カメラ | 毎収穫の通知、強制追尾、学習への割込み |
