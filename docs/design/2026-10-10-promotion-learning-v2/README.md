# 学習を主役にした宣伝サイト v2

対象は宣伝サイト `/promo/`。候補は `promotion-learning-town-v2`。依頼は「今のゲームでサイトを最高に」「島中心すぎるので学習アプリ感を」。ゲームのコード・規則・学習・保存・配信flagは変更しない。

[画面比較](contact-sheet.html)と[ブラウザー確認](browser-checks.json)。サイトの入口は算数・英語と実際の1+1の画面。学習内容→ヒント/復習/記録→材料とまち時間→島の成長→島の遊び→家→保護者FAQの順にする。

## 実画面の由来

[撮影記録・画像hash](source-evidence.json)、[紹介用保存](scene-fixtures.json)。ゲームは main `4db3e1a397bd8905a1bb6698861a0ec994423592` を `git archive` で共有の未コミット美術変更から分離し、Island有効でproduction buildしたもの。ローカルbuildの実versionは記録内の `development-local:1e200bbc-e47b-49af-a6a1-2587b7abafe7`。このversionを公開版のversionと呼ばない。実world候補 `growing-island-v1`、feature true、配信 `snap-root-v1`。今回は既存の描画コードをそのまま使い、以前のローカル美術候補の画像は現ページに混ぜていない。

初期6×5・住人0、小さな村9×5・住人2/家2、育った町18×8・住人16/家8。育った町の家はstage4、屋根色・不思議な模様、木や花の周囲で決まる形を使う。市場・パン屋・噴水・演奏台・お祭り・ブランコ・すべり台・トランポリン・灯台・不思議な種・橋も実装済みのもの。土地・購入・配置は既存のcommands、衝突・到達・定員をassert。成熟・資源・住人は紹介用に明示設定し、学習の獲得履歴は作らない。遊び方の一例であり、固定の最終形・日数・必要回答数を示さない。

写真はローカルChromiumの実frame。全景はゲームの「みせる モード」、近景は実wheel/dragによるカメラ操作。画面端70pxを撮影範囲から外して操作UIを避けた。生成イラスト、追加の施設、人物、装飾や地形を画像へ合成していない。家は同じゲームの通常表示。算数・英語は新規の紹介用プロフィールで生成された実問題。家の壁と棚は未学習の初期状態で、学んで増える模様・記念品の写真とは扱わない。

再撮影は `node tools/capture-promotion-showcase.mjs SOURCE_EXPORT LOOPBACK_URL NEW_OUTPUT_DIRECTORY`。`learning-only`を第5引数にすると算数と英語だけを撮る。利用者の本番や本人のブラウザーは操作しない。

## 検証と評価の区別

320/390/768/1440幅で画像、横溢れ、44px操作、3段階切替、連続切替、キーボード、FAQ、anchors、ゲームCTA、no-JS、reduced motionを確認。宣伝サイトにSW登録・IndexedDB作成なし。[検査CLI](../../../tools/verify-promotion-website.mjs)を実行した。

作者レビュー：学習アプリであることが入口からわかり、島は学ぶ先の楽しみとして見える。以前の同じ家の一列配置より、段階・屋根・施設・用途の差が伝わる。既存のゲームの平坦な地形や建物モデルの品質は、この変更では改善していない。見た目の改善を子どもの魅力・学習意欲の合格へ置き換えない。

参加者による魅力、無説明理解、安全、翌日の自発的利用は **未評価**。runtimeのPASSと別に扱う。[検証記録](verification.md)に必要コマンドと確認したソース境界を記す。
