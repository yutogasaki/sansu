## 修正した点

- 最初に選んだホーム用portraitは足が入っていなかった。ユーザーの指摘を受けて採用を取り消し、足まである全身フレームへ差し替えた。キャラクター自体の描き直しはしていない。
- 現在のレベル横に全身を表示。カード・数字・足が重ならず、全フレームを56×63pxに縮小して表示する。
- 島の下部メニューと同じIslandToyIconを見出しとしあげ入口で再利用。既存SurfacePanel/Button/ProgressBarとpokomoko tokenを使用し、新しい画像・常時アニメーション・報酬を追加しない。
- 単元名は空白で分かれた語をまとめ、「わりざん」などの途中で改行しない。
- 文字を畳んだ構造、保存、昇格条件、テスト導線、学習画面は維持。
