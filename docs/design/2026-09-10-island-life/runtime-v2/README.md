# 置いたものに住人が気づく：活動の試作 v2

通常学習で得た資源を使って置くと、住人が気づき、近づき、好きな場所で喜ぶ。配置と暮らしのつながりを、歩行だけでなく姿勢と短い表情で示すDEV試作。

## 追加したこと

- 新規購入に、好みと距離で「!」または「?」。全員の集合や追加の操作を必須にしない。ぽこもこの指定先を上書きしない。
- 好きなものへの到着で「♪」。うさぎは花のそばで小さく二度跳び、地面へ戻る。着座中の住人は座面を離れない。
- ベンチでは腰を下ろし、ブランコでは座面と身体が一緒に揺れる。横棒と頭・耳の高さを調整。reduced motionでは跳ばず、記号と静止した利用姿勢を残す。
- 配置後は景色へ戻し、画面外で反応が終わることを避ける。花を見る・座る・揺れる表示は到着後だけにする。
- 花や遊具の地区、好みのものの近くのベンチ、ぽこもこの所在が次の利用先に作用。空き席は少なく利用した住人にも回し、固定順による独占を避ける。

反応へのタップ、報酬回収、追加ポイントはない。移設は新規購入の驚きを再発させず、同じぽこもこの行き先を連打しても住人の選び直しを再抽選しない。

## 保存の境界

試作DB `SansuIslandLifePreviewV1` を維持。旧試作は切替前の行動をv1で再現し、以後をv2で動かす。切替前のしずく・ひかり・花の育ち・品物・外観を保持。時計を戻して切替と過去の購入が同じ時刻になった場合も、既存の購入を先に処理する。

新しいベンチ/ブランコは前面の通路と1人分の席を確保する。旧v1の端の家具は従来の隣接経路を保持し、移設・消失を強制しない。通常学習のwriter、独力判定、Due、報酬の量・利用周期は今回変更していない。

## 失敗から直した点

旧メニューを開いたまま背後の成長ボタンを押す手順、折り畳まれた「ほかの あそび」、以前のアルバム/持ち物のラベルを現在の導線へ合わせた。筆算の保存配列順と画面上の入力順も分離した。アプリの採点や保存を検査に合わせて変更していない。

throughputは空欄の複数マス「□□」を数字の残留と混同していた。空白マスだけを許容し、数字の残留は引き続き拒否する。現在の数字自動確定に合わせ、最後の数字から次の入力可能時点までを測る。昔のEnter起点の数値と直接比較しない。

活動検査では、固定順で席を割り当てるとカワウソが一度も使えない問題、短い表情が画面外で消える問題、ブランコの横棒と耳の重なりを発見して修正した。短い表情は購入前から実DOMを観測し、画面内に現れたことを検査する。
