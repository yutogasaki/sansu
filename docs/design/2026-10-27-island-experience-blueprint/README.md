# 島の体験の全体設計（最高の形の提案）

2026-10-27。利用者の「全体像から何が良いか全部整理して最高の体験にしたい。まだ実装しない。島の数とか個性とかふくめて仕様を最高にするのから」に基づく提案。2026-10-27、利用者の「一気に実装して」で、§7はすべて推奨どおり、§9の穴の答えを含めて採用。正本は[島の航路と まなびの節目](../../product/island-journey.md)。

## 0. ひとことで

> **「自分の島」を育てながら、学びの節目ごとに“別世界の島”が一つずつ開き、その島だけの仕掛けで遊び、見つけたものを家の島へ連れて帰る。**

守るもの（[憲法](../../../CONSTITUTION.md)・[仕様52 §0.3](../../product/52_growing_island_game_spec.md)と利用者の方針）：置くと自然に育つ／島で冒険させない（探しに行かせない）／何も減らない・期限なし・ガチャなし・毎日の受け取りなし／学習は本人が選び、正しさは教科が判定する／その子だけの、見せたくなる島。

本が4冊（あそびかた・そだつ場所・はなずかん・きろく）、メニューのボタンが9つあり、**どこを見れば「次の楽しみ」が分かるかが一つに決まっていない**。

### 島の数が「無制限＋6」で、一つひとつの重みが薄い

ふつうの島は無料で何個でも作れ、特別な島が6つある。無制限の島は「自分の島」への愛着を分散させ、特別な島の“開いた！”の価値も下げる。

### 特別な島の個性が「見た目」どまり

地面・海・しるし・固有種で見た目は別世界になったが、**遊びの規則は家の島と同じ**。島ごとの“遊びの仕掛け”がない。

### 節目の間が長い

航路はLv2・5・9・13・17。Lv9から13の間は数か月かかりうる。間をつなぐのは海図の星だけ。

### 開く順番が見えない

地面を変える・海図・旗・橋などの道具が、最初からメニューに全部並ぶ。最初の10分で覚えることが多い。

## 3. 島の数と構成（提案）

| 島 | 数 | 開き方 |
| --- | --- | --- |
| **家の島**（はじまりの島） | 1 | 最初から。ずっと育てる中心 |
| **特別な島** | **6** | 枠0＝しおかぜの小島（最初の住人を迎えた時）、枠1〜5＝学びの節目で1つずつ選ぶ |
| ふつうの島（無料で何個でも） | **新規作成をやめる** | 既に作った島は消さず、そのまま遊べる（既得の権利） |

合計 **7島**。理由：一つひとつの島を「開いた」「育てた」と言える数にする。7つなら海図に全部並び、子どもが自分の世界地図として覚えられる。

- 家の島の土地拡張はこれまで通り（5段階＋地区）。
- 特別な島も土地拡張できるが、**島ごとの仕掛けが完成すると「しるし」が育ちきる**（§4）ので、家の島ほど広げなくても満足できる大きさにする。
- 節目のLvは、実測までは **Lv2・5・9・13・17** のまま。実測で開く間隔が長すぎれば、前半寄り（2・4・7・11・15など）へ調整する（§7の判断事項）。

## 4. 特別な島の個性：見た目＋**その島だけの仕掛け**

どの仕掛けも「置き方を工夫すると、島が応える」形にする。失敗・時間切れ・探しに行くはない。仕掛けを育てきると、島の「しるし」（海の向こうの巨大なもの）が最終形になり、固有種の2種目が来る。

| 島 | 見た目（済） | 仕掛け（新） | 仕掛けの完成形 | 学びとの小さな縁 |
| --- | --- | --- | --- | --- |
| **しおかぜの小島** | 白い砂・浅瀬・巻き貝 | **しお**：本当の時刻で潮が満ち引きし、浜の区画が出たり沈んだりする。引き潮に貝が打ち上がる | 入り江に貝の花を咲かせると、巻き貝が鳴って潮だまりができる | 時刻と時計 |
| **こだまの森** | 濃い緑・大樹 | **こだま**：木を並べた列をさわると、木ごとに音が鳴る。並べ方で短い旋律になり、住人が歌う | 3本以上の林を3つ作ると、大樹が実をつけ、森じゅうで合奏 | 数の並び・リズム |
| **ひかりの入り江** | ミントの地面・ガラスのアーチ | **ひかりの水**：水路の水が光り、流れの長さと分かれ方で色が変わる。滝で色が混ざる | 光の流れが入り江までつながると、アーチが虹色に光る | 長さ・分かれ方 |
| **空の島** | 雲の海・雲の小島 | **かぜ**：風向きが日ごとに変わり、ふうせんばなとわたげが流れる。風車を置くと向きが見える | 雲の小島へ、わたげで橋がかかり、上に花が咲く | 向き（東西南北） |
| **ぜんまい島** | 鋼と真鍮・巨大な歯車・蒸気 | **からくり**：水車（水路）や蒸気（あかり）から歯車をつなぐと、つながった先の機械が動く（時計塔・噴水・ベルトの橋） | 島じゅうの歯車がつながると、時計塔が鳴り、巨大歯車が全部回る | 大きい歯車と小さい歯車の回り方（割合の入口） |
| **星の島** | いつも夜・三日月 | **せいざ**：置いたあかりの並びが、夜空に星座として写る。形によって名前がつく（三角・四角・ひしゃく など） | 星座を5つ作ると、三日月が満月になり、星の海に光の道 | かたち |

- 仕掛けは**その島だけ**で動く。家の島には、固有種と小さな記念（ミニ歯車・風車など）だけを「おみやげ」で持ち帰れる。
- 仕掛けに数字や問題を出さない。学びとの縁は、遊んでいて自然に感じる程度にする。
- 固有種は今の12種を使う（ぜんまい島＝ねじまきそう・ぜんまいどり、空の島＝ふうせんばな・わたげひつじ など）。2種目が来る条件を、上の「仕掛けの完成形」と同じものにそろえる（今は別の条件なので一本化する）。

## 6. 最初の30分と、その後のリズム

**最初の10分**：家を置く → つぼみを開く → 住人を迎える → 「しおかぜの小島への こうろが ひらいたよ」→ 船で行く → 貝の花と出会う → 家の島へ帰る → 「まなぶと、つぎの こうろの ほしが ともるよ」。

**毎日**：島を開く → ひらく（学習の成果）→ 小さな出来事1つ → 置く・育てる・仕掛けを一歩 → 学ぶ（任意）。

**節目と節目の間**：特別な島の仕掛けを育てる（1島で数週間分）、家の島の場所・ふしぎ・ずかんを埋める、星が一つずつ灯る。

**知らせ**：島を開いた時に、優先順で**1つだけ**（航路が開いた＞固有種が来た＞仕掛けが完成＞記念品＞きろく）。残りは「つぎの たのしみ」とずかんに残る。学習中・操作中は出さない。

## 7. 決めてほしいこと

1. **ふつうの島（無料で何個でも）の新規作成をやめ、家の島＋特別な島6つの計7島にするか。**（推奨：やめる。作った島は残す）
2. **特別な島に、島ごとの仕掛け（しお・こだま・ひかりの水・かぜ・からくり・せいざ）を入れるか。**（推奨：入れる。順番は、しお→からくり→せいざ→ほか）
3. **本を「しまの きろく」1冊にまとめ、メニューを6つに減らすか。**（推奨：まとめる）
4. **道具を要る時に増やすか。**（推奨：増やす。既存の子は全部出たまま）
5. **節目のLv**：実測までは2・5・9・13・17のまま。実測後に前半寄りへ変えてよいか。

## 8. 進め方（採用後）

1. 正本へ書き分ける（仕様52・島の航路・保存13・画面44）。
2. 本1冊化と「つぎの たのしみ」→ 航路カード（白い箱で遊び方を確かめる）。
3. 仕掛けは1島ずつ、白い箱（簡単な形）で面白さを確かめてから美術。最初は **ぜんまい島のからくり**（「つなぐと動く」が一番伝わりやすく、メカの個性も一番強い）。
4. 児童観察で、最初の10分・節目の間隔・本の分かりやすさを確かめる。
