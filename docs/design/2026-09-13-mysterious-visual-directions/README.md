## 制作前の比較条件

ユーザーは仕掛けよりもデザイン自体のミステリアスさを求めた。島の通常状態の静止画を3方向で比較し、イベント前後の連続画は今回の対象にしない。

参照は `../2026-09-13-island-discovery-ground/phone-joined.png`（390×844保存済みDEV画面）。同じ家・紫の木・ミント地面・住民と、斜め上からの縦構図を基準にする。UIは除き、風景を比較する。厳密な位置・画素一致は生成後に別確認する。

| 取り入れる要素 | 取り入れない要素 |
|---|---|
| Monument Valleyの重なる奥行き・明るい幻想性 | 不可能な歩行床・作品固有の建築 |
| Botaniculaの有機物の尺度・透ける素材 | 敵性生物・極小で読めない操作対象 |
| Samorost 3の素材差・覗きたくなる空間 | 黒い空の全面適用・作品固有の造形 |
| 既存島の色瓦・布住民・紫の木 | UIの焼き込み・既存画像を本番品質とみなすこと |

出典と既存憲章の検討は[ベンチマーク資料](../2026-09-13-wonder-charter-benchmark.md)。

## 方向

- A `a-canopy-light`: 昼の庭と深い青緑の木陰、透ける葉、琥珀の窓。局所的な光と陰。
- B `b-opal-water`: 乳白色・翡翠色の水、反射、半透明の葉。明るい異質な素材と空気。
- C `c-botanical-architecture`: 巨大な木と巻き込む葉が家を包む。尺度と空間・形の幻想性。

学習入力・速度・保存・delivery flagは変更しない。画像生成はbuilt-in image_genを使用。生成文はprompts.mdへ保存する。

## 生成結果の比較

[4案を横並びで見る](comparison.html)。全画像は853×1844、目標390×844とほぼ同じ縦横比。カメラ・住民の向き・家の細部・背景は完全には固定されていないため、厳密な一変数比較ではなく方向比較とする。

| 案 | 静止画からの判断 | 留意点 |
|---|---|---|
| [A](a-canopy-light.png) | 紫の葉の内側の光と木陰が効く。現在の島との連続性が高い | 空と海が明るく、神秘性より豊かな庭・リゾート感が強い |
| [B](b-opal-water.png) | 葉と水の透明感が夢のような美しさを作る | 空間は見通せるため、ミステリアスさは弱い |
| [C](c-botanical-architecture.png) | 巨大な枝のアーチと前景の葉で、形と尺度から幻想性が出る | 樹冠と前景が大きく、実画面では配置領域と操作の検証が必要 |
| [D](d-twilight-secret.png) | 青緑の薄明、葉の内部光、重なる遠景、琥珀の窓。今回の神秘性は最も強いと判断 | 暗さが増えた。実画面での顔の可読性と、子どもが怖いと感じないかは未検証 |

A〜Cが明るい観光地の印象へ寄ったため、比較の幅を広げるDを追加した。推奨はDを検討の中心にし、Cの形の面白さも参照すること。これは制作側の推奨で、ユーザーによる採用ではない。

Dの光を全画面夜景として固定するか、昼の木陰へ限定するかは次の比較事項。屋根、顔、住民の数は概ね引き継いだが、布の質感が地面にも強く出ており、素材の分離には改善余地がある。すべて生成コンセプトであり、現行rendererによる再現性や全景・配置時の成立は未確認。
