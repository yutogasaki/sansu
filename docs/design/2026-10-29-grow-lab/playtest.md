# そだつ島 試作を、iPhoneで開いて子どもに触ってもらう

[そだつ島 試作の記録](README.md)の続き。試作はMacの上で動く開発用のページなので、本番のアプリには入っていない。ここでは、家のWi-FiでiPhoneから開く方法と、子どもに触ってもらう時に見ることをまとめる。

## iPhoneで開く

1. MacとiPhoneを、同じWi-Fiにつなぐ。
2. Macのターミナルで、次を実行する（止める時は `Ctrl+C`）。

```bash
cd /Users/yutogasaki/Projects/sansu-terrace-ground && npx vite --host 0.0.0.0 --port 5290
```

3. iPhoneのSafariで、次のどれかを開く。`192.168.11.22` は2026-10-30時点のMacのWi-Fiのアドレスで、変わることがある。変わった時は、Macで `ipconfig getifaddr en0` を実行すると分かる。

| 開くページ | 何が見られるか |
|---|---|
| `http://192.168.11.22:5290/prototypes/grow-lab/?start=blank` | 何もない島から作る（ふつうはこれ）。📖まなぶ で育つ |
| `http://192.168.11.22:5290/prototypes/grow-lab/?start=blank&roads=draw` | 子どもが道を引く版。「みち」でなぞった所に道ができる |
| `http://192.168.11.22:5290/prototypes/grow-lab/` | 見本の丘から始まり、時間で育つ |

- 初めて実行した時、Macが「受け入れますか」と聞いてきたら、許可する。
- 実行している間だけ、同じWi-Fiの機器から試作が見える。終わったら `Ctrl+C` で止める。
- ホーム画面に追加すると、全画面で遊べる。

## 子どもに触ってもらう

**人数と時間**：2〜3人、1人10分ほど。道を島が引く版と、子どもが道を引く版を、半分ずつ試す。どちらを先にするかは、子どもごとに入れ替える。

**始め方**：「島を つくってみてね」とだけ言う。操作は教えない（説明しすぎない方針）。困って止まったら、30秒待ってから「どうしたい？」と聞く。

**学習の代わり**：📖まなぶ は、大人が「いま がくしゅう おわったよ」と言って押す。3分ごとに1回くらい。

**見ること**（その場でメモする。顔の写真は撮らない）

| 見ること | 書くこと |
|---|---|
| 最初の1分 | 最初に何をしたか。つむ・けずる・🌱・★・📖・視点を回す、のどれか |
| 止まった所 | どこで、何秒、何をしようとしていたか |
| 「見て！」 | 何を見せたか、いつ言ったか |
| 道 | 島が引く版：道に気づいたか。道を引く版：引けたか、どこへ引いたか |
| 学ぶと育つ | 📖の後に、何が変わったと言ったか |
| 色 | どの色を選んだか、選び直したか |
| 終わった後 | 「どこが すき？」「もっと どうしたい？」の答え |

**決めたいこと**：この結果で、次の2つを決める。

1. 道は、島が引くか、子どもが引くか（[本番へ入れる案](integration.md)の「決めること」）。
2. 学習1回で、どれだけ育つか。今は6歩で、仮に決めた量。
