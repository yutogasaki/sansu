# そだつ島を本番の島へ入れる案

[そだつ島 試作の記録](README.md)の続き。**まだ決定ではなく、案**。[仕様52](../../product/52_growing_island_game_spec.md)は書き換えていない。子どもに触ってもらった結果（[手順](playtest.md)）を見てから、利用者が決める。

## 何を入れて、何を残すか

試作は、本番の島の「地面と町の見え方」を作り直したもの。本番の遊びの規則（たね・住人・船・時計・しずく・保存）は、試作にはほとんど入っていない。なので、**地面と道と町を試作の作りに置き換え、遊びの規則は本番のまま残す**のを基本にする。

| 仕様52の節 | 今の本番 | 案 |
|---|---|---|
| §1.1・1.2・1.5 地形 | 区画ごとの整数の段。崖・階段・断る規則 | なめらかな高さに置き換える。盛った土は1.1の急さまですべる。断らず、島が階段・橋・高床・引っ越しで合わせる。子どもが置いた物のまわりには、陸（砂州）が必ず残る |
| §0.3・§1「道を引く」はない | 島が道を作る | **決めること1**。試作では、島が引く版と子どもが引く版の両方を作った |
| §2 まちの時計 | 学習の完了でだけ進む | そのまま。試作の📖まなぶ は、この時計を進めることに当たる。地形を変えた時の道の引き直しは、時計を待たずにすぐ行う（さわり心地のため） |
| §3 くらしの たね | すむ・たべる・あそぶ・しぜん。周りで形が変わる | そのまま。試作の「子どもの家のたね」は「すむ」に当たる。たねの色選び（4色）は、§1「ぬる」を広げたものとして足す |
| 町の家 | ない（家は全部、子どもが置く） | **決めること2**。試作では、島が道ぞいに家を建てる |
| §4 めじるし | ベンチ・水ばち・あかり等 | そのまま。とうだい等は、住人の行き先になる |
| §7 住人 | 船で来る。好きな物の近くを歩く | そのまま。試作では、住人が道を歩き、自分の家に出入りする。行き先へ通うと、通った道が育つ |
| §3.5 ふしぎの たね | 水玉・色面のふしぎの品 | そのまま。試作の差し色（水玉のドーム、色面の壁、広場の床）と同じ系譜なので、まとめて扱う |

## 決めること

1. **道は、島が引くか、子どもが引くか。** 子どもが引くと「自分の町」になりやすいが、仕様52の「道を一本ずつ引かせない」を変えることになる。港から子どもの家までは島が引くので、どちらでも止まらない。子どもの反応で決める。
2. **町の家は誰の物か。** 案A：町の家は景色とにぎわいで、住人は今どおり「すむ」のたねの家に住む（しこむ一周を残す）。案B：船の子が、空いた町の家に住める（たねを置かなくても来る）。案Aをすすめる。仕様52の §0.1「待っている子のために家を建てる」を守れるため。
3. **土地は、しずくで広げるか、盛れば広がるか。** 試作は盛れば広がる。今の取得の仕組みと所有権をどう引き継ぐかを決める必要がある。

## 進め方

| 段階 | すること | 合格の見方 |
|---|---|---|
| 0 | 子どもに触ってもらい、決めること1〜3を決める | 子どもの様子のメモ |
| 1 | 地面を置き換える（`VITE_ISLAND_SHAPING` の裏）。今の家・持ち物・住人を、新しい地面の上に立たせる。高さの保存と、段からの引き継ぎ | 本人の島で「盛る・けずる → 物が一緒に動く → もどす → 閉じて読み込み直す」を実際に操作して一致する（仕様52 §1.1の合格の見方） |
| 2 | 道と町：道・階段・橋・港、町の家、舗装の色と段階、広場 | 同じ操作で、道が届き、家が建ち、読み込み直しても同じ |
| 3 | 行き来：行き先と人通り。まちの時計で、通った道と町が育つ | 学習1回ごとに、目に見える変化がある |
| 4 | 見た目の仕上げと実機の速さ | 実機で、なぞる間と育つ時に止まらない |

段階1から、本番の保存に触れる。本番の島で遊んでいる子の記録を壊さないよう、段階ごとに切り替えの裏で出し、自分たちで確かめてから広げる。
