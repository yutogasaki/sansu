# 4状態の演技と見出しの復元

2026-09-28。ユーザー再提示の[画像](benchmark.png)を実装基準として、v6で弱くなった表情・前傾・数字の受け渡し・3/5連続の構図を改修する。対象は通常Island学習、candidate `pokomoko-pop-live-v7`。採点・問題生成・保存・入力テンポを変えない。

| 取り込む | 取り込まない |
|---|---|
| 元の顔・布・足とカード上縁の接地 | 別キャラクターや画像内の数字の焼き込み |
| 前かがみと視線、入力値だけを運ぶ桃色の曲線 | 演技のための次問待ち、次の問題への古い数字の着地 |
| 桃色3・青5の白/濃紺の縁取り、笑顔と違うジャンプ | 常時放射・顔を横切る紙吹雪、誤答を責める表情 |
| 白い問題カード・大きい筆算数字・3列のキー | 例示の27+35への問題固定、時間の圧力 |

物語は「押した数字をぽこもこが受け取り、解答へ渡す。正解が続くと跳び、両腕を広げて喜ぶ」。既存3Dモデルのニュートラルの顔は変えず、節目に限って閉じ目の笑顔へ切り替える。3連続は片足と体のひねり、5連続は大きく開いた腕と着地後の笑顔で違いをつける。
