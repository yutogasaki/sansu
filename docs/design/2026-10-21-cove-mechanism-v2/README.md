## 変えた仕組み

初期地表を丸い外周と曲がる入り江から作り、各操作の高さ差を局所的に加える。描画、根元の支持、足元、歩行探索、操作の位置判定は同じ地表を参照する。曲線を画像で重ねる処理ではない。地表の描画分割を増やし、土・斜面・草地の色を連続的に変えた。

木の初期配置は前回から変更したが、家と木の種類・数・尺度は同じ。三つの編集の途中では、ID、描画instance、位置、向き、尺度を保持する。既存モデル由来の根元と高さ別の障害物判定も継続する。

| 累積編集 | 実ブラウザで導出された観察点 x,z |
| --- | --- |
| ① 湾を奥へ掘る | 0, −0.525 |
| ② 小さな岬を作る | 0, 1.4 |
