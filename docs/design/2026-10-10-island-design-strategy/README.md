## 開く・更新する

`index.html`は相対画像とローカルscriptを使う静的ページ。ファイルから直接開ける。HTTPで使う場合はrepo rootで以下を実行し、`http://127.0.0.1:8230/design/2026-10-10-island-design-strategy/`を開く。

```bash
python3 -m http.server 8230 --bind 127.0.0.1 --directory docs
```

参照の正本は`references.json`。追加時に固定ID・全注釈・出典・証拠種別・hashを記入して、同じフォルダで`node build.mjs`を実行する。画像の存在、ID重複、必要項目、hashを検証し、`reference-data.js`を生成する。画像を差し替えたら前のIDを保持したまま上書きせず、新しいIDを追加する。

検討メモはこのページのブラウザoriginのlocalStorageへ保存する。別originや別ブラウザへは自動移動しない。書き出したJSONを候補フォルダへ保存し、決定事項を戦略とレビュー記録に転記する。カードのメモは製品の採用決定を自動変更しない。入力メモをネットワークへ送信しない。
