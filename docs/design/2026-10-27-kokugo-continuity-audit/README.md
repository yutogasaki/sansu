## 境界と訂正

- 英語基礎も従来 `logs` の活動集計とは分かれている。記録の問題は「国語だけの欠落」と一般化せず、集計に含む範囲を画面と仕様で明示する。
- 初回の国語も既に他教科と同じ選択枠にある。classic初回画面は他の教科にも説明が付く。科目ごとに必要な設定手順が違うこと自体は不具合にしない。
- 保存方式や学習評価の別実装は、体験を共通化するために消す必要はない。読字・聴解、初答・支援、後日復習、読書・作品は区別する。作文を正解率へ足さない。
- 音オフと、本人が明示的に押して聞く課題音声の扱いは区別する。背景音の設定に合わせて聴解課題を解けなくするような統一は行わない。
- 上記の順序はCodexの推奨。まず記録の矛盾と科目切替、続いて共通の画面枠・子ども向け文言を扱い、保存集計やレベル表示は別の検証単位で進める。既存の学習記録、予約、下書き、所有、島報酬を保持する。

## 統一後の追補：実画面で確認した残件

以下の4件はその後の依頼で修正した。[追加監査と修正・検証](../2026-10-27-kokugo-continuity-loop/README.md)を参照。下記は修正前の再現記録。

2026-10-27の「ほかにない？」で再確認。追加実装は行わず、同じローカルproductionを390px幅・隔離した合成本人で操作した。児童の実データは用いていない。詳細はローカルの `output/kokugo-followup-audit-20261027/` に保持。

1. **退出を先に直す候補**：同じ本人を2タブで国語に開くと、後のタブに「ほかの画面で学習中」の案内が出る。このとき国語の戻ると教科切替がともにdisabledになることを確認。保存中の保護と、学習権を持たないタブの安全な退出を区別する必要がある。[画面のlocked判定](../../../src/pages/Kokugo.tsx)。
2. **戻り先を先に直す候補**：記録→まなぶ→国語→教科をえらぶ→戻る、で設定一覧へ、さらに戻ると島へ進む。渡している開始元の記録画面へは戻らないことを確認。共通切替が渡す親hrefにはkeyがなく、共有backの履歴分岐では利用されない。[切替](../../../src/components/progress/StudySubjectSwitch.tsx)、[共有ナビゲーション](../../../src/components/island/useIslandNavigation.ts)。
3. **やさしい表示の未対応が残る**：実設定でやさしい表示へ切り替えると、国語の見出し・領域ボタンはひらがなになる。しかし漢字カタログは「1,026字の漢字」「字・ことば・読みでさがす（全学年）」のまま。漢字の詳細記録にも「後日も確認」「異なる例で確認」「前の例の後日復習」が残る。教材の字・本文は維持し、操作と記録の説明を対象にする。[漢字カタログ](../../../src/components/kokugo/KokugoKanjiCatalog.tsx)、[漢字の記録](../../../src/components/kokugo/KokugoKanjiProgress.tsx)。
4. **無関係な設定の混在**：国語選択中でも筆算モードが同じ設定欄に出ることを確認。英語選択時も起きる共有の整理不足で、国語だけの欠陥ではない。「算数の設定」と明示するか、算数を含む場合に表示する候補。[設定](../../../src/pages/Settings.tsx)。

体験の改善候補として、通常の学習にある相棒・回答への反応に対し、国語の問題画面は文字でのフィードバックが中心という差も残る。これは上の操作不具合と区別する。読解の集中を妨げずどこまで共通化するか、実画面・児童の理解で判断し、伴奏や演出を一律に増やさない。
