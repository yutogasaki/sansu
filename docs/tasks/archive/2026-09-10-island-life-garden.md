# 島の庭と海岸を描く

- Review By: 2026-09-17

## Goal

次の継続指示により、既存の暮らしと自由配置が景色から読み取れるDEV視覚試作を進める。地面・海岸・成熟花のまとまりを今回の一目的とする。

## Plan

1. キービジュアルとv4実画面を比較し、継承する特徴を固定。
2. 海・地面・花壇と影を実装。座標、入力、学習、保存は保持。
3. 同じ状態の前後、空の島、成熟と移設、配置と学習への復帰を両幅で比較。coreと該当回帰を検証。

## Docs To Touch

仕様48、runtime-v5の視覚/体験/runtime別判定、検証記録、月次完了記録。

## Verification

更新した描画の接地・配置領域・地区の不変性、正常なshader描画と破棄、phone/tablet reduced motionの実一周を確認。coreと既存島/学習/PWA/throughputは入力版を明示する。視覚は実画面で採点し、子どもN=0と本番移行は別に残す。

## Reference Transfer

方向は既存の初期キービジュアルに固定し、別の世界観の候補は作らない。まずreadyと成熟時の薄い実装で実画面比較し、全画面のアート完成とはしない。

| 対象 | 継承 | 継承しない |
|---|---|---|
| 海岸 | 青い海から明るい浅瀬、砂浜へ連続する奥行き | 単色背景、厚い四角の盤面、波の点滅 |
| 庭 | 草・土・葉の異なる質感、まとまりと余白、接地影 | 全セルを同じ密度で埋める、飾りで通路を隠す |
| 花 | 芽→つぼみ→開花、花が連なると庭になる | 花の消費合成、所有していない花の追加、固定順の成長 |
| 主役 | 家と布のぽこもこ、住人の顔と足場 | 人物の造形変更、飾りのための操作や回収 |

体験の一文：花を置く→育つ→隣の花と庭をつくる→住人がそばで楽しむ。学習をしてつくる選択につながるという仮説で、再訪意欲の実証ではない。

## Result

海・浅瀬・砂浜、接地影、斜め視点、成熟花のつながった土と低い縁を実装。最終core3,481、通常学習からの新島2幅、操作診断2幅、既存島11、PWA4/8+offline、production guard、正式80runがPASS。3回の仮配置取消後もgeometry206/texture5で増加なし。

smoke初回は30PASS/旧Root Tangleの次問待ち1件timeout。同じ1,500ms条件で該当5幅が再検査PASS、原因未確定を保持。最初の描画資源診断は通路をふさぐマスを検査が選び、アプリが正しく無効化。検査側だけを実際に置けるマスへ変更した。
