## 次にすること

最初の実装単位「同じ島の一画で、植物を育て、住人が収穫物を運び、食卓に届ける」と、水ばち・木陰・水路・土の時間変化から鉢への影響はローカル実装済み。更新とオフラインの学習・所有保持は検証済み。次は実機で一周を確認し、供給から住人と土地の増加をつなぐ。

1. 本番相当の更新・オフラインで、鉢→住人のかご→食卓→学習往復と経路不通からの復旧を確認する。
2. 固定地形水源を現行の島へどう置くか決める。現在の水源は所有した水ばちのみ。
3. 供給の継続から来訪・入居・土地拡張をつなぐ。小さな一周だけで全体完了としない。

## 完了条件

- 通常の島から別画風の町へ移動せず、同じ場所・住人・家で遊べる。
- 実際の育成・在庫・配送・共同食・入居・土地拡張がつながる。
- 学習履歴、途中の問題、作品、購入済みの物、住人と土地を保つ。
- スマホとタブレットで配置→変化→学習→再開を確認。無音・動き抑制でも状態が分かる。
- 検証結果を「絵の魅力」「子どもの理解と安全」「動作と保存」に分け、未確認を明記する。

## Verification

変更後の確認：

- 食料の収穫・配送・食事、道の不通、配置変更時の在庫保全、保存境界と再読込、実際の3D住人のかごを自動テストする。
- `npm run verify:core` と島の関連画面テストを実行し、失敗の原因を分けて記録する。
- 実機phone/tablet、学習往復、オフライン更新、絵の魅力、子どもの無説明理解を別々に確認する。未確認を完成率へ加えない。
