## 方針

- 新しいエンジンは島の**今の状態**を保存し、純粋関数で進める。今の `replayLife`（全記録の再生と10以上の切替境界）には積まない。
- 今の島（保存版21）は、切り替える時に一度だけ再生して新しい形へ写す。元の記録は書き換えない。
- 通常の入口は切り替え完了まで今の島のまま。新しい島は専用flagとdev portで作る。
- 各段階で「実装」「自動検証」「画面確認」「本番反映」「子どもの確認」を分けて記録する。

### 開発画面で見つけて直したこと

- 花が通り道をふさぎ、たねが「行けない」まま止まる → 花・畑・野生の草は歩いて通れるようにした。
- 村が4人で止まる／1週で23人に増えすぎる → 次の船の間隔（24＋2×住人の数）と家の人数を調整した。
- 人が増えないとレベルが上がらず、土地がないと人が増えない行き詰まり → 岬をLv5/6で開く。
- 今の島の仕組みが裏で作る空の記録を「引き継ぐ島」と判定し、最初のお試しが出ない → 中身のない記録は新しい島として始める。
- 置く場所を選ぶときに住人や物を触ると選べない → 置く間は、どこを触っても下のマスを選ぶ。
- 船の子を触ると詳細が開く → 船の子を触ると降りる。
