## Goal

**子どもがすぐ学び始められ、初回は短い成功・発見・報酬で仕組みを体験し、慣れたら途切れずに解けて、島へ戻ると住民との暮らし・収集・成長を楽しめる。自分の意思でまた遊び、学習を続けたくなるSansuにする。**

2026-09-08の追加指示で更新。元の「セッションで見えてきた課題を解決していって欲しい」と [体験評価](../../design/audits/2026-09-07-experience-review/README.md) を引き継ぐ。学習の入口や続行が遠くならないこと、初回と通常時に強弱をつけること、Forestと指定されたゲームの楽しさを参考にすることを新しい判断基準とする。

これは更新後の作業目標・受入条件であり、実装済みという記録ではない。アプリの具体的な挙動は親01/島28で先に仕様化する。前回の「約7割」は旧範囲の概算で、この新しい範囲の進捗へそのまま転記しない。

## 更新後の優先順位と完了条件

1. **学習への近さと連続性**: 再訪時はホームから1操作、中断した学習は起動時に復帰できることを保つ。初回の必要設定後に再び学習開始を選ばせる回り道を短縮する。通常学習では3/6問の予約区間をまたいでも、光を送る、報酬を見る、続ける等の必須操作を挟まない。初回の導入は別に測り、任意の遊びや配置を次問の条件にしない。
2. **短く、変化の濃い初回体験**: 長い説明の前に、解く→世界が応える→物や住民との新しい遊びが生まれる、という因果を体験できる。初回には短い間隔で達成と報酬を見せ、通常時は集中を支える静かな反応へ移る。導入の対象・終わり・報酬のタイミング・後回しの方法は実装前に具体化し、3問ごとの強制停止を通常ループへ戻さない。
3. **島へ戻る楽しみと長期の変化**: 自分で触る・置く・組み合わせると、住民や環境が具体的に応える。家具の数を増やすだけで済ませず、住民ごとの役割、新しい使い方、出会い・収集・成長を短い因果として実装・比較する。学習中は保存後の光と小さな成長、戻ったときに受取・配置・発見を楽しむ。既存moon-gardenの世界とのつながりを守る。
4. **学習の質と操作・保存の安全性**: 通常入力、筆算、分数、英語、誤答からの再試行、段階支援、独力再確認を保持する。支援完了や同問訂正を独力初回正答・定着と混同しない。SRS/進級条件を根拠なく変更せず、獲得物と途中の学習を保持する。共有遊び開始時の重さ、未観測の住民反応もこの優先順位で改善する。
5. **実測で閉じる**: 同一候補のphone/tabletで実際の初回・再訪・区間跨ぎ・帰還・再遊びを確認する。自動検査、作者の画面評価、人の観察を分ける。人数を多く揃えることを前提にせず、まず1人の自発的な操作・再遊び・支援なしの別問題・翌日の確認を記録し、欠測は欠測のまま示す。

## 評価と測定

| 軸 | 確認すること |
|---|---|
| 学習への近さ | 初回・再訪・中断復帰の操作数、最初に入力できるまでの時間。任意の寄り道と必須手順を分ける |
| サクサク感・学習阻害 | 問題間と区間境界の入力可能時間、必須の追加操作数、遊び開始の長い処理。通常時の区間跨ぎも0追加操作を受入条件にする |
| 強弱・説明量 | 初回の短い達成と報酬、通常の集中、帰還時の発見。文字を読まずに理解できるかは人の観察で確かめる |
| ゲーム体験・継続性 | 置き方や行動で結果が変わるか、自分から別の方法や再遊びを試すか |
| 世界観・デザイン・住民 | 材質と住民の個性、因果の読み取り、学習から島へ戻る一貫性、初回以降の新しい遊び |
| UI・アクセシビリティ | 主要操作の見つけやすさ、44px以上の操作対象、キーや図のはみ出し、タッチ/キー、音なし、reduced motion |
| 演習・学習 | 既存入力と出題の正しさ、支援の使いやすさ、同問訂正と独力回答の区別、日を空けた別問題での確認 |
| 安心・実装整合 | 中断/再開、保存失敗/再送、プロフィール分離、既存モード、PWA更新/実offline。獲得や学習を失わせない |

正答→入力P95≤650ms、誤答→再入力P95≤550msの既存基準を保持し、通常の区間境界にも計測を追加する。旧固定10問は6問後の継続操作を1回許容していたため、旧PASSを新しい0操作の受入へ転用しない。美術・読み取り、子どもの理解/安全、runtimeは別判定とし、総合点で未達を隠さない。
