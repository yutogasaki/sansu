# Sansu 全体バックログ

更新日: 2026-09-22
次回棚卸し目安: 2026-09-27

## 読み方

Sansuを中心に、関連する実装・美術・学習・保存・公開・制作環境を棚卸しした計画。現在の実行状態は[共有キュー](../../.agents/tasks/TASKS.md)、外部確認待ちは[保留キュー](../../.agents/tasks/BLOCKED.md)。各モードの製品仕様は変更しない。アプリのタスクがidleでも、製品として完了したとは判断しない。

古い進捗率は[3月の履歴](backlog-2026-03-13.md)へ分離した。以下の順番は今回の整理による推奨であり、公開や旧モード廃止の決定ではない。

## タスクの分類

| 分類 | 対象 | このバックログでの扱い |
|---|---|---|
| 現行アプリの仕上げ | Island、家、学習、共通画面、保存・PWA | 現在の家庭内利用と公開候補へ直接つながる。対象版をそろえて優先する |
| 自然と町を育てる | Nature Townから今の島への機能統合 | 今の絵・家・住人を土台に、育成・運搬・入居を取り込む。旧試作の合格を統合後へ流用しない |
| 横断管理 | 島の主要体験、学習と暮らし、全体UX | 個別タスクの索引として使う。同じ残件を複数箇所で実装しない |
| 保留 | 実Safari、実iOS、実読み上げ、参加者回答 | 実装作業で代用せず[保留キュー](../../.agents/tasks/BLOCKED.md)に置く |

[現在のタスク一覧](../../.agents/tasks/TASKS.md)は、この分類で「何の話か／現在地／次の一手」を短く示す。検証番号や長い経緯は各詳細タスクを参照する。

## 重複を増やさないための対応関係

- 「学習と島の楽しさ」「島の主要体験」は横断目的と既存採用項目の索引。個別UI・島の美術・自然の統合の同じ残件を別々に新規起票しない。
- 家の接続試作は比較用として保持する。Nature Townは別作品として仕上げず、今の島へ機能を取り込む。旧S1記録はarchiveへ退避し、既存の島・家の残件は保持する。
- `active/`内のファイルの存在だけでは実行中と判断しない。3月のcore計画は現行との差分を再評価してから再起票、7月のroot観察は文書で停止済み。coverage/workshop/remaining-auditは親タスクの補助資料。
- 最近の読込表示ともちものは実装済みとして扱い、残る配布確認は統合作業へ寄せる。WebKitの写真保存失敗は実Safari確認まで保留キューに置く。
- 他プロジェクトの進行やアプリのサイドバー配置は今回変更しない。

## 後で再評価する候補

単位換算・時間計算・追加読み上げ、学習係数の運用改善は現行仕様/実装を再照合してから起票する。3月の未着手一覧をそのまま現行TODOにしない。クラウド同期はConstitutionのlocal-first境界により現行スコープ外。旧Nature Town S2の作物・渡し船・市場は、基本の統合後に再評価する候補。
